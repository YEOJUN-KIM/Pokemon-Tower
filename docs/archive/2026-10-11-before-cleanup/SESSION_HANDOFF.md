## 확정 구상과 미정 사항

- 6개 도전 룰(기본·메진·다맥·Z·테라·개판)을 기획으로 기록했다. 도전 시작 선택·끝까지 유지·상대 동일 적용 방향. 구현은 아직 없으며 Z는 보류, 개판룰 횟수·기존 저장 이관·룰별 경제는 미정이다. [룰 구상](BATTLE_RULE_MODES.md).

- 테라: 도감 타입 무료 저장·도전 시작 고정, 장착 없이 팀 공용 소모권, 진영별 배틀 1회. 해당 포켓몬의 메가/다이맥스 중첩 금지. 새 도전 1장·상점 에픽900코인·새 상대1장은 시험용 공급안. 재사용형 레전더리는 미구현.
- 메가·다이맥스는 합쳐 진영별 배틀당 1회. 테라는 별도 1회다. Z 사용 제한은 미정.
- 영양제 히든 상점은 후보 제안. 현재는 일반 상점 유지하며 이벤트화하지 않았다.
- 테라의 UI·상대 배정·DB v19는 구현. 공급/가격은 임시이며 기믹 추가 후 경제·난이도 재측정 필요. Z상품은 미정.
- 원작 울음소리는 경로 훅만 있고 파일을 적용하지 않았다. 직접 만든 임시 효과음은 사용자가 일단 유지하기로 했다. 기술 이펙트 적용은 보류 중.
