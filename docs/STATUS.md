1~10층 상대 IV는 0이다. 미진화 상대는 폴리곤2·럭키·미라몽·글라이거·스라크와 레드의 피카츄 예외 외에는 제외한다. 기존 저장은 당시 목표 층과 생성/배틀 규칙을 유지한다.

현재 대표 가격은 소모품300·테라권1,350·메가스톤/다이버섯5,000코인, 첫 10층 정비 영양제2,400이다. 영양제는 입장 층 기준 `1400 + 100×(floor−1)`이며 10층 클리어 정비는 floor=11이다. 확정 저장된 상품은 당시 가격을 유지할 수 있다. [가격 변경 기록](experiments/balance/SHOP_PRICE_DISCOUNT.md), [정비·도구 규칙](gameplay/BATTLE_ITEMS_MAINTENANCE.md).

도감은 포켓몬 센터 PC·DS 메뉴를 참고한 첫 시안을 적용했다. 보관 목록·선택 포켓몬 정보·출발 파티를 구분하며 모바일은 정보창을 축소한다. 타이틀·도감에서 영구 업그레이드 메뉴에 접근한다. 도감 기본 정보는 종족값·육각형 차트·테라 타입·변신 배지를 표시한다. Enter/Z로 포켓몬 선택·설정 메뉴를 열며 도감 메인 Q/E는 제거했다. 배틀 기술칸은 상성 표시를 제공한다. 자세한 조작은 [UI_FLOW](current/UI_FLOW.md).

## 영구 업그레이드

성장 포인트로 리롤 1→2회500P·2→3회1,000P, 이로치 교환권10,000P, 알 뽑기1회200P를 사용한다. 리롤은 즉시 현재 도전에도 적용하며 일반 상점과 기술머신 각각 별도 횟수다. 교환권은 보유 포켓몬 외형을 영구 해금하고 다음 도전부터 적용한다. 알은 현재 배틀 지원612종 중 일반95%·준전설3.5%·전설1%·환상0.5%를 먼저 추첨, 각 등급 내 동일 확률, 개체값 각0~31 균등, 합법 기술1종 추첨이다. 1/10회 사용, 중복 능력치별 최대값 수집, 신규 종·IV 상승·새 기술·이로치 해금만 해당할 때 표시한다. 알 이로치1/1,024, 새 트레이너 포켓몬 이로치1/8,192. 기존 생성된 배틀은 변경하지 않는다. 서버 거래/요청 영수증으로 중복 차감·재추첨을 방지한다. 초기 가격·확률은 추후 균형 조정 가능(이로치10,000P는 사용자 지정).

## 다음 작업과 보류

사용자 결정으로 **기획 기준 정리 → Z기술 → NPC별 기믹/층수 프리셋 → 육성·AI·상대 등급 조정 → 영양제 개선** 순서로 진행한다. 도감 UI·영구 상점·무료 테스트 배포는 앞 단계에서 구현했다. [로드맵](current/ROADMAP.md), [배틀 개선 기준](current/BATTLE_REBALANCE_PLAN.md).

Z기술은 다음 구현 대상으로 전환했으며 아직 제공되지 않는다. 오리지널 NPC·150/200층 확장·온라인 대전은 구상이다. 영구 리롤 확장은 최대3회까지 구매할 수 있다. 로그인과 무료 Docker/Quick Tunnel 테스트 배포는 구현했다. 유료 서버·고정 도메인·PWA·정기 백업은 미설정이다. 외부 자료의 기술·도구 완전 대조와 전체 난이도 검증은 계속 필요하다. 새 컴퓨터 작업은 [컴퓨터 이전 안내](current/COMPUTER_MOVE.md)를 따른다.

알 뽑기는 티켓 구매 단계 없이 1회/10회 버튼으로 바로 진행한다. 보유 티켓 우선 차감, 부족한 횟수만 성장 포인트200P씩 차감하며, 혼합 결제도 하나의 거래로 저장한다. 티켓3장으로10회는3장+1,400P. 포인트 부족 시 티켓도 소비하지 않는다.

최종 검증: 프로덕션 빌드·타입 검사, 저장/구매/뽑기/기존 룰 관련 단위26개, PC·모바일 뽑기·이로치 배틀·타이틀·스프라이트 브라우저8개 통과. 화면: `artifacts/screenshots/permanent-upgrades-final/`, 이로치 GIF: `artifacts/previews/shiny-entry/shiny-entry.gif`.
