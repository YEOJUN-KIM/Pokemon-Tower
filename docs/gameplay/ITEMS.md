# 도구와 상점

현재 Run의 도구·메가스톤·영양제·TM·배틀 소모품·중요 도구·Z크리스탈은 새 Run에 이월되지 않습니다. TM은 획득한 Run 동안 반복 사용하며 수량이 없습니다. 일반 TM 상점의 기존 4개 슬롯은 유지하고 미보유 TM을 추첨합니다. 파티가 배울 수 있는지는 상점 생성이 아니라 실제 사용 시 검사합니다. [저장·사용·30개 항목 보고](../engineering/BAG.md).

공통 배낭은 출전 준비·정비 첫 메뉴·히든상점에서 사용합니다. 지닌 도구는 종류별 한 개이며 장착 중에도 배낭에 소지자 이름과 함께 표시합니다. 다른 멤버에게 장착하면 원 소지자는 자동 해제하고 대상의 이전 도구는 배낭으로 반환합니다. 오거폰 가면 등 모습에 고정된 도구는 자유롭게 변경할 수 없습니다.

다이맥스밴드와 테라스탈오브는 포켓몬이 아닌 트레이너가 보유합니다. 지닌 도구 상점의 전설 등급 상품으로 각각 3,750코인이며, 두 장비를 함께 보유할 수 있습니다. 구매하면 배틀 화면 좌측 상단 포켓몬 명단 옆에 아이콘이 표시됩니다. 포켓몬의 지닌 도구 칸은 사용하지 않습니다.

보유한 장비에 해당하는 변신 버튼만 표시됩니다. 한 마리가 사용하면 같은 배틀에서는 다른 멤버도 해당 기믹을 다시 쓸 수 없고, 다음 배틀에서는 다시 사용할 수 있습니다. 새 도전에는 기본 지급 장비나 테라권이 없습니다. 기존 저장도 실제 장비 구매 기록이 있어야 보유로 인정합니다. 기존 포켓몬의 밴드나 기본 지급 테라권만으로 장비를 지급하지 않습니다. 진행 중인 배틀 기록은 보존하되 구매하지 않은 장비의 버튼과 사용 요청은 차단합니다.

메가스톤 50개와 Z크리스탈 34개는 상점·도구 관리·파티의 지닌 도구 표시에서 각각에 맞는 개별 아이콘을 사용합니다.

공통 가격 설정은 핵심 시스템 도구에 0.75배를 적용합니다. 메가스톤 50종·주홍구슬·쪽빛구슬은 각각 3,750코인, Z크리스탈 카탈로그 34종은 각각 2,250코인입니다. 일반 소비 아이템·일반 지닌 도구·별도 폼 변경 도구 전체에 적용되는 할인은 아닙니다. 히든상점처럼 별도 가격표를 사용하는 상품과 이미 저장된 상품 snapshot은 해당 정의를 따릅니다.

10층 단위 정비에서 지닌 도구·배틀 아이템·기술머신 상점을 이용합니다. 영양제 판매는 제거했으며 Elite 도전자 보상으로 받은 영양제를 공통 배낭에서 사용합니다. 상품과 기믹 도구는 도전 룰·보유 상태에 따라 달라지며, 일반 상점과 기술머신의 무료 리롤은 종류별로 관리합니다. 영양제는 한 포켓몬당 종류와 무관하게 도전 중 총 3개 제한입니다. 배틀 소모품은 화면에 표시된 합법적인 대상에 사용합니다.

영구 상점은 도전 코인과 별개인 성장 포인트를 사용합니다. 알은 별도 페이지이며 이로치 교환권 판매·알 탐색 연구 UI는 종료했습니다. 영구 육성의 능력 포인트는 +1당 8P입니다.

| 상품 | 현재 가격·효과 |
|---|---|
| 다시하기 확장 | 기본 0회. 500/1,000/1,500P로 도전당 1/2/3회, 다음 새 도전부터 적용 |
| 리롤 확장 | 500/1,000P의 두 단계 확장 |
| 출발 지원금 | 800/1,600/2,800P, 새 도전 시작 코인 +150/+300/+450 |
| 알 뽑기 | 1회 200P. 보유 알 티켓이 있으면 먼저 사용 |

통찰로 상대 도구를 공개하는 이벤트는 도구를 획득하거나 삭제하는 이벤트가 아닙니다. 실제 획득과 표시를 구분해 정산합니다.
