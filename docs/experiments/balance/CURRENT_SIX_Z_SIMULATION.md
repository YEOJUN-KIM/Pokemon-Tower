# 현재 규칙 재시뮬레이션 · 2026-10-10

현재 인하 가격, 10층 상점, 종류별 무료 리롤1회, 배틀 도구 직접 사용, 1~10층6Z, 미진화체5종 예외 및 레드 피카츄 규칙으로 재실행했다. 기존 지역별8개씩72코스 × 4시작 상태 = 288등반·8,002실제 엔진 배틀이다. 같은 코스/시드의 재실행이며 독립 표본을 추가한 것은 아니다.

미육성은5층에서34회/72회,10층에서13회/72회 패배했다. 완전 육성 스타터도50층 통과12.5%, 준비된 강팀은30.6%다. 자동 전략 기준100층 완주0회로 여전히 어려운 곡선이다. 기존 초반 개체값도 낮았으므로6Z 변화만으로 큰 완화를 기대하기 어렵다. 미진화체 제거와 네임드 진화체 치환도 함께 반영되어6Z만의 인과 효과를 분리한 실험은 아니다.

검사: 코스72개·각100층, 초기10층2,160마리6Z, 미진화체 예외 준수,288등반의 코인/테라권 비음수 및 정산,10층 상점 간격,리롤 지출0 확인. 게임 코드·가격·난이도는 이번 요청에서 변경하지 않았다.

AI 자동 플레이 결과이며 사람 승률이 아니다. 자동 정비에서 추가 성장 포인트를 쓰는 영구 육성은 미반영이다. 기존 코스에 저장된 메타데이터가 없는 일반 상대 일부는 혼합 샘플로 재구성한 근사 코스다. 상세 변환 조건은 docs/SIX_Z_OPPONENTS.md 및 코스 sixZChange에 기록했다.
