# 현재 게임 상태

기준: 2026-10-18. 현재 실제 구현을 설명한다. 완료 로그·과거 승률·미래 작업 목록은 누적하지 않는다.

대규모 기반 구축과 중간점검은 마친 상태다. 현재는 **콘텐츠 보강과 완성도 검증 단계**이며, 구현되어 있다는 사실과 사람의 장기 플레이에서 충분히 검증됐다는 판단을 구분한다.

## 구현과 검증의 구분

- 자동 회귀 검사는 동작·저장 호환·롤백·반복 요청·일부 PC/모바일 조작을 검증한다. 실제 실행한 범위는 [중간점검 보고](engineering/REFACTORING.md)에 있다. 자동 완료 fixture나 AI 승률을 사람의 100층 Run 검증으로 대신하지 않는다.
- 전체 NPC/룰/이벤트의 난이도·경제·반복 피로, 모든 화면의 일관된 조작, 긴 Run의 재접속/실행기·연출/음향 품질은 실제 사용을 통해 더 확인해야 한다.
- 알 기계 조정은 서버·도메인/API만 있고 선택 UI는 아직 없다. 현재 사용자 화면에서 사용할 수 있는 기능으로 보지 않는다. 범위는 [알 문서](gameplay/EGGS.md)에서 구분한다.
- 기존에 저장된 팀·시드·규칙·보상은 당시 snapshot을 유지한다. 새 생성 기준과 다르다고 즉시 오류로 판단하지 않는다.

남은 핵심 단계는 **콘텐츠 → 밸런스 → UI/UX → 비주얼/연출·사운드 → 장기 플레이 → 최종 QA**다. 세부 순서와 실제 100층 플레이 기준은 [ROADMAP](current/ROADMAP.md)에만 관리한다. 1차 완성 이후 적극적 후보는 Hard Mode와 ML AI이며, 150/200층·온라인 대전·PWA는 현재 계획이 없다.
