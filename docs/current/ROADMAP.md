# 앞으로 할 일

기준: 2026-10-24, beta.5 공개 이후. 현재 구현과 완료 상태는 [STATUS](../STATUS.md), 공개·검증 기록은 [beta.5](../releases/WINDOWS_BETA_5.md)를 따른다. 아래에는 앞으로 할 작업만 둔다.

## 우선순위

### 1. 사운드

- BGM을 교체·확장하고 장면 전환과 반복 재생의 흐름을 다듬는다.
- UI와 배틀 효과음을 보강한다.
- 포켓몬 울음소리 도입을 검토하고 출처·이용 조건 확인 후 연결한다. 현재 울음소리 파일은 등록되어 있지 않다.

### 2. VFX와 연출

- 기술 이펙트의 지원 범위를 넓히고 대표 기술의 타격·HP 변화·음향 순서를 다듬는다.
- 메가진화·다이맥스·테라스탈·Z기술 연출을 보강한다.
- 네임드·보스의 등장과 승부 연출을 개선한다.

### 3. UI / UX

- 현재 화면의 배치와 정보 우선순위를 다듬는다.
- 아이콘·버튼·색상·설명 표현의 일관성을 높인다.
- 키보드·마우스·게임패드 조작 감각과 진행/저장 오류 안내를 개선한다.

### 4. 콘텐츠

- 일반 이벤트의 변형과 보상을 추가한다.
- NPC·Raid·빌런 캠페인·특수 전투를 확장한다.

### 5. 밸런스

- 실제 플레이 피드백으로 난이도·성장·경제를 조정한다.
- 사람의 100층 플레이 결과를 자동 테스트·AI 시뮬레이션 수치와 구별해 평가한다.
- 변경 시 이미 생성된 팀·시드·보상·정책 snapshot과 저장 호환을 유지한다.

## 후순위

- **모바일 최적화:** 폰트·배치·터치 조작 및 실제 기기 검증. 같은 서버 계정의 기기 전환 경험도 개선한다.
- **Hard Mode:** Normal Mode와 별도로 NPC·자원 제한·이벤트·보상을 설계한다. 세부 규칙은 미확정이다.
- **ML AI:** 충분한 플레이·배틀 로그를 확보한 뒤 장기 연구한다. 현 규칙 기반 AI를 바로 대체하지 않는다.

## 현재 계획 없음

- 150층 / 200층 확장
- 온라인 대전
- PWA
- 상시 공개 호스팅 서비스 운영

GitHub Release를 통한 로컬 게임 배포는 이미 제공한다. 상시 호스팅 서비스와는 구분하며, 개인 서버·Docker·임시 터널은 별도 운영 도구로 유지한다.
