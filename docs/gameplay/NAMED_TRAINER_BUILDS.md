# 네임드 대표 포켓몬과 전투 구성

현재 배치(2026-10-10): 새 도전은 9개 지역 테마 중 하나를 추첨한다. 아래 추가 최종전/기믹 후보 논의는 기획 이력이며, 현재40/50층 배치와 후속 범위는 [세대 테마](REGIONAL_THEMES.md)를 기준으로 한다.

최종 갱신2026-10-10. 네임드는 대표 포켓몬 1마리와 후보 엔트리에서 뽑은 파트너 2마리로 등장한다. 선봉은 계속 시드로 섞는다. 두 파트너는 타입 폭·물리/특수·속도/내구·공통 약점을 고려해 가중 추첨한다. 플레이어의 비공개 기술·도구·능력치를 읽어 맞춤 카운터 팀을 구성하지 않는다.

## 현재 적용

- 대표 포켓몬 한 마리를 고정하고 원작 후보에서 두 파트너를 뽑는 방향이다. 현재 성도 테마의 14명은 HGSS 재대결/은빛산 자료로 대조를 완료했다. 1~9세대 테마에 총144개 네임드 배치 샘플을 준비했다. 성도 이외는 원작 참고 타워용 각색이며 원작 기술/도구 대조는 후속이다. [지역별 배치](REGIONAL_THEMES.md).
- 성도 후보는 원작 그대로다. 유빈의 중복 팬텀 두 마리는 서로 다른 종 3마리 출전 규칙에 맞춰 한 종으로 합쳐 5종 후보를 사용한다. 키링키·신뇽을 지원 풀에 추가했다. 대표는 HGSS 기준 호일 핫삼, 류옹 맘모꾸리, 이향 킹드라, 규리 강철톤이다.
- 레드 후보는 피카츄·라프라스·잠만보·이상해꽃·리자몽·거북왕, 목호 후보는 망나뇽·보만다·한카리아스·리자몽·파비코리·갸라도스다.
- 원작 기술·특성·도구를 먼저 사용한다. 스왈로의 근성+화염구슬, 버섯모의 포이즌힐+맹독구슬, 시바 괴력몬의 노가드+폭발펀치 등을 유지한다. 원작 빈 도구 칸은 관장/사천왕에게 그대로 두며, 챔피언급만 어울리는 도구로 보완한다. 같은 팀에서 도구가 겹치면 대표의 원작 도구를 우선하고 다른 멤버에게 적합한 대안을 준다.
- 피카츄는 원작 볼트태클을 유지하며 현재 새 성도 최종전에는 다이맥스밴드를 지닌다. 전기구슬은 기믹 이전 원작 기본 세팅과 과거 저장 배틀에서 사용한다. 생명의구슬이나 임의 방어·종족값 강화는 적용하지 않는다. 전기구슬·화염구슬·맹독구슬·검은진흙·원작 열매 일부는 현재 NPC 전용으로 상점 목록에는 추가하지 않았다.
- 이미 생성된 상대 팀은 변경하지 않는다. 새 배틀의 기술·특성·도구를 함께 저장한다. 선봉은 시드로 섞고 플레이어의 비공개 세팅에 맞춘 카운터 추첨은 하지 않는다.

### 원작에서 바꾼 부분

원작을 전부 최신 강공격 기술로 덮어쓰지 않는다. 기본 레벨은 타워 공통 50을 유지한다.

- 일격기에 의한 갑작스러운 탈락을 피하려고 쁘사이저 가위자르기→칼춤, 쥬레곤 절대영도→냉동빔.
- 준비/수면 연계를 현재 AI가 지원하지 않아 사도의 힘껏펀치→드레인펀치/인파이트, 동탁군·루주라 꿈먹기→사이코키네시스.
- 공격 수단이 지나치게 부족한 델케티 조수→은혜갚기, 무우마직 놀래키기→섀도볼, 질뻐기 뽐내기→독찌르기. 피죤투 뽐내기→브레이브버드.
- 패리퍼의 잠재파워→에어슬래시: 사용자 정의 개체값에서 잠재파워 타입을 원작 격투로 보장하지 않으므로 비행 자속 공격으로 보완.
- 자포코일 전자포/록온→10만볼트/볼트체인지, 목호 망나뇽 파괴광선→신속, 레드의 반동 대기 기술→일반 자속 공격(잠만보 기가임팩트→누르기, 이상해꽃 하드플랜트→에너지볼, 리자몽 블러스트번→화염방사, 거북왕 하이드로캐논→파도타기).
- 팬텀 부유→저주받은바디는 현행 엔진의 합법 특성 제약에 따른 호환 수정이다. 나머지 원작 특성은 보존한다. 일부 과거 기술은 내셔널덱스 규칙에서 합법이므로 그대로 사용한다.

## 특수 기믹과 추가 최종전 — 구상

메가진화·다이맥스의 조작·상대 AI·화면 연출을 구현했고 양쪽 진영 각각 공통 배틀 1회 제한을 적용한다. 성도 40층 목호(망나뇽)와 50층 레드(피카츄)에 다이맥스밴드를 배정한다. 나머지 네임드 자동 배정은 후속 작업이다. 아래 네임드별 기믹 배정과 거다이맥스·Z·테라는 후속 기획이다.

- 일반 챔피언 및 히든 최종 상대는 대표 1마리에게 메가진화·다이맥스·Z기술·테라스탈 중 어울리는 기믹 하나를 부여하는 방향으로 검토한다.
- 레드 피카츄는 전기구슬을 밴드로 교체해 다이맥스한다. 전기구슬 동시 장착과 거다이맥스는 지원하지 않는다. 난천 한카리아스, 성호 메타그로스, 카르네 가디안은 메가진화 후보. 종별 합법성·엔진 지원·기믹 사용 AI를 확인한 뒤 확정한다.
- 플레이어와 상대 모두 팀 단위 사용 제한과 도구 중복 금지 규칙을 공유한다. 메가스톤은 지닌 도구 칸을 사용하므로 생명의구슬 등 다른 도구와 동시에 장착하지 않는다. 다른 기믹의 슬롯과 횟수는 기존 특수 기믹 구상에 맞춰 결정한다.
- 추가 최종전 후보: 성도 목호 → 레드, 에메랄드 호연 윤진 → 성호, 팔데아 테사 → 네모. 하나의 테마가 끝나는 50층의 두 번째 배틀로 둘지 아직 확정하지 않았다.
- 8세대 마스터드 추가 최종전은 제외한다. 8세대 챔피언 단델 및 대표 리자몽은 유지한다. 모든 세대에 추가 최종전을 강제하지 않는다.
