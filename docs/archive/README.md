# 정리 전 문서 원문

`2026-10-11-before-cleanup/`은 문서 정리 직전의 핵심8개 파일을 바이트 그대로 복사한 기록이다. [snapshots.json](2026-10-11-before-cleanup/snapshots.json)에 원래 경로·보존 경로·SHA-256을 기록했다.

현재 상태는 [STATUS](../STATUS.md)를 따른다. 원문에는 여러 시점의 ‘최신’ 기록과 오래된 가격/층수/키 조작이 섞여 있다. 원문 안의 상대 링크는 당시 원래 문서 경로 기준이며 이 archive 위치에서 바로 열리지 않을 수 있다. 내용을 바꾸지 않고 보존하기 위해 원문 archive는 현재 문서 링크 검사 대상에서 제외한다.

새 정리 이력이 생기면 별도 날짜/작업 폴더를 사용하며 이 원문을 덮어쓰지 않는다. 기능별 실험 문서·개발 로그·원자료는 원래 위치에서 유지한다.

## 개발 이력과 초기 구상

[과거 계획·개발 로그 모음](history/README.md)을 별도 폴더에 모았습니다. 현재 상태나 다음 작업을 찾을 때는 읽지 않아도 됩니다.
