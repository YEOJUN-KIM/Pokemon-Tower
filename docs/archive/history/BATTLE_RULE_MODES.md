# 도전별 배틀 룰 구상

기준일: 2026-10-10. 사용자와 정리한 기획이며 아직 구현하지 않았다. 3대3에서 여러 기믹이 한꺼번에 등장하는 복잡함을 줄이고, 혼합 플레이는 별도 룰로 제공하는 방향이다.

| 룰 | 허용 기믹 |
|---|---|
| 기본룰 | 기믹 없음 |
| 메진룰 | 메가진화만 |
| 다맥룰 | 다이맥스만 |
| Z룰 | Z기술만 |
| 테라룰 | 테라스탈만 |
| 개판룰 | 모든 기믹 허용 |

## 공통 방향

- 도전 시작 시 룰을 선택하고 도전 종료까지 유지한다.
- 아군과 상대에게 같은 룰을 적용한다.
- 상점의 기믹 상품, 상대의 기믹 배정, 배틀 버튼을 선택한 룰에 맞춘다.
- Z기술 구현은 계속 보류한다. 룰 선택 화면 구현 시 Z룰은 준비 중으로 표시하고 선택할 수 없게 하는 구상이다.
- 개판룰도 무제한 사용을 의미하지 않는다. 같은 포켓몬의 변신 중첩을 금지하고 사용 횟수 제한을 둔다.

## 구현 전에 정할 사항

- 개판룰의 최종 횟수: 현재 구현은 메가·다이맥스 합쳐 진영별 배틀당 1회, 테라는 별도 1회다. 개판룰에서 기믹마다 독립 1회로 바꿀지는 아직 결정하지 않았다.
- 기존 진행 중 도전의 룰 지정과 저장 호환 방식.
- 룰별 기믹 상품 가격·공급 및 상대 배정, 보상·난이도 차등 여부.
- Z룰 재개 시 장착 상품과 실제 사용 제한.

현재 실행되는 게임은 기존 규칙을 유지한다. 이 문서를 룰 분리 구현 완료로 해석하지 않는다.
