# 개발 로드맵

갱신: 2026-10-12. 현재 구현은 [STATUS](../STATUS.md), 실험 흐름은 [EXPERIMENTS](../experiments/README.md)를 기준으로 한다. 이전 계획은 [원문](../archive/2026-10-11-before-cleanup/ROADMAP.md)에 보존했다.

## 완료

612종 수집·육성, 3대3 싱글, 100층 진행/저장 복구, 1~9세대 랜덤 테마·네임드·빌런 조직, 메가·다이맥스·테라·Z기술, 여섯 룰 선택, 10층 정비·무료 리롤·배틀 도구 직접 사용, 도감 조작/기본 정보 개선을 구현했다. 새 상대는 v8의 공개 무효·흡수 학습을 계승한 v9로 Z기술 사용을 지원하며 기존 저장의 AI 버전은 유지한다. [Z기술](../gameplay/Z_MOVES.md), [특성 재생](../gameplay/ABILITY_EFFECT_TIMING.md).

여러 팀·룰·코스의 시뮬레이션과 샘플 수정 비교를 완료했다. 실험용 플레이어의 개선 후보를 실제 상대 기능 전체와 동일시하지 않는다.

## 다음 우선순위

100층 플레이 피드백을 [배틀 개선 기준](BATTLE_REBALANCE_PLAN.md)에 정리했다. 초반 후보군 확대·빌런 캠페인 개선·Z기술 기반과 선택 화면 강조는 완료했다. 다음 순서는 NPC별 대표 기믹·층수별 파티 → 육성·AI·일반/엘리트 구분 → 영양제 조정이다. 구체적인 미정 수치는 기준 문서에서 구분한다.

도감·영구 상점과 배포 준비를 진행했고 현재 무료 PC/Docker/Quick Tunnel 테스트를 운영한다. 계정 로그인·저장·백업·PC/모바일 UI 검증 및 새 PC 복원을 완료했다. 사용자는 유료 서버 전환을 보류했다. 정기 백업·터널 자동 시작·고정 주소·PWA는 미설정이다. 기존 AI 실험 자료는 보존한다.

AI 개선·난이도·경제 조정은 후속 후보다. 진행한다면 공개 정보에 기반한 기술 사용 조건을 검사하고 변경 전후를 같은 코스와 새 코스에서 비교한다. 최신 화면 조작은 [UI_FLOW](UI_FLOW.md), 가격·확률은 [STATUS](../STATUS.md)를 따른다.

## 보류·구상

- 고유 컨셉·파트너·기믹을 가진 오리지널 상위 NPC. 라이벌 관계·등장 일정·최종 에이스는 미정이며 기존 NPC 정비 이후 검토한다.
- 150/200층 확장, 추가 히든 최종전·쉬움 모드. 현재 목표는100층이다.
- ML 학습: 데이터와 행동 판단의 신뢰성을 먼저 확보하며 아직 학습하지 않았다.
- 온라인 대전·독립 운영 서버. 계정 로그인은 구현 완료했고 현재 단일 서버 저장을 사용한다.

룰 선택은 이미 구현했다. 현재 이름은 혼합룰이며 내부 ID chaos는 저장 호환을 위해 유지한다. 기획 초안이나 옛 측정의 개판룰 표기는 당시 기록이다.
