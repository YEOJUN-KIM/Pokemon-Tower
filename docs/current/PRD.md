# PRD — Pokémon Tower

갱신: 2026-10-11. 로컬 MVP 구현·확장 중. 원본 요구사항 이력은 [정리 전 PRD](../archive/2026-10-11-before-cleanup/PRD.md), 실제 구현은 [STATUS](../STATUS.md), 다음 범위는 [ROADMAP](ROADMAP.md)를 따른다.

## 목적

팀 편성·턴제 싱글 배틀·타워 진행·수집·영구 성장을 연결한 웹 게임을 만든다. 웹/백엔드 포트폴리오로 서버 검증, 데이터 모델, 트랜잭션, 보상 중복 방지, 저장 복구와 테스트를 설명할 수 있어야 한다.

## 현재 요구사항과 구현 범위

- 612종 도감에서 해금한3마리를 고르고 수집 IV·능력 포인트·성격·특성·기술·테라 타입을 저장한다.
- 새 도전은100층과 무작위1~9세대 테마를 유지한다. 50층 관문 뒤 난이도를 완화했다가100층까지 다시 올린다.
- 기본/메진/다맥/테라/혼합룰을 시작 시 선택하고 상대에게도 동일 적용한다. 일반 트레이너는 기믹을 쓰지 않는다.
- 승리 보상·영입/기술 수집·다음 층 흐름, 10층 정비와 상점, 도구/TM별 무료 리롤1회를 제공한다.
- 배틀 소모품은 턴 소모 없이 출전 포켓몬에 사용하고, 정비 기술/능력치 변경은 현재 파티와 영구 도감에 함께 저장한다.
- 상대 AI는 공개 타입·기술·특성 사건을 이용해 판단하고 관측된 무효·흡수 공격을 반복하지 않도록 한다. 비공개 상대 팀/도구를 입력으로 미리 읽지 않는다.
- 키보드·마우스·터치로 선택/취소 가능하며 현재 선택, 기술 상성, 종족값과 설정 정보를 읽기 쉽게 표시한다.

## 기믹과 저장

메가·다이맥스는 팀당 배틀1회를 공유한다. 테라는 별도1회와 팀 공용 소모권을 사용하고, 같은 포켓몬에 변신을 중첩하지 않는다. 룰에 맞는 상품과 버튼만 제공한다. Z기술은 보류한다.

게스트 쿠키·SQLite로 저장하며 서버가 합법 행동·소유권·잔액·진행 상태를 검증한다. 새로고침/서버 재시작 시 초기 팀·시드·행동·버전으로 복구하고 보상/소모품을 중복 처리하지 않는다. 기존 저장은 당시 규칙을 보존한다.

## 검증과 미정 범위

기능 검증은 타입 검사·관련 단위/통합·브라우저·배틀 재생으로 수행한다. 난이도 검증은 고정 코스와 변경 요인을 명시하고 실험/실제 게임을 구분한다. 자동 승률을 사람 승률로 해석하지 않는다.

전체 난이도·후반 경제·네임드의 원작 기술/도구 대조는 계속 검토한다. 리롤 영구 업그레이드,150/200층,ML 학습,로그인·온라인 대전·운영 배포는 현재 제공 범위에 포함하지 않는다.
