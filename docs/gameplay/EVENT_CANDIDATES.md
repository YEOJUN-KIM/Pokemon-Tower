# 이벤트 콘텐츠 설계

기준: 2026-10-16. 이번에 방향을 정한 이벤트 설계를 관리합니다. **방향 확정은 구현 완료를 뜻하지 않습니다.** 미스터리 상자의 중앙 Reward Popup 기반은 초기 구현했으며, 도전자 선택전 1차 버전과 서버 선택 보상도 구현했습니다. 다른 확정 방향은 후속 기획입니다. 현재 동작과 수치는 [이벤트와 보상 기획](EVENTS.md), 알의 현재 규칙과 향후 등급별 뽑기는 [알 종류와 부화](EGGS.md)를 따릅니다.

기존 엑셀 선별 초안의 우선순위와 아래에서 대체·흡수한 제안은 더 이상 유효한 구현 목록으로 사용하지 않습니다. 새 이벤트의 확률·가격·보상량·등장 층은 명시적으로 예시인 경우를 제외하면 모두 **추후 결정**입니다.

## 1. 도전자 선택전

### 현재 1차 구현과 후속 방향

현재는 공통 20개 Sample 풀에서 가중 랜덤 3명, Normal/Elite/Master Training Profile, 위험·성향·예상 보상, 돌아가기, 기존 3 VS 3 배틀, 영입 생략, Reward Popup·서버 선택 지급을 구현했습니다. 구체적인 현재 수치는 [현재 이벤트](EVENTS.md)를 따릅니다. 패배는 일반 lost/재도전 정책이며 상대·시드를 유지합니다. 초기 샘플·육성 계산은 [NPC 육성 프로필](../engineering/NPC_TRAINING.md)을 따르고 날씨·트릭룸 등 추가 컨셉은 후속입니다.

- 기존 상대·보상 선택전을 발전시킵니다. 여러 컨셉 트레이너 풀에서 **정확히 3명**의 후보를 가중 무작위로 제시합니다. ID와 표시명 중복을 제외하며 발생 시 저장합니다.
- 난이도 상·중·하를 한 명씩 보장하지 않습니다. 후보 전원이 강하거나 전원이 비교적 약할 수도 있습니다.
- 각 후보에 컨셉, 예상 위험도, 간단한 전투 성향, 예상 보상을 보여줍니다.
- 커서를 올리거나 선택을 확인할 때 작은 정보 팝업으로 예상 보상을 확인하는 방향입니다. 키보드·터치에서의 구체적인 조작은 추후 결정합니다.
- 마지막 선택지는 항상 **돌아간다**입니다. 현재 팀으로 감당하기 어렵다면 전투를 포기할 수 있습니다.
- 승리 후 **포켓몬을 영입하지 않습니다.** 대신 공통 Reward UI로 보상을 받습니다.

### 컨셉 풀 예시

부유한 신사, 브리더 계열, 날씨 전술가, 트릭룸 마스터, 상태이상 전문, 벽 전개형, 교체전 전문, 속공형, 내구형, 도구 전문가, 기타 전술형 트레이너를 후보로 둡니다. 최종 컨셉 목록·팀 구성·AI 세부 동작은 추후 결정합니다.

전술 마스터 수련전은 별도 이벤트로 두지 않습니다. 기존 타입 마스터·관장 수련전의 전술적 역할도 이 컨셉 풀에서 검토하여 별도 후보와 중복되지 않게 합니다.

### 보상 안내와 공통 Reward UI

전투 전에는 에픽 도구 선택, 타워 코인 대량, 영양제, 희귀 보상 가능 등 **보상 성향**을 안내합니다. 실제 아이템의 정확한 종류까지 미리 공개할 필요는 없습니다.

전투 후에는 Slay the Spire의 전투 후 보상 화면과 비슷한 공통 Reward UI에서 재화 획득·영양제 선택·도구 선택·특별 보상을 처리합니다. 예를 들어 에픽 도구 후보 4개 중 1개를 고를 수 있습니다. 이 후보 수와 등급 명칭·지급량은 설명용 예시이며 확정 수치가 아닙니다.

이 UI는 추후 레이드·빌런·기타 이벤트에서도 재사용하는 방향입니다. 공통 Reward Popup 기반은 미스터리 상자에서 구현했지만, 도전자 전투와 코인·티켓 선택 UI·서버 지급도 구현했습니다. 실제 에픽 도구 선택은 미구현입니다.

## 2. 특수개체 레이드

### 확정한 방향

- 희귀 포켓몬 스카우트전을 삭제하고 일반 트레이너전과 다른 특수 보스전으로 대체합니다.
- 기본 구도는 **플레이어 3마리 VS 특수개체 1마리**입니다.
- 보스는 높은 HP, 이벤트 전용 능력, 페이즈, 필드 효과 등을 가질 수 있습니다. 모든 보스에 이를 전부 적용한다는 뜻은 아닙니다.
- 폭주 갸라도스, 특수 마기라스, 전설 포켓몬, 무한다이노·무한다이맥스 등은 보스 컨셉 예시입니다.
- **이벤트용 특수개체 자체는 절대로 플레이어 소유 포켓몬이 되지 않습니다.** 보스 전용 강화·능력·폼을 그대로 지급하지 않습니다.

### 보상 방향

포켓몬 획득 보상이 있으면 해당 종의 정상적인 일반 개체를 지급하거나, 도감·알·티켓·해금 등 별도 보상으로 처리합니다. 폭주 마기라스 격파 후 일반 마기라스 획득 가능, 무한다이노급 보스 격파 후 해금·초희귀 보상 등은 예시입니다. 모든 보스가 해당 종을 반드시 지급하는 구조는 확정하지 않습니다.

## 3. 빌런 캠페인 이벤트

### 일반 타워와의 관계

현재 일반 트레이너층을 확률적으로 빌런으로 교체하는 방식은 **줄이거나 제거**하는 방향입니다. 빌런은 일반 배틀과 별개의 연계 이벤트 캠페인으로 만듭니다. 한 번의 등반에서는 **하나의 빌런 조직만 활성화**하고 여러 조직을 동시에 진행하지 않습니다.

빌런은 등반의 메인 콘텐츠가 아니라 도중에 진행되는 서브 스토리 정도의 비중을 유지합니다. 기존 층 대체 방식과의 전환·공존 범위는 추후 결정하며, 현재 코드는 변경하지 않았습니다.

### 기본 흐름

1. 빌런 시작 이벤트를 발견합니다.
2. 플레이어가 사건에 개입합니다.
3. 해당 조직과 적대 관계가 생깁니다.
4. 이후 등반 중 별도 기습 이벤트가 발생할 수 있습니다.
5. 조직원을 격파하며 정보를 얻습니다.
6. 특정 미래 층의 거점 위치를 알아냅니다.
7. 해당 층에 도착하면 거점에 들어갈지 선택합니다.
8. 거점·연구소에서 간부전 등을 진행합니다.
9. 보스 위치 정보를 얻습니다.
10. 최종 본거지·보스전에 도전합니다.
11. 캠페인을 종료합니다.

### 기습전

예를 들어 17층 일반 트레이너를 정상적으로 이긴 후, 다음 층으로 이동하려는 순간 `!` 연출과 함께 빌런이 기습할 수 있습니다. **17층 일반전을 대체하는 것이 아니라 추가 전투**이며, 승리 후 정상 진행은 18층입니다. 17·18층은 흐름을 설명하는 예시이고 기습 고정 층이 아닙니다.

직전 전투에 쓴 3마리를 그대로 출전시키고 전투 중 정상적인 교체는 허용하는 아이디어가 있습니다. **출전 멤버 고정과 HP/PP 회복 여부는 미확정 TODO**입니다. 기존의 모든 전투 전 회복 규칙을 이 기획만으로 변경하지 않습니다.

### 위치 정보와 활성 목적지

- 핵심 정보는 **다음 거점의 위치**입니다. 동시에 활성화된 목적지는 최대 **1개**입니다.
- 이미 거점 위치를 알고 있다면 새 목적지를 계속 쌓지 않습니다. 중간 빌런전에서는 현재 목표의 부가 정보를 얻을 수 있습니다.
- 부가 정보 예: 담당 간부의 이름, 대표 타입·전술·포켓몬, 특수개체 실험 여부, 주요 보상 성향, 조직 계획 일부.
- 예를 들어 13층에서 `31층에 비밀 연구소가 있다`는 정보를 얻으면, 31층 도착 시 `연구소에 들어간다 / 지나간다`를 선택합니다. 이 층수는 예시입니다.
- 거점을 지나가도 캠페인은 종료되지 않습니다. 이후 조직원을 격파해 47층의 다른 거점 같은 새 목적지 정보를 얻을 수 있습니다. 지나간 목표의 정리·재지정 시점은 추후 결정합니다.

### 거점·연구소와 레이드 연결

거점에서 조직원전·간부전·특수 사건·특수개체 레이드를 연결할 수 있습니다. 예를 들어 빌런의 포켓몬 실험을 폭주 특수개체 레이드로 이어가고, 간부를 격파한 뒤 보스 위치를 알아내는 식입니다. 레이드 보스 자체를 소유할 수 없다는 원칙은 이 경우에도 유지합니다.

## 4. 히든 상인

### 조기 획득 선택

일반 상점보다 드물고 특별한 상품을 판매합니다. 핵심 역할은 **현재 룰의 기믹을 정상 획득 시점보다 일찍 사용할 기회**를 주는 것입니다.

다이맥스 룰에서 다이맥스밴드를 매우 비싼 타워 코인으로 먼저 살지, 돈을 모으며 정상 획득 시점까지 기다릴지 선택하는 구조가 예시입니다. 메가진화·Z기술·테라스탈 관련 상품도 현재 룰에 맞춰 같은 방향으로 검토합니다. 실제로 해당 룰에 필요한 기존 장비·도구와 연결하며 없는 장비를 구현된 것으로 가정하지 않습니다.

**히든 상인이 기믹의 유일한 획득 경로가 되어서는 안 됩니다.** 일반적인 획득 경로는 유지하고, 조기 획득 수단으로 둡니다. 정상 획득 시점·방법과 조기 판매 시점·가격은 추후 결정합니다.

| 결제 재화 | 상품 방향 |

| 타워 코인 | 고등급 지닌 도구, 기술 관련 상품, 룰 기믹 조기 해금 장비, 기타 현재 런 강화 아이템 |
| 영구재화 | 희귀 알, 희귀 알 뽑기권, 초희귀 알 뽑기권, 기타 영구 수집 상품 |

**알 관련 상품은 타워 코인이 아니라 영구재화로 구매**하는 방향입니다. 현재 임시 여행 상인의 `300코인 → 공통 알 티켓` 거래는 기존 구현으로 별도 유지되며, 새 히든 상인 정책과 혼동하지 않습니다. 기존 임시 거래를 전환·종료할지는 추후 결정합니다.

모든 상품을 항상 판매하지 않고 일부가 무작위 등장하는 방식을 고려합니다. 희귀·초희귀 알 티켓은 진열 자체가 희귀할 수 있습니다. 알의 확률·풀·티켓 규칙은 [EGGS.md의 향후 확장](EGGS.md#향후-확장-등급별-뽑기와-전용-티켓)에서 관리합니다.

## 5. 영양제 상인

현재 10층 단위 정비에서 이용하는 고정 영양제 상점을 **제거하거나 축소하고 랜덤 영양제 상인 이벤트로 이동**하는 방향입니다. 기존의 '고정 상점 유지 + 히든 상점 추가' 제안은 이 방향으로 대체합니다. 일반 상점·기술머신 상점까지 함께 없애는 결정은 아닙니다.

완전 무작위라 한 런 동안 지나치게 만나지 못하는 문제에 대해 등장 확률 보정 등을 검토합니다. 정확한 확률이나 최소 등장 횟수는 확정하지 않습니다. 현재 한 포켓몬당 도전 중 영양제 총 3개 제한은 기존 규칙이며, 새 판매 경로만으로 이를 해제하지 않습니다.

## 6. 미러 매치 계열

독립적인 특수 전투 이벤트로 유지합니다. 완전히 동일한 복제 팀보다는 **같은 종·폼을 다른 세팅으로 사용하는 상대**를 기본 방향으로 둡니다.

| 종류 | 상대 포켓몬 구성 | 세팅·난이도 방향 |
|---|---|---|
| 일반 미러 매치 | 플레이어가 현재 사용하는 3마리와 같은 종·폼 | 기술·스탯·특성·도구 등을 어느 정도 무작위 또는 이벤트용으로 구성 |
| 왜곡된 미러 매치 | 현재 6마리를 보유했다면 그중 무작위 3마리 | 별도 무작위·이벤트 세팅. 6마리 미만일 때 등장 여부·선정 방식은 TODO |
| 챔피언 미러 | 플레이어의 핵심 3마리를 기반으로 완성형 팀 구성 | 매우 희귀하고 고난도. 최대급 개체값·강한 능력치 배분·최적 기술·특성·좋은 도구·최고 수준 AI 방향 |

챔피언 미러는 **현재 선택한 룰**의 기믹을 극단적으로 활용할 수 있습니다. 예를 들어 핫삼·한카리아스·갸라도스 팀을 본뜬 메가진화 룰 상대가 세 마리 모두 메가진화하는 등, 이벤트 전용 규칙으로 일반적인 전투당 메가진화 1회 제한을 일부 깨는 것도 허용하는 방향입니다. 예시 전체를 확정된 보스 세팅으로 취급하지 않습니다.

다이맥스·테라스탈·Z기술도 현재 룰 기준으로 별도 강화 규칙을 설계할 수 있습니다. 이 예외는 해당 이벤트에 한정하며 일반 배틀 규칙 변경이나 플레이어의 동일 권한 부여를 뜻하지 않습니다. 챔피언 미러 보상은 일반 미러보다 훨씬 좋게 설정할 수 있습니다.
