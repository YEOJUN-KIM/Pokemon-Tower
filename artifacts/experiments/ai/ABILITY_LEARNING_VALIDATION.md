# 공개된 무효·흡수 결과를 이용한 AI 판단 검증

대상은 실험용 플레이어 `CoverageFactorPolicy({immunity:true,switching:false})`다. 기존 `PublicImmunityV2`에 공개 특성 기억 기능이 있어 판단 코드는 수정하지 않고 실제 배틀 엔진을 이용한 회귀 테스트와 재현 데이터를 추가했다. 게임 내 적 AI·난이도·가격은 이번 작업에서 변경하지 않았다.

첫 턴에만 무효가 될 공격을 의도적으로 지정한다. 다음 턴은 AI가 공개된 결과를 바탕으로 스스로 결정한다. 통하는 다른 타입의 기술이 있으면 교체하지 않고 그 기술로 공격하는지 확인한다. 상대 특성만 무효가 아닌 특성으로 바꾼 대조군에서는 첫 공격이 실제 피해를 주는지 확인한다. 상대의 실제 특성·기술배치는 테스트 대상을 만드는 데만 사용하며 AI 입력으로 전달하지 않는다. 원시 요청 데이터도 학습 이벤트 입력에서 제외했다.

| 상대 | 발동 특성 | 대조군 특성 |
|---|---|---|
| 동탁군 | 부유 | 내열 |
| 누오 | 저수 | 천진 |
| 라이츄 | 피뢰침 | 정전기 |
| 트리토돈 | 마중물 | 점착 |
| 윈디 | 타오르는불꽃 | 위협 |
| 쥬피썬더 | 축전 | 속보 |
| 에레키블 | 전기엔진 | 의기양양 |
| 바라철록 | 초식 | 엽록소 |
| 꿈트렁 | 흙먹기 | 모래숨기 |
| 바우첼 | 노릇노릇바디 | 아로마베일 |

## 실행과 결과

`node node_modules/tsx/dist/cli.mjs --test tests/ability-learning.test.ts`

`node node_modules/tsx/dist/cli.mjs scripts/check-ability-learning.ts`

10사례 × 발동군/대조군 × 3시드 = 60전. 결과는 `artifacts/experiments/ai/ability-learning-20261011.json`에 저장한다. 발동군 30전 모두 다음 턴에 막힌 타입을 피하고 다른 기술로 공격했다. 대조군 30전은 첫 공격이 실제 피해를 줬다. 전체 60전의 행동 합법성, 공개 로그와 양측 행동 순서의 리플레이 일치를 확인했다. 관련 회귀 테스트 44개와 TypeScript 검사도 통과했다.

별도 테스트에서는 저수를 확인하면 다른 물 기술도 제외하는지, 틀깨기로 특성을 무시할 수 있는지, 새 상대가 나오면 이전 증거를 초기화하는지 확인했다.

이 결과는 첫 공격이 막힌 뒤 대응하는 동작의 집중 검증이다. AI가 자연스럽게 첫 기술을 선택하는 빈도나 100층 클리어율을 측정하지 않았다. 가중치를 학습시키는 머신러닝도 아니다. 다른 공격이 없을 때의 교체 판단과 위험한 상대에게 살아남는 판단은 추가 검증 범위다. 적 AI 적용은 다음 단계로 남긴다.
