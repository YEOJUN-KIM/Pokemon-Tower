# 개발 로드맵

최종 갱신: 2026-10-10. 일정 대신 구현 결과와 검증 기준으로 관리한다. 테라스탈·빌런 이벤트·v7 상대 교체 AI·100층 난이도 곡선·1~9세대 랜덤 테마 구현을 반영했다. 사용자 요청으로 Z기술·영구 성장 상품은 보류하며 UI 배치 조정도 다음으로 미룬다. 다음 순서는 대화에서 제안한 추천 순서이며, 미정 규칙을 구현 완료나 확정 결정으로 취급하지 않는다.

## 현재까지 완료

- 612종 도감·육성·수집·영입, 3대3 싱글 배틀, 100층 진행·완주·종료 정산·재시작 복구.
- 1~9세대 지역 테마를 새 도전에서 무작위 선택·저장하고 지역별 트레이너/빌런을 배치한다. [전체 배치](REGIONAL_THEMES.md). 성도 테마: 관장 8명 중 5·15·25·35·45층 중복 없이 추첨, 10·20·30층 사천왕, 40층 목호, 50층 레드. 대표 포켓몬 고정 + 원작 후보에서 파트너 2마리 선택. 포켓몬의 출신 세대는 제한하지 않는다.
- 일반·엘리트·혼합 39종과 1~9세대 네임드 144개 배치 샘플. 같은 인물의 지역/직급별 샘플은 별도다. 성도 외 파티는 원작 참고 각색이며 기술/도구 완전 대조는 후속이다.
- 같은 조직의 빌런 조직원·간부·보스 이벤트, 격파 추가 보상·보스 격파 후 종료·저장 복구, 상황별 음악·경기장 배경, 임시 효과음과 변신 연출.
- 테라스탈: 무료 도감 타입 저장·팀 공용 소모권·배틀 1회·변신 중첩 금지·결정 연출·복구. [상세](TERASTALLIZATION.md).
- 메가진화 47종·다이맥스, 각 진영 두 기믹을 합쳐 배틀당 1회, 목호 망나뇽·레드 피카츄 밴드, v7 교체 AI(기존 v6 이하 보존). [교체 판단](SWITCH_AI.md).
- 지닌 도구 83종·TM 47종, 등급 확률로 각각 최대4종, 전체 코인 리롤, 랜덤 소모품3종·영양제 4종, 실제 포인트·배틀 효과·저장.
- 50층 상점 경제 가격 조정: 64코스 가격 전후 비교 및 구매 성향 대조/재실행 포함 768회 등반. 상세는 [경제 검증](SHOP_ECONOMY_50.md).

현재 구현된 메가·다이맥스·테라와 상점·빌런 보상을 포함한 9세대 [경제/난이도 재측정](REGIONAL_SIMULATION.md)을 완료했다. 다음은 초반 1~5층·테라권 수급 대조 실험이다. Z기술 구현을 재측정의 선행 조건으로 두지 않는다. 이후 콘텐츠를 늘려도 동일한 코스로 이전 결과와 비교할 수 있도록 원자료와 가격 스냅샷을 보존한다.

## 구현 전에 정할 것

- 도전별 기본룰·메진룰·다맥룰·Z룰·테라룰·개판룰 분리를 구상으로 기록했다. 시작 시 선택·도전 중 유지·양쪽 동일 적용·상품/버튼 연동 방향이며 아직 구현하지 않았다. Z는 계속 보류한다. [룰 구상](BATTLE_RULE_MODES.md).

- 현재 공통 사용 제한은 메가·다이맥스 합쳐 진영별 배틀당 1회다. 테라는 별도 팀당 1회·공용 소모권이며 해당 포켓몬의 메가/다이맥스와 중첩 불가로 구현했다. Z의 사용 제한은 미정이다.
- 테라권은 에픽 소모품·900코인, 새 도전과 새 상대의 초기 1장 지급으로 시험한다. 재사용형 레전더리는 구현하지 않았다. Z상품은 미정이다.
- 영양제는 현재 일반 상점에 유지한다. 히든 상점/이벤트화는 강함과 구매 빈도를 추가로 보며 재검토할 후보이며 구현하지 않았다.
- 빌런 등장 추첨은 임시 8%, 16층부터 간부·31층부터 보스가 후보에 들어간다. 간부 +250·보스 +1,000코인과 조건부 비율은 시험용 설정이며 경제·난이도 재측정이 필요하다. [빌런 상세](VILLAIN_EVENTS.md).
- 히든 최종 상대를 추가할 때 8세대는 제외하는 방향으로 논의했다. 이는 8세대 일반 테마 자체의 제외를 의미하지 않는다. 목호/레드의 현재40/50층 배치는 유지한다.

## 보류

- Z기술: 사용자가 현재 기믹 수가 많다고 판단해 보류했다. 재개 전 상품·장착·사용 제한을 결정한다.
- 추가 UI 배치 조정: 사용자 요청으로 다음에 검토한다.
- 영구 성장 상품: 리롤권·상품 출현 제외 등의 후보는 사용자 요청으로 더 고민한 뒤 재개한다. 가격·적용 범위는 미정이다.

## 이후 확장 후보

- 150·200층 확장과 서로 다른 세대 테마 두 구간은 후보다. 현재 100층은 같은 지역을 유지하고 50층 관문 이후 잠시 완화한다. 일반 트레이너 기믹 금지·후반 엘리트 비율 증가를 구현했다. [100층 검증](HUNDRED_FLOORS.md).
- 진화 도구·조건 및 폼체인지 성장 루트, 거다이맥스 전용 형태·원시회귀 등 추가 기믹.
- v6 자발 교체를 기반으로 더 정교한 AI, 엘리트 전용 보상/육성 차등, 쉬움 모드의 다음 상대 예고.
- 관장/챔피언 BGM 후보 추가, 경기장 배경 보강, 기술 이펙트·울음소리. 원작 음원/이미지 자료는 출처와 적용 가능 범위를 확인하며 기술 이펙트는 보류 중.
- 로그인·기기 간 저장·게스트 이전·공개 배포·CI·운영 성능 검증.

## 이력과 현재 상태

초기 우선순위였던 기술머신 → 트레이너 샘플 → 10/20/30/50층 확장 → 시뮬레이션 조정은 1차 완료했다. 9개 지역 테마까지 추가했고 100층을 구현했으며 테마별 완전한 원작 세팅 대조와 사람 기준 후반 난이도 조정은 남아 있다. [현재 상태](STATUS.md), [작업 인계](SESSION_HANDOFF.md), [개발 로그](DEVLOG.md)를 기준으로 이어간다.
