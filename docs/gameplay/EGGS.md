# 알뽑기와 부화

- Status: Active
- Updated: 2026-11-03
- Baseline Commit: `1c05b6f5079143ba4be7df3f3745155aee483ce7`
- Applies To: beta.6 개발 / 문서 담당 영역 (공개 패키지 표기는 beta.5)

기준: 2026-10-20. 타이틀의 알뽑기에서 공통 Egg Station을 이용한다. 영구 업그레이드와는 별도 페이지다. 현재 화면은 **기본 뽑기만** 제공하며 지역/타입 선택·알 탐색 연구는 표시하지 않는다.

## 가격과 입력

1회 200 성장 포인트, 10회 2,000P다. 공통 뽑기권을 먼저 1회당 1장 사용하고 모자란 횟수만 포인트로 결제한다. 10회 할인·천장·추가 보장은 없다.

중앙 기계 아래 1회/10회 선택지를 둔다. 방향키로 이동, Enter/Z·패드 결정키로 뽑고 X로 타이틀에 돌아간다. Y 또는 A 보조키와 하단 명령으로 알 확률을 연다. 보상 티켓은 보유한 경우 별도 선택지에 표시한다. 뽑기 중 중복 입력은 막으며 실패한 요청은 동일 요청 번호로 재확인한다.

## 등급과 이로치

| 등급 | 기본 확률 | 대상·표현 |
|---|---:|---|
| 일반 | 85% | 전설 계열을 제외한 일반 포켓몬, 흰 알·초록 문양 |
| 레어 | 12% | 준전설·패러독스·울트라비스트, 보라/청록 에너지 |
| 슈퍼레어 | 3% | 초전설·환상, 백금/연보라 후광·별빛 |

등급을 고른 뒤 **빛나는 부적 레벨에 따른 별도 이로치 판정**을 한다. 부적이 없는 레벨 0은 0.24%, 최대 레벨 5는 0.54%다. 당첨되면 어느 등급이든 황금 이로치 알로 표시하며 10회도 알마다 독립 추첨이다. 레어 내부 분류는 45:25:15, 슈퍼레어는 초전설:환상 5:1이며 분류 안에서 종을 균등하게 선택한다. 부적은 등급 85/12/3 자체를 바꾸지 않는다.

## 빛나는 부적과 공통 이로치 확률

빛나는 부적은 **계정 전체 이로치 발견 확률을 올리는 영구 업그레이드**이며 알 전용 연구가 아니다. 같은 `shinyCharmLevel`(0–5)을 콘텐츠별 노출 빈도에 맞춘 별도 표에 적용한다. 단일 기준은 `src/data/shiny-odds.ts`다. 아래는 **임시 확률, 추후 시뮬레이션 조정 예정**이다.

| 레벨 | 알 (분자/10,000) | 타워 상대 (분자/65,536) | Scout (분자/10,000, 미연결) |
|---|---|---|---|
| 0 | 24 = 0.24% | 8 ≈ 0.012207% (1/8192) | 6 = 0.06% |
| 1 | 30 = 0.30% | 12 ≈ 0.018311% | 9 = 0.09% |
| 2 | 36 = 0.36% | 17 ≈ 0.025940% | 13 = 0.13% |
| 3 | 42 = 0.42% | 25 ≈ 0.038147% | 18 = 0.18% |
| 4 | 48 = 0.48% | 36 ≈ 0.054932% | 25 = 0.25% |
| 5 | 54 = 0.54% | 52 ≈ 0.079346% | 35 = 0.35% |

`eggShinyChance`·`towerShinyChance`는 실제 연결됐다. `scoutShinyChance`는 데이터/헬퍼 준비 완료이며 실제 Scout 연결은 예정이다. Raid의 `rollEncounterShiny`는 별도 기본 1/8192를 유지하므로 모든 특수 이벤트에 부적 효과가 연결됐다고 확대하지 않는다.

타워는 `TowerStore.createBattle`에서 한 번 판정해 opponent packed team에 저장한다. **encounter 생성 → 전투 → 재접속 → 재도전 → 영입 후보 → 실제 영입**에서 동일 shiny 상태를 쓴다. 계정의 기존 shiny 보유와 영입 상대 shiny는 OR로 누적하며 기존 이로치를 잃지 않는다. 기존 전투는 부적 레벨이 변해도 재판정하지 않는다. `tests/shiny-odds.test.ts`가 경계값·저장·재접속·재도전·영입을 검사한다.

수집 가능한 배틀 도감 항목만 대상이다. 분류와 풀의 기준은 src/server/egg-pool.ts·src/data/egg-grades.ts·src/data/egg-kinds.ts이며, 과거 등급 분류 보고 (로컬 전용: `artifacts/reports/changes/EGG_POOL_CLASSIFICATION.md`)의 개수를 새 데이터의 고정값으로 사용하지 않는다.

## 배출·부화

기계가 들썩인 뒤 출구에서 대표 알 하나를 배출하고 결과를 펼친다. 10회에도 열 개를 순서대로 배출하지 않는다. 실제 결과 중 **이로치 > 슈퍼레어 > 레어 > 일반** 우선으로 대표 알을 고른다.

각 알을 눌러 하나씩 부화하거나 한 번에 열 수 있다. 남은 알이 있을 때 닫기를 누르면 먼저 전체를 열고, 모두 열린 뒤 확인으로 닫는다. 새 포켓몬·IV 개선·새 기술·이로치 해금을 표시하며 종 분류 라벨과 중복 설명은 생략한다. 큰 화면은 최대 1,500px의 결과 창에 5개씩 두 줄로 배치하고, 작은 화면은 결과 영역만 스크롤한다.

| 결과 | 배경·효과 |
|---|---|
| 준전설 | 하늘색·푸른 후광 |
| 울트라비스트 | 보라·회전 오라 |
| 패러독스 | 민트·흐르는 빛결 |
| 초전설 | 샴페인 골드·백금 광선·금빛 후광·별빛 |
| 환상 | 연분홍·후광·별빛 |
| 이로치 | 선명한 금빛·반짝임, 원래 분류보다 우선 |

동작 감소 설정은 회전·반짝임을 정지하고 전환을 단축한다. 색 비교 (로컬 전용: `artifacts/qa/previews/egg-results/background-colors.png`)·효과 GIF (로컬 전용: `artifacts/qa/previews/egg-results/background-effects.gif`)·초전설 효과 (로컬 전용: `artifacts/qa/previews/egg-results/legendary-effects.gif`)는 해당 효과 도입 당시 비교 자료다.

## 전용 티켓과 저장

Master 보상의 알 후보는 일반 티켓 3장 / 슈퍼레어 티켓 1장 / 이로치 티켓 1장 중 60/35/5 비중으로 생성한다. 이 비중은 보상 후보의 종류이며 기계의 등급 확률이 아니다. 선택한 보상만 지급한다. 슈퍼레어/이로치 티켓은 영구 보관하며 해당 1개 부화에 사용하고 공통 티켓·포인트를 쓰지 않는다.

추첨·차감·수집·영수증은 서버 트랜잭션에서 함께 저장한다. 알을 여는 동작은 이미 확정된 결과의 공개이며 재추첨하지 않는다. 같은 요청은 같은 결과를 반환하고 다른 구매로 바꾸면 거절한다. 기존 종류 선택형·조정 영수증도 저장된 결과로 복구한다. 새로고침 후 수집과 재화는 유지되지만 부화 공개 화면을 이어서 보여주는 기능은 없다.

이로치 상시 교환권 판매/변환, 타입별 알·등급별 상시 판매는 현재 제공하지 않는다. 예전 교환권·영수증은 보존하며 `eggFocus` 연구 레벨은 schema 49에서 `shinyCharm`으로 이전한다.
