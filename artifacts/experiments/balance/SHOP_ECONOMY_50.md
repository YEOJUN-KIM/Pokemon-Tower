# 50층 상점 경제 조정 · 2026-10-10

리롤·8종 중 3종 랜덤 소모품·6종 중 4종 영양제·도구/기술머신 구매를 실제 배틀 엔진에 반영했다. 기존 32개 고정 코스에서 가격안을 비교한 뒤 새 32개 코스로 다시 검증했다. 구매 성향 대조 및 적용 가격 재실행을 포함해 총 768회 등반, 16,957회 배틀이다.

## 최종 가격

| 상품 | 이전 | 조정 |
|---|---:|---:|
| 소모품 | 200 | 200 유지 |
| 리롤 1~4회 | 200 / 400 / 600 / 800 | 200 / 400 / 700 / 1,100 |
| 영양제 5 / 10 / 25 / 45층 클리어 | 2,200 / 2,400 / 3,000 / 3,800 | 1,400 / 1,800 / 3,000 / 4,600 |
| 도구 언커먼 / 레어 / 유니크 / 에픽 / 레전더리 | 도구별 120~900 | 200 / 400 / 600 / 900 / 2,500 |
| 자뭉열매 | 120 | 150 (레어 예외) |
| TM 언커먼 / 레어 / 유니크 / 에픽 / 레전더리 | 100 / 200 / 300 / 450 / 650 | 100 / 200 / 400 / 650 / 1,000 |

리롤 비용은 200 + 200×횟수 + 50×횟수×(횟수−1), 횟수는 구매 전 0부터 센다. 두 상점별로 따로 증가하고 다음 체크포인트에서 초기화한다. 영양제는 1,000 + 80×클리어층이다. 희귀도·확률·배틀 보상·상대 난이도·소모품/영양제 효과는 바꾸지 않았다.

## 영양제와 히든 상점 판단

기존 코스 준비팀 32회 대조: 보통 구매 4/32회 완주, 영양제 미구매 5/32회, 영양제 최대 4개 우선 구매 4/32회. 구매 비용은 동일하게 차감하되 능력 포인트를 주지 않는 대조는 4/32회, 평균 30.78층으로 실제 영양제의 31.00층과 가까웠다. 이는 이번 구매/전투 정책에서 영양제가 압도적인 승리 요인이 아니었다는 증거이며 사람 플레이에서의 강함을 확정하는 결과는 아니다. 미구매 대조는 다른 상품에 더 지출하므로 순수 효과 대조가 아니다.

영양제는 현재 일반 상점에 유지한다. 초반 가격을 낮춰 선택 가능성을 늘리고 후반 반복 구매는 더 비싸게 했다. 히든 상점·이벤트화는 후보 기획으로 남겨둔다. 변신 도구를 노리는 최대 10회/상점 탐색 대조에서는 평균 리롤 4.74 → 3.75회/방문으로 감소했고 준비팀 완주 5/32회는 유지했다. 이 탐색 대조는 영양제를 사지 않는 상한 실험이다.

## 재현과 한계

스크립트: scripts/simulate-shop-economy.ts. 기본과 추가 코스는 artifacts/experiments/balance/balance-50-courses.json, artifacts/experiments/balance/balance-50-economy-holdout-courses.json. BALANCE_COURSES로 선택한다. 가격 스냅샷은 artifacts/experiments/balance/shop-price-before.json 및 shop-price-trial.json. BALANCE_PRICE_FILE로 지정하면 이전 가격도 재현된다. BALANCE_STAGES와 BALANCE_BEHAVIOR로 준비 수준/구매 성향을 선택한다. reports는 artifacts/experiments/balance/balance-50-economy-*.json, 요약은 artifacts/experiments/balance/shop-economy-summary.json.

예: BALANCE_PRICE_FILE=artifacts/experiments/balance/shop-price-before.json, BALANCE_BEHAVIOR=balanced 환경에서 tsx scripts/simulate-shop-economy.ts economy-current. 새 가격은 가격 파일 없이 economy-final로 실행한다.

양측 v4 공개 정보 정책, 미래 상대 정보 없이 자체 스탯/타입으로 3마리 선택, 최고 종족값 포켓몬 영입 및 IV 흡수, 다음 층 전체 회복, 코인 0 시작을 적용한다. 상점 난수는 서버의 도전 ID·층·리롤 횟수 해시 규칙을 재현한다. 미수집 기술 후보와 파티는 시뮬레이터의 영입/구매 결과를 따른다. 지닌 도구 중복·장착 종 적합성·도구 가방·TM 학습·영양제 추가 능력치를 포함한다. 성향에 따라 최대 리롤 1/4/10회, 최대 영양제 0/2/4개이며 기본 구매 정책은 400코인을 남긴다.

HTTP로 매번 구매/영입하지 않고 규칙을 내부 모델링하며 자발적 교체·사람의 대응 전략은 없다. 자동 완주율을 유저 완주율로 해석하지 않는다. 기존 저장 TM 상품은 저장 가격을 유지하며 다음 추첨부터 새 가격이다. 이미 구매한 도구/기술/능력 포인트에 추가 비용을 청구하지 않는다. DB 구조 변경은 없다.


검증: 단위 테스트 123개, Chrome PC/모바일 상점·기술머신·도구 E2E 11개, 프로덕션 빌드 통과. 적용된 가격의 최종 준비팀 32회 결과가 비교 가격안과 코스별 구매·배틀 결과까지 동일한지 확인했다. 모든 768회에서 수입=지출+잔액 및 상품 개수를 검증했다.
