# 이로치 등장 미리보기

실제 게임 브라우저에서 캡처한 별빛 등장 연출입니다. 확인용 계정만 플레이어 리자몽과 상대 이로치를 확정으로 지정했습니다. 실제 추첨 확률(알1/1,024·트레이너 포켓몬1/8,192)은 유지합니다.

- GIF: [이로치 등장](shiny-entry.gif)
- 원본 캡처: frames-sendout/00.png~21.png
- 재현: e2e/permanent-upgrades.spec.ts의 shiny battle entry 테스트 → scripts/assemble-shiny-preview.py

포켓몬 원본 스프라이트를 교체/업스케일링하지 않고 이로치 원본 이미지와 CSS 별빛을 실제 화면에서 캡처했습니다. 캡처는 별빛의 시간만 60ms 간격으로 고정해 같은 타이밍을 재현합니다. 이미지가 준비된 뒤에 반짝임이 시작되고 일상적인 기술/HP 변화에는 다시 반짝이지 않으며 교체 등장에 다시 표시합니다.

최신 GIF는 실제 몬스터볼 등장 연출에서만 별빛이 재생되는 버전이다. 대기/새로고침에는 별빛 요소가 없음을 브라우저로 확인했다.
