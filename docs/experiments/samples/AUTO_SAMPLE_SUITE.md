# 자동 샘플 점검과 대량 시뮬

개별 포켓몬을 하나씩 수동 수정하기 전에 공통 오류와 반복 실패를 찾는 실험 도구다. 실제 게임 설정/세이브/NPC 정책은 변경하지 않는다.

## 한 번에 실행

```powershell
node scripts/run-auto-suite.mjs 20261012
```

숫자는 조합 생성 시드다. 현재 생성기 v2는 1~9세대 스타터 9팀, 벽/트릭룸/혼합 각 3팀을 준비하고 기본·테라·개판룰을 실행한다. 18팀×9지역 코스×3룰, 486등반이다. 실행 시 환경에 남은 가격/팀 제한을 초기화하고, 원본 해시를 확인하며, 기존 결과 파일은 덮어쓰지 않는다. 로그는 `artifacts/auto-suite-시드-룰.log`이다. 실패한 실행 기록도 보존하므로 재시도는 새 시드를 쓰거나 완료된 결과를 별도 집계한다.

새 시드는 플레이어 조합을 바꾼다. 적은 기존 9개 코스를 고정해 비교하며 새 독립 검증 표본이 되지는 않는다. 실행기는 세 룰을 병렬 프로세스로 돌린 뒤 마지막 패배 전부를 재생해 기록 일치를 검사하고 보고서를 만든다.

샘플 검사만 하려면:

```powershell
node node_modules/tsx/dist/cli.mjs scripts/prepare-auto-suite-v2.ts 20261013
```

612종의 기본 도감 설정을 검사하고, 기존 벽/트릭룸 샘플 원본·정정본과 새 생성팀을 검사한다. 기술/특성/육성 합법성, 공격 분류와 투자/성격 불일치, 양벽/트릭룸 조건, 상대 종별 타입 및 대표 무효 특성에 대한 정적 공격 범위를 기록한다. 속임수/바디프레스/고정 피해는 자신의 공격 투자 검사에서 제외한다. 혼합 공격이나 지원 역할을 자동으로 공격형으로 고치지 않는다. 변신/간접 공격 중심 종은 도감 검사에는 포함하되 일반 공격팀 무작위 생성에서 제외한다. 해당 역할의 전용 생성은 후속 확장이다.

메타몽·해무기·루브도의 직접 공격 부재는 역할 검토 경고다. 상태이상/날씨/특성/테라/PP/봉인/도구까지 완전히 모델링하는 검사기는 아니다. 상대 특성을 열거하는 정적 검사와 전체 팀을 사용하는 재생은 오프라인 진단이며 정책 입력에 상대 비공개 정보를 넣지 않는다.

완료된 결과 재검사:

```powershell
node node_modules/tsx/dist/cli.mjs scripts/summarize-auto-suite.ts 20261010
```

`cases.json`은 출발팀, `samples.json`은 정적 검사, `manifest.json`은 원본/정책/생성기 해시, 룰별 `battles.jsonl`은 배틀 기록, `summary.json`은 실패 그룹/팀별 결과, `report.md`는 읽는 보고서다. 학습에 쓴다면 코스 ID 단위로 분할하고 중복 재생을 새 표본으로 세지 않는다. 현재 머신러닝 모델 학습은 하지 않는다.

## 첫 실행 결과

시드 20261010은 보존된 생성기 v1을 사용했다. 18팀·48종, 486등반·10,770배틀이며 마지막 패배 483개를 정확히 재생했다. 이후 다른 시드 20261011로 v2의 18팀·53종 생성/합법성/정적 검사도 확인했다(이 두 번째 시드는 등반 미실행).

| 룰 | 100층 완주 /162 | 50층 통과 /162 | 평균 성공 층 |
|---|---:|---:|---:|
| 기본 | 2 | 17 | 22.0 |
| 테라 | 0 | 12 | 20.5 |
| 개판 | 1 | 13 | 21.0 |

완전 육성/매 층 회복/자동 영입·구매 조건인데도 일반 조합의 성적은 낮았다. 준비된 강팀을 사용했던 이전 실험과 입력 조합이 다르므로 직접 개선율로 비교하지 않는다. 236개의 마지막 패배는 10층 이하였고, 반복 무효 공격이 나온 마지막 패배는 74개였다.

공개 무효 사건을 더 나누면 정적으로 가능한 공격이 남은 동료에게만 있는 패배 56개, 살아 있는 동료 중에 정적 공격 해법이 없는 패배 67개, 현재 포켓몬에 정적 공격 대안이 있는 패배 33개, 현재 정책의 목록 밖 특성 공개 사건이 있는 패배 5개였다. 그룹은 겹친다. 실제 PP/봉인/선택 잠금/교체 제한/예상 생존 가능성을 확인하지 않는 정적 신호라서 무조건 행동 오류라고 단정하지 않는다.

다음 개선 우선순위는 이 그룹의 공통 원인이다: 공개 무효 특성 처리 누락, 남은 공격 해법을 가진 동료 보호와 교체, 공격 수단을 잃는 기술 정비/팀 선발. 각각 정책 후보를 별도 버전으로 만든 뒤 같은 조합·코스에 비교하고, 새 적 코스로 독립 검증한다. 포켓몬별 예외를 계속 추가하는 방식으로 해결하지 않는다.

관련 테스트 24개와 TypeScript 검사 통과. 상세 수치는 `artifacts/auto-suite-20261010-report.md`와 `artifacts/auto-suite-20261010-summary.json`에 있다.
