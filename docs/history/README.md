# 과거 결정과 검증

현재 규칙은 [게임 안내](../gameplay/README.md), 현재 수치·버전은 [STATUS](../STATUS.md)를 따른다. 이곳의 수치와 테스트 개수는 작성 당시 기록이다.

- [2026-10-18 중간점검](REFACTORING-2026-10-18.md): 저장 호환·트랜잭션 경계·설정 복구·생성 입력 보존과 과도한 재분할을 피한 근거.
- [배틀 음향 결정 기록](BATTLE_AUDIO.md): 음악 교체·크로스페이드·효과음 합성·측정 방식과 과거 검증. 현재 파일별 출처는 [라이선스 안내](../references/THIRD_PARTY.md)와 `public/audio/music-sources.json`이 기준.

QA 로그·이미지·실험 원자료는 Git 제외 `artifacts/`에 둔다. 공식 문서에서 그 로컬 자료의 존재를 필수로 요구하지 않는다.
