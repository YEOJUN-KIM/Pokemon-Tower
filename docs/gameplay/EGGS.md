# 알 종류 구상

기준: 2026-10-14. 이벤트와 별개로 알 뽑기의 종류와 수집 방향을 정리합니다. 종류별 알은 구상 단계이며, 확률·가격·획득 방법은 아직 확정하지 않았습니다.

## 현재 알 뽑기

- 알 티켓을 먼저 사용하고, 부족한 횟수는 1회 200 성장 포인트로 뽑습니다. 1회·10회 뽑기가 있습니다.
- 배틀에 사용할 수 있는 도감 항목에서 포켓몬을 뽑아 바로 부화 결과를 보여줍니다. 현재 별도의 부화 대기 시간은 없습니다.
- 희귀도 추첨 비중은 일반 95%, 준전설 3.5%, 전설 1%, 환상 0.5%입니다.
- 이로치 추첨 확률은 1/1,024입니다.
- 새 포켓몬은 도감에 등록하고, 중복은 기존보다 높은 개체치·새 기술·이로치 외형 획득으로 이어질 수 있습니다.
- 현재 알 티켓은 한 종류입니다. 아래 타입별·희귀·이로치 알은 추가 구상입니다.

현재 구현 근거: `src/data/permanent-upgrades.ts`, `src/data/pokemon-rarity.ts`, `src/server/tower-store.ts`의 알 부화 처리. 위 확률은 현재 기본 알의 기준이며 새 알의 확정 확률이 아닙니다.

## 사용자가 제안한 알 종류

| 알 후보 | 수집 목적 | 구상 방향 | 아직 정할 내용 |
|---|---|---|---|
| 타입별 알 | 원하는 타입의 포켓몬 수집 | 물 타입 알처럼 해당 타입 포켓몬이 나오는 알. 불꽃·풀·전기 등 다른 타입으로도 확장 검토 | 해당 타입 확정 여부, 복합 타입·폼의 포함 기준, 희귀도 비중 |
| 희귀 포켓몬 알 | 희귀한 포켓몬을 더 잘 얻음 | 기본 알보다 희귀 포켓몬의 등장 비중을 높임. 희귀 포켓몬 확정으로 취급하지 않음 | 희귀의 정의, 준전설·전설·환상 포함 여부, 희귀 일반종 목록과 확률 |
| 이로치 알 | 이로치 수집 | 기본 알보다 이로치 확률이 높음. 이로치 확정으로 취급하지 않음 | 이로치 확률, 포켓몬·희귀도 목록, 이미 해금한 이로치가 나왔을 때의 보상 |

기존 알 뽑기는 기본 알로 유지하는 방향을 제안합니다. 새 알은 타입·희귀도·이로치 중 어떤 수집 목적을 원하는지 선택할 수 있도록 차이를 줍니다. 이름과 외형은 추후 정합니다.

## 규칙을 정할 때 검토할 것

- **타입별 알:** 물/비행처럼 복합 타입이어도 물 타입 알에 포함할지, 선택 폼이 아니라 기본종 타입을 기준으로 할지 정합니다. 테라 타입과 본래 타입은 구분합니다.
- **희귀 포켓몬 알:** 현재 코드의 일반·준전설·전설·환상 구분과, 도감에서 만나기 어려운 일반 포켓몬의 희소성은 구분해서 목록을 정합니다.
- **이로치 알:** 이로치 교환권은 원하는 보유 포켓몬의 외형을 해금하고, 알은 무작위 포켓몬을 얻는 방식이므로 가격·희소성·중복 보상을 함께 검토합니다.
- **종류별 티켓:** 물 타입 알 티켓 등 전용 티켓으로 나눌지, 공통 알 티켓으로 종류를 선택할지, 알 자체를 보관하는 방식으로 할지 미정입니다.
- **획득 경로:** 영구 상점·등반 보상·이벤트 등과 연결할 수 있지만, 알 종류가 특정 이벤트에만 종속되도록 확정하지 않습니다.
- **비용과 확률:** 기본 200P 뽑기와 10,000P 이로치 교환권의 가치를 기준으로 검토합니다. 구체적인 배율·가격·천장 도입 여부는 미정입니다.
- **결과 처리:** 현재 도감 등록·중복 개체치 개선·기술 해금 흐름을 활용할지, 중복 보상을 추가할지 정합니다.
- **부화 방식:** 우선 현재 즉시 결과를 보여주는 방식을 기준으로 검토합니다. 부화 대기·걸음 수 등의 별도 시스템은 요청된 알 종류에 포함된 확정 사항이 아닙니다.
- **확장 범위:** 첫 버전에 모든 타입 알을 넣을지 일부 타입부터 시작할지, 타입+이로치 같은 조합 알을 만들지는 추후 결정합니다.

## 다음 구체화 순서

1. 타입별·희귀·이로치 알의 대상 목록과 차이를 정합니다.
2. 티켓·알 보관 방식과 획득 경로를 정합니다.
3. 기본 알과 비교해 확률·비용·중복 보상을 정합니다.
4. 종류별 선택 화면과 결과 표시를 구상합니다.
