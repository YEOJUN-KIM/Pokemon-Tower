# 선택 폼·출전 순서·도구 정산 후속 수정

갱신: 2026-10-13. 우라오스 플레이 피드백에서 확인한 공통 경로를 수정했다. 개발 서비스 버전은47, SQLite 스키마는28이다.

2026-10-14 표시명 후속: 배틀 HP 패널에서는 일격·연격 모두 ‘우라오스’, 거다이맥스 시 ‘거다이맥스 우라오스’로 표시한다. 태세별 이미지·타입과 도감의 상세 폼 이름은 유지한다.

2026-10-14 파티 이미지 후속: 배틀 교체창과 상단 팀 아이콘도 기본 보유 종이 아닌 현재 표시 폼의 이미지 경로를 사용한다. 연격 우라오스·오거폰 가면 등 선택 모습과 배틀 변신을 반영하며, 교체 요청의 멤버 식별자는 유지한다.

2026-10-14 출전 카드 도구 아이콘 후속: 포켓몬 이미지 크기 규칙을 카드의 직접 자식 이미지로 제한한다. 카드 안 도구 아이콘은18px, Z크리스탈은18×22px로 표시해 PC·모바일에서 포켓몬 이미지 크기를 상속하지 않도록 했다.

2026-10-14 거다이맥스 기술명 후속: PokeAPI 기술 CSV에 없는 거다이맥스 전용 기술33종의 한국어 이름을 `src/data/gigantamax-moves.json`에 보완하고 공통 `moveInfo`에 연결했다. 거다이연격·거다이일격·거다이환영 등 기술칸과 메시지가 같은 매핑을 사용한다. 타입·분류·기본 메타데이터는 설치된 Showdown 엔진에서 가져오며, 실제 기술칸의 위력·분류는 기존 배틀 요청 값을 사용한다. 목록 대조: [거다이맥스 기술 목록](https://pokemonshelter.com/swsh-gigantamax/). 기존 일반 기술 카탈로그 재수입과 분리해 번역 보완을 유지한다.

## 적용 내용

2026-10-14 기술 설명 후속: 거다이맥스 기술의 공통 안내 문구를 제거했다. 실제 한국어 효과 설명이 없는 기술은 PC 상세창·모바일 툴팁에서 설명 문단을 숨기고, 타입·분류·PP·위력·명중률은 표시한다. 일반 기술의 기존 효과 설명은 유지한다.

| 문제 | 현재 동작 |
|---|---|
| 연격 우라오스 선봉이 경기 후 마지막으로 이동 | 배틀의 선택 폼을 보유 멤버 식별자로 환산해 다음 출전 순서를 유지한다. 영입으로 교체한 멤버는 기존 순서에 반영한다. |
| 우라오스와 연격 우라오스에 도구가 따로 저장 | 모든 가족형 선택 폼의 도구 정산을 기본 멤버 식별자로 통일한다. 로토무 가전 등 별도 수집 폼은 독립 항목으로 유지한다. |
| 기존 중복 장착 기록 | 저장소를 열 때 기본 멤버 장착을 유지한다. 폼에만 있던 도구는 기본 멤버로 옮기고, 기본 멤버와 다른 도구가 중복 기록돼 있으면 가방에 돌려놓는다. 동일 도구 중복 기록은 하나로 합친다. 재실행해도 가방 수량이 다시 증가하지 않는다. |
| 플레이어 거다이맥스가 일반 확대만 표시 | 새 배틀·재도전 생성 시 밴드를 지닌 거다이맥스 지원 종에 엔진 플래그를 저장한다. 우라오스 일격·연격을 구분해 변신하고3턴 후 원래 태세로 복귀한다. 미지원 종은 일반 다이맥스를 사용한다. |
| 연격 거다이맥스의 기본 타입·이름 혼동 | 카탈로그를 연격 우라오스에서 파생해 해당 태세의 정보와 로컬 이미지를 사용한다. |
| 오거폰 테라스탈 후 기본 가면 이미지로 표시 | 벽록·우물·화덕·주춧돌의 선택 가면 이미지를 유지하고 테라 연출·공개 타입을 적용한다. 별도의 신규 테라 전용 스프라이트를 추가한 것은 아니다. |
| 일반 층 출전 준비에서 도구 관리 진입 불가 | 매 층 출전 선택에 지닌 도구 관리와 각 멤버 장착 표시를 추가한다. 24층에서도 우라오스의 밴드를 팬텀에게 이동하거나 기존 도구와 교환할 수 있다. |
| 고정 가면 해제·교환 시 잘못된 재고 | 전용 도구가 고정된 선택 폼은 해제·교환·다른 도구 장착을 거절한다. 관리 화면에서 고정 안내와 버튼 제한을 제공한다. |

도구 구매는 기존 상점에서만 가능하다. 출전 준비는 보유 도구의 장착·해제·이동·교환을 제공한다. 확인 후 거래하며 현재 소지자·룰·양쪽 장착 조건을 검증한다. 진행 중 배틀의 저장된 팀·플래그는 다시 쓰지 않으므로 거다이맥스 등록 변경은 다음에 생성하는 배틀부터 적용된다.

## 검증

다음8개 파일의 단위·통합39개와 `tsc --noEmit`을 통과했다.

```powershell
node --import tsx --test tests/form-equipment.test.ts tests/team-order.test.ts tests/gimmicks.test.ts tests/held-items.test.ts tests/selectable-forms.test.ts tests/form-display-consistency.test.ts tests/npc-gimmicks.test.ts tests/battle-retry.test.ts
node node_modules/typescript/bin/tsc --noEmit
```

선택 가능한 가족형 폼26종의 도구 정산, 모든 플레이 가능한 거다이맥스 종의 플래그·이미지 경로, 우라오스 두 태세와 팬텀의 실제 변신·복귀·연출, 오거폰4종의 실제 테라 변신과 가면 유지,24층 도구 교환·고정 도구 보호를 확인했다. 출전 준비 UI는 React 정적 렌더링으로 관리 버튼·층수·태세 표시를 확인했다. 기존 NPC 기믹과 재도전 회귀도 포함한다.

이번 후속 수정에서 브라우저 PC/모바일 조작·프로덕션 빌드·전체 테스트 묶음·난이도 시뮬레이션은 재실행하지 않았다. 별도 확인한 기존 `tests/tower.test.ts`의3건 실패는 출전 순서 수정 전에도 같은 영입 후보/해금 수 불일치로 발생했다. 최신39개 통과와 구분한다.

구현: `collectionSpecies`·`dynamaxDisplaySpecies`는 `src/data/selectable-forms.ts`, 플레이어 팀 생성은 `packPlayerTeam`, 저장 복구는 `TowerStore.repairFormHeldItems`, 화면 진입은 `TowerControls`와 `HeldItemManager`다.
