# 테라스탈 · 2026-10-10

도감에 저장한 테라 타입으로 변신한 뒤 선택한 기술을 사용한다. 테라권은 팀 공용 소모품이며 포켓몬에게 장착하지 않는다. 일반 지닌 도구 칸은 그대로 사용한다.

## 현재 규칙

- 양쪽 진영 각각 배틀당 한 번. 여러 장을 보유해도 한 배틀에서 두 번 쓸 수 없다. 교체·기절로 사용 횟수를 돌려주지 않는다.
- 해당 포켓몬이 메가진화·다이맥스 중이면 테라스탈 불가. 테라스탈 중인 포켓몬도 메가진화·다이맥스 불가. 다른 일반 상태의 팀원은 테라권과 배틀 사용 횟수가 남아 있으면 사용할 수 있다. 메가·다이맥스끼리의 기존 팀 공통 1회 제한은 유지한다.
- 도감 설정은 무료이며 새 도전 시작 시 스냅샷으로 고정한다. 기본은 원래 첫 번째 타입이다. 예: 어흥염의 불꽃/악 → 불꽃. 엔진의 전용 폼 규칙이 있는 오거폰은 해당 가면 타입, 테라파고스는 스텔라만 허용한다.
- 테라권 사용 명령을 서버가 확정할 때 행동 기록과 재고 차감을 같은 트랜잭션으로 저장한다. 버튼 예약·취소만으로는 차감하지 않는다. 새로고침·서버 재시작 시 배틀 생성 당시 테라권 수와 저장된 행동을 재현하며 다시 차감하지 않는다.
- 실제 방어 타입·원래 타입의 STAB 유지·일치 테라의 추가 보정·테라버스트 및 전용 폼 처리는 Showdown 엔진이 수행한다. 이번 구현은 자체 피해 공식을 따로 만들지 않는다.

## 시험용 공급과 상대

공급·가격·상대 등장 확률은 사용자가 지정하지 않아 다음 임시 구성을 적용했다. 새 도전은 테라권 1장으로 시작한다. 매 정비 상점에서 에픽 테라권 1장을 900코인에 구매하고 남은 재고는 도전 안에서 이월한다. 재사용형 레전더리 테라권은 추가하지 않았다. 기존 진행 중 도전에 초기 지급을 소급하지 않는다.

새 배틀의 상대에게도 팀 공용 테라권 1장을 배정한다. 기본 테라 타입을 팀 생성 시 저장하며 v5 AI가 유효한 공격을 결정할 때 사용한다. 메가·다이맥스가 먼저 선택되면 일반 팀원에게 테라를 남긴다. 상대의 테라 타입은 발동 전에는 공개하지 않는다. 층별 등장 확률과 새 기믹 포함 경제·난이도는 재측정 전이다.

## UI와 연출

싸운다 화면에서 기술 목록 오른쪽, 기술 정보 칸 앞에 타입 색상의 결정 버튼을 둔다. 다이맥스·메가진화는 기술 패널 상단 경계 위에 독립된 문양 버튼으로 나란히 둔다. 기술 4칸의 가로 공간을 줄이고 세 문양을 약 1.5배 확대했다. 메가진화는 무지개 구슬과 검은 문양으로 표시한다. 세 버튼의 박스 테두리와 배경을 제거하고 빛과 체크 표시로 예약 상태를 구분한다. 사용할 수 없는 문양도 회색으로 남아 위치가 유지된다. 테라는 T 또는 버튼으로 예약·취소하고 기술 결정으로 발동한다. X로 기술 메뉴를 나가도 예약은 취소한다. 사용할 수 있으면 빛나고, 사용 불가일 때도 회색 버튼으로 표시하고 툴팁으로 이유를 제공한다.

에너지 집중 → 결정 껍질 → 파편 해방 → 타입 색상의 결정 모습 → 공격 순서로 연출한다. 불꽃은 주황·붉은색, 물은 파란색, 풀은 초록색이며 19개 타입을 구분한다. 변신 뒤에는 결정 장식과 윤곽이 유지되고 Shift로 건너뛰어도 최종 상태는 유지한다.

버튼의 위치·타입 색상·예약 방식은 [PokéRogue 공식 저장소의 명령 UI](https://github.com/pagefaultgames/pokerogue/blob/beta/src/ui/handlers/command-ui-handler.ts)를 참고했다. [공식 테라스탈 소개](https://scarletviolet.pokemon.com/en-us/news/terastal_phenomenon/)와 사용자가 첨부한 이미지를 함께 참고했다. 결정 아이콘과 연출은 직접 작성한 SVG/CSS이며 외부 게임 이미지·코드를 복사하지 않았다.

## 저장과 확인

DB v19: `run_tera_tickets`(재고), `tera_purchases`(상점별 중복 구매 방지), `battles.tera_tickets`(진영별 시작 재고). 타입은 기존 육성 프로필 JSON과 도전 프로필, 배틀 팀에 저장한다. 이전 Terastal Clause 포맷과 v1~v4 AI는 보존하며 새 배틀만 새 포맷/v5를 사용한다.

검사: `tests/tera.test.ts`는 기본 타입·무료 저장·도전 고정, 발동 순서·STAB·테라버스트, 배틀 1회·진영별 제한·변신 겹침 방지, 소모·복구·리플레이·중복 구매를 확인한다. `e2e/tera.spec.ts`는 PC/모바일 버튼 위치·예약/취소·Shift·새로고침·타입 색상·도감 저장·상점·상대 연출을 확인한다. 캡처는 `artifacts/screenshots/gimmick-dock/` (이전 배치는 `artifacts/screenshots/tera-ui/`)에 보관한다.

최종 검증: 전체 단위·통합 129개, Chrome 기믹/테라 관련 PC·모바일 E2E 13개, 타입 검사·프로덕션 빌드 통과. 모든 E2E를 재실행한 기록은 아니다. 기존 다이맥스 E2E의 기술 분류 기대값은 이전의 글자 검사에서 현재 분류 아이콘의 접근성 이름 검사로 고쳤다.
