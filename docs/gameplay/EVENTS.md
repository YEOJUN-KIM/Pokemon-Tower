# 이벤트와 보상 기획

기준: 2026-10-16. **미스터리 상자의 초기 확장과 독립 중앙 Reward Popup 기반을 구현했습니다.** 브리더·여행 상인은 기존 동작을 유지합니다. 도전자 선택전·레이드·새 빌런 캠페인·히든 상인·미러 매치는 아직 구현하지 않았습니다. 후속 설계는 [이벤트 콘텐츠 설계](EVENT_CANDIDATES.md), 알 규칙은 [알 종류와 부화](EGGS.md)를 따릅니다.

## 현재 구현: 미스터리 상자와 기존 만남

전체 등장률은 대상 층마다 **10%**, 등장한 뒤 종류 비중은 상자 50% / 브리더 30% / 여행 상인 20%입니다. 기존 확률·쿨다운·배치 규칙을 유지합니다.

| 적용 대상 | 이벤트 | 현재 동작 |
|---|---|---|
| 새 이벤트 활성 런(v2) | 미스터리 상자 | 열기 / 지나가기. 아래 테스트용 결과표에서 한 번 추첨하고 공통 Reward Popup으로 확인 |
| 기존 이벤트 활성 런(v1) | 길에서 발견한 상자 | 기존 80%로 150코인, 20%로 알 뽑기권 1장. 선택 대기 상태와 이미 지급한 결과도 그대로 복구 |
| v1·v2 공통 | 브리더의 응원 | 선물 받기 / 지나가기. 받으면 알 뽑기권 1장 |
| v1·v2 공통 | 여행 상인의 제안 | 300코인으로 구매 / 지나가기. 알 뽑기권 1장, 잔액 부족 시 차감·지급 없이 재선택 |

### 미스터리 상자 초기 테스트값

아래는 **최종 밸런스가 아닌 초기 테스트값**입니다. 확률·보상·손실률은 `src/data/run-events.ts`의 `mysteryChestResults`에 모았습니다. 컴포넌트에는 하드코딩하지 않습니다.

| 계열 | 결과 | 전체 상자 기준 확률 | 적용 내용 |
|---|---|---|---|
| 꽝·손해: 합계 50% | 빈 상자 | 25% | 아무것도 얻지 못함 |
| 꽝·손해: 합계 50% | 함정 | 25% | 선택 확정 시 보유 타워 코인의 15% 손실. 소수점 버림 |
| 좋은 보상: 합계 30% | 코인 | 15% | 300 타워 코인 |
| 좋은 보상: 합계 30% | 알 티켓 | 15% | 공통 알 뽑기권 1장 |
| 매우 좋은 보상: 합계 20% | 보물 | 10% | 1,000 타워 코인 + 공통 알 뽑기권 1장 |
| 매우 좋은 보상: 합계 20% | 티켓 묶음 | 10% | 공통 알 뽑기권 3장 |

손실은 서버가 실제 잔액으로 계산해 잔액 이하로 제한하고 지갑을 음수로 만들지 않습니다. 예를 들어 101코인이면 15코인, 1코인·0코인이면 0코인을 잃습니다. UI는 비율과 실제 손실 코인을 함께 표시합니다. 코인 손실은 현재 지갑만 줄이며, 누적 획득 코인 표시는 상점 지출과 마찬가지로 총 획득량을 유지합니다.

### 진행과 공통 Reward UI

- 상자 발견 → 메시지 → `선택지 보기` → `상자를 연다 / 지나간다` → 짧은 열림 연출 → 중앙 Reward Popup → `확인` → 기존 정비·출전 준비 순서입니다. 지나가면 보상 추첨 없이 기존 진행으로 돌아갑니다.
- 하단 메시지창은 짧은 상황 안내만 담당하고 실제 결과 목록을 중복 표시하지 않습니다. 열림 연출 약 650ms 뒤 별도 중앙 팝업에서 제목·여러 결과 항목·확인을 표시합니다. 동작 감소 설정에서는 지연을 생략합니다. 코인 획득·코인 손실·알 티켓·단순 메시지를 지원하며, 빈 상자는 가짜 보상을 표시하지 않습니다.
- 팝업은 실제 modal dialog로 배경을 어둡게 표시하고 배경 클릭·키보드 조작을 막습니다. 확인에 기본 포커스·커서를 두며 Enter/Z/Space를 지원합니다. Tab은 팝업 안에서 순환하고 ESC/X·배경 클릭으로 닫지 않습니다. 모바일·작은 화면에서는 내용만 내부 스크롤하고 확인 버튼을 유지합니다. 브리더·상인과 v1 상자는 기존 문구·보상 표시·`계속하기` 흐름을 유지합니다.
- 상단 배틀 필드와 기존 상자 SVG는 그대로 보입니다. 결과 단계에는 발견 요약창을 숨기고, 꽝·손실에는 성공용 별·Glow를 표시하지 않습니다. 팝업도 neutral/loss/good/great별 테두리·강조를 구분하며 great에 짧은 반짝임을 사용합니다.
- 일반층 승리·영입 선택을 마친 뒤 만남을 추첨합니다. 5의 배수 관문·마지막 클리어·히든 보스 대기에는 추가하지 않습니다. 만난 다음 두 층은 모든 이벤트의 재등장을 막으며, 지나가도 동일합니다. 층·승리 횟수·보스 배치를 소모하지 않습니다.

### 저장·결제·호환

- DB v35에서 이벤트 규칙은 v1·v2를 구분합니다. 기존 런의 활성화 여부와 v1을 유지하고 새 이벤트 활성 런만 v2를 사용합니다.
- 서버가 상자를 열 때 결과를 한 번 추첨하고, 실제 손실·획득 항목을 포함한 `RewardResult`를 `result_json`에 저장합니다. 재접속 시 문구·항목·수량까지 같은 결과를 복원합니다.
- 결과 결정·코인 차감·모든 보상 지급·이벤트 선택과 결과 저장은 하나의 기존 트랜잭션에서 처리합니다. 한 항목이나 결과 저장이 실패하면 코인 손실·획득과 티켓 지급도 모두 롤백합니다.
- 같은 선택 재전송은 재추첨·재차감·재지급하지 않습니다. 이미 확정한 것과 다른 선택은 거절합니다. 결과 확인 전 다음 배틀 진입은 서버에서도 막습니다. `확인`은 완료 상태만 저장하며 보상을 다시 지급하지 않습니다.
- 코인은 현재 도전 지갑에, 알 뽑기권은 영구 보관함에 반영합니다. 기존 런·대기 이벤트·지급 보상·완료 기록을 마이그레이션에서 재정산하지 않습니다.

[이벤트 화면 GIF](../../artifacts/qa/previews/events/chest-event.gif)와 기존 촬영·GIF 스크립트를 활용할 수 있습니다. 새 상자 결과 6종은 결정론적 E2E fixture로 PC·모바일 화면을 확인합니다. 개발 책임과 확장 방식은 [이벤트 확장 방법](../engineering/EVENT_SYSTEM.md)에 정리합니다.

## 확정된 큰 방향: 후속 구현

| 이벤트 | 방향 |
|---|---|
| 도전자 선택전 | 컨셉 풀에서 약 3명 무작위 후보, 위험도·성향·예상 보상 안내, 마지막은 돌아간다. 승리 후 영입 없이 공통 Reward UI 사용 |
| 특수개체 레이드 | 플레이어 3마리 대 특수개체 1마리. 이벤트 보스 자체는 소유 불가, 지급한다면 정상 개체·도감·알·티켓·해금 등 별도 보상 |
| 빌런 캠페인 이벤트 | 등반당 한 조직, 사건 개입·기습·정보·거점·보스의 별도 연계 서브 스토리. 활성 목적지는 최대 1개 |
| 히든 상인 | 룰 기믹 조기 획득·희귀 상품 판매. 정상 획득 경로 유지. 런 강화 상품은 타워 코인, 알·영구 수집 상품은 영구재화 |
| 영양제 상인 | 고정 영양제 상점을 제거·축소하고 랜덤 이벤트 판매로 이동. 장기간 미등장 보정은 검토 |
| 미러 매치 계열 | 같은 종·폼에 다른 세팅을 쓰는 일반 미러, 보유 6마리 중 무작위 3마리의 왜곡 미러, 희귀·고난도 챔피언 미러 |
| 미스터리 상자 | 초기 구현 완료. 현재 지원 범위는 위 결과표이며, 아이템·영양제·영구재화 등의 후속 보상은 미구현 |

- 도전자 선택전은 상·중·하 후보를 한 명씩 보장하지 않습니다. 후보 전원이 강하거나 약할 수도 있고, 정확한 후보 수·보상은 추후 결정합니다.
- 공통 Reward Popup과 기존 결과 적용 기반은 미스터리 상자에서 구현했습니다. 선택 대기·완료 타입과 후보 목록·선택 ID 콜백의 UI 기반만 추가했습니다. 실제 도구·영양제 풀, 선택 저장·지급 API, 도전자·레이드 등은 미구현입니다.
- 기존 빌런 층 교체 방식은 줄이거나 제거하는 방향입니다. 현재 구현은 [타워 진행](PROGRESSION.md)을 따르며, 새 캠페인의 기습전은 일반전 뒤 추가 전투입니다.
- 레이드 특수개체의 소유 금지, 도전자 선택전의 영입 없음은 확정 방향입니다. 다른 이벤트의 포켓몬 보상까지 일괄 금지하는 뜻은 아닙니다.
- 챔피언 미러의 기믹 예외는 해당 이벤트에만 적용하는 방향이며, 일반 배틀 규칙을 바꾼 것은 아닙니다.
- 현재 브리더의 응원·여행 상인은 임시 구현으로 남습니다. 독립 후보인 브리더의 알 선택을 히든 상인에 흡수한 결정과 혼동하지 않습니다.
- 히든 상인의 알 상품은 영구재화 사용 방향입니다. 현재 여행 상인의 300코인 거래를 이번 작업에서 변경하지 않았고, 전환 여부는 추후 결정합니다.

상세 설계와 예시는 [이벤트 콘텐츠 설계](EVENT_CANDIDATES.md)에만 모읍니다. 후속 이벤트의 확률·가격·보상량·등장 층은 TODO입니다. 미스터리 상자만 위의 50/30/20 초기 테스트값으로 구현했으며 최종 밸런스는 미정입니다.

## 제외한 보상

- **회복권·부활권:** 매 배틀 전에 회복해주는 현재 흐름에서는 필요하지 않아 후보에서 제외합니다.

## 보류한 보상

- **폼 변경·진화 재료:** 도감에서 포켓몬을 해금하면 폼체인지를 자유롭게 할 수 있으므로 보류합니다. 도입 여부와 기존 해금 방식과의 관계는 추후 검토합니다.

## 외형 보상: 후속 구상

- 현재 하나인 플레이어 스프라이트의 선택지를 늘리는 방향을 검토합니다.
- 추가 트레이너 외형을 이벤트 보상으로 해금하는 방식은 구상 단계입니다.
- 외형 종류, 리소스 확보 방식, 선택 화면, 해금 조건은 아직 정하지 않았습니다.
- 칭호·프로필 테두리·배틀 배경 등 다른 외형 보상의 범위도 추후 검토합니다.

## 추후 결정할 규칙
