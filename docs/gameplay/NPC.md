# 상대 트레이너

새 일반 모드의 관장·사천왕·챔피언·네임드·빌런은 대표 기믹과 두 단계 팀을 사용합니다. 일반 트레이너와 조직원은 대표 기믹을 사용하지 않습니다. 플레이어가 선택한 룰별로 NPC 파티를 따로 만들지 않습니다.

| 구간 | 팀 단계·기믹 |
|---|---|
| 5~45층 관장·사천왕 | 전반 팀, 기믹 없음 |
| 50층 챔피언·관문 | 첫 관문 팀, 대표 기믹 사용 시작 |
| 55~95층 관장·사천왕·간부 | 후반 팀과 대표 기믹 |
| 100층 챔피언·최종 보스 | 최종 팀과 대표 기믹 |

51~54층은 완화 구간입니다. 빌런 보스는 75층 이상에서 후반·최종 팀을 사용합니다. 능력 포인트는 해당 층의 육성 곡선을 상한으로 역할 비율을 유지합니다. 새 관장 이상급의 IV는 총합 예산과 역할 가중치로 시드 기반 랜덤 배분하고, 일반·엘리트의 기존 IV는 유지합니다.

검토 자료는 164종×두 단계=328팀입니다. 표의 균등 IV는 템플릿 참고값이며 실제 배틀에 저장되는 역할별 IV와 다릅니다. 상대 AI는 공개된 정보를 이용하고 플레이어의 비공개 팀 정보를 미리 읽어 맞춤 파티를 만들지 않습니다.
