# 배틀 기믹

2026-10-13 최신 후속: 새 플레이어 배틀·재도전에서 다이맥스밴드를 지닌 거다이맥스 지원 종은 해당 거다이맥스 형태와 기술을 사용한다. 우라오스의 일격·연격 모습을 구분해3턴 후 원래 태세로 돌아온다. NPC 거다이맥스 회귀도 확인했다. [적용·검증](FORM_EQUIPMENT_FIXES.md). 아래 미지원·가격·AI 설명은 최초 구현 당시 기록이다. 현재 룰은 [배틀 룰 선택](BATTLE_RULE_SELECTION.md)을 따른다.

기준일: 2026-10-10. 메가진화와 다이맥스를 합쳐 **각 진영 배틀당 1회** 사용한다. 한쪽이 메가진화를 사용하면 그 팀의 다른 포켓몬은 다이맥스나 추가 메가진화를 사용할 수 없다. 기절·교체해도 횟수를 돌려주지 않고 다음 배틀에서 초기화한다. 상대도 같은 규칙을 적용한다.

## 조작과 연출

싸운다 화면에서 변신 버튼을 클릭하거나 M으로 예약한다. 기술을 선택해 Z로 결정해야 발동하며 다시 M을 누르면 예약을 취소한다. 메가진화는 메가스톤·키스톤 반응 문구 → 회전 고리와 에너지 집중(950ms) → 연한 무지개 구체의 맥동(650ms) → 빛의 껍질이 파편으로 해방(400ms) → 짧은 섬광(250ms) → 실루엣에서 메가 모습 공개(850ms) → 선택한 기술 순서다. 공식 XY 소개 영상(https://www.youtube.com/watch?v=YTHgE0vtOXU)의 0:43~0:45 구간의 회전 에너지와 실루엣 공개를 참고해 CSS/SVG로 제작했다. 다이맥스는 볼로 회수 → 붉은 볼 확대·발사 → 에너지 폭발 → 거대한 실루엣 출현 순서로 연출하며 분홍·붉은 빛을 유지한다. 공식 소드·실드 소개 영상의 1:37~1:47 구간을 참고했다. 최대 HP 증가/복귀에 따른 엔진의 silent 이벤트는 회복 문구나 초록 회복 효과를 띄우지 않는다. Shift로 연출을 건너뛰어도 실제 효과와 최종 모습은 유지된다. 저장 후 새로고침도 변신 상태를 재현한다.

## 실제 효과와 도구

- 메가스톤 47종: 해당 종만 장착, 실제 메가 종족값·타입·특성으로 변신. X/Y는 별도 도구다. 도구 칸을 사용하며 다른 지닌 도구와 동시에 장착할 수 없다.
- 다이맥스밴드: 도구 칸을 사용한다. HP 2배, 다이맥스 기술로 변환, 3턴 후 원상복귀. 자시안·자마젠타·무한다이노는 장착 불가다.
- 둘 다 레전더리, 각각 2,500코인. 랜덤 4종 상점의 기존 층별 등급 확률을 따른다. 첫 상점에서도 레전더리 확률 0.01%가 있으므로 완전히 차단하지 않는다.
- 생명의구슬은 에픽 900코인으로 이동했다. 기본 도구 35종 + 메가스톤 47종 + 밴드 1종 = 83종. 같은 도구 동시 중복 장착 금지 규칙도 유지한다.

종별 목록은 src/data/mega-items.json, 변신 형태 정보는 mega-forms.json에 있다. 6·7세대 메가스톤 형태만 지원하며 메가레쿠쟈, ZA 추가 메가, 원시회귀, 거다이맥스 전용 형태, Z기술은 아직 지원하지 않는다. 테라스탈은 별도 팀 공용 테라권으로 구현했다.

## 상대와 저장 호환

새 배틀은 tower-policy-v4를 사용한다. 메가는 기술 결정 시 사용하고, 다이맥스는 유효한 공격 기술을 선택했을 때 사용한다. 변화기술/무효 공격, 건강한 상태에서 HP 25% 이하 상대를 마무리할 때는 보류한다. 다이맥스 중에는 원래 공격의 예상 피해를 기준으로 공격을 골라 Max Guard 남발을 방지한다. 성도 40층 목호의 망나뇽과 50층 레드의 피카츄가 밴드를 사용한다. 피카츄는 전기구슬 대신 밴드를 장착한다. 모두 동일한 도구 칸과 팀 공통 횟수를 지킨다. 저장된 v1·v2·v3 AI는 원래 정책으로 재현하며 이미 저장된 팀은 수정하지 않는다. 새 난이도 결과는 BOSS_GIMMICK_BALANCE.md에 기록했다.

## 스프라이트

Smogon Pokémon Showdown의 gen5/gen5-back PNG와 gen5ani/gen5ani-back GIF를 사용한다. 47종 모두 앞·뒤 2D 정지 이미지를 확보했고 정면 23종·뒷모습 10종은 gen5ani 도트 애니메이션을 사용한다. 애니메이션이 없는 방향은 2D PNG로 표시하고 3D 모델 GIF로 대체하지 않는다. 파일은 public/sprites/gimmicks, 출처 목록은 artifacts/reports/mega-sprite-sources.json, 가져오기 스크립트는 scripts/import-mega-assets.mjs에 있다. 메가 형태별 키·타입·키 정보를 사용하고 다이맥스 확대는 화면 높이에 맞춰 잘림을 제한한다.


## 테라스탈 — 구현

팀 공용 소모 테라권, 도감 타입 저장, 진영별 배틀 1회, 해당 포켓몬의 메가/다이맥스와 중첩 금지, 타입 색상 버튼과 결정 연출을 구현했다. 메가·다이맥스끼리의 기존 공통 1회와 테라 1회는 별개다. 구현 당시 새 도전 1장·상점 900코인·새 상대 1장은 시험용 공급안이었다. 현재 테라권 가격은 [현재 상태](../STATUS.md)를 따른다. 기존 배틀의 포맷과 AI는 보존한다. [상세 규칙·검증·캡처](TERASTALLIZATION.md).

Z기술은 2026-10-12 구현했다. 크리스탈 34종·3,000코인 구매·팀당 배틀 1회·공격/변화/전용 기술을 지원한다. [현재 규칙·화면·검증](Z_MOVES.md). 전체 기믹을 하나의 배틀 공통 횟수로 묶는 방식은 구현하지 않았다.
