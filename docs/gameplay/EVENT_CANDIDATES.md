# 우리 게임에 맞는 이벤트 선별

기준: 2026-10-14. `pokemon_tower_event_planning.xlsx`의 「이벤트 기획」 29개 항목과 「1차 구현 추천」을 현재 게임 규칙에 맞춰 검토한 제안입니다. 아래 우선순위와 각색은 선별 초안이며 구현 확정 사항이 아닙니다. 원본 엑셀은 수정하지 않았습니다.

현재 짧은 만남으로 층을 소모하지 않는 [상자·브리더 선물·여행 상인](EVENTS.md)을 구현했습니다. 브리더는 알 티켓 선물, 상인은 300코인으로 알 티켓 1장 구매까지만 지원하며 아래 확장 구상 전체를 구현한 것은 아닙니다. 아래 후보 선별 순서와 별개로 공통 선택·보상·저장 흐름부터 검증합니다.

## 현재 게임에 맞추는 기준

- 일반 모드는 100층, 최대 6마리 보유·3마리 출전의 싱글 배틀입니다. 초반에는 보유 파티가 3마리일 수 있습니다.
- 5층 단위 네임드 관문과 50·100층 관문을 유지하고, 전투 이벤트는 일반 트레이너층 자리에 배치하는 방향을 제안합니다. 엑셀의 등장 구간은 참고값으로만 사용합니다.
- 상대 6마리 공개·6마리 중 상대 선출은 현재 미구현입니다. 초기 후보는 상대 3마리 배틀로 각색합니다.
- 매 배틀 전 회복하는 흐름을 유지합니다. 연전의 위험은 누적 피해보다 추가 상대의 난이도와 이벤트 보상 정산 방식으로 만듭니다.
- 일반전에도 승리 후 영입이 있으므로, 수집 이벤트에는 희귀 후보·선택권 등 별도의 차이가 필요합니다.
- 영양제는 코드 기준 **한 포켓몬당 한 도전에서 종류와 무관하게 총 3개** 제한입니다. 이벤트 획득분도 같은 사용 한도를 따르는 방향을 제안합니다.
- 빌런은 도전 동안 같은 조직이 이어집니다. 새 빌런 이벤트도 기존 조직·보스 진행에 연결합니다.
- 보상 후보에 있는 새 교환권은 아직 구현됐다고 가정하지 않습니다. 성장 포인트·알 티켓·이로치 교환권 등 기존 기능에 연결 가능한 보상부터 검토합니다.

### 첫 검토 순서

희귀 스카우트전 → 히든 상인 → 상대·보상 선택전 → 전술 마스터를 먼저 구체화하는 것을 추천합니다. 기존 영입·상점·배틀 흐름을 활용하면서 수집·소비·선택·전술을 각각 추가합니다. 훈련소·브리더·교환 NPC는 보상과 사용 규칙을 정한 뒤, 빌런 사건은 기존 캠페인의 확장으로 이어갑니다.

## 배치·보상에서 다음에 정할 것

- 전투 이벤트는 일반층 대체, 비전투 이벤트는 층 사이 추가 만남으로 제안합니다. 비전투 만남이 층을 소모하는지·정비와 겹칠 때의 순서는 미정입니다.
- 새 이벤트들의 등장 빈도·연속 제한·희귀 등급과 기존 빌런 추첨과의 관계를 정해야 합니다. 원본 엑셀의 층수·우선순위를 확정값으로 옮기지 않습니다.
- 성장 포인트를 영구재화의 기본 후보로 삼고, 새 통화 추가 필요 여부를 검토합니다.
- 이로치 교환권은 현재 10,000P 상품이므로 흔한 이벤트 보상으로 지급하지 않는 방향을 제안합니다. 종류별 알도 기존 200P 알 뽑기와 함께 밸런스를 정합니다.
- 일반 승리 보상과 이벤트 추가 보상·영입을 중복 지급하지 않도록 정산 규칙을 정합니다.
- 구체적인 수치와 구현 작업은 후보를 확정한 뒤 진행합니다.
