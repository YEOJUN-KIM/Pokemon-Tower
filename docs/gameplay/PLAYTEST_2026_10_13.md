# 2026-10-13 배틀 플레이 피드백 반영

사용자가 제시한 8개 항목의 구현 범위다. 기존 생성된 상대 팀은 다시 추첨하지 않는다.

우라오스 플레이 후속은 [선택 폼·출전 순서·도구 정산 수정](FORM_EQUIPMENT_FIXES.md)에 정리했다. 매 층 출전 준비 도구 관리, 태세별 거다이맥스, 오거폰 테라 가면 유지와 관련39개 검증은 아래 최초8건의 검증과 구분한다.

| 항목 | 적용 |
|---|---|
| 영입 후보 정보 | 후보를 선택한 뒤 정보 버튼으로 이번 상대의 기술·위력·분류·설명·특성·성격·종족값을 확인한다. 승리 후에만 API가 정보를 반환한다. 영입 후 최종 설정과 상대의 현재 세팅은 구분한다. |

| 도구 이동·교환 | 다른 멤버의 도구도 선택할 수 있다. 확인 후 대상이 빈손이면 이동, 기존 도구가 있으면 상호 교환한다. 양쪽 장착 조건과 현재 소지자를 검증하고 한 트랜잭션으로 처리한다. |

장착 조건이 맞지 않는 교환, 전용 도구가 고정된 모습, 승인 이후 소지자가 바뀐 요청은 거절한다. 확인창을 취소하면 변경 요청을 보내지 않는다.

후속 UI 수정: 도구 확인창은 왼쪽 예·오른쪽 아니요이며 좌우 방향키로 이동한다. 위아래 키는 선택을 바꾸지 않는다. 배틀 기록은 창을 연 뒤 레이아웃이 생긴 시점에 최신 기록으로 스크롤하며, 닫았다 다시 열어도 맨 아래에서 시작한다. PC 좌우 키·PC/모바일 로그 재열기 검증을 통과했다.

이미지 감사 후속: 육파리·베라카스·키키링·오거폰·무쇠감투의 Showdown 정면 PNG는 도트가 아닌 일러스트형 원본이다. 해당5종은 기존 로컬 PokeAPI 도트 PNG를 사용하도록 경로를 수정했다. 612종×앞뒤×일반/이로치 총2,448개 경로, 그중 실제 사용 PNG772개를 점검했다. 높은 색상 수로 탐지한 비도트 후보5개는 직접 시각 확인했으며 교체 후 같은 후보와 누락 경로는0개다. 이미지 회귀7개·타입 검사 통과. 색상 수 검사는 후보 탐지용이며 전체 스타일을 수동 검수했다는 의미는 아니다.

영양제 히든 상점·2종 진열·가격 할증은 후속 기획으로 유지한다. 이번 구현은 총3개 제한이다. [배틀 개선 기준](../current/BATTLE_REBALANCE_PLAN.md).

도구 확장 후속: 부스트에너지·맹독구슬·화염구슬·풍선·속임수주사위·하양허브·파워풀허브·약점보험·멘탈허브·탈출버튼·탈출팩·레드카드·검은진흙·리샘열매·유루열매·날씨 연장 바위4종·그라운드코트 총20종을 상점·장착·이동·교환에 추가했다. 사용자 제외 목록인 목스프레이·클리어참·은밀망토·방진고글·방호패드·전기구슬·굵은뼈는 추가하지 않았다. 자연 소모·풍선 파괴는 다음 배틀에 장착을 복원하고, 탁쳐서떨구기 등 상대의 제거는 복원하지 않는다. 아이콘17개는 기존 PokeAPI 고정 버전 `a3a1432e688ea028f12c51371d5253037cb9f17b`의 PNG, 그 버전에 없는 부스트에너지·속임수주사위·탈출팩3개는 프로젝트 자체 SVG다.

신규 상점의 전설 등급 추첨 가중치는 클리어 층5/10/15/20/25/30에서3/4/6/8/10/12%로 변경했다. 이는 개별 슬롯의 등급 가중치이며 한 상점 전체의 출현 확률이나 획득 보장은 아니다. 전설 등급은 장착 가능한 메가·다이맥스·Z·원시회귀 중 종류를 먼저 추첨하여 도구 수가 많은 종류에 다른 종류가 묻히지 않도록 한다. 기존4종 진열은 유지하고 새 상점·리롤에 적용한다. 신규20종 실제 효과, 자연 소모 후 다음 층·리플레이,8,000회 상점 표본, 기존 구매·재고·교환·기믹 관련 회귀41개와 타입 검사 통과. [선택교환권 이벤트 구상](../current/BATTLE_REBALANCE_PLAN.md)은 문서에만 기록했다.

도구 이미지 후속: 사용자 참고 이미지와 승인한 부스트에너지 스타일을 기준으로 이미지 생성 도구에서 투명 배경 도트 PNG3종을 만들었다. 부스트에너지·속임수주사위·탈출팩의 실제 표시 경로는 각각 `public/sprites/items/booster-energy.png`, `loaded-dice.png`, `eject-pack.png`다. 초기 자체 SVG는 표시 경로에서 제외했다. 실제 게임 컴포넌트와 레이아웃을 사용하는 별도 메모리 DB 검증에서 Chrome PC1280px/모바일390px의 도구 관리·상점 아이콘 로딩을 확인하고 캡처했다. 플레이 계정의 재고는 변경하지 않았다. 도구 회귀8개·타입 검사 통과. 캡처와 생성 프롬프트는 로컬 `.data/item-icon-preview/`에 보관한다.

도구 설명에서는 반복되던 다음 배틀·다음 층 재사용 문구를 제거했다. 효과와 배틀 내 발동 횟수만 표시하며 실제 도구 복원 동작은 유지한다. 최종 화면 캡처에도 정리한 설명을 적용했다.

특성 한글화 후속: 영어로 남은9세대·신규 메가 특성 설명과 이름 누락을 공통 번역 데이터에서 보완했다. 초상투영4폼의 엔진 이름을 모두 초상투영으로 연결하고 천정부지·불꽃의갈기·파동의방호 등의 표시 이름을 추가했다. 설명은 현재 설치된 엔진 효과를 한국어로 옮겼으며, 미리보기 전용 Aura Guard는 최신 Showdown 효과를 기준으로 번역했다. `ability-localization.json`의 보완 데이터를 특성 이름·설명 가져오기 스크립트에서 병합하여 재생성 후에도 유지한다. 도감·폼 미리보기·배틀 카탈로그의 모든 특성 이름과 설명에 한글이 존재하고 영문 문장이 남지 않는지 검사한다(HP·PP·Z 표기는 허용). 특성 설명 재생성 및 관련 회귀8개·타입 검사 통과.

폼 표시 후속: 도감 이름은 기본 이름을 유지하며, 저장한 선택형 폼의 이미지·타입·종족값을 상세 영역과 선택 메뉴에 일치시킨다. 기본 정보 팝업에서는 폼 이름을 표시하고, 우라오스는 일격·연격의 태세와 각 거다이맥스를 구분한다. 누락된 연격 거다이맥스 일반·이로치 앞뒤 이미지4개는 기존 PokeAPI 고정 버전 `a3a1432e688ea028f12c51371d5253037cb9f17b`에서 추가했다. 전체 선택형 폼 데이터·이미지와 관련 회귀18개, 타입 검사 통과. Chrome PC1280px/모바일390px에서 켄타로스 워터종·우라오스 연격·오거폰 화덕의 가면의 메뉴 및 기본 정보, 우라오스 양쪽 거다이맥스 탭을 확인했다.

붉은달·메가 특성 후속: 붉은달 다투곰을 일반 다투곰 옆의 독립 수집·육성·배틀 항목으로 추가했다. 표시 이름은 다투곰, 구분 라벨은 붉은달, 전국번호901·등장9세대이며 독립 종족값·심안·블러드문 기술배치를 사용한다. 앞뒤·이로치 PNG는 기존 PokeAPI 고정 버전에서 확보했다. 메가 미리보기97개를 [Showdown 원본](https://github.com/smogon/pokemon-showdown/blob/490b7fb8c2e5e548df9b752f93a589a2a42ce398/data/pokedex.ts)과 비교하여 설치된0.11.11의 오래된 특성4개를 미리보기에서 보정했다: 갑주무사→단단한발톱, 앱솔Z→예리함, 한카리아스Z→부유, 루카리오Z→Aura Guard. 이4폼은 현재 타워에서 사용할 메가스톤이 없는 미리보기 전용이며 전투 지원을 추가한 것은 아니다. 사용 가능한48종은 실제 엔진에서 메가진화시켜 특성 변경을 전부 확인했다(메가후딘은 트레이스 직후 상대 특성을 복사하는 동작 포함). 관련 회귀19개·타입 검사 및 Chrome PC1280px/모바일390px의 붉은달 항목·메가갑주무사 특성 표시 검증 통과.

관련 회귀43개와 타입 검사를 통과했다. 실제 기합의띠 발동·다음 층·리플레이·탁쳐서떨구기 구분, 영양제4번째 구매 차단·종류/상점/재시작 합산, 도구 이동·교환·이전 요청·호환성·재고 보존, 승리 전 후보 정보 비공개, 일반/엘리트 팀 생성을 검증했다. 실제 게임 레이아웃을 재사용하는 별도 UI 테스트에서 Chrome PC1280px/모바일390px의 정보창·교환 승인/취소·영양제 최대 투여 버튼 차단·가로 넘침 없음도 확인했다. UI 검증은 실제 플레이 DB를 사용하지 않았다. 빌드와 전체 테스트 묶음을 재실행한 기록은 아니다.
