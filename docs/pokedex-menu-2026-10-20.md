# 도감 기능·구조 정리 및 임시 도전 룰 선택

## 변경 내용

- 상단은 도감 제목과 등록 수만 유지했다. 타이틀·업그레이드·새 도전 링크와 성장 포인트 표시를 제거했다. X를 통한 기존 뒤로 이동은 유지한다.
- 이름 검색 영역은 데스크톱 300px, 모바일 한 행으로 확보하고 검색어만 지우는 초기화 버튼을 복구했다. 검색:필터:보조 조작의 300:478:180 비율로 툴바 전체 폭을 채운다. 필터 안에서는 보유:타입:세대:특수 형태의 108:108:108:134 비율을 유지한다. 모바일은 행을 나눠 채운다. 보유 상태는 '모두 보기 / 보유 중 / 미보유'로 표시한다.
- 메가진화·거다이맥스 필터를 '특수 형태' 선택 메뉴로 통합했다. 기존 forms 데이터를 사용하는 '별도 폼 존재', '기타 특수 변신'도 선택할 수 있다. 별도 폼은 selectable, 기타 변신은 primal/battle 및 canPrimal을 기준으로 한다. 현재는 조건 한 개를 선택하며 옵션 정의와 판정은 별도 모듈에 분리했다.
- 현재 포켓몬 즐겨찾기 등록/해제(F)는 하단 조작 안내 옆으로 옮겼다. 즐겨찾기만 보기(V)와 필터 초기화(R)는 상단에 유지한다. 즐겨찾기에 등록한 포켓몬에만 채운 별(★)을 표시하며, 빈 별과 테두리·배경은 표시하지 않는다. 등록은 F/하단 조작으로, 등록 해제는 F/하단 조작 또는 해당 별 클릭으로 할 수 있다.
- 목록 제목·중앙 기본 정보 버튼·긴 출발 설명·큰 시작 버튼·항상 길게 나열하던 하단 키 안내를 제거했다. 기본 정보는 기존 포켓몬 선택 메뉴에서 열 수 있다.
- 오른쪽 출발 파티 3칸을 역할·스프라이트·이름·타입이 있는 카드로 분리했다. 빈 카드도 같은 틀과 역할을 사용한다. 모바일에서도 목록 오른쪽에 세로로 유지한다.
- 세 번째 포켓몬을 추가하면 '도전을 시작하시겠습니까?' 확인창을 연다. 기본 선택은 '아니요'이며 취소해도 3마리를 유지한다.
- 기존 공통 팝업과 GameMenuFooter를 재사용한다. 전체 UI 시스템, 타이틀, 업그레이드, 배틀 규칙·밸런스는 변경하지 않았다.

## 임시 도전 룰 영역

`ChallengeRuleChoice`를 도감 헤더의 작은 임시 영역으로 배치했다. 기존 `battleRules` 6개 항목과 `SettingsChoice`를 재사용한다. 위치를 바꾸려면 부모에서 이 컴포넌트의 배치만 변경하면 된다.

- 초기 선택: `chaos` / 혼합 룰.
- 없거나 비정상적인 값: `challengeRule()`이 혼합 룰로 정규화.
- 표시·선택 콜백·시작 요청 경계에서 정규화한다.
- 페이지 내부 상태로 유지하고, 도감의 직접 시작 요청 및 배틀 화면에 포함된 도감의 `onStart` 양쪽으로 전달한다.
- 필터 초기화와 시작 확인 취소는 룰을 초기화하지 않는다. 새로 페이지에 진입하면 혼합 룰이 기본값이다.
- 이미 진행 중인 도전의 룰을 변경하거나 새 도전으로 덮어쓰지 않는다. 기존 activeRun 방어 조건을 유지한다.

## 키보드 조작

| 위치 / 상태 | 조작 |
| --- | --- |
| 목록 맨 위 행 | ↑는 열 위치와 무관하게 항상 이름 검색으로 이동 |
| 검색·필터 | ←/→ 항목 이동, ↓ 목록 복귀. 검색의 Enter도 목록 복귀 |
| 목록 | 방향키 이동, 목록 좌우 끝에서 페이지 이동, PageUp/PageDown 유지 |
| 3마리 미만 | Enter/Z로 기존 포켓몬 선택 메뉴 열기 |
| 3마리 완료 + 목록/파티/페이지 영역 | Enter는 시작 확인, Z는 기존 선택·해제 메뉴 |
| 시작 확인창 | ↑/↓ 선택, Enter/Z 결정, Esc/X 취소. 기본 선택 '아니요' |
| 오른쪽 파티 | ↑/↓ 카드 이동, ← 목록 복귀, 마지막 카드에서 ↓로 하단 즐겨찾기 이동 |
| 헤더 룰 | Enter/Z 선택 메뉴, ↓ 검색. 검색·필터에서 ↑로 접근 |
| 검색 입력 중을 제외한 도감 | F 현재 포켓몬 즐겨찾기, R 필터 초기화. 기존 V 즐겨찾기 필터 단축키도 유지 |

검색 입력 중 Enter는 검색 영역의 조작으로 남겨 3마리 시작 단축키와 충돌하지 않게 했다. 마우스로 카드를 클릭하면 3마리 완료 상태에서도 기존 선택 메뉴가 열린다.

## 검증

- 프로덕션 빌드·TypeScript·CSS 구조 검사 통과.
- `pokedex-controls` 단위 테스트 2개: 기존 룰 보존/혼합 fallback, 실제 도감 데이터의 특수 형태 판정.
- 신규 Chrome 시나리오 4개: 1280×900 / 390×740에서 검색·필터·즐겨찾기·초기화·페이지·파티 카드·해제·시작 확인·취소 유지·재시도·선택 룰/기본 룰 전달.
- `/pokedex`의 직접 시작과 `/battle?prepare=1`의 내장 도감 시작을 각각 검증했다. 실제 시작 POST와 저장된 run.rule을 확인했다.
- 기존 game-menu Chrome 회귀 시나리오 7개도 통과했다.
- 데스크톱·모바일 스크린샷으로 검색 폭, 카드 정보와 빈 슬롯, 헤더 룰 영역 및 페이지 스크롤 여부를 확인했다.

## 남은 선택 사항

- 도전 룰의 최종 배치·디자인과 새 룰은 이번 범위에 포함하지 않았다.
- 특수 형태 여러 조건을 동시에 결합하는 필터는 후속으로 확장할 수 있다.
- 기존의 큰 시작 버튼·상단 링크·옛 검색 이름을 전제로 하는 구형 E2E는 새 UX에 맞춘 선택자 갱신이 필요하다. 전체 E2E 묶음을 모두 실행한 것은 아니다.

도감 목록·파티 카드는 기존 밝은 바탕을 사용하고 선택 배경도 옅은 민트로 조정했다. 목록은 개별 칸의 테두리 없이 하나의 밝은 바탕을 사용하며, 선택은 배경 변화로 표시한다. 기존 메뉴 동작은 유지한다. 보유·타입·세대·특수 형태에는 개별 단축키가 정의되어 있지 않아 키 표기를 추가하지 않았다.

이전/다음 버튼·페이지 번호·항목 범위가 있는 하단 페이지 바는 제거했다. 목록 끝의 ←/→와 PageUp/PageDown 페이지 이동은 유지하고 브라우저 테스트에서 확인한다.

V/R 및 즐겨찾기 갱신 후 목록이 교체되어도 커서는 기존 영역과 가능한 가까운 위치에 남는다. 결과가 비면 툴바로 이동하지 않고 빈 목록 영역을 유지한다.

별 표시는 파티 선택 번호보다 왼쪽·아래(셀 상단 18px(모바일 10px), 우측 28px)에 배치해 번호와 분리하고 스프라이트보다 위에 둔다.
