# 게임 소개 화면

2026-10-12 현재 프로덕션 빌드를 별도 SQLite 시연 저장으로 실행하고 Chrome에서 촬영했다. 실제 사용자의 계정·진행을 사용하지 않았다.

- `title.png`: PC 타이틀.
- `pokedex.png`: 도감과 출발 파티.
- `upgrades.png`: 영구 업그레이드.
- `battle.png`: PC 기술 선택.
- `mobile.png`: 모바일 기술 선택.

루트 README의 소개 이미지는 이 폴더에서 관리한다. 이전 개발 캡처는 최신 UI로 소개하지 않는다. 게임 UI가 달라지면 해당 이미지를 다시 촬영한다.
