# 선택 폼과 모습 설정

2026-10-13 최신 후속: 가족형 선택 폼은26종이다(초기24종에 켄타로스 팔데아 블레이즈·워터2종 추가). 선택 폼을 동일한 보유 멤버로 처리해 경기 후 출전 순서와 도구 장착을 유지한다. 우라오스 태세별 거다이맥스, 오거폰 테라 후 가면 표시와 고정 도구 보호도 반영했다. [후속 수정·검증](FORM_EQUIPMENT_FIXES.md). 아래24개와 수집 개수는 초기 도입 기록이다.

2026-10-13 사용자 결정: 기본 포켓몬 하나를 영입하거나 알에서 얻으면 그 포켓몬의 선택 폼을 모두 사용할 수 있다. 폼마다 별도로 승리·뽑기·아이템 해금을 요구하지 않는다. 개체값·능력 포인트·성격·이로치는 같은 포켓몬의 육성을 공유한다.

## 사용 방법

1. 도감에서 보유 포켓몬을 선택하고 Z/Enter로 선택 메뉴를 연다.
2. **2번 능력치 조정 → 모습 설정 탭**을 열고 원하는 모습을 선택한다. 선택 메뉴는 기존1~5번을 유지한다.
3. 아래 설정 저장 버튼으로 저장한다. 모습 변경은 무료이며, 다른 탭에서 수정한 능력 포인트·성격도 함께 저장된다. 저장하면 선택한 모습의 기본 특성·기술4개·테라스탈 타입이 설정된다. 이후 기술배치에서 수집한 기술을 다시 배치할 수 있다.
4. 다음 도전부터 선택한 모습으로 출전한다. 이미 진행 중인 도전은 출발 당시 설정을 유지한다.

폼마다 한 마리를 새로 만드는 방식이 아니다. 버드렉스는 기본·백마·흑마 중 하나를 고르고 같은 버드렉스의 육성을 공유한다. 출발 전에 고르는 폼과 배틀 중 자동 변신은 구분한다.

## 이번에 연결한 선택 폼24개

| 포켓몬 | 기본 모습 외 선택 폼 |
|---|---|
| 버드렉스 | 백마 탄 모습, 흑마 탄 모습 |
| 큐레무 | 블랙큐레무, 화이트큐레무 |
| 네크로즈마 | 황혼의 갈기, 새벽의 날개 |
| 디아루가·펄기아·기라티나 | 각각 오리진폼 |
| 테오키스 | 어택폼, 디펜스폼, 스피드폼 |
| 쉐이미 | 스카이폼 |
| 후파 | 굴레를 벗어난 모습 |
| 케르디오 | 각오의 모습 |
| 지가르데 | 10%폼 |
| 토네로스·볼트로스·랜드로스·러브로스 | 각각 영물폼 |
| 우라오스 | 연격의 태세 |
| 오거폰 | 우물·화덕·주춧돌 가면 |

이 폼들은 기본 정보에서 모습·타입·특성·종족값을 확인할 수 있고 모습 설정에서 실제 출전 형태를 저장할 수 있다. 원본 PokeAPI 앞·뒤·이로치 스프라이트를 로컬로 가져왔다. 원본에 없는 이미지 방향은 기존 기본종 이미지 대체 규칙을 사용한다.

추가한29개 폼 중22개의 정면·21개의 후면은 [Showdown 픽셀 애니메이션](https://play.pokemonshowdown.com/sprites/gen5ani/)을 확보했다. 실제 GIF 프레임 수를 검사하고 도감·모습 선택·배틀에 연결했으며, 이로치도 해당 소스가 있으면 움직이는 이미지를 사용한다. 우라오스 연격, 버드렉스 흑마, 펄기아 오리진, 러브로스 영물, 오거폰 가면3종은 이 픽셀 소스에 정면 애니메이션이 없어 정지 이미지를 유지한다. 후파 굴레를 벗어난 모습은 정면만 움직인다. 기존 픽셀 그래픽과 동일한 소스를 우선하며 3D 모델 GIF로 대체하지 않는다.

수집 스크립트는 `scripts/import-selectable-form-animations.mjs`, 파일 존재·프레임 수·해시 기록은 `artifacts/qa/assets/reports/selectable-form-animations.json`이다. 도감의 타입 표기는 **테라스탈 타입**, 성격 표기는 **성실**처럼 이름만 표시한다.

오리진폼과 오거폰 가면처럼 엔진이 전용 도구를 요구하는 모습은 선택한 모습에 도구가 자동 고정된다. 그 도구칸에 다른 일반 도구를 장착할 수 없다. 폼 해금 아이템을 새로 뽑는 절차는 없다. 기술·특성·종족값·전용 도구는 설치된 Showdown의 실제 동작과 합법성 검사에 따른다.

## 로토무는 별도 수집5종

히트로토무(전기/불꽃), 워시로토무(전기/물), 프로스트로토무(전기/얼음), 스핀로토무(전기/비행), 커트로토무(전기/풀)를 별도 도감·영입·알 뽑기·육성·출전 항목으로 추가했다. 기존 고스트 로토무도 유지한다. 전국도감 번호는 모두479번이며, 내부 식별에는 PokeAPI의 각 폼 ID를 사용한다.

배틀 지원 수집 항목은612개에서617개가 됐다. 전설 선택 폼24개는 별도 도감 보유 개수를 늘리지 않는다. 아르세우스·실버디의 모든 타입별 폼은 추가하지 않았다. 기존 메가·거다이맥스·원시회귀 미리보기는 유지한다.

## 배틀 변신폼의 기본 정보

사용자 후속 요청에 따라 **모습과 종족값이 달라지는 배틀 변신폼13개**를 기본 정보의 모습 미리보기에 추가했다. 폼을 누르면 해당 이미지·타입·특성·종족값·종족값 합계를 보여준다. 사용자 요청으로 변신 조건 및 정보 미리보기 안내 문구는 화면에서 제거했다. 기본 모습 버튼으로 돌아가 비교할 수 있다. 배틀 중 변신폼은 정보 미리보기이며, 능력치 조정의 모습 설정에서 출발 폼으로 저장하지 않는다. 보유 개수·해금·기존 배틀 동작은 그대로다.

돌핀맨의 공격 종족값은 기본70/마이티160, 마이티폼 종족값 합계는650이다. 모든 값은 설치된 배틀 엔진의 폼 데이터에서 읽는다. 설명만 있는 독립 수집 항목을 만들지 않는다. 종족값이 그대로인 따라큐 들킨 모습·캐스퐁 날씨폼 등은 이 목록에서 제외한다. 현재 엔진의 유대변화는 능력 단계 상승을 사용하므로 과거 세대 지우개굴닌자 변신 미리보기도 추가하지 않는다. 수집되지 않는 가라르 불비달마의 달마모드는 일반 불비달마 항목에 섞지 않는다.

메타데이터는 `src/data/battle-preview-forms.ts`이며 기존 `battle-forms.json`의 이미지 식별자를 사용한다. 전체13개 데이터 검사와 PC1280px·모바일390px의 돌핀맨·약어리·테라파고스 화면 검증을 통과했다.

배틀 변신폼도 움직이는 픽셀 스프라이트를 우선한다.13개 중 정면11개·후면9개에 실제 다중 프레임 GIF가 있으며, 도감의 기본 정보와 배틀에서 우선 사용한다. 돌핀맨 마이티폼·지가르데 퍼펙트폼은 현재 Showdown 픽셀 소스에 움직이는 버전이 없어 정지 이미지를 유지한다. 이로치도 확보한 GIF를 우선한다. `node scripts/import-selectable-form-animations.mjs --battle-previews`로 확인·갱신하며 기록은 `artifacts/qa/assets/reports/battle-form-animations.json`이다. 메테노는 기본 코어와 유성 모습의 이미지를 각각 구분했다.

## 저장과 검증

선택은 기존 육성 JSON의 `forme` 필드에 저장한다. DB 스키마27을 유지하고 개발 서비스 버전39을 사용한다. 선택한 폼의 packed species와 기본 포켓몬의 닉네임을 함께 저장해 수집·육성 키는 기본 포켓몬으로 유지한다. 개인 계정의 보유 목록이나 진행 데이터를 임의로 해금하지 않았다.

새 선택 폼 데이터는 `src/data/selectable-forms.json`, 가져오기는 `scripts/import-selectable-forms.ts`가 담당한다. 로토무는 공통 배틀·기술 목록에도 추가한다. 이번에 보스 샘플은 변경하지 않았다. 기존 승률 보고서는 새 선택 폼을 플레이어가 사용하기 전의 조건에서 측정한 기록이다.

선택 폼24개의 실제 배틀, 대표 폼 재생, 공유 육성과 무료 변경·재개방·출발 스냅샷, 로토무의 기술·타입·상대 풀을 검사했다. PC1280px·모바일390px에서 능력치 조정 내부 탭·육성과 모습 동시 저장·새로고침·폼 이미지 표시·도감 문구를 확인했다. 타입 검사와 프로덕션 빌드도 통과했다.

## 메가 지가르데 이미지 보완

메가 지가르데(API10301)는 기본 픽셀 스프라이트가 없어 일반 지가르데 이미지로 대체되던 문제를 수정했다. PokeAPI의 전용 공식 일러스트를 로컬로 가져와 일반·이로치 미리보기에 연결했다. 이 폼처럼 표준 스프라이트가 없는 경우 등록된 전용 일러스트를 기본종 대체보다 우선한다. 현재 확인한 원본 소스에는 메가 지가르데의 움직이는 픽셀 버전이 없어 정지 일러스트를 사용한다.
