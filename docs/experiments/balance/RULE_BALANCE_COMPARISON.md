# 룰별 난이도 비교 · 2026-10-10

동일한 72개 코스(1~9세대 각8개)·상대·시드·시작 상태를 다섯 룰에서 비교했다. 4시작 상태 × 5룰 × 72회 = 1,440등반, 실제 엔진 배틀41,462회다. 기존 6Z 코스를 사용했고 개판룰의 등반별 결과는 직전 측정과 네 시작 상태 모두 정확히 일치했다. 독립 표본을 새로 추가한 실험은 아니다.

기본룰은 기믹 없음, 메진/다맥/테라는 해당 기믹만, 개판룰은 모두 허용한다. 상대 팀의 금지 도구 제거·상점 후보 제외·초기 테라권·양쪽 합법 행동 제한은 현재 게임 구현과 같다. 상대의 금지 메가스톤을 해당 룰의 다이버섯으로 바꿔주는 등 새 기믹을 추가하지 않았다.

모든 룰·시작 상태에서100층 완주는0/72다. 표의 승률은50층까지 연속 통과한 등반 비율이다. 평균 클리어는 승리한 층수이며 패배한 층은 포함하지 않는다. 배틀 단위 승률은 이미 통과한 쉬운 층들의 승리를 반복 집계하므로 완주 난이도를 보여주기에는 적합하지 않다.

완전 육성 스타터에서는 기본룰50층 통과율33.3%, 개판룰12.5%로20.8%p 차이, 평균 클리어는5.21층 차이다. 동일 코스별로 기본룰이 더 오래 버틴 것은33회, 더 일찍 패배한 것은5회, 같은 결과34회다. 준비된 강팀에서는 기본룰/개판룰50층 통과율 모두30.6%로 차이가 작다. 따라서 기믹이 난이도에 영향을 주지만 팀과 자동 전략에 따라 영향이 다르고, 기믹만 제거한다고 전반적으로 쉬워지는 결과는 아니다.

테라룰의 스타터50층 통과율은20.8%로 기본룰33.3%보다 낮다. 기본룰에 테라를 넣으면 현재 테라룰과 같은 허용 구성이다. 이 결과에서 전 모드 테라 공통 적용을 서두를 이유는 없다. 메진+테라/다맥+테라 조합은 이번에 측정하지 않았으므로 해당 조합의 결과로 일반화하지 않는다.

초반은 다섯 룰 모두 미육성10층19/72, 중간 육성48/72, 완전 육성63/72, 강팀72/72다. 기믹 분리로 초반 병목이 해결되지는 않았다. 지금은 기본룰을 난이도 기준으로 두고 초반 상대 구성/강도와 후반50~100층의 생존 곡선을 별도로 검토하는 편이 맞다. 이번 요청에서 게임 난이도·가격·테라 허용 규칙을 변경하지 않았다.

## 검증과 한계

실행 중 금지된 기믹 발동이 있으면 중단하도록 검사했다. 최종 감사에서 코스/시드 출처 해시·72개 동일 코스·코인 정산·비음수 잔액/테라권·무료 리롤·10층 상점·금지 모드의 테라권 및 변신 사용0회·금지 도구 구매 없음·기존 개판룰 결과 완전 일치를 확인했다. TypeScript 검사도 통과했다.

AI 자동 플레이 결과이며 사람 승률이 아니다. 플레이어/상대 모두 기존 v7 공개 정보 기반 자동 전략이다. 미육성은IV0/능력포인트0, 중간IV15/33, 완전 육성IV31/66 및 공격 성격 스타터, 강팀은한카리아스·갸라도스·팬텀IV31/66와 준비된 기술이다. 최고 종족값 영입·6마리 파티 유지·자동 상점/영양제 구매를 사용하지만 정비 중 추가 영구 육성과 사람의 수동 팀 조합은 미반영이다. 테라권은 플레이어 초기1장 및 상점 구매를 소모하고, 상대는 기존 정책에 따라 각 배틀에서 지급되므로 사용량이 대칭적이지 않다. 지역 표본은 균등8개씩이므로 실제 무작위 지역 분포의 가중치를 반영한 결과는 아니다.

코스는 이전6Z 실험의 변환 코스로, 미진화 상대 진화체 치환과 일부 일반 상대 메타데이터의 근사 복원이 포함된다. 상세는 SIX_Z_OPPONENTS.md와 코스 sixZChange 기록을 참고한다. 각 조건72회이므로 소수 회의 통과율 차이는 확정적인 난이도 순위로 보지 않는다.
