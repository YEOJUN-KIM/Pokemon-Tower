# 20종·10층 콘텐츠와 검증

새 도전은 1~9세대 지역 테마 중 하나를 무작위 선택해 100층 동안 유지한다. 50층은 중간 관문, 51~60층은 완화 구간, 100층은 최종전이다. 일반 트레이너는 기믹을 쓰지 않으며 후반 엘리트 출현 비율을 높인다. 기존 저장은 목표 층과 생성 규칙을 유지한다. [지역 배치](../../gameplay/REGIONAL_THEMES.md), [100층 난이도·검증](../../gameplay/HUNDRED_FLOORS.md).

2026-10-04. 현재 고정 세팅은 레벨 50·중립 성격·도구 없음·개체값 31이다.
초기 해금은 기존 리자몽·거북왕·이상해꽃 3종을 유지한다. 기본 진화 단계와 최종 세팅/성장 규칙은 미정이다.

## 종과 출처

기존 7종: 리자몽, 거북왕, 이상해꽃, 피카츄, 갸라도스, 잠만보, 윈디.
추가 13종: 라이츄, 파르셀, 에브이, 팬텀, 루카리오, 딱구리, 라프라스, 쥬피썬더, 핫삼, 망나뇽, 마기라스, 메타그로스, 한카리아스.
20종 모두 스타터 또는 층 상대를 통해 해금 기회가 있다. 한 도전에서 모두 얻는다는 뜻은 아니다.

종·특성·기술의 전투 규칙은 설치된 Showdown Dex/TeamValidator에서 확인한다. `src/data/teams.ts`의 고정 세팅과 `src/data/floors.ts`의 상대 조합은 직접 구성했다.
이미지는 기존 PokéAPI sprites URL을 사용한다. 한글 종/기술 이름·표시 타입은 `src/web/catalog.ts`에 추가했다.
한카리아스는 Sand Veil이 현재 규칙에서 금지되어 Rough Skin을 고정 세팅으로 사용한다. 숨겨진 특성 구매/해금 조건을 확정하지 않는다.
무성별 메타그로스는 N, 기존 혼합 성별 종은 M으로 고정하여 기존 배틀의 난수 소비를 유지한다.

## 난이도 측정의 의미

`pnpm tower:audit`는 기본 스타터 3종의 모든 출전 순서(6가지), 12개 고정 시드로 각 층 72경기, 총 720경기를 실행한다. 엔진 버전·규칙·시드 범위·승수·평균 턴을 `logs/tower-balance.json`에 저장한다.
초기 측정에서 기존 1층 상대(피카츄·갸라도스·잠만보)의 승수는 8/72, 기본 순서는 2/12였다. 새 1층으로 바꾼 뒤 72/72, 기본 순서 12/12로 초반 접근성을 개선했다.

3·5·8층의 급격한 난도와 4층의 낮은 난도는 후속 밸런스 조정 대상이다. 배틀 개선 단계에서 자발 교체·상태/특성·변동 위력 및 다중 타격 데미지 추정도 개선한다.

## 검증 범위

- 20종 세팅을 현재 규칙의 엔진 검증기로 검사, 종 ID/표시 데이터/모든 기술 번역 검사.
- 10개 층에서 실제 엔진 경기 종료 확인.
- 디스크 DB의 새 도전에서 10경기 승리·층 진행·6마리 교체·중복 보상/영입 거부·7층 저장 복구·3,400원·10층 종료·해금 종 재도전 확인.
- 완주 테스트는 고정 시드에서 보유 멤버의 팀 순서를 탐색해 승리 경로를 고른다. 이는 시스템 연결 가능성 검증이며, 일반 사용자의 완주 난이도나 게임 AI 성능 검증이 아니다.
- v1의 진행 중 배틀과 입력을 v2로 복구하여 기존 3층 목표와 돈을 보존한다. 새 도전은 10층 목표다.
- E2E는 기존 플레이 흐름과 실제 엔진의 10층 완료 기록에서 클리어·새로고침 보존을 검증한다. 브라우저 테스트는 중간 층을 생략하는 경계 fixture를 사용하며 10경기 전체 진행은 별도 통합 테스트에서 확인한다.

## 2026-10-05 · 605종 확장 이후

현재 범위 확인일: 2026-10-09. 아래 구현 설명과 앞의 초기 측정 기록을 구분한다.

앞의 20종 고정 층 표와 승률 측정은 초기 버전 기록이다. 현재 도감의 일반 605종은 모두 배틀·영입·설정을 지원한다. 신규 계정의 개체값은 6Z, 능력 포인트는 0이다. 시작 기술은 자력기 중 최대 4개이며 특수 종은 더 적을 수 있다.

일반 층은 종별 핵심 2기술과 보조 후보에서 나머지 기술을 구성하며, 최근 세 층과의 종 중복을 피하고 팀 내 타입 중복을 줄인다. 종족값 상한은 층에 따라 증가한다. 새 일반 후보 풀은 75층부터 전설, 90층부터 환상을 허용한다. 종전 저장의 생성 규칙은 유지한다. 새 도전은 100층이며 40·90층 챔피언과 50·100층 최종 상대는 해당 지역 테마를 따른다. 네임드는 6마리 후보에서 공통 약점·타입 폭·물리/특수·속도/내구를 고려해 3마리를 뽑으며 선봉과 기술도 시드로 구성한다. 대표 포켓몬 한 마리를 필수로 포함하고 두 파트너를 가중 추첨한다. 네임드 팀은 중복 없는 도구를 사용하며 챔피언급은 전용 기술 배치를 사용한다. [상세](../../gameplay/NAMED_TRAINER_BUILDS.md). 준비 화면의 상대는 도전 ID와 층으로 결정하고, 생성 후 상대 정보와 파티를 저장한다. 초기 층 표의 상대 조합은 과거 콘텐츠와 완주 검사 fixture이며 현재 NPC 팀과 구분한다. 이미 생성된 배틀은 저장된 상대를 유지한다.

`pnpm battle:audit`는 605종을 플레이어와 상대 선봉 양쪽에서 실제 배틀시켜 총 1,210경기를 확인한다. 여러 시드의 기술 합법성, 시작 자력기·기본 능력치·한국어 표시, 일부 리플레이 재현도 검사한다. 결과는 `artifacts/reports/battle-roster-audit.json`이다. 이 검사는 실행 호환성 검사이며 전 종의 난이도·승률이나 모든 기술/특성 조합의 전수 검증은 아니다.

## 일반 트레이너 샘플과 후속 콘텐츠

`src/data/trainer-catalog.ts`에 일반 18종·타입별 엘리트 18종·혼합 3종·네임드 39명, 총 78종을 정의했다. 이름·그림·출신 세대·타입·전술·등장 최소 층·네임드의 6마리 후보 엔트리를 묶는다. [샘플 목록](../../../artifacts/trainer-samples.md)과 [기술 포함 예시](../../../artifacts/trainer-samples.json)를 생성했다. 일반 트레이너의 그림은 여러 세대 자료를 사용하며 공용 분류다. 네임드는 1~9세대마다 관장/관문·빌런·챔피언/최종 상대 역할의 3명을 준비했다. 키아웨는 관장 대신 캡틴, 쿠쿠이는 챔피언 대신 리그 최종 상대 역할이다.

현재 일반 층에서 타입 전문 또는 혼합 파티를 뽑는다. 4층부터 25%를 엘리트 후보로, 각 구분에서 20%를 혼합 후보로 우선 선택하는 임시 규칙이다. 최근 3명의 같은 샘플과 최근 2명의 같은 전문 타입을 피하며 후보가 부족하면 같은 일반/엘리트 구분의 다른 후보를 사용한다. 파티는 기존 층별 종합 능력치·희귀 종 제한과 3마리 중복 금지·최근 종 회피를 유지한다. 전술에 따라 강화·상태이상·회복 기술을 우선하거나 물리/특수/선공 견제 기술을 선호한다. 타입 전문 파티는 세 마리 모두 해당 타입을 포함한다. 네임드는 대표 파트너 등 다른 타입을 포함할 수 있다. 포켓몬 세대는 제한하지 않는다.

트레이너 정보는 배틀의 `trainer`에 저장하며 보스의 `boss`와 분리한다. 일반·엘리트는 보스 보너스를 받지 않는다. 이름·그림·역할만 화면에 전달하고 미공개 파티·타입/전술 메타데이터를 전달하지 않는다. 예전 경기에서 `trainer`가 없으면 기존 배틀 ID 기반 4종 외형으로 복구하며 파티를 재생성하지 않는다. 엘리트는 전용 음악을 사용하지만 별도 보상·특별 개체값·도구·교체 AI는 아직 없다.

100층과 두 세대 테마, 다른 세대 사천왕 추가와 100층 챔피언 배치는 [ROADMAP.md](../../current/ROADMAP.md)의 계획이다. 현재 관장/캡틴 9명과 챔피언/최종 상대 9명은 실제 배치하고, 도전별 같은 조직의 빌런 조직원 이벤트를 연결했다. 네임드 빌런 간부·보스 배치는 후속이다. 모든 네임드 파티는 본 게임용 구성으로 원작 파티 전체의 복제가 아니다. 메가진화·다이맥스는 구현했고 테라스탈·Z는 후속이다.

## 2026-10-09 · 607종과 50층 어려움 조정

HGSS 후보의 키링키·신뇽을 추가해 현재 607종이다. 성도 14명의 원작 파티와 기술·특성·도구를 우선 사용한다. 유빈의 중복 팬텀은 5종 후보로 합쳤다. 다른 세대 샘플의 원작 대조는 후속이다. 기본은 첫 완주까지 여러 번 실패하며 수집·세팅을 준비하는 어려움으로 정했다. 32개 고정 코스를 도구·기술머신 구매까지 포함해 비교한 [결과와 한계](../../experiments/balance/BALANCE_50_FLOORS.md)를 따른다. 위의 605종 및 30층 측정은 당시 기록이다.
