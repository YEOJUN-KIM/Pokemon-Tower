# 기본 알뽑기 화면 변경 결과

## 1. 변경 파일

제품 코드:
- `src/web/egg-station-menu.tsx`: 기본 뽑기만 남기고 입력·화면 구조 단순화.
- `src/web/styles/egg-station-menu.module.css`: 중앙 기계, 정보 한 줄, 하단 선택지 배치와 반응형 크기 계산.
- `src/web/permanent-shop.tsx`: 지정 뽑기 상태·요청·확률 설명 제거. 사용자가 추가 승인한 알 탐색 연구 상품 제거.

테스트:
- `e2e/egg-game-menu.spec.ts`: 기본 뽑기, 티켓, 포인트 부족, 저장 호환성, 패드, 크기별 이미지·버튼 검증.
- `e2e/permanent-research.spec.ts`: 출발 지원금 유지와 알 탐색 연구 상품 제거 검증.
- `e2e/permanent-header.spec.ts`: 기본 뽑기 선택지에서 X 복귀 검증으로 변경.
- `e2e/title-composition.spec.ts`: 알뽑기 탭 없음·업그레이드 상품 3개로 기대값 변경.
- `e2e/menu-navigation.spec.ts`, `e2e/permanent-upgrades.spec.ts`: 업그레이드 상품 수 기대값 4→3.

보고서: `artifacts/reports/egg-basic-menu-2026-10-20.md`.

## 2. 제거한 기능 — UI 기준

기본/지역/타입 탭, 지역·타입 선택 그리드, 현재 대상, 지정 비중, 보너스·연구 설명을 제거했다. 관련 선택 상태와 탭 기억 상태, 지정 요청을 만드는 클라이언트 코드도 제거했다. 확률 팝업에서도 지정 관련 설명을 제거했다. 업그레이드 상점의 알 탐색 연구 구매 항목은 사용자 확인 후 제거했다.

서버와 기존 저장 스키마는 변경하지 않았다. 기존 연구 기록을 삭제하거나 이로치 연구로 전환하지 않았으며 새 이로치 업그레이드도 추가하지 않았다.

## 3. 유지한 기능

기본 1회·10회 뽑기, 기존 기본 가격 200P, 뽑기권 우선 사용과 나머지 포인트 차감, 보상 알 티켓 사용, 연출, 개별·일괄 부화, 결과 표시·저장, 확률 팝업을 유지했다. 기존 트랜잭션 처리, 중복 요청 잠금, 실패한 요청 재확인 처리도 유지했다.

실제 브라우저/API 검증에서 10회는 티켓 2장과 1,600P를 사용했고 이후 1회는 200P를 사용했다. 0P 상태에서도 티켓 1장으로 1회 뽑기가 가능하며, 포인트가 필요한 뽑기는 비활성화된다.

## 4. 기계 이미지 배치

A안으로 구현했다. 기존 `/sprites/eggs/machine.png`를 중앙 핵심 비주얼로 유지했다. 옵션 패널과 큰 외곽 패널을 없앴다. 이미지 크기는 가용 영역의 너비·높이와 원본 1122:1402 비율에 맞춰 계산한다. 이미지 잘림·늘어짐·버튼 가림 없이 전체 기계를 보여준다.

## 5. 1회·10회 UI

기계 아래에 `뽑기권 N장 · 1회 200P`를 한 줄로 표시한다. 그 아래 1회·10회를 나란한 큰 게임 메뉴 선택지로 배치했다. 실제 사용 티켓·포인트는 선택지 안의 보조 텍스트다. 선택 강조는 공통 게임 커서를 사용한다. 보상 알 티켓은 보유한 경우에만 추가 행으로 표시한다.

## 6. 키보드·패드

- ←/→ 또는 D-pad·스틱 좌우: 1회·10회 이동.
- Enter/Z 또는 표준 패드 A: 결정.
- X 또는 표준 패드 B: 팝업 뒤로 / 타이틀 복귀.
- Y 또는 표준 패드 Y: 기존 알 확률 팝업.
- 보상 티켓이 있으면 아래로 내려가 선택하고, 위로 뽑기 선택지에 복귀.
- Q/E·L/R 탭 명령과 안내는 제거했다.
- 마우스 클릭 지원. 하단 확률·돌아가기 명령은 기존처럼 Tab·방향키 선택 대상에서 제외했다.

표준 Gamepad API 모의 입력으로 패드 조작을 검증했다. 실물 컨트롤러 테스트는 수행하지 않았다.

## 7. 스크롤

1920×1080, 1280×900, 390×844, 360×640, 320×568, 844×390에서 문서 가로·세로 스크롤이 없음을 확인했다. 보상 티켓 2종이 있는 조건에서도 기계 원본 비율·중앙 정렬·기계와 버튼 분리·하단 안내 영역을 검증했다. 기존 부화 결과 팝업 내부 스크롤은 유지했다.
