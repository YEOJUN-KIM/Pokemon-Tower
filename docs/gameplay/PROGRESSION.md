# 타워 진행

일반 모드의 새 도전은 100층입니다. 팀·룰 선택 → 배틀 → 승리 보상·영입 → 출전 준비 → 다음 층 순서로 진행합니다. 50층은 중간 관문이고 이후 잠시 완화한 뒤 최종 관문까지 난이도가 다시 올라갑니다.

앞·뒤 50층에 서로 다른 지역 테마가 적용됩니다. 관장·사천왕·챔피언과 지역별 추가 상대가 등장하며, 신규 런의 빌런 조직은 첫 지역 테마에서 정해지고 두 번째 지역으로 넘어가도 유지됩니다. 조직별 조무래기·간부·보스 트랙은 일반 이벤트와 독립 판정하며 같은 층의 추가 전투로 진행합니다. 옛 일반층 빌런 보스 75층 제한을 현재 캠페인 전체의 고정 등장 조건으로 취급하지 않습니다.

상점이 없는 층에서도 출전 멤버·선봉과 도구를 준비할 수 있습니다. 패배 후에는 확장한 다시하기 횟수 안에서 같은 상대에 맞춰 준비를 바꿀 수 있습니다. 이미 사용한 자원과 정산 기록을 되돌리거나 보상을 중복 지급하지 않습니다. Raid·도전자·빌런 추가 전투와 챕터 히든보스는 저장된 이벤트 흐름을 따릅니다. 조건을 충족한 히든보스는 회복·조우 안내를 확인한 뒤 전투로 이어지며 중간 영입/팀 재선택을 거치지 않습니다.

새로하기는 현재 도전의 종료와 성장 포인트 정산을 확인한 뒤 진행합니다. 계정의 영구 수집·육성은 유지됩니다. 기존 도전과 배틀은 생성 당시 팀·버전을 유지할 수 있습니다.
