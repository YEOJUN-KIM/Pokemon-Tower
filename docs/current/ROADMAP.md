# 1차 완성 이후

기준: 2026-10-23. Normal Mode 100층의 1차 완성은 82c870ed에서 마쳤으며, 이후 파일·문서 정리도 완료했다. 현재부터는 기본 시스템 구축이 아니라 게임의 완성도와 콘텐츠를 확장하는 업데이트 단계다. 완료된 개발 단계와 과거 수치는 Git과 보고서 (로컬 전용: `artifacts/README.md`)에 남긴다.

## 향후 업데이트

현재 개발 기준은 **v1.0.0-beta.4**다. 공개 Release와 패키지 버전은 [현재 상태](../STATUS.md)에서 구분한다. 2026-10-23 플레이 피드백 두 차례는 반영을 마쳤으며 변경 기록 색인 (로컬 전용: `artifacts/reports/changes/README.md`)에서 확인한다. 아래는 이후 작업만 다룬다.

### UI / UX / 디자인

- 화면별 UI 디자인과 버튼 위치·역할을 일관되게 다듬는다.
- 개선한 공통 폰트·대화창·기믹 선택 표현을 바탕으로 다른 화면의 정보 우선순위와 일관성을 다듬는다.
- 키보드·마우스·터치·게임패드의 조작 감각을 개선한다.
- 포켓몬 RPG 느낌의 비주얼, 화면 배치와 정보 우선순위를 개선한다.

### 추가 콘텐츠

- 새로운 일반 이벤트와 기존 이벤트의 변형·보상을 추가한다.
- Raid와 빌런 조직·캠페인 콘텐츠를 확장한다.
- 네임드 NPC와 특수 전투를 추가한다.

### 연출 / 사운드

- 기술 VFX를 추가하고 대표 기술·기믹·보스 전용 연출을 개선한다.
- UI·배틀 효과음과 BGM을 추가하거나 다듬는다.

### 밸런스 / 유지보수

- 실제 플레이 피드백을 바탕으로 이미 적용한 이벤트 20%·코인 배율·층별 성장 지급·50층 강화의 체감을 평가하고 난이도와 경제를 추가 조정한다.
- 진행 불가·저장/재접속·입력·표시 문제를 수정한다.
- 사람의 100층 플레이와 실제 모바일·컨트롤러 확인은 자동 테스트·AI 승률과 구별해 기록한다.
- 기존 진행의 팀·시드·보상·정책은 저장 당시 snapshot을 유지한다.

### 모바일 환경 최적화
- 현재는 PC 환경을 중심으로 UI와 플레이 경험을 개선하고 있다.
- 모바일에서는 폰트 크기, UI 배치, 터치 조작 등 별도의 최적화가 필요한 부분이 있어 추후 모바일 전용 대응을 진행한다.
- 모바일 환경에 맞는 반응형 UI와 터치 조작 방식을 별도로 개선한다.

### 멀티 디바이스 플레이 지원 개선
- 같은 서버·계정의 저장 공유 경로를 바탕으로 기기 전환 시 UI·입력·이어하기 경험을 개선한다.


## 향후 확장

### Hard Mode

Normal Mode와 별도로 설계한다. 강화된 NPC·AI, 위험한 이벤트, 자원·회복 제한, 강화된 Raid와 높은 보상을 검토한다. 세부 규칙은 아직 확정하지 않는다.

### ML AI

충분한 실제 플레이·배틀 로그를 확보한 뒤 장기 연구 대상으로 검토한다. 현재 규칙 기반 AI를 바로 대체하지 않는다.

## 현재 계획 없음

- 150층 / 200층
- 온라인 대전
- PWA
- 공개 서비스 운영

개인 실행기·Docker·임시 터널을 통한 접속을 유지한다.
