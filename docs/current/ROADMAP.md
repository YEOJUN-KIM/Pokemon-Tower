# 다음 작업

기준: 2026-10-18. 완료 내역과 시뮬레이션 표는 이 파일에 누적하지 않습니다.

## 우선순위

1. 1차 완성을 우선하고, 시작·육성·배틀·영입·정비·클리어까지 진행을 막는 문제를 해결합니다.
2. 도감·출전 준비·도구 관리·알 뽑기·배틀 화면의 조작을 실제 PC·모바일에서 확인하고 발견된 문제를 정리합니다.
3. 개인용 통합 실행기·저장 이전·복구를 실제 사용으로 확인하고, 1차 완성 이후 정기 백업 운영을 검토합니다. 공개 서비스나 유료 호스팅 전환은 목표가 아닙니다.
4. 난이도·경제 밸런스는 마지막에 점진적으로 조정합니다. 완성 파티의 일반 100층 체감, 보스별 격차와 룰별 유리함을 현재 조건으로 비교하며 과거 고정 IV·다른 팀의 승률을 현재 결과로 사용하지 않습니다.

## 유지할 결정

현재 장비·관장급 IV의 [단판 비교](../../artifacts/experiments/balance/NORMAL_MODE_BALANCE_CURRENT_EQUIPMENT.md)와 [극단 상대 추가 검사](../../artifacts/experiments/balance/NORMAL_MODE_BALANCE_CURRENT_OUTLIERS.md)를 참고합니다. [장비·화면 재검사](../../artifacts/reports/changes/TRAINER_EQUIPMENT_RECHECK.md)는 자동 검증 범위를 설명합니다. 장비 획득·경제와 사람의 판단을 포함한 실제 100층 플레이 체감은 계속 확인할 항목입니다.

- 현재 일반 모드는 네 구간과 대부분의 단계별 NPC 샘플, 검토한 6종의 단일 후보 빌드를 유지합니다. 지금 10층마다 별도 샘플을 만들거나 육성·도구를 추가 보정하지 않습니다.
- 일반·엘리트 IV는 유지하고, 새 관장 이상급의 IV만 역할에 맞춰 시드 기반으로 배분합니다.
- 유료 서버 전환은 보류합니다. 현재 정기 백업 자동화는 설정하지 않습니다.
- [알 종류와 부화](../gameplay/EGGS.md)는 일반 85%·레어 12%·슈퍼레어 3% 등급과 별도 이로치 0.24% 판정 및 개별/전체 부화를 사용합니다. 모두 1회 200P이며 타입별 알은 제외합니다.

## 이벤트 콘텐츠 후속 기획

- [현재 이벤트와 확정 방향](../gameplay/EVENTS.md): 미스터리 상자와 공통 Reward Popup 기반은 초기 구현했습니다. 기존 v1 상자·브리더·상인의 동작은 유지합니다. 도전자 Rank별 보상, 에픽 교환·TM·영양제 보관함·영구재화·전용 알 티켓·Master 장비 선택까지 구현했습니다. 영양제 정비 판매는 제거했습니다. 상자·도전자 경제 밸런싱은 후속입니다.
- [이벤트 콘텐츠 설계](../gameplay/EVENT_CANDIDATES.md): 도전자 선택전·특수개체 레이드·빌런 캠페인·히든 상인·영양제 상인·미러 매치·미스터리 상자의 방향을 정했습니다. 공통 Reward Popup은 상자에서 구현했으며, 일반층/도전자 공통 20개 Sample·Normal/Elite/Master·가중 랜덤 3명·추가 배틀·영입 생략·선택 보상은 구현했습니다. Raid·포탈·로켓단 캠페인·히든보스는 구현되어 있습니다. 날씨 등 추가 전술과 콘텐츠별 실제 플레이 검증을 후속으로 남깁니다. 세부 수치와 구현 순서는 추후 결정합니다.
- 희귀 스카우트전은 삭제·레이드로 대체, 전술 마스터는 도전자 컨셉으로 흡수, 훈련소는 삭제, 브리더의 알 선택은 히든 상인으로 흡수했습니다. 교환 NPC는 보류하고 위험 선택 배틀·연승 도전·라이벌 등은 추후 검토로 유지합니다.
- [알 종류와 부화](../gameplay/EGGS.md): 현재 공통 뽑기와 향후 등급별 뽑기·티켓을 구분합니다. 히든 상인의 알 상품은 영구재화 사용 방향이며 확률·풀·가격·조건은 알 문서에서 관리합니다.

하드모드, 150/200층, 상대 6마리 공개, 오리지널 상위 NPC, 머신러닝, 온라인 대전, 고정 인터넷 주소·PWA는 후속 검토입니다.

- [기술 이펙트·배경·필드 연출 개선 구상](../gameplay/MOVE_EFFECTS_PLAN.md): 기술별 형태·궤적·타격감 차별화, 외부 자료 활용·직접 제작, 배경 디테일과 필드에 따른 바닥·배경 색 변화 방향을 기록했습니다. 일렉트릭필드의 노란 기운을 예시로 두며, 구현과 신규 에셋 수집은 보류합니다.

## 유지보수 기준

이벤트 10%·쿨다운과 종류/내부 결과 weight는 분리했습니다. 향후 수치 조정은 수동 QA 우회 없이 [이벤트 개발](../engineering/EVENT_SYSTEM.md)을 따릅니다. 로켓단 초기 weight=100 등 이전 안정값이 없는 튜닝은 별도 설계·실측 후 조정합니다. NPC 입력 변경은 [NPC 생성·검증](../engineering/NPC_DATA.md)을 따르며, 옛 단계 생성기를 재설계하기 전에는 리뷰 완료 단일 빌드를 덮어쓰지 않습니다. TowerStore/BattleGame 전면 분리·새 엔진 도입은 현재 목표가 아닙니다.
