# 개발 로드맵

갱신: 2026-10-11. 현재 구현은 [STATUS](../STATUS.md), 실험 흐름은 [EXPERIMENTS](../experiments/README.md)를 기준으로 한다. 이전 계획은 [원문](../archive/2026-10-11-before-cleanup/ROADMAP.md)에 보존했다.

## 완료

612종 수집·육성, 3대3 싱글, 100층 진행/저장 복구, 1~9세대 랜덤 테마·네임드·빌런 조직, 메가·다이맥스·테라, 다섯 룰 선택, 10층 정비·무료 리롤·배틀 도구 직접 사용, 도감 조작/기본 정보 개선을 구현했다. 실제 상대 v8의 공개 무효·흡수 학습과 기존 저장 호환을 검증했다.

여러 팀·룰·코스의 시뮬레이션과 샘플 수정 비교를 완료했다. 실험용 플레이어의 개선 후보를 실제 상대 기능 전체와 동일시하지 않는다.

## 다음 우선순위

도감·영구 상점과 배포 준비를 진행했고 현재 무료 PC/Docker/Quick Tunnel 테스트를 운영한다. 계정 로그인·저장·백업·PC/모바일 UI 검증을 완료했다. 사용자는 유료 서버 전환을 보류하고 새 컴퓨터에서 작업을 이어가기로 했다. 당장 다음 작업은 [컴퓨터 이전 안내](COMPUTER_MOVE.md)에 따른 코드·최신 저장 이전과 개발 환경 확인이며 이후 기능은 사용자 요청에 따른다. 정기 백업·터널 자동 시작·고정 주소·PWA는 미설정이다. 기존 AI 실험 자료는 보존한다.

AI 개선·난이도·경제 조정은 후속 후보다. 진행한다면 공개 정보에 기반한 기술 사용 조건을 검사하고 변경 전후를 같은 코스와 새 코스에서 비교한다. 최신 화면 조작은 [UI_FLOW](UI_FLOW.md), 가격·확률은 [STATUS](../STATUS.md)를 따른다.

## 보류·구상

- Z기술/Z룰, 추가 기믹 UI 배치 조정. 영구 재화 리롤 최대3회 확장은 구현 완료했다.
- 150/200층 확장, 추가 히든 최종전·쉬움 모드. 현재 목표는100층이다.
- ML 학습: 데이터와 행동 판단의 신뢰성을 먼저 확보하며 아직 학습하지 않았다.
- 온라인 대전·독립 운영 서버. 계정 로그인은 구현 완료했고 현재 단일 서버 저장을 사용한다.

룰 선택은 이미 구현했다. 현재 이름은 혼합룰이며 내부 ID chaos는 저장 호환을 위해 유지한다. 기획 초안이나 옛 측정의 개판룰 표기는 당시 기록이다.
