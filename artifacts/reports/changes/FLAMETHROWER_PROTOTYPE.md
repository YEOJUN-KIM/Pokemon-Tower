# 사용자 PNG 화염방사 프로토타입

2026-10-14. 사용자가 제작해 제공한 `대각선 레트로 픽셀 화염 빔.png`를 수정 없이 `public/sprites/effects/flamethrower-beam.png`로 복사했다. 원본과 로컬 파일의 SHA-256은 `7d3a2a7bce809218927ae313691c6d4ac66774619751e141b4a91756b5d8e211`이다. 새 효과 이미지를 생성하지 않았으며, 기존 Showdown 효과 자산의 라이선스를 이 사용자 제공 파일에 적용하지 않는다.

기존 `move-animation-plan.ts`에 화염방사 전용 빔 설정을 추가하고, `move-visuals.tsx`의 Canvas 재생 안에서 PNG를 변형한다. 발사점은 포켓몬의 실제 화면 위치에 고정하며, 공격 축으로 길이와 두께를 늘린다. 플레이어 공격은 좌측 하단에서 우측 상단, 상대 공격은 반대 방향으로 표시한다. 열풍 등 공용 불꽃 연출은 유지한다.

- 0~80ms: 발사 전 대기
- 80~480ms: 짧고 얇게 나타난 뒤 상대 방향으로 빠르게 확장
- 480~680ms: 최대 길이 유지, 600ms부터 기존 효과 자산으로 작은 타격 표시와 불씨 확산
- 680~840ms: 빔의 투명도와 두께 감소
- 840~950ms: 남은 불씨가 사라지고 종료

재생 시간은 950ms이며 공개 로그·HP 처리 코드는 변경하지 않는다. 빗나감은 기존 목표 좌표 이동을 사용하고, 빗나감·무효 시 타격 표시와 불씨 및 피격 흔들림을 표시하지 않는다. 스킵·종료·페이지 이탈은 기존 취소 처리로 정리한다. 동작 감소에서는 정적인 빔을 표시한다. PNG 로딩 실패 시 기존 불꽃 선 표현으로 대체한다.

[리자몽 화염방사 대표 프레임](../../qa/screenshots/flamethrower-prototype/frame-09.png)은 실제 배틀 UI에서 공개 프로토콜 테스트 입력으로 촬영했다. 기존 GIF 파일은 현재 보관돼 있지 않아 남아 있는 PNG 프레임으로 연결한다. 화면 프레임은 50ms 간격이다. 상대 AI가 기술을 선택한 실제 전투 녹화와는 구분한다.

검증: 타입 검사·프로덕션 빌드, 기술 구성/HP 순서/실패 처리 단위 검사 4개, 데스크톱·모바일 스킵과 기존 대표 기술·양방향·빗나감·무효·자연 종료 브라우저 검사 통과. 동작 감소에서도 기존 기술과 새 빔을 확인한다. 촬영 및 후속 재검증은 `e2e/move-visuals.spec.ts`를 사용한다.

배경·필드 및 다른 기술의 전면 개선은 계속 [구상 문서](../../../docs/gameplay/MOVE_EFFECTS_PLAN.md)에 보류한다.
