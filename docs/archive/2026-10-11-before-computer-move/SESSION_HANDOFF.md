# 작업 인계

갱신: 2026-10-11. 현재 기능은 [STATUS](STATUS.md), 다음 순서는 [ROADMAP](current/ROADMAP.md)을 먼저 읽는다. 이전 누적 인계는 [정리 전 원문](archive/2026-10-11-before-cleanup/SESSION_HANDOFF.md)에 보존했다.

## 마지막으로 완료한 작업

동탁군·데스니칸·어흥염 테스트 팀의 기술배치를 점검했다. 필드 없이 아이언롤러를 선택하고 이미 예약된 미래예지를 반복하는 문제가 있었다. 동탁군만 **트릭룸 / 아이언헤드 / 사념의박치기 / 지진**으로 바꾼 후보가 가장 좋았다.

같은 18코스·5룰, 네 조건 각90/총360등반·18,109배틀. 평균36.86→66.64층, 50층21→57/90, 완주0→4/90. 기존3,407배틀 일치, 마지막 패배356전 전체 재생 일치. 관련 테스트3개·타입 검사 통과. 이는 실험 팀 수정이며 실제 플레이어 도감 배치나 전체 난이도 변경이 아니다.

## 최신 구현 — 영구 업그레이드

타이틀/도감 → `/upgrades`. 리롤 확장500/1,000P(각 상점 최대3회), 이로치 교환권10,000P, 알 뽑기1회200P. 1/10회 알 뽑기 기계 연출, 결과 수집/이로치, 상대 희귀 이로치와 등장 별빛. 스키마24·개발 서비스30. 구매/사용 요청 영수증은 재시도 시 결과를 재사용하며 서버 트랜잭션으로 재화/권 차감을 보호한다. 신규 알 결과의 shiny는 뽑기 자체의 이로치 여부이며 기존 외형 해금은 계속 보존한다. AI 개선/난이도는 이번 변경에 포함하지 않는다.

## 다음 시작점

사용자 결정: **도감 UI·영구 재화 기능 → 배포 준비 → AI 개선**. 세부 내용은 [메뉴 설계](current/PERMANENT_PROGRESS_UI.md)와 [로드맵](current/ROADMAP.md)을 따른다.

배틀 메뉴는 설정·도전 포기·타이틀·계속하기로 줄였다. 타입 검사·빌드 통과, 관련 PC/모바일·필드/교체 브라우저5개 확인(PC 커서 검사는 종료 조작을 기존 X 흐름으로 맞춰 재실행 통과). 필드 상태·소리 켜기/끄기·도감 항목을 제거했고 C 필드 단축키는 유지한다. 도감은 센터 PC·DS 메뉴 참고 첫 시안을 적용했다. 선택 포켓몬 정보 패널·밝은 보관 목록·모바일 축소 정보창을 추가했고 타입 검사·빌드·관련 브라우저7개가 통과했다. 영구 상점은 구현됐고 배포 준비는 미착수다.

다음은 게임 메뉴 느낌의 도감과 리롤 확장·이로치 교환·랜덤 포켓몬/IV 뽑기다. 새 종은 해금하고 중복은 높은 IV만 갱신한다. 획득에 따라 새 포켓몬/개체값 상승/새 기술을 표시하며 '변화 없음'은 표시하지 않는다. 현재 가격·확률·기술 배정은 STATUS의 영구 업그레이드 항목을 따른다.

AI 공통 조건 검사와 비교 실험은 배포 준비 이후로 미룬다. 사용자 요청 없이 가격·상대 능력치·상대 벽 전략을 함께 바꾸지 않는다.

## 문서 정리 상태

2026-10-11에 현재 안내 문서를 재작성하고 이전 원문을 해시와 함께 보존했다. 원자료 경로는 유지하고 `artifacts/index.*`, `scripts/README.md`를 추가했다. 이번 정리는 게임 코드나 시뮬레이션 결과 변경을 포함하지 않는다.

알 뽑기는 티켓 구매 단계 없이 1회/10회 버튼으로 바로 진행한다. 보유 티켓 우선 차감, 부족한 횟수만 성장 포인트200P씩 차감하며, 혼합 결제도 하나의 거래로 저장한다. 티켓3장으로10회는3장+1,400P. 포인트 부족 시 티켓도 소비하지 않는다.

최종 검증: 프로덕션 빌드·타입 검사, 저장/구매/뽑기/기존 룰 관련 단위26개, PC·모바일 뽑기·이로치 배틀·타이틀·스프라이트 브라우저8개 통과. 화면: `artifacts/screenshots/permanent-upgrades-final/`, 이로치 GIF: `artifacts/previews/shiny-entry/shiny-entry.gif`.
