# 50층 플레이 시간 추정

이 문서의 시간은 100층 난이도 변경 전 50층 측정에 사람의 선택 시간을 가정한 추정이다. 새 100층 버전의 실제 사용자 플레이 시간은 아직 측정하지 않았다. 현재 규칙과 자동 결과는 [100층 검증](../../gameplay/HUNDRED_FLOORS.md)을 따른다.

2026-10-10. 사람의 실제 평균 플레이 시간은 아직 측정하지 않았다.

기존 최신 AI 시뮬에서 완주한 강팀 코스 17개(850배틀)를 같은 조건으로 재실행했다. 평균 배틀 턴 수는 층당 5.11턴, 50층 합계 255.47턴이다. 팀 프리뷰를 제외한 플레이어 결정 요청은 50층당 평균 272.94회였다.

현재 presentationFrames의 연출 대기 시간을 합산하면 50층 평균 23.76분, 코스별 20.85~27.55분이다. 배틀당 등장 대기 0.55초를 포함한다. 서버 처리 속도가 사람 플레이 속도라는 뜻은 아니다.

기술/교체 판단 2~5초, 층간 영입 5~15초, 상점 9회에서 각 30~90초를 가정하면 평균 코스 기준 41.4~72.3분이다. 등장 확인·결과 확인·층 이동·통신·브라우저 지연은 직접 측정하지 않았으므로 안내용으로 **50층 약 45~75분**을 잡는다. 기술 설명과 도감 세팅을 오래 보는 플레이는 더 걸릴 수 있다. 연출을 자주 건너뛰는 경우 단순 모델은 약 18~48분이며 안내용으로 약 20~50분이다.

동일한 층당 속도라면 **100층은 약 90~150분**이다. 현재 100층 콘텐츠가 완성된 상태의 측정값은 아니며 후반 교체·회복전과 난이도 변화에 따라 달라진다.

100층을 첫 확장 목표로 삼고, 50층을 중간 관문으로 다루는 편이 적절하다. 전체 완주 시간과 별개로 기존 중간 저장을 활용해 짧은 세션으로 나누어 플레이할 수 있어야 한다.

한계: 강팀의 성공한 17코스만 사용한 조건부 표본이다. 사람의 판단 시간은 가정이며 실패 후 재도전·처음 팀을 준비하는 시간은 제외했다. 전체 프로토콜에서 프레임을 합산했으므로 실제 요청 경계에서 안내가 중복되는 경우 약간 달라질 수 있다.
