# 도구 적용 전 30층의 1차 난이도 조정

2026-10-09. 24개 타워 코스의 종·기술·개체값·배틀 시드를 저장하고 새 계정, 중간 육성, 최대 육성의 세 상태로 비교했다. 독립된 각 층 전투와 영입·상점 강화가 있는 연속 등반을 모두 실행했다. 층별 비교만 조정 전후 총 4,320전이며 연속 등반은 별도다.

## 조정

기존 상대는 1층부터 개체값 0~31 전체 범위를 사용했다. 플레이어의 기본 개체값은 0이라 첫 층부터 영입하기 전에 탈락하는 경우가 많았다. 새 상대는 상한을 `min(31, 4 + 층)`으로 적용한다. 1층 0~5, 5층 0~9, 10층 0~14, 20층 0~24, 27층 이후 0~31이다. 구간 관문에서 상한을 갑자기 올리지 않는다. 무작위 추첨 분포를 낮은 범위로 다시 매핑하며 전부 같은 낮은 값으로 고정하지 않는다.

상대의 종·기술·레벨, 11층 이후 능력 포인트, 보상·상점 가격·강화 효과는 유지했다. 이미 저장된 배틀의 팀은 바꾸지 않으며 이후 생성되는 상대에게 적용한다. 도구는 아직 사용하지 않는다.

## 같은 코스·시드에서의 결과

| 시작 육성 | 평균 클리어 층 전 → 후 | 30층 완주 전 → 후 |
|---|---:|---:|
| 새 계정: 개체값 0·능력 포인트 0 | 1.6 → 2.5 | 0/24 → 0/24 |
| 중간: 개체값 15·능력 포인트 33 | 4.0 → 7.2 | 0/24 → 0/24 |
| 최대: 개체값 31·능력 포인트 66 | 13.5 → 17.2 | 3/24 → 4/24 |

동일한 스타터 팀을 유지한 층별 독립 전투에서 새 계정의 1층 승리는 15/24 → 23/24, 첫 관장 5층 승리는 7/24 → 10/24였다. 27층 이후는 상대 조건이 같아 독립 전투 결과도 같다. 초반 완화가 모든 층을 쉬워지게 하는 것은 아니다. 연속 등반의 영입 개체값도 낮아지므로 획득한 멤버의 성장 효과까지 함께 비교했다.

## 해석과 제한

- 세 육성 상태 모두 동일한 스타터 종과 기본 자력 기술로 출발한다. 성격은 중립이며 도구·기술머신 구매·능동적인 전술 교체는 없다. 전투 정책은 양쪽 모두 공개 정보만 사용하는 TowerPolicy다. 자동 플레이 승률을 사람의 승률로 해석하지 않는다.
- 연속 등반은 승리 후 종족값이 높은 후보 1마리를 영입하고 개체값을 병합한다. 공개된 획득 기술과 자기 능력치로 기술을 고르고, 자기 능력치·타입 다양성으로 출전 팀을 선택한다. 다음 층의 숨겨진 상대를 보고 팀을 고르지 않는다. 최대 6마리이며 코인이 있으면 실제 가격으로 상점에서 공격·속도 강화를 구매한다.
- 육성한 플레이어가 영입한 새 종은 능력 포인트가 없는 상태를 따른다. 각 전투 사이 완전히 회복하고, 패배한 등반은 즉시 종료한다. 재도전 간 영구 수집 누적은 이 측정에 없다.
- 코스당 각 층 1개 배틀 시드, 총 24코스의 작은 표본이다. 특정 포켓몬 우열이나 상품 가격을 확정할 자료는 아니다. 중간 육성 상태와 일부 트레이너가 아직 막힐 수 있으며 실제 플레이 피드백과 도구 구현 후 추가 측정한다.
