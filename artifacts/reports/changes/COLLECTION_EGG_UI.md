# 수집·알 화면 개편

기준: 2026-10-15. 2026-10-14~15 작업의 최종 동작과 검증 범위를 기록합니다. 현재 게임 규칙은 [알과 부화](../../../docs/gameplay/EGGS.md), [수집과 육성](../../../docs/gameplay/COLLECTION.md), [조작](../../../docs/gameplay/CONTROLS.md)을 따릅니다.

## 변경 결과

- 영구 업그레이드와 알 뽑기를 두 탭으로 분리했습니다. PC에서는 다시하기·리롤·이로치 교환권 세 상품을 한 줄에 배치하고 모바일에서는 세로로 표시합니다.
- 이로치 교환 대상을 도감 번호순으로 표시하고 이름 검색·타입·세대를 확인할 수 있게 했습니다. 선택 후 일반/이로치 모습을 함께 미리 보고 교환권 사용 버튼으로 적용합니다.
- 종류를 골라 구매하던 알 화면을 하나의 기계에서 무작위 뽑는 방식으로 개편했습니다. 일반 85%·레어 12%·슈퍼레어 3%이며, 모든 등급에 별도 이로치 0.24% 판정을 적용합니다. 슈퍼레어는 전체 기준 초전설 2.5%·환상 0.5%입니다.
- [현재 뽑기 대상 615개](EGG_POOL_CLASSIFICATION.md)를 일반 496개·레어 71개·슈퍼레어 48개로 분리했습니다. 일반에는 준전설·패러독스·울트라비스트·초전설·환상이 섞이지 않습니다.
- 사용자 제공 알 네 종류와 기계 PNG를 로컬 자산으로 연결했습니다. 원본 PNG는 수정하지 않고 화면에서 오라·후광·반짝임을 추가합니다. [파일별 출처](../../../public/sprites/eggs/sources.json)를 보관합니다.
- 1회·10회 모두 기계가 들썩인 뒤 실제 결과 중 가장 높은 등급의 대표 알 하나를 배출합니다. 우선순위는 이로치 > 슈퍼레어 > 레어 > 일반입니다. 그 뒤 실제 개수의 알을 펼쳐 개별 또는 전체 부화합니다.
- 확률 팝업은 일반·레어·슈퍼레어를 한 줄로 표시하고 이로치를 별도 영역에 둡니다. 부화 결과 팝업은 최대 1,500px로 확대하고 카드 여백·능력치 배치를 정리했습니다.
- 결과 카드에 준전설 하늘색·울트라비스트 보라색·패러독스 민트색·초전설 샴페인 골드·환상 연분홍·이로치 금색 배경을 사용합니다. 초전설은 백금빛 광선과 여섯 별 반짝임을 강화했습니다. 카드의 분류 라벨과 상단 분류 안내 문구는 제거하고 이로치 해금 표시는 유지합니다.
- 도감·상세 정보·육성 설정·테라 타입 선택창에 배틀과 같은 타입별 테라스탈 PNG 아이콘을 표시합니다. 타입 이름과 기존 선택·저장 제한은 유지합니다.
- 전체 동작 버튼에서 Z·X·Enter·Shift 단축키 꼬리표를 제거했습니다. 실제 키보드 동작과 별도의 조작 안내는 유지합니다.
- 배틀 등장 연출과 이로치 반짝임에 서로 다른 React key를 사용하도록 수정해 `player-275` 등의 중복 key 경고를 해결했습니다.

## 저장과 검증

추첨·재화 차감·수집 결과·구매 영수증은 서버에서 한 번에 저장합니다. 개별 열기와 전체 열기는 결과 공개만 수행합니다. 같은 요청 재전송의 중복 결제 방지와 과거 알 구매 영수증 복구를 유지합니다. 로컬 테스트용 포인트 충전은 개인 DB에만 적용한 작업이며, 기본 지급량을 바꾸는 코드 변경은 아닙니다.

- `tests/egg-kinds.test.ts`, `tests/egg-pools.test.ts`, `tests/permanent-upgrades.test.ts`: 분류·확률 구간·대표 알 우선순위·이로치·결제·영수증 재전송·저장 검증.
- `e2e/egg-kinds.spec.ts`, `e2e/permanent-upgrades.spec.ts`: PC/모바일의 확률 팝업, 1회/10회, 개별/전체 부화, 교환 미리보기와 키보드 동작 확인.
- `e2e/egg-result-presentation.spec.ts`: 1920·1280·390px에서 결과 배경·효과·동작 감소 설정과 배치 확인. PC 두 크기에서 열 개 카드의 스크롤과 능력치 글자 범위를 검사합니다.
- `e2e/tera.spec.ts`의 도감 저장 사례: 19개 아이콘 로딩, PC/모바일 선택창, 변경 타입 저장·재표시와 배틀 전달 확인.
- 타입 검사·CSS 구조 검사·프로덕션 빌드를 통과했습니다. 기능별 변경 시 관련 검사를 실행했으며 모든 브라우저 테스트 파일의 전체 실행을 의미하지 않습니다.

## 유지할 자료와 재생성

[배경색 PNG](../../qa/previews/egg-results/background-colors.png), [배경 효과 GIF](../../qa/previews/egg-results/background-effects.gif), [초전설 강화 GIF](../../qa/previews/egg-results/legendary-effects.gif)는 화면 검증용 결과를 실제 UI에 표시해 촬영한 비교입니다. 개인 계정의 실제 획득 기록은 아닙니다. 이 세 파일은 현재 문서에서 사용하므로 Git 제외 규칙에 개별 예외를 두고 보존합니다. 촬영은 결과 화면 브라우저 검사, 합성은 `scripts/render-egg-background-preview.py`로 재생성합니다. 등급 목록은 `node --import tsx scripts/export-egg-pools.ts`로 다시 생성합니다.

현재 트레이너 장비 조건의 시뮬레이션·화면 재검사는 [별도 근거](TRAINER_EQUIPMENT_RECHECK.md)에 있습니다. 이번 UI 개편에서 게임 난이도를 추가 조정하지 않았습니다. 1차 완성을 우선하며 난이도·경제와 실제 100층 체감은 [후속 계획](../../../docs/current/ROADMAP.md)으로 유지합니다.
