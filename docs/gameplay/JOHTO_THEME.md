# 2세대 성도 테마 — 첫 50층

2026-10-09 사용자 지정. 2026-10-09에는 새 도전을 성도 테마로 고정했다. 2026-10-10부터 새 도전은 [1~9세대 테마](REGIONAL_THEMES.md) 중 하나를 추첨하며 기존 성도 도전은 이 배치를 유지한다. 목호는 사천왕급 관문, 레드는 최종 챔피언으로 배치하는 본 게임의 임시 구성이다. 기존 도전의 배치와 이미 생성된 상대는 유지한다.

| 층 | 상대 |
|---|---|
| 5·15·25·35·45 | 성도 관장 8명에서 도전별로 순서를 섞어 서로 다른 5명 배치 |
| 10·20·30 | 일목·독수·시바·카렌 중 도전별로 서로 다른 3명 배치 |
| 40 | 목호 — 사천왕급 트레이너, 엘리트 음악 역할 |
| 50 | 레드 — 최종 챔피언 |
| 나머지 층 | 기존 타입별 일반·엘리트·혼합 상대와 같은 조직의 빌런 조직원 이벤트 |

관장 후보는 비상·호일·꼭두·유빈·사도·규리·류옹·이향이다. 사천왕 네 명을 한 도전에서 모두 만나는 규칙은 아니다. 마지막 사천왕급 관문을 목호로 고정하고 앞의 세 관문을 무작위로 구성한다.

네임드마다 원작 5~6종 후보에서 조합을 고려해 3마리를 뽑는다. 대표 포켓몬 한 마리는 고정하고 두 파트너는 가중 추첨한다. HGSS 원작 기술·특성·도구를 우선 적용하고 필요한 부분만 보완하며 도구 중복은 금지한다. 새 배틀의 레드 피카츄와 목호 망나뇽은 다이맥스밴드를 사용한다. 피카츄는 전기구슬 대신 밴드를 지니며 이미 저장된 배틀의 도구는 유지한다. 상세는 [네임드 전투 구성](NAMED_TRAINER_BUILDS.md)을 따른다. 포켓몬 세대는 제한하지 않으며 일반 상대를 성도 타입·포켓몬으로 제한하지 않는다. 레드 후보는 피카츄·라프라스·잠만보·이상해꽃·리자몽·거북왕이다. 목호 후보는 망나뇽·갸라도스·리자몽·한카리아스·파비코리·보만다다. 나머지 후보와 예시 파티는 [전체 샘플](../../artifacts/trainer-samples.md)을 따른다.

## 저장과 확장

새 도전에 `run_themes.theme=johto`를 저장한다. 준비 화면은 해당 테마와 도전 ID로 같은 상대를 예고하고, 배틀 생성 시 이름·역할·초상화·실제 파티를 저장한다. 50층 이후 진행은 아직 없다.

v16 이전 도전에는 테마를 소급 부여하지 않는다. 테마가 없는 도전은 종전 27명 중 관장·챔피언 각 9명의 혼합 후보 규칙을 유지한다. 신규 성도 후보 추가로 기존 도전의 미생성 관문 후보까지 바뀌지 않도록 기존 후보 목록을 분리했다.

1~9세대 전체 테마와 무작위 세대 선정, 51~100층 두 번째 테마, 테마별 전용 배경·음악은 후속이다. 현재 테마 식별자·트레이너 데이터·배치 함수·저장 테이블을 분리했으므로 다른 테마 후보와 배치 규칙을 추가할 수 있다. 로그인·다른 기기 저장 기능은 추가하지 않았다.
