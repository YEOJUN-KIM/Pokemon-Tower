# 난이도·경제 보고서

현재 팀 검토에는 아래 일반 모드 보고서를 우선합니다. 수치는 당시 팀·고정 IV 조건이며 새 관장급 IV의 재측정 결과가 아닙니다.

| 주제 | 보고서 |
|---|---|
| 일반 모드 네 구간 초기 비교 | [기본 검사](NORMAL_MODE_BALANCE_CHECK.md) |
| 너무 쉽거나 어려운 상대 | [극단 상대](NORMAL_MODE_BALANCE_OUTLIERS.md) |
| 출전 순서에 따른 차이 | [선봉 비교](NORMAL_MODE_BALANCE_LEADS.md) |
| 라인업 변경 후 재검사 | [라인업 갱신](NORMAL_MODE_BALANCE_REFRESH.md) |
| 상점·리롤·영양제 경제 | [상점 경제](SHOP_ECONOMY_50.md) |

기타 50/100층·룰 비교는 역사적 조건의 자료입니다. 같은 접두사의 JSON·코스·요약과 함께 해석하고 현재 게임 규칙은 [현재 상태](../../../docs/STATUS.md)를 따릅니다.
