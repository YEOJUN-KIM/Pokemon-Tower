# 원시회귀

2026-10-13 플레이어 지원. 그란돈·가이오가 도감 상세의 기본 정보에서 원시그란돈·원시가이오가 모습을 선택할 수 있다. 원시회귀는 같은 포켓몬의 변신 형태이며 도감 해금·IV·기술 수집은 기본 종을 따른다.

## 플레이어 사용

1. 그란돈 또는 가이오가를 수집하고 출발 파티나 도전 보유 멤버에 넣는다.
2. 메가진화 룰 또는 혼합 룰을 선택한다.
3. 정비 상점의 지닌 도구에서 주홍구슬(그란돈), 쪽빛구슬(가이오가)을 구매·장착한다. 각각5,000코인, 전설 등급, 기존 기믹 도구와 같은 5층 클리어 이후 판매 후보이며 해당 종이 없으면 후보에서 제외한다.
4. 구슬을 지닌 포켓몬이 등장하면 자동으로 원시회귀한다. 별도 기믹 선택 버튼은 없다. 구슬은 소모되지 않는다.

메가진화·원시회귀·다이맥스는 팀당 배틀1회 사용권을 공유한다. 이미 메가진화/다이맥스를 사용했으면 새 원시회귀는 발동하지 않는다. 이미 원시회귀한 포켓몬은 교체 후에도 원시 형태를 유지하고 다음 층 배틀에서 사용권을 회복한다. 원시 포켓몬은 테라스탈·Z기술·다이맥스를 중첩하지 않는다. 기본·다이맥스·테라·Z 룰은 플레이어의 구슬 구매/장착과 원시회귀를 허용하지 않는다. NPC 대표 기믹은 별도 배정대로 사용한다.

원시그란돈은 땅/불꽃·끝의대지, 원시가이오가는 물·시작의바다다. 실제 종족값·특성·날씨·피해는 설치된 Showdown 엔진을 사용한다. 도감에도 이 종족값과 특성을 표시한다. 일반/이로치·앞/뒷모습을 로컬로 제공한다.

## 저장과 검증

주홍구슬·쪽빛구슬 아이콘은 PokeAPI sprites의 `sprites/items/red-orb.png`, `blue-orb.png` 원본을 로컬로 사용한다. 초기 임시 SVG는 제거했다.

기존 지닌 도구 가방·장착·실제 packed team·행동 기록을 사용하며 DB 스키마 v27을 유지한다. 개발 서비스 버전36. 개인 계정·보유 목록·기존 진행을 임의로 변경하지 않았다.

프로덕션 빌드, 관련 단위/통합22개와 PC1280px·모바일390px 도감 브라우저2개 통과. 도감 형태·특성·종족값·이미지, 구슬 구매/장착과 다른 종 장착 거절, 여섯 룰의 발동 제한, 공용 사용권, 교체·재시작·배틀 재생을 확인했다. 화면은 `artifacts/qa/screenshots/primal/`이다.
