# Z기술

2026-10-12 구현. 새 도전에서 Z기술 룰을 선택하거나 혼합 룰로 시작한다. 도전 중에는 룰을 바꿀 수 없다.

## 사용

- 정비 상점에서 크리스탈을 **3,000코인**에 구매해 장착한다. 기존 기믹 도구와 같은 전설 등급 추첨을 사용하며 크리스탈은 소모되지 않는다.
- 공격·변화 기술에 대응하는 타입 크리스탈 18종, 전용 크리스탈 16종을 등록했다. 전용 크리스탈은 해당 포켓몬만 장착하고 지정된 원본 기술이 있어야 발동한다. 현재 도감/파티에 해당 포켓몬이 없으면 상점 후보에서 제외한다.
- 싸운다 → Z기술 버튼 또는 A키로 선택 → 강화할 기술 확정. 버튼만 켜거나 취소하는 것은 사용권을 소모하지 않는다. 원본 기술의 PP가 있어야 하며 대응하지 않는 칸은 비활성화한다.
- Z기술 선택 중 강화 가능한 기술 버튼은 금빛 배경·테두리·광택을 표시한다. 기술명은 일반 기술과 다른 글꼴 우선순위, 굵은 기울임꼴과 자간으로 강조하며 키보드 선택 상태에서도 금빛을 유지한다. 별도 `Z POWER` 표식은 표시하지 않는다. 선택을 해제하면 일반 기술 표시로 돌아간다.
- 위력·분류는 원본 기술과 엔진의 Z기술 정의를 기준으로 표시한다. 변화 Z기술은 추가 효과를 한국어로 설명한다. 짧은 Z파워 효과 후 실제 기술 연출을 재생한다. 일본어 영상·화면·긴 트레이너 컷신은 사용하지 않는다.

## 제한과 효과

Z기술은 팀당 배틀 1회다. 다른 크리스탈을 든 파티원으로 교체해도 다시 사용할 수 없으며 다음 층 배틀에서 회복된다. 혼합 룰에서는 기존 메가/다이맥스 공용 1회와 테라권 제한에 더해 Z기술 1회가 별도로 있다. Z크리스탈을 든 포켓몬은 테라스탈할 수 없고, 메가/다이맥스/테라 상태에서 Z기술을 사용할 수 없다.

공격 Z기술의 실제 위력, 방어 관통 1/4 피해, 변화 Z기술의 추가 효과와 전용 기술의 부가 효과는 설치된 Showdown 엔진이 판정한다. Z크리스탈 등록으로 새로운 기본 기술을 해금하거나 도감 종을 추가하지 않는다. 울트라네크로즈마용 크리스탈은 울트라버스트가 필요하므로 제외한다.

## 상대와 저장

2026-10-13 새 100층 상대는 `tower-policy-v10`. v9의 공개 정보 판단을 유지하면서 플레이어 룰과 독립된 자기 대표 기믹을 사용한다. Z 담당은 전용 크리스탈을 우선하며 필요한 원본 기술도 준비한다. 아세로라는 따라큐Z, 아이리스는 짜랑고우거Z 담당을 포함한다. 일반 트레이너에게는 지급하지 않는다. [NPC 배정·샘플·범위](NPC_GIMMICKS.md). 이전 v9 이하 배틀은 기존 양쪽 룰을 유지한다.

저장 스키마는 v27. v26 이하의 기존 룰과 팀·행동을 보존하고 새 `z` 룰만 추가한다. 기존 AI v8 이하도 복원 가능하며, 기록한 Z행동으로 재시작하면 사용권·PP·효과를 재현한다.

## 검증과 시각 참고

최종 화면(2026-10-12): [PC 선택 화면](../images/z-move-desktop.png), [모바일 선택 화면](../images/z-move-mobile.png). 금빛 기술명·버튼 강조를 유지하고 `Z POWER` 표식을 제거한 버전이다.

`tests/z-moves.test.ts`: 타입/전용 크리스탈, 공격·변화·전용 발동, 팀 사용권, PP 소모, 방어 관통, 금지 룰, 장착, 구매, v26 마이그레이션, 저장 복원과 AI 재생. 기존 기믹·상점·이전 저장 회귀 테스트도 포함한다.

`e2e/z-moves.spec.ts`: PC 1280px·모바일 390px, 키보드·터치 선택, 실제 위력·분류, 발동, 새로고침 후 재사용 금지, 구매·장착. 화면은 `artifacts/screenshots/z-moves/`.

최종 UI 확인 명령은 `node --import tsx node_modules/@playwright/test/cli.js test e2e/z-moves.spec.ts --grep 'Z selection'`이다. Node.js 24.19.0에서 기본 Playwright 실행은 JSON import attribute 오류로 테스트를 수집하지 못해 `--import tsx`로 실행했다. 최종 화면 갱신 결과와 빌드·검증 범위는 [작업 인계](../SESSION_HANDOFF.md)에 기록한다.

크리스탈의 마름모형과 타입 표식은 [공식 썬·문 Z기술 소개](https://www.pokemon.co.jp/ex/sun_moon/fight/160801_01.html)를 참고한 로컬 SVG다. [공식 소개 영상](https://www.youtube.com/watch?v=3AZHowhxM0U)은 참고 링크로만 보관한다. 엔진 데이터 출처는 `pokemon-showdown` 0.11.11이며 기술 이름은 기존 로컬 도감 번역을 우선한다.
