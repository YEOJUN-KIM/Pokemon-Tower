미진화 수집 예외는 폴리곤2·스라크·피카츄·두랄루돈입니다. 기존 저장·이미 생성된 배틀은 당시 팀과 규칙을 유지하므로 새 생성 기준과 다를 수 있습니다.

하드모드·150/200층·상대 6마리 공개·머신러닝 학습·온라인 대전은 현재 구현 범위에 포함하지 않습니다. 새 팀 구성과 관장급 IV 변경 후의 난이도·경제 평가는 [다음 계획](current/ROADMAP.md)에서 관리합니다.

새 일반층과 도전자 선택전은 공통 [NPC Sample·Rank 시스템](engineering/NPC_TRAINING.md)을 사용합니다. v38은 새 런만 적용하며 기존 네임드/빌런과 저장 상대는 유지합니다.

공통 NPC는 클래스별 rankWeights와 teamConcept으로 Rank를 결정하고 테마 수를 유지합니다. Normal 도구 슬롯을 제한하며 신규 encounter snapshot v2와 기존 v1 읽기를 함께 지원합니다.

공통 배낭은 도구 장착/이동/해제와 Run TM 반복 사용을 지원합니다. TM 타입별 디스크·위력/분류/PP와 실제 폼 포켓몬 칩, 고정 크기 팝업·내부 스크롤을 사용합니다. [배낭 명세](engineering/BAG.md).

랜덤 이벤트는 정상 추첨 10%·통과 순서 쿨다운 2를 사용하며 수동 QA 강제 등장은 없습니다. Raid·포탈·로켓단·히든보스의 조건과 기존 저장 보존은 [이벤트 개발](engineering/EVENT_SYSTEM.md), 설정 위치와 검증은 [구조](engineering/ARCHITECTURE.md)를 따릅니다.
