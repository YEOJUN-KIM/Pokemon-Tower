# 다음 작업

기준: 2026-10-14. 완료 내역과 시뮬레이션 표는 이 파일에 누적하지 않습니다.

## 우선순위

1. 일반 100층의 실제 플레이 체감을 확인하고, 현재 NPC 팀·기믹·관장급 IV 배분 이후의 난이도를 같은 조건으로 비교합니다.
2. 보스별 난이도 격차와 다이맥스 등 룰별 유리함을 검토합니다. 과거 고정 IV·다른 팀의 승률을 현재 결과로 사용하지 않습니다.
3. 도감·출전 준비·도구 관리·배틀 화면의 조작을 실제 PC·모바일에서 확인하고 발견된 문제를 정리합니다.
4. 1차 완성 기준을 확정한 뒤 배포·복구 절차를 다시 확인하고 정기 백업 운영을 시작합니다.

## 유지할 결정

- 현재 일반 모드는 네 구간과 두 단계 NPC 샘플을 유지합니다. 지금 10층마다 별도 샘플을 만들거나 육성·도구를 추가 보정하지 않습니다.
- 일반·엘리트 IV는 유지하고, 새 관장 이상급의 IV만 역할에 맞춰 시드 기반으로 배분합니다.
- 유료 서버 전환은 보류합니다. 현재 정기 백업 자동화는 설정하지 않습니다.

## 보류

하드모드, 150/200층, 상대 6마리 공개, 오리지널 상위 NPC, 머신러닝, 온라인 대전, 고정 인터넷 주소·PWA는 후속 검토입니다.

- [이벤트와 보상 기획](../gameplay/EVENTS.md): 보상 후보를 정리했습니다. 지급량·확률·사용 조건과 이벤트 내용은 미정입니다. 플레이어 스프라이트 확장과 외형 보상은 후속 구상으로 두고, 폼 변경·진화 재료는 보류합니다. 회복권·부활권은 후보에서 제외합니다.
- [이벤트 후보 선별](../gameplay/EVENT_CANDIDATES.md): 제공된 엑셀의 29개 이벤트를 현재 게임 규칙에 맞춰 우선 후보·후속 후보·보류로 정리한 제안입니다.
- [알 종류 구상](../gameplay/EGGS.md): 타입별 알, 희귀 포켓몬 확률이 높은 알, 이로치 확률이 높은 알을 별도 검토합니다. 확률·가격·티켓 방식은 미정입니다.
- [기술 이펙트·배경·필드 연출 개선 구상](../gameplay/MOVE_EFFECTS_PLAN.md): 기술별 형태·궤적·타격감 차별화, 외부 자료 활용·직접 제작, 배경 디테일과 필드에 따른 바닥·배경 색 변화 방향을 기록했습니다. 일렉트릭필드의 노란 기운을 예시로 두며, 구현과 신규 에셋 수집은 보류합니다.
