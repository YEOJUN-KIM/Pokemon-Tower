# Pokémon Tower

10층 정비에서 기술·능력치를 현재 파티/영구 도감에 함께 저장하고, 배틀 도구칸에서 턴 소모 없이 소모품을 사용할 수 있습니다. 일반 상품 가격 인하·일반 상점/기술머신 각각 무료 리롤1회. [상세 규칙](docs/BATTLE_ITEMS_MAINTENANCE.md).

새 도전은 **1~9세대 지역 테마 중 하나를 무작위로 선택**해 100층 동안 유지한다. 관장·사천왕급·챔피언·빌런 조직은 그 테마를 따른다. 기존 성도 및 테마 없는 저장은 이전 배치를 유지한다. 포켓몬의 출신 세대는 제한하지 않는다. 상세는 [세대 테마](docs/REGIONAL_THEMES.md)를 따른다.

팀 편성·턴제 배틀·타워·수집·영구 성장을 목표로 하는 웹·백엔드 포트폴리오 프로젝트.
현재는 Showdown 기반 3대3 싱글 배틀과 **팀 선택 → 승리 보상 → 영입 → 다음 층** 흐름을 플레이할 수 있습니다.
현재 **612종 도감·100층 타워**, 영입·개체값 수집·능력 포인트·성격·특성·기술배치를 사용할 수 있습니다. 일반 상대는 층과 시드에 따라 달라지고, 5·15·25·35·45층 관장과 10·20·30층 사천왕급·40층 챔피언·50층 최종 상대는 후보 엔트리에서 3마리를 뽑습니다. 새 100층 도전은 10층마다 상점이 열리며 한 도전에서 같은 빌런 조직의 조직원·간부·보스가 무작위로 등장하며 보스 격파 시 추가 보상과 함께 해당 도전의 조직 이벤트가 종료됩니다.

2026-10-10 문서 기준: 플레이어는 성도편 지우의 생성 뒷모습 4프레임을 사용합니다. 타입별 일반·엘리트·혼합 트레이너를 사용하며 새 도전의 네임드는 무작위 세대 테마에 맞는 관장·사천왕급·챔피언·최종 상대입니다. 하단의 ‘누가 나타났다!’를 확인한 뒤 **Enter 또는 화면 버튼**을 누르면 서로 볼을 던지고 배틀을 시작합니다. 볼 던지기는 0.55초이며 Shift로 건너뛸 수 있습니다.

Node.js와 pnpm 준비 후:

```sh
pnpm install --frozen-lockfile
pnpm dev
```

http://127.0.0.1:3000 타이틀에서 **게임 시작** 또는 **이어하기**를 누르세요.
해금된 포켓몬에서 3마리를 선택합니다. 승리 후 상대를 영입하면 다음 층과 이후 도전에서도 사용할 수 있습니다.
돈·도감·도전은 SQLite에 저장되며 새로고침·서버 재시작 후 같은 브라우저에서 복구됩니다.

검증과 CLI:

```sh
pnpm battle:auto
pnpm battle
pnpm typecheck
pnpm test
pnpm build
pnpm test:e2e
pnpm tower:audit
pnpm battle:audit
pnpm sprites:audit
```

Node.js 24 이상이 필요합니다. 별도 DB 설치 없이 `.data/tower.sqlite`를 자동 생성합니다.
E2E는 설치된 Google Chrome과 별도 3001·3002번 서버/테스트 DB를 사용합니다.
현재는 게스트 쿠키 기반 단일 서버 버전입니다. 쿠키를 지우면 기존 저장에 접근할 수 없습니다.
기존 도전은 저장 당시의 규칙과 상대 팀으로 이어갑니다. 새 도전의 일반 상대는 핵심 기술 2개와 무작위 보조 기술을 사용하며 최근 세 층의 중복 종을 피합니다. 새 도전은 50층을 중간 관문으로 통과하고 51~60층에서 상대 난이도가 낮아졌다가 100층 최종전까지 다시 상승합니다. 일반 트레이너는 기믹을 쓰지 않고 후반 엘리트 출현과 기믹 활용이 늘어납니다. [100층 규칙·검증](docs/HUNDRED_FLOORS.md)을 참고하세요. [검증 결과 요약](docs/STATUS.md)은 동작 확인과 승률 균형 검사를 구분합니다.
도감에서는 이름 검색·필터·즐겨찾기·파티 선택·능력치와 기술 설정을 사용할 수 있습니다. 방향키로 이동, 도감 포켓몬에서 Enter/Z로 선택·설정 메뉴 열기, 메뉴에서 Enter/Z 선택·확정, X 취소/메뉴, Q/E 도감 상단 항목, PageUp/PageDown 도감 페이지, A 배틀 교체, S 배틀 기록, Shift 연출 건너뛰기입니다. 배틀에서는 싸운다에서 기술 설명을 확인하고, C를 누르는 동안 날씨·벽·트릭룸·설치기와 아군·상대 랭크를 함께 확인합니다. V키는 사용하지 않습니다. D키는 사용하지 않습니다. 마우스·터치는 상세/필드 버튼으로 확인하고 X나 닫기 버튼으로 돌아갑니다. 상태이상은 포켓몬 색상과 HP창 문구로 표시하며, HP창에 포켓몬 타입은 표시하지 않습니다. 상대 HP창의 몬스터볼은 남은 포켓몬 수를 나타내며 기절하면 회색으로 바뀝니다. 배틀은 순차 HP·특성 및 도구 알림·임시 BGM/효과음을 지원합니다. 처음에는 음소거이며 **소리 켜기** 또는 설정에서 활성화하세요. [음원 출처·교체와 연출 범위](docs/BATTLE_AUDIO.md)를 참고하세요. 메가진화 47종·다이맥스의 실제 효과와 2D 연출을 지원하며 각 진영 둘을 합쳐 배틀당 1회 사용합니다. Z·거다이맥스 전용 형태·기술별 정교한 연출·계정 로그인은 후속 단계입니다.

레트로 테마의 한글 픽셀 글꼴은 [Neo둥근모 공식 웹폰트](https://github.com/neodgm/neodgm-webfont)입니다. 게임 실행 중 외부 글꼴 서버를 호출하지 않도록 파일을 포함했으며 [SIL OFL 1.1 라이선스](public/fonts/NEODGM-LICENSE.txt)를 함께 보관합니다.

영입 후보에 도감에 없는 기술이 있으면 NEW 표시가 나옵니다. ‘기술만 저장하고 계속’을 고르면 영입 없이 선택한 상대의 기술을 도감에 모을 수 있습니다. 이번 도전의 파티에는 추가하지 않지만 선택한 포켓몬의 해금·개체값·기술은 도감에 저장합니다. 영입 확인에서는 기술을 도감에만 저장하거나, 이번 도전의 기술 한 칸에 바로 장착할 수 있습니다. 교체 전에는 위력·명중·PP·효과를 비교하며, 도감의 기본 기술배치는 유지됩니다.

데이터를 다시 가져오려면 `pnpm data:import`를 실행합니다. PokéAPI의 한국어 이름·자력기 자료와 설치된 Showdown의 합법성·배틀 규칙을 함께 사용합니다. [데이터·이미지 출처 설명](docs/THIRD_PARTY.md)과 [검증 범위](docs/STATUS.md)를 확인할 수 있습니다. 개발용 원본 보고서는 `artifacts/reports/`에 보관합니다.

테라스탈을 구현했습니다. 도감에서 타입을 무료 저장하고 팀 공용 테라권으로 진영별 배틀당 한 번 사용합니다. 메가·다이맥스 상태의 해당 포켓몬에는 겹칠 수 없습니다. 싸운다 화면에서 T로 예약한 뒤 기술을 결정하세요. 새 도전 1장 지급·상점 900코인은 임시 공급안입니다. [규칙·저장·UI 캡처](docs/TERASTALLIZATION.md).
