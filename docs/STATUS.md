# 현재 게임 상태

기준: 2026-10-14. 현재 동작을 설명하며 완료 로그·테스트 개수·과거 승률은 누적하지 않습니다.

| 영역 | 현재 구현 |
|---|---|
| 도감·수집 | 서버 도감 615개 항목. 기본 스타터 27종, 승리 후 영입·알 뽑기·기술·개체값 수집 |
| 배틀 | 3마리 팀의 턴제 싱글 배틀, 기술·교체·변신·소모품·로그·상세 확인 |
| 도전 | 일반 모드 100층, 50층 중간 관문, 두 지역 테마와 빌런 이벤트 |
| 룰 | 기본·메진·다맥·테라·혼합·Z기술. 새 도전에서 선택하고 도중 변경 불가 |
| NPC | 일반·엘리트·관장·사천왕·챔피언·빌런. 새 네임드에는 두 단계 고정 팀과 역할별 육성 적용 |
| 성장 | 능력 포인트·성격·특성·기술·테라 타입·선택 폼·지닌 도구 관리 |
| 트레이너 장비 | 다이맥스밴드·테라스탈오브를 상점에서 구매, 동시 보유. 배틀 좌측 상단에 아이콘 표시 |
| 영구 상점 | 알 뽑기, 이로치 교환, 리롤 확장, 다시하기 횟수 확장 |
| 저장 | 계정 로그인, SQLite 저장, 진행 중인 배틀 복구. 같은 서버의 같은 계정으로 이어하기 |

| 포켓몬 이미지 | 도트 스타일 유지. 확보한 애니메이션을 방향·이로치·폼별로 사용하고, 없는 모습은 정지 이미지로 표시. [재점검 기록](../artifacts/reports/changes/ADDITIONAL_POKEMON_ANIMATIONS.md) |
