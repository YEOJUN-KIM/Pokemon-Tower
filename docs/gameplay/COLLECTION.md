# 수집과 육성

- Status: Active
- Updated: 2026-11-03
- Baseline Commit: `1c05b6f5079143ba4be7df3f3745155aee483ce7`
- Applies To: beta.6 개발 / 문서 담당 영역 (공개 패키지 표기는 beta.5)

타이틀의 **게임 시작**은 출전 파티 편성 화면이고, **포켓몬 도감**은 열람·성장·기술 관리 화면입니다. 포켓몬 목록과 계정의 해금·육성·기술·즐겨찾기·성장 포인트는 같은 저장 데이터를 사용합니다.

| 진입점 | 기본 표시 | 제공하는 기능 |
|---|---|---|
| 게임 시작 → 출전 파티 편성 | 보유 중 | 3마리 선택/제외, 선봉·중견·마무리 편성, 기본 정보, 배틀 룰과 도전 시작 |
| 포켓몬 도감 | 모두 보기 | 전체 도감/미보유 열람, 기본 정보, 보유 포켓몬의 성장·성격·특성·기술 설정 |

일반 도감에는 포켓몬 선택/제외, 출발 파티 칸, 도전 시작이나 룰 선택이 없습니다. 편성 화면에서는 육성 설정을 열지 않으며 도감에서 저장한 설정을 불러옵니다. 각 화면에서 필터를 초기화하면 해당 화면의 기본 표시로 돌아갑니다. 아직 영입하지 않은 포켓몬은 기본 정보만 볼 수 있습니다.

편성한 첫 번째 포켓몬이 선봉입니다. 기본 스타터는 1~9세대 일반 최종 진화형 27종입니다. 도감/편성 분리 당시 API·DB를 분리하지 않았으며, 현재 영구 성장 저장은 schema 49를 따릅니다. 기존 저장을 초기화하지 않습니다.

검사 범위: `e2e/pokedex-modes.spec.ts`는 두 기본 필터·도감/편성 역할·육성 저장 공유·전투 시작을 다룹니다. 과거 분리 당시 통과 수를 현재 HEAD 전체 E2E 결과로 사용하지 않습니다. 최신 확인 범위는 [개발자 검증](../development/DEVELOPER_COMMANDS.md#beta6-기준-검증)을 따릅니다.

기본 스타터는 기존 자력기를 전부 유지하고, `src/data/starter-moves.ts`의 추천 기술을 추가로 보유합니다. 처음 장착되는 4개도 이 추천 배치로 시작하므로 별도 편집 없이 사용할 수 있습니다. 예를 들어 이상해꽃은 기가드레인·오물폭탄·대지의힘·수면가루으로 시작합니다. 직접 저장한 기술배치나 영입·뽑기로 저장된 개체 설정은 추천 기본값으로 덮어쓰지 않습니다. [27종 최종 추천 배치와 특성 확인](STARTER_MOVES.md)을 참고하세요.

승리 후 상대를 영입하거나 도감에 등록하고, 중복 수집으로 더 높은 개체값과 기술을 모읍니다. 도전이 끝나도 계정의 도감·육성·성장 포인트는 남습니다. 수집 가능한 미진화 예외는 폴리곤2·스라크·피카츄·두랄루돈입니다.

일반 영입은 **승리 → 방금 싸운 상대 3마리를 후보로 제시 → 그중 1마리 선택**입니다. 후보를 랜덤 리롤하지 않으며, 향후 코인 상점의 Pokémon Scout와 별개입니다. 수집할 수 없는 옛 상대가 저장된 전투·Raid 등 특수 콘텐츠는 자체 후보 규칙을 유지합니다.

## 영구 성장: 빌드 자유도와 해금

성장 포인트는 포켓몬별 선택지·영구 해금을 늘리는 데 사용합니다. 가격은 현재 코드의 **임시값**이며 최종 밸런스가 아닙니다. `src/data/training.ts`, `src/data/growth-unlocks.ts`, `src/server/training.ts`, `TowerStore.train/unlockMove/unlockHiddenAbility`가 기준입니다.

| 항목 | 현재 구현 |
|---|---|
| EV capacity | 포켓몬별 `pokemon_growth.ev_capacity`. 신규 시작 0, 스탯별 최대 32·합계 최대 66. 새 배분 합계가 이미 확보한 capacity를 넘는 부분에만 +1당 8P. 0→66은 528P(임시 가격) |
| 재분배 | 확보한 capacity 내에서는 무료. 배분을 줄여도 capacity는 줄지 않고 포인트 환불은 없음. EV는 게임의 능력 포인트이며 원작 EV 252와 다름 |
| 성격 | 합법 성격으로 무료 변경, 별도 해금 없음 |
| 일반 특성 | 실제 사용 가능한 0/1 slot 특성 무료 변경 |
| Hidden Ability | 실제 H slot이며 일반/S slot과 겹치지 않는 합법 특성만 종별 1회 1,000P로 해금(임시값). 해당 종의 선택 폼들과 해금을 공유하고 이후 무료 변경 |
| Special slot | H와 구분하며 숨특 과금하지 않음. 현재 Greninja의 Battle Bond, Zygarde의 Power Construct가 실제 사례. 아무 폼/특성을 임의 허용하는 규칙은 아님 |
| 기술 | 기본·자력기 및 기존에 획득한 기술 무료. 추가 합법 기술은 포켓몬별 영구 해금. 같은 기술도 다른 종에는 별도 해금 필요 |

기술 가격은 기존 machine rarity를 재사용합니다: uncommon 300 / rare 500 / unique 800 / epic 1,200 / legendary 1,800P(모두 임시). 기계 목록 밖 기술은 uncommon으로 분류합니다. `move_unlocks`를 알·TM·성장 해금이 공유하므로 이미 얻은 기술에 재결제하지 않습니다. 해금 후 4칸 장착/교환은 무료입니다. 기술 적법성은 현재 폼과 Showdown 검증을 따릅니다.

기존 세이브는 투자한 EV 합계 이상 capacity를 보장하며, 저장된 실제 숨특 사용은 해금 상태로 이전합니다. 포인트·기술·IV·폼 설정을 초기화하거나 과거 투자를 다시 청구하지 않습니다. 상세 [migration](../engineering/DATABASE.md).

능력치 조정에서 개체값·능력 포인트·성격·특성·테라 타입을 관리하고 기술배치에서 기술 4개를 선택합니다. 기술 교체·칸 교환은 무료이며 선택 즉시 저장됩니다. 별도 기술 저장 버튼은 없습니다. 도감·상세 정보·육성 설정·테라 타입 선택창에는 배틀과 같은 타입별 테라스탈 아이콘을 타입 이름과 함께 표시합니다. 게임의 능력 포인트는 원작의 EV 252 수치와 구분합니다. 선택 폼은 기본종의 수집·육성을 공유하며 출발 전에 모습 설정에서 고릅니다. 배틀 중에만 바뀌는 변신폼은 기본 정보에서 확인할 수 있지만 출발 폼으로 저장하지 않습니다.

매 층 출전 준비에서 지닌 도구를 관리할 수 있습니다. 층 승리로 즉시 받은 성장 포인트는 현재 도전의 능력치 조정에도 사용할 수 있습니다. 도전 중 조정은 현재 파티 snapshot과 영구 설정의 차이를 검증하며 이미 생성된 배틀 팀을 바꾸지 않습니다. 이미 시작한 도전이나 생성된 배틀에는 저장된 스냅샷이 있으므로 영구 도감 변경이 모든 과거 기록에 소급 적용되지는 않습니다.

## 상대 후보와 수집 기준

새 일반·엘리트 상대의 미진화 허용 기준은 도감의 수집 기준과 일치시킨다. 폴리곤2·스라크·피카츄·두랄루돈 외 미진화체는 새 무작위 후보에서 제외하며, 네임드 원본 후보의 제외 대상은 최종 진화체로 환산하고 중복을 합친다. 레드의 피카츄·금랑의 두랄루돈과 대표 기믹은 유지한다. 기준은 `src/server/opponent-species.ts`와 공통 수집 판정이다.

이전 packed 팀·진행 중 배틀·재도전·legacy 생성 규칙은 재작성하지 않는다. 따라서 과거 미진화 상대가 저장된 배틀에서는 영입 후보가 세 마리보다 적을 수 있다. 당시 재생성한 328개 템플릿은 현재 입력 수가 아니며 현재 목록은 [NPC 데이터](../engineering/NPC_DATA.md)를 따른다.

## 테라 타입 선택

일반 포켓몬은 스텔라를 포함한 19개 테라 타입을 선택할 수 있습니다. 테라파고스는 스텔라로 고정되며, 오거폰은 가면에 따라 풀·불꽃·물·바위 중 해당 타입으로 고정됩니다. 선택 가능한 타입 목록과 저장 검증에 같은 제한을 적용합니다. 아이콘 변경은 타입의 선택·저장 비용이나 배틀 규칙을 바꾸지 않습니다.

[조작](CONTROLS.md) · [도구 관리](ITEMS.md) · 선택 폼의 상세 변경 근거 (로컬 전용: `artifacts/reports/changes/FORM_EQUIPMENT_FIXES.md`)

같은 포켓몬의 선택 폼들은 하나의 개체와 성장 데이터를 공유합니다. 개체값·능력 포인트·성격·성별·이로치는 공통이며, 타입·종족값과 사용할 수 있는 특성은 각 폼의 정보를 따릅니다. 현재 레벨 50 고정과 경험치 육성 없음 규칙은 유지합니다.

기술 배치·선택 특성·테라 타입은 폼별로 독립 저장합니다. 모습 설정에서 다른 폼으로 바꿨다가 돌아오면 해당 폼의 마지막 저장 설정을 불러옵니다. 아직 설정하지 않은 폼은 그 폼의 기본 설정으로 시작합니다. 능력치·특성·테라 등은 각 편집기의 저장 동작을 따르며 기술배치는 선택 즉시 자동 저장합니다. 새 도전은 선택한 폼의 저장 설정을 복사합니다. 이미 생성한 배틀의 팀과 행동 기록은 변경하지 않습니다.
