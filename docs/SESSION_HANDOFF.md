## 2026-10-12 Z기술 기반 구현

Z룰과 혼합 룰에 Z기술을 연결했다. 크리스탈 34종·가격3,000코인·팀당 배틀1회·위력/분류/변화 추가효과 표시·키보드/터치·짧은 한국어 연출·AI v9·스키마v27 저장 복원을 구현했다. 일본어 화면과 긴 컷신은 사용하지 않는다. 기존 AI/저장 호환을 유지한다. [사용/범위/검증](gameplay/Z_MOVES.md). 실데이터 변경 전 `.data/backups/pre-z-moves-20261012.sqlite` 백업을 생성하고 무결성 검사를 통과했다.

### 최종 화면과 후속 수정

- Z기술 예약 시 강화 가능한 기술만 금빛 배경·테두리·광택과 굵은 기울임꼴 기술명으로 강조한다. 키보드 커서 색상이 금빛을 덮지 않도록 처리했다. 사용자 결정으로 `Z POWER` 표식은 제거했다. 해제하면 일반 기술 표시로 돌아간다.
- 기술배치에서 이미 다른 칸에 배치된 기술을 선택하면 두 칸을 맞바꾼다. HP 이름 옆에는 현재 공개 타입을 표시한다. 특성 안내 → 효과/타입 갱신 → 기술 연출 순서와 저장 복원은 [특성 재생 안내](gameplay/ABILITY_EFFECT_TIMING.md)를 따른다. 개발 서비스 버전은 현재34다.
- 최신 UI 검증과 캡처는 아래 최종 검증 기록을 따른다. `artifacts/screenshots/z-moves/z-select-1280.png`, `z-select-390.png`는 최종 선택 화면이며 DB 백업·실험 원자료와 구분한다.

최종 검증(2026-10-12): `Z POWER` 제거 후 Windows 빌드와 빌드 내 TypeScript 검사 통과. `node --import tsx node_modules/@playwright/test/cli.js test e2e/z-moves.spec.ts --grep 'Z selection'`로 PC 1280px·모바일 390px 선택/위력/분류/발동/재사용 금지 2개 통과. 캡처를 최종 버전으로 갱신했고 문서용 사본은 `docs/images/z-move-desktop.png`, `z-move-mobile.png`다. 이 실행에는 구매 테스트·전체 회귀·난이도 시뮬레이션을 포함하지 않았다.

커밋 전 추가 검증: `tests/z-moves.test.ts`, `ability-timing.test.ts`, `battle-type-gender-regression.test.ts`, `run-rules.test.ts`, `held-items.test.ts`의 단위·통합43개 통과. Z공격/변화/전용 발동·구매/장착·마이그레이션·재생, 특성 안내와 타입 복원, 기존 룰·도구를 확인했다.

## 2026-10-12 새 PC 후속 작업

- 사용자가 기존 계정·저장을 로컬에서 확인했다. 개발 DB는 `.data/dev-migrated.sqlite`, `.env.local`에서 선택한다. 원본 인계 백업은 `.data/backups/`로 모았으며 Git·Docker 빌드에서 제외한다. 2026-10-12 기존 백업33파일을 해시 검증 후 이동하고 비어 있는 `pokemon-backups/`를 제거했다. 현재 개발 저장의 SQLite backup API 백업은 `.data/backups/transfer-2026-10-12-current.sqlite`이며 무결성 검사를 통과했다. 다른 PC로 옮길 때는 `.data/`, `.env.local`, `artifacts/`를 챙긴다. 실행 중인 DB는 복사 도중 변할 수 있으므로 게임을 종료하고 폴더를 복사하거나 검증된 백업을 복원한다.
- Docker 이미지 빌드와 새 `tower-preview_tower-data` 볼륨의 인계 백업 복원까지 완료했다. 사용자는 공개 터널을 나중에 사용하기로 했으므로 지금은 로컬 개발만 진행한다.
- 브라우저 아이콘과 오리지널 플레이어 트레이너 4프레임을 적용했다. 이전 지우 자산은 보존한다.
- Windows 상대 폴더 링크 문제는 빌드 전용 junction 처리로 해결했다. `pnpm build` 및 독립 패키지 전투·재시작·백업 복원을 검증했다.
- PokeAPI 포켓몬 이미지도 로컬 제공으로 변경했다. 가져오기 버전·파일 목록은 `artifacts/reports/local-pokemon-sprites.json`, 누락된 원본 변형은 `src/data/local-sprite-missing.json`에 기록한다. 이미지를 다시 옮길 때 `public/vendor/pokeapi/`를 포함한다.
- 알 뽑기 중 안내 문구 두 곳을 제거하고 기계 연출·결과 표시를 유지했다. AI·가격·확률은 변경하지 않았다.
- 최종 로컬 이미지 7,370개(약 121MiB), 원본에 없는 선택 변형 292개는 로컬 대체 경로로 처리한다. 전체 이미지·변신 검사 7개와 Windows 빌드 통과. PC 1280px·모바일 390px에서 외부 요청을 차단한 채 도감·일반/뒷모습/이로치 GIF·뽑기 연출·결과 로딩을 확인했고 외부 요청은 0건이었다. 남아 있던 Google Fonts import도 제거했다. 화면 기록은 `artifacts/screenshots/local-assets/`.

## 현재 사용자 결정

2026-10-12 100층 플레이 피드백 후속: [배틀 개선 기준](current/BATTLE_REBALANCE_PLAN.md)에 구현/설계/구상을 정리했다. 초반 종족값 후보군 확대, 빌런 등장15%·조직 독립 선정·100층 유지·승리 누적 직급 확률은 구현했고 관련32개/타입 검사를 통과했다. Z기술 기반 구현은 완료했고 다음은 네임드·빌런 간부/보스의 고정 대표 기믹과 층수별 준비된 팀, 기술에 맞는 육성·AI, 일반/엘리트 구분, 영양제 개선을 진행한다. 플레이어와 NPC의 서로 다른 기믹 사용은 설계 방향이며 현재는 여전히 양쪽 동일 룰이다. 오리지널 상위 NPC는 구상만 보관한다.

2026-10-12 기술 연출 후속: 기존 Showdown CC0 효과 PNG 22개를 Canvas 기술 연출에 연결했다. 이름별 대표 기술과 타입/물리·특수·변화 대체 구성을 제공한다. 명중 실패·흡수·스킵·동작 감소를 처리하며 AI·데미지·기술 규칙·음원은 변경하지 않았다. 구현·출처·검증은 [기술 시각 연출](gameplay/MOVE_EFFECTS.md)을 참고한다.

- 무료 PC + Docker + Cloudflare Quick Tunnel로 테스트를 유지한다. 유료 서버·도메인·PWA는 지금 진행하지 않는다.
- 실제 휴대폰에서 길게 누르기, 손 떼기, 더블 터치 스킵, 로그인 유지, 화면 잘림이 잘 동작함을 사용자가 확인했다.
- 새 컴퓨터의 코드·저장 복원은 완료했다. 다음은 정리한 기획 기준에 따른 NPC 대표 기믹과 준비된 팀 정비다. 합의하지 않은 AI·가격·난이도 수치를 임의로 확정하지 않는다.

## 저장과 무료 공개

2026-10-12 Git 자료 정리: `artifacts/`의 로그·경기 JSONL·중간 이미지/GIF·미리보기 WAV 920개를 추적에서 제외했다. 팀 샘플·manifest·요약·검증 보고서와 현재 문서에 직접 링크한 캡처 등 기존 408개는 유지한다. 로컬 원본은 삭제하지 않았으며 변경은 다음 커밋/푸시에 반영한다. 기존 과거 실험을 다른 PC에서 재감사하려면 제외된 원자료를 별도로 옮긴다. Z기술 구현을 이어가는 데는 Git의 코드·데이터·실행 자산으로 충분하다.

인터넷 DB는 `tower-preview_tower-data` 볼륨의 `/data/tower.sqlite`. 로컬 개발 DB와 자동 동기화되지 않는다. 최신 백업 이름, 새 PC 복원 명령, 실행 순서는 [컴퓨터 이전 안내](current/COMPUTER_MOVE.md)에 있다. 코드는 GitHub에 올렸으나 Docker 볼륨·개인 백업·제외된 AI 상세 로그는 clone에 포함되지 않아 직접 복사해야 한다.

임시 주소는 재시작 후 바뀔 수 있으며 `.data/preview.env`와 실제 터널 로그를 확인한다. 게임 자동 재시작은 설정돼 있지만 터널 자동 시작·정기 백업·고정 주소는 아직 미설정이다. `down -v`와 volume prune을 쓰지 않는다.
