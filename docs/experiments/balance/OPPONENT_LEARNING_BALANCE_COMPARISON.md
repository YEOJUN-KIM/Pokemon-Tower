# 적 AI 학습 적용 후 난이도 비교

2026-10-11. 화면 이름을 **혼합룰**로 변경했다. 저장 데이터의 내부 ID `chaos`는 유지해 이전 도전과 호환된다.

수정 샘플 18팀, 지역별 2개씩 총 18개 코스, 다섯 룰을 이용해 적 AI v7/v8을 같은 조건으로 비교했다. 플레이어는 기존 공개 정보 기반 immunity-only AI이고, 구성·영입·상점·육성치와 난수는 동일하다. 기존 코스를 재사용하는 비교이며 새 홀드아웃 검증이나 사람 승률 측정은 아니다.

공개 정보와 당시 합법 공격 후보로 측정한, 다른 공격이 있는데도 막힌 공격을 고른 횟수는 12,615→0이었다. 실제 반복 무효 횟수는 11,187→567로 줄었다. 다른 공격이 없는 상황 등이 포함되므로 모든 무효 공격이 없어지는 것은 아니다. 자발 교체는 23,276→23,139였다.

단기 동료 복귀 12건을 별도 재생해 확인했다. 모두 상대 포켓몬이 바뀐 뒤 발생했고, 그중 7건은 현재 포켓몬의 공격이 전부 막혀 다른 동료가 필요한 상황이었다. 나머지 5건도 상대가 모크나이퍼에서 어흥염으로 바뀐 뒤 루카리오에서 이븐곰으로 교체한 동일 사례의 룰별 반복이었다. 단기 복귀 횟수를 곧바로 불필요한 왕복으로 해석할 근거는 없었다.

## 영향이 큰 조합과 다음 작업

동탁군·데스니칸·어흥염 트릭룸 샘플(`auto-room-1`)의 평균 성공 층은 다섯 룰 합계 기준 약 46.22→36.86으로 내려갔다. 이 팀의 50층 통과는 33/90→21/90이었다. 전체 72건의 하락 중 36건이 이 시작 팀이었다.

기본룰의 한 관동 코스에서는 이 팀이 기존 70층에서 새 AI 상대 9층으로 내려갔다. 같은 10층 전투의 기존 적 AI는 15회 반복 무효를 내고 플레이어에게 패배했고, 새 AI는 반복 무효 없이 승리했다. 기존 통과 결과 일부가 상대의 잘못된 반복 선택에서 나온 사례다. 이후 층에서는 승패에 따라 영입·구매·아이템 사용도 달라질 수 있어 모든 차이를 특정 한 기술의 효과로 단정하지 않는다.

가격이나 상대 육성치를 일괄 조정할 근거는 이번 비교만으로 충분하지 않다. 우선 이 트릭룸 샘플의 기술배치와 대응 범위를 점검하는 것을 다음 작업으로 권한다. 이번 측정에서는 가격·육성치·AI를 추가 조정하지 않았다.
