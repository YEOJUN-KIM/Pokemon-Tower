# 50층 상점 포함 자동 시뮬레이션 · 2026-10-10

기술 표시는 새 전투용 등급을 만들지 않고 타입 색상 + 물리/특수/변화 아이콘을 함께 사용한다. 기술머신의 기존 상점 등급·가격·제목 색상은 유지한다.

## 조건과 결과

32개 고정 조우 코스에서 준비 수준 4종, 총 128회 등반. 같은 코스로 수집 준비팀의 메가/다이맥스 확보 조건을 각각 32회 추가하여 최종 비교는 192회다. 초기 구매 AI 결과 128회도 별도 보관했다.

| 조건 | 평균 클리어층 | 완주 |
|---|---:|---:|
|기본 스타터|4.8|1/32|
|중간 육성 스타터|10.7|1/32|
|충분히 육성한 스타터|21.0|2/32|
|수집·세팅 준비팀|32.7|3/32|
|준비팀 + 한카리아스나이트|32.9|5/32|
|준비팀 + 다이맥스밴드|36.5|8/32|

## 해석

- 준비가 결과를 바꾸는 방향은 확인됐다. 표본이 작고 자동 정책은 사람보다 단순하므로 이 값을 실제 유저 완주율로 해석하지 않는다. 난이도 수치는 이번 작업에서 변경하지 않았다.
- 기본 스타터 23/32는 1~4층에서 패배했다. 초반 실패 비중이 크다.
- 실제 확률 상점 표본에서는 플레이어가 사용할 변신 도구를 구매하지 못했다. 특수 기믹이 없는 기본 결과와 확보 조건을 분리했다. 확보 조건은 1층부터 무료 제공하는 통제 실험이며, 자연 드롭 확률 실험이 아니다.
- 준비팀의 평균 남은 코인은 약 27,187코인, 평균 지출은 약 6,351코인이다. 자동 구매가 필요한 품목만 사므로 사람이 쓰는 돈과 다르지만, 후반 자금보다 적절한 상품 출현이 제한 요인일 가능성이 있다.

## 방법과 한계

실제 Showdown 엔진과 현재 v4 기믹 정책을 양쪽에 적용했다. 실제 가중치 알고리즘으로 도구 4개와 기술머신 후보를 생성하며 가격·학습 가능 여부·장착 중복 제한을 적용했다. 상대 미래 정보는 사용하지 않는다. 승리 후 영입, IV 흡수, 기술 평가·교체, 상점 구매·장착, 5층 지속 강화, 다음 층 완전 회복을 포함한다.

고정 코스는 기존 녹화 자료를 사용하고 현재 네임드 팀/도구를 다시 생성한다. 쇼핑 RNG는 녹화된 다음 배틀 seed를 사용하며 실제 저장된 상점 seed와 동일한 상품을 재현하는 것은 아니다. 구매/학습/영입은 시뮬레이터 내부에서 합법 규칙을 모델링하고 Showdown에 전달하며, HTTP API를 매번 호출하는 완전한 서비스 시뮬레이션은 아니다. 구매 API/기술 교체는 별도 Chrome E2E로 검증했다. 자발적 교체 없음, 단순 타입/스탯/기술 평가, 세팅 변화기 보존 전략과 재고 재배치 최적화 없음. 초기 코인은 0, 영구 도감 재투자·테라/Z는 미포함이다.

초기 스크립트에서 전체 등반은 기믹 없는 TowerPolicy를 사용하던 부분을 수정했다. 초기 구매 정책의 빈 도구칸 제한을 완화해 더 좋은 도구로 교체하며, 충전기·특수공격 하락기를 할인 평가한다. 이는 게임 AI/난이도 변경이 아닌 측정 정책 수정이다.
