# NPC 라인업 갱신 후 밸런스 검사

2026-10-13. 총 13056전, 오류 0건. 재실행 12전에서 전체 배틀 로그 해시가 일치했다.

이전 단판 검사와 같은 팀·층·룰·시드 조건을 사용했다. 일반 코스 평균79.9%→79.2%, 아강55.2%→21.9%, 플라드리69.8%→21.9%, 게치스83.3%→49.0%. 다시하기의 별도 검사는 [패배 후 다시하기](../../reports/changes/BATTLE_RETRY.md)를 참고한다.

승률은 플레이어 AI의 단판 승률이다. 100층 완주율이나 사람 승률이 아니다. 9개 지역을 같은 비중으로 검사했으며 빌런 보스는 과다 표집하므로 별도로 표시한다.

양쪽 모두 실제 NPC의 ZMovePolicy를 사용한다. 네 플레이어 팀은 아래와 같으며 상대마다 바꾸지 않는다. 개체치와 포인트는 같은 층의 기존 곡선에 맞춘다. 10층부터 일반 도구와 룰별 기믹 도구를 지급하고 테라/혼합에는 매 배틀 테라권1개를 지급한다. 쇼핑 비용·재고 운·포획·소모품·영양제 추가분은 반영하지 않는다. 따라서 실전 경제와 연속 생존을 검증하는 검사는 아니다.

- 스타터: 리자몽 / 거북왕 / 이상해꽃
- 공격형: 한카리아스 / 메타그로스 / 라프라스
- 내구형: 야도란 / 아머까오 / 트리토돈
- 전용 Z 후보: 따라큐 / 짜랑고우거 / 갸라도스
