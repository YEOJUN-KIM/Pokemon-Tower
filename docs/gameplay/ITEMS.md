# 도구와 상점

지닌 도구는 가방과 장착 상태를 구분해 저장합니다. 출전 준비에서 장착·해제하고 다른 멤버의 도구를 확인 후 이동·교환할 수 있습니다. 오거폰 가면 등 모습에 고정된 도구는 자유롭게 변경할 수 없습니다.

10층 단위 정비에서 일반 상점·기술머신·육성을 이용합니다. 상품과 기믹 도구는 도전 룰·보유 상태에 따라 달라지며, 일반 상점과 기술머신의 무료 리롤은 종류별로 관리합니다. 영양제는 종류와 무관하게 도전 중 총 3개 제한입니다. 배틀 소모품은 화면에 표시된 합법적인 대상에 사용합니다.

영구 상점은 도전 코인과 별개인 성장 포인트를 사용합니다.

| 상품 | 현재 가격·효과 |
|---|---|
| 다시하기 확장 | 기본 0회. 500/1,000/1,500P로 도전당 1/2/3회, 다음 새 도전부터 적용 |
| 리롤 확장 | 500/1,000P의 두 단계 확장 |
| 이로치 교환권 | 10,000P, 보유 포켓몬의 이로치 외형 해금 |
| 알 뽑기 | 1회 200P. 보유 알 티켓이 있으면 먼저 사용 |

통찰로 상대 도구를 공개하는 이벤트는 도구를 획득하거나 삭제하는 이벤트가 아닙니다. 실제 획득과 표시를 구분해 정산합니다.
