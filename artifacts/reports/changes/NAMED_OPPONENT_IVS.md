# 관장급 개체값 총합·역할 배분

갱신: 2026-10-14. 개발 서비스51, DB 스키마28.

사용자 결정은 **관장 이상급만 역할에 따른 랜덤 배분**이다. 새 일반 모드의 관장·사천왕·챔피언·네임드·빌런 간부/보스에 적용한다. 일반·엘리트·조직원의 기존 IV 생성, 능력 포인트·성격·기술·도구·상대 멤버 구성은 변경하지 않는다.

## 배분

이전에는 템플릿의 같은 IV6개를 실제 층의 상한까지 일괄 낮춰 `9/9/9/9/9/9` 같은 배분이 나왔다. 이제 층별 총합 예산을 먼저 정하고 역할 가중치에 따라 각 스탯에 배분한다. 모든 IV는0~31의 정수이며 배분 총합을 보존한다.

| 역할 | 주로 배분하는 스탯 |
|---|---|
| 물리형 | 공격·스피드 |
| 특수형 | 특수공격·스피드 |
| 쌍두형 | 공격·특수공격·스피드 |
| 막이형 | HP·방어·특수방어 |

현재 기술의 물리/특수 위력과 종족값, 템플릿의 내구 포인트, 회복·지원 기술로 역할을 판단한다. 트릭룸 기술을 가진 구성은 스피드 IV0을 유지한다. 배분에 랜덤 변동을 주므로 같은 역할도 같은 수치6개로 고정하지 않는다. 스탯당31에 도달하면 나머지 스탯에 배분한다.

기존 층별 IV 상한을 `C`라 할 때 총합 최솟값은 `min(175,6C+2)`, 최댓값은 `min(180,최솟값+max(4,C))`다. 일반·엘리트의 기존 분포보다 총합을 우대하며 초중반에는 기존 최대 총합보다도 높다.99~100층은0~31 한계와 변동성을 함께 유지하므로 매우 높은 일반/엘리트 무작위 결과보다 항상 높다고 보장하지는 않는다. 트릭룸은 스피드0 때문에 최대 총합155를 적용한다. 일반의1~10층 IV0은 유지하고 관장급에는2~6점 예산을 준다.51층 이후 기존 완화 곡선도 반영한다.

| 층 | 관장급 총합 범위 |
|---|---|
| 5 | 2~6 |
| 40 | 56~65 |
| 45 | 62~72 |
| 50 | 74~86 |
| 55 | 50~58 |
| 95 | 170~180 |
| 100 | 175~180 |

예시:40층 한카리아스, 시드 `[1,2,3,4]`, 지진/드래곤클로/스톤샤워/칼춤 구성은 HP6·공격25·방어5·특공1·특방4·스피드15(총합56)다.50이라는 사용자 예시는 총합 예산의 설명용 가정이며 모든 층에50을 고정한 것은 아니다.

## 저장과 자료

`named-opponent-ivs.ts`에서 배틀 시드·종·층으로 배분을 재현하고 `generateOpponentTeam`의 관장급 경로에만 연결했다. 생성된 IV는 기존 packed opponent team에 저장하므로 새로고침·서버 재시작·재도전에서 다시 뽑지 않는다. 이미 생성된 배틀과 legacy 생성은 변경하지 않는다.

템플릿 JSON·샘플 CSV의 균등 IV는 참고용 원본 값이다. 실제 관장급 IV는 위 배분으로 대체한다. 시뮬레이션 소스 해시에 새 파일도 포함한다. 이전 승률 자료는 변경 전 IV 기준이며 이번 작업에서 새 난이도 시뮬레이션은 실행하지 않았다.

관련33개와 타입 검사 통과.1~100층의 범위·정수·총합·같은 시드 재현성, 역할별 평균 편향, 일반/엘리트/legacy 경로 유지, 실제 네임드 팀의 저장/재시작·재도전 보존과 NPC 기믹·라인업·통찰 도구 회귀를 검증했다. 프로덕션 빌드·전체 테스트·새 난이도 측정은 이번 실행에 포함하지 않았다.
