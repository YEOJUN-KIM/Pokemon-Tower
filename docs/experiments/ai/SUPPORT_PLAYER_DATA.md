# 벽 활용 자동 플레이어와 학습용 행동 데이터 · 2026-10-10

실험용 자동 플레이어 v9가 안전한 상황에서 벽을 설치하고, 보호받을 수 있는 딜러로 교체한 뒤 랭크업을 판단하도록 구현했다. 게임 상대 v7과 기존 실험 v8은 수정하지 않았다. 모델 가중치 학습은 아직 하지 않았다.

## 측정 조건

- 6개 고정 팀 × 9개 지역 코스 × 11개 층(1/5/10/20/30/40/50/60/75/90/100) × 5개 룰 × 3개 AI × 기존/새 코스 = **17,820개 독립 배틀**.
- 기존 코스에서 지역별 첫 코스 하나씩 9개, 새로 생성한 9개 코스. 코스 ID 중복 없음. 정책·팀·원본 코스 해시를 실행 전에 고정했다.
- v7은 기존 공격/교체 정책, v8은 이전 벽/트릭룸 실험 정책, v9는 새 벽 설치→딜러 교체→랭크업 정책이다. 상대는 모두 v7.
- 모든 배틀은 완전 육성된 동일 팀/기술/도구로 HP를 회복하고 시작한다. 벽 요원에게 빛의점토를 미리 지급했다. 영입·상점·경제·층간 누적 소모는 측정하지 않는다. **등반 성공률이나 사람의 승률로 읽으면 안 된다.** 초반 상대는 6Z라 개별 승률이 높다.
- 기본/메진 수치가 같은 이유는 이번 고정 팀 및 샘플에서 실제 메가진화가 없었기 때문이다. 메진 활용 능력 검증으로 해석하지 않는다. 새 코스 v9에서 상대 다이맥스는 다맥/개판 각22회, 테라는 테라/개판 각 플레이어594회·상대432회 발생했다. 플레이어 메가스톤·다맥 도구는 지급하지 않았다.

## 정책과 입력 범위

- 마무리 공격 우선, 상대의 공개 타입/마지막 기술로 필요한 벽 추정, 예상 생존 여유·동료 존재·벽 중복·벽 파괴 기술 확인.
- 벽이 두 턴 이상 남았을 때 교체 피해/체력/타입/공격력/랭크업 기술을 고려해 딜러 교체. 자발적 교체 최대4회, 간격3턴, 재진입 제한, 교체 불가/다이맥스 상태 확인.
- 보호 중 랭크업은 체력과 예상 피해를 확인하고 반복을 제한. 트릭룸은 살아 있는 아군이 모두 상대보다 느린 경우 우선 고려.
- 상대의 실제 노력치/개체값/도구/비공개 기술/선택 행동을 읽지 않는다. 데미지·속도 추정은 근사치이고 모든 특성/우선도/상태를 완전하게 모델링하지 않으므로 개선 대상이다.

## 데이터 형식과 다음 학습

- `artifacts/support-player-*-turns.jsonl`: 행동 직전 자기 팀 상태, 공개 상대 상태, 합법 행동 목록, 공개 벽/트릭룸/날씨/랭크/이전 행동 맥락, 선택한 행동과 이유, 배틀 결과. 총 **164,948개 플레이어 결정**.
- 입력은 `observation`과 행동 전 `context`만 사용한다. `action/reason/outcome`은 목표 또는 결과 라벨이다. `outcome`은 미래 정보이므로 입력에 넣지 않는다. `reason`은 기존 규칙의 설명이지 최적 행동의 증명은 아니다.
- `artifacts/support-player-*-battles.jsonl`: 재생용 시드/양쪽 팀/행동/전체 공개 프로토콜. 여기에 저장된 상대 전체 팀은 오프라인 재생용이며 정책·모델 입력에 사용하지 않는다.
- 같은 `courseId`에 속한 모든 룰/정책/팀/층을 같은 학습 또는 검증 그룹에 둬야 한다. 턴별 무작위 분할은 같은 배틀과 코스가 양쪽에 섞인다. `battleKey`는 조인 키이며 숫자형 학습 특성으로 쓰지 않는다.
- 같은 상대/시드에서 v7/v8/v9의 개선·악화·동률 쌍 비교는 `artifacts/support-player-audit.json`에 저장했다. 벽이 도움이 된 경우와 턴만 낭비한 경우를 모두 남겼다. 다음은 이 차이를 분류하고 실제 등반/정비/영입 조건에서도 검증하는 작업이다.

재실행: `node scripts/run-support-player-simulation.mjs --resume`. 실행 전에 해시를 비교하며 기존 파일은 완성된 동일 조건에만 재사용한다. 데이터 검증: `node scripts/audit-support-player-data.mjs`. 재생 검증: `node node_modules/tsx/dist/cli.mjs scripts/audit-support-player-replays.ts`.
