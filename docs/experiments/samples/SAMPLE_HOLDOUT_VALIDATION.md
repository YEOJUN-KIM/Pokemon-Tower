# 수정 샘플 새 코스 검증 · 2026-10-11

앞선 샘플/벽 분리 실험에서 선택한 **시작 공격 기술 수정만**을 기존 샘플과 비교한다. 새 결과를 보고 계수나 샘플을 조정하지 않는다. 실제 플레이어 조작이나 게임 상대 AI·가격·난이도는 변경하지 않는다.

## 검증 설계

1~9세대 테마별 2개, 총 18개의 새 100층 코스를 실제 타워 생성기로 기록했다. 기록은 임시 메모리 저장소에서 만들며 실제 플레이 저장을 변경하지 않는다. 기존 생성기와 같이 각 층을 기록할 때 이전 층 승리를 가정해서 빌런 캠페인의 진행 상태를 적용한다. 코스는 두 조건을 실행하기 전에 확정했다.

기존 기록 709코스·44,420개의 서로 다른 배틀 시드와 새 18코스·1,800배틀을 비교했다. 코스 ID·전체 코스 내용·배틀 시드 중복은 모두 0이었다. 기존 코스에서 변형해 만든 이전 자료 간 중복은 기존 시드 수에서 제거한다. 같은 종이나 트레이너가 다시 나오는 것은 정상적인 생성기의 표본이다.

시작 팀은 기존 실험의 18팀을 그대로 사용한다. 원본/수정 샘플 모두 같은 종·IV·육성·특성·성격·테라 타입·보조 기술을 가지며 수정 조건은 시작 공격 기술만 다르다. 샘플 생성 계수도 이전 파일 해시와 일치한다. 플레이어 immunity-only, 상대 v7, 기존 조합 평가와 상점 경제를 고정한다. 벽 유지 후보는 적용하지 않는다.

18팀×18코스×3룰(기본/테라/개판)로 **조건별 972등반, 총 1,944등반**이다. 추가 영입/TM의 공격 기술 평가는 기존 방식이다. 시작 팀은 재사용하므로 새로운 포켓몬 조합 검증까지 포함한 결과는 아니다. 지역별 두 코스 및 동일 코스의 팀/룰 반복은 연관되므로 독립적인 972코스 표본이나 사람 승률로 해석하지 않는다.

## 결과

총 **75,928배틀·1,944등반** 완료. 마지막 패배 **1,870개**의 전체 공개 프로토콜과 기록된 행동을 재생해 일치 확인했다. 층 순서, 승리 후 계속 진행, 돈의 수입·지출, 금지 기믹, 공통 입력·가격·정책, 정비 전후 프로필과 소스 해시 검사를 통과했다. 개발 실험의 샘플 정의·가격·플레이어/상대 정책과도 일치했다.

| 조건 | 50층 통과 /972 | 100층 완주 /972 | 평균 성공 층 | 10층 미만 종료 |
|---|---:|---:|---:|---:|
| 기존 | 143 | 15 | 26.75 | 328 |
| 수정 샘플 | 428 | 59 | 49.44 | 156 |

대응 등반 중 680개는 더 높이 올라갔고, 154개는 낮아졌고, 138개는 같았다. 스타팅·벽·트릭룸·혼합 네 그룹 모두 평균이 상승했다. 트릭룸 평균은 10.59→27.48로 개선됐지만 다른 그룹보다 낮았다. 모든 조합의 일관된 개선을 의미하지 않는다.

| 룰 | 기존 100층 완주 /324 | 수정 100층 완주 /324 |
|---|---:|---:|
| 기본 | 3 | 17 |
| 테라 | 2 | 13 |
| 개판 | 10 | 29 |

마지막 패배에서 반동 대기가 관측된 사례는 619→4개, 실제 대기 턴은 1,045→4턴이었다. 시작 시 껍질몬 직접 공격 수단 손실과 트릭룸 역할 손실은 두 조건 모두 0이었다. 공개 정보로 유효한 합법 공격 대안이 있는 무효 선택도 모두 0이었다. 하지만 반복 무효가 발생한 마지막 패배는 99→118개여서 전투 중 공격 담당 생존·교체 문제까지 해결한 결과로 보지 않는다. 등반 길이와 노출 배틀 수가 달라 사건의 절대 횟수만으로 정책을 평가하지 않는다.

**시작 기술배치 수정의 개선은 새 코스에서도 유지됐다.** 이후 비교에서는 이 수정 샘플을 기준 후보로 사용한다. 게임 정책·상대 AI·가격·난이도 승격은 하지 않는다. 새 팀 조합 검증과 남은 패배의 공격 담당 생존/교체 진단은 별도 후속 범위다.

## 자료와 재실행

```powershell
node scripts/run-sample-holdout.mjs <new-numeric-id>
```

기존 개발 실험 20261010의 샘플과 평가 코드를 사용한다. 실행은 먼저 입력·소스·이전 코스 파일의 해시와 비교 계획을 저장하고, 새 코스를 기록한 뒤 중복 검사에 통과해야 시뮬을 시작한다. 같은 ID나 기존 코스가 있으면 덮어쓰지 않고 중단한다.

현재 결과 재감사:

```powershell
node node_modules/tsx/dist/cli.mjs scripts/audit-sample-holdout.ts 20261011
```

- `artifacts/sample-holdout-20261011-preregister.json`: 새 코스 생성 전 확정한 조건/샘플/정책/소스 및 이전 코스 해시.
- `artifacts/sample-holdout-20261011-{courses|freshness|manifest}.json`: 새 코스·중복 검사·최종 입력 해시.
- `artifacts/sample-holdout-20261011-{basic|tera|chaos}-{baseline|samples}-{battles|trace}.jsonl`: 실제 팀·행동·마지막 패배 전체 공개 기록과 보유 프로필 변화.
- `artifacts/sample-holdout-20261011-{audit.json|report.md}`: 룰/팀/카테고리별 대응 결과와 재생 감사.
- `artifacts/sample-holdout-20261011-theme-summary.json`: 원본 결과/코스 해시와 테마별 요약(지역별 두 코스).

관련 단위 테스트 46개 및 `tsc --noEmit` 통과. 추가 2개는 이름만 바꾼 코스 재사용, 배틀 시드 재사용, 새 코스 내부 중복, 잘못된 층 순서를 거부하는지 검사한다. 모델을 훈련하거나 실제 게임 정책에 승격하지 않는다.
