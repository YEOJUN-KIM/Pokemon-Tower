# 일반 모드 NPC 샘플 밸런스 1차 검사

2026-10-13. 총 13056전, 오류 0건. 재실행 12전에서 시간 표시를 제외한 배틀 이벤트 해시가 일치했다.

승률은 플레이어 AI의 단판 승률이다. 100층 완주율이나 사람 승률이 아니다. 9개 지역을 같은 비중으로 검사했으며 빌런 보스는 과다 표집하므로 별도로 표시한다.

양쪽 모두 실제 NPC의 ZMovePolicy를 사용한다. 네 플레이어 팀은 아래와 같으며 상대마다 바꾸지 않는다. 개체치와 포인트는 같은 층의 기존 곡선에 맞춘다. 10층부터 일반 도구와 룰별 기믹 도구를 지급하고 테라/혼합에는 매 배틀 테라권1개를 지급한다. 쇼핑 비용·재고 운·포획·소모품·영양제 추가분은 반영하지 않는다. 따라서 실전 경제와 연속 생존을 검증하는 검사는 아니다.

- 스타터: 리자몽 / 거북왕 / 이상해꽃
- 공격형: 한카리아스 / 메타그로스 / 라프라스
- 내구형: 야도란 / 아머까오 / 트리토돈
- 전용 Z 후보: 따라큐 / 짜랑고우거 / 갸라도스

## 1차 판단과 추가 확인

총 19,584전과 별도 재실행 54전을 확인했다. 전투 오류·무승부는0건이며 저장한 시드로 재현됐다.

일반 상대 구간 평균은 약81~82%, 50층54.2%, 100층59.0%로 관문에서 난이도가 높아지는 경향은 보인다. 다만 100층이50층보다 더 어려운 결과는 아니며, NPC 종류·육성·룰 조합이 달라 층수만의 효과로 해석할 수 없다. 모든 구간이 같은 네 플레이어 팀을 사용하지만 이것은 100층 완주 검사가 아니다.

다이맥스 룰87.8%는 기본76.8%보다11.0%p 높다. 다른 룰은77~81%다. 이 조건에서는 다이맥스가 가장 유리했고 혼합이 가장 쉬운 결과는 아니었다. 플레이어 기믹 후보·고정 기술 구성과 AI 판단의 영향을 받으므로 룰 자체의 최종 강함 순위는 아니다.

보스별 편차가 가장 큰 점검 후보다. 시드를 늘리고 선봉을 바꿔도 마적·단델은 어려운 편이고 비주기·구즈마는 쉬운 편이다. 최초2개 시드의 마적12.5%를 확정값으로 사용하면 과장되므로 아래 추가 확인을 같이 본다.

플레이어 기믹 도구를10층부터 지급하는 유리한 조건이며, 실제 상점의 전설 등급 재고·가격은 반영하지 않았다. 영양제 추가 육성·소모품·포획도 없다. 따라서 실제 플레이는 장비 수급과 팀 교체에 따라 더 쉽거나 어려워질 수 있다. 같은 상대·같은 팀 반복 결과는 서로 독립적인 사람 표본이 아니다.

현 단계에서는 전 구간을 일괄 강화·약화하기보다 마적·단델과 비주기·구즈마의 격차, 이후 다이맥스 우위를 점검할 근거가 생겼다. 게임 밸런스와 NPC 샘플 수치는 변경하지 않았다.

상대별 추가 검사 승률은 빌런76/96층, 단델50/100층 합산이다. [시드16개 검사](NORMAL_MODE_BALANCE_OUTLIERS.md)와 [출전 순서 검사](NORMAL_MODE_BALANCE_LEADS.md)에 층별 표를 따로 기록했다.
