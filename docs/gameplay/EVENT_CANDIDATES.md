# 이벤트 콘텐츠 보강과 후순위 후보

기준: 2026-10-20. 이벤트 시스템의 기반은 구현된 상태다. 이 문서는 **기존 콘텐츠를 무엇부터 보강할지**와 아직 채택하지 않은 아이디어를 구분한다. 새 엔진·공통 보상 시스템 재구현을 남은 작업으로 잡지 않는다. 현재 수치/규칙은 [EVENTS](EVENTS.md), 추가 절차는 [EVENT_SYSTEM](../engineering/EVENT_SYSTEM.md)을 따른다.

## 구현된 기반과 남은 콘텐츠

| 구현된 콘텐츠 | 현재 범위 | 앞으로 검토할 내용 |
|---|---|---|
| 미스터리 상자 | v1 보상 유지, v2 꽝/손실/보상 결과와 공통 Reward Popup | 위험·보상 비율과 기대 가치 |
| 브리더·여행 상인 | 티켓 선물/900코인 거래 | 실제 수급과 구매 가치·빈도 |
| 도전자 선택전 | 공통 Sample에서 3명 추첨·Rank·추가 배틀·저장된 보상/선택 | Sample/전술·보상 다양화, 난이도·빈도 |
| Mirror | 도전자 내부의 3% 희귀 후보·기존 팀 복사·별도 보상 | 반복 체감·강화/보상 가치 |
| Raid | 20종 보스의 단계 전투·영입·보상·재도전 snapshot | 보스 추가, 패턴·보상 차별화, 발생 시점/빈도 |
| 순간이동 | 구간 내 목적지 저장·재방문 순서와 쿨다운 처리 | 이동 가치·진행 흐름·장기 플레이 검증 |
| 히든상점 | 상품/가격/재화 snapshot·구매 한도·공통 배낭 | 상품 가치·재화별 가격·희소성과 등장 빈도 |
| 빌런 캠페인 | 8개 조직의 독립 조무래기→간부→보스 트랙 | 필요에 따라 다른 조직 테마/NPC/보스/보상 추가 |
| 히든보스 | 조건부 챕터 완료 확정 이벤트·기존 보스 샘플·보상 | 필요한 테마의 보스와 연출/보상 검토 |

위 항목은 **구현 완료**를 뜻하며 콘텐츠 양·경제·사람의 100층 플레이 검증까지 끝났다는 의미는 아니다. 도전자 상·중·하 고정 3명, 레이드 연결 미구현, 빌런 캠페인 미구현이라는 옛 계획은 현재 기준이 아니다.

## 1차 완성 후 보강 기준

1. 현재 콘텐츠를 사람이 플레이해 부족한 보스·NPC·패턴과 반복 피로를 찾는다.
2. Raid 보스/패턴/보상, 도전자 Sample, 조직별 NPC/보스/보상을 기존 정의·snapshot·배틀/Reward 경로로 보강한다. 추가 조직/히든보스 수를 먼저 정하지 않는다.
3. 일반 전투와 보상·재화를 함께 측정해 콘텐츠별 기대 가치와 플레이 시간을 비교한다.
4. 전체 발생률 20%·쿨다운 2에서 시작하고 종류 weight와 내부 결과 weight를 별도로 조정한다. 신규 독립 빌런 트랙과 과거 로켓단 weight는 구별한다.
5. 콘텐츠 수정 후 선택 전/배틀 중/보상 선택 중/다음 층의 저장·재접속·중복 지급 방지를 확인한다.

도전자 영입 없음, Raid의 기본 모습 영입과 특별 보상, 히든상점 두 재화/구매 한도 등은 현재 코드의 규칙이다. 과거 기획 예시로 이를 덮어쓰지 않는다. 새 캠페인 분기·다른 보상 방식은 별도 요청과 설계가 있을 때만 채택한다.

## 후순위 아이디어 — 1차 완성 필수 아님

| 후보 | 현재 상태 |
|---|---|
| 위험 선택 배틀 | 미채택 아이디어. 위험·실패 비용·보상을 실제로 설계하기 전까지 구현 순서에 넣지 않음 |
| 연승 도전 | 미채택 아이디어. 기존 100층 진행과 자원 소비를 해치지 않는지 추후 검토 |
| 라이벌 | 미채택 아이디어. 반복 만남·팀/서사 변화는 미정 |
| 교환 NPC | 보류. 교환 대상·가치·현재 수집과의 관계가 미정 |

독립 영양제 상인, 추가 Mirror 변형, 새 교환권·외형 보상·상점 할인권 등의 옛 예시는 확정된 구현 목록으로 유지하지 않는다. 기존 보상/상점으로 충족되는지 필요성을 먼저 검토한다. 희귀 스카우트전은 Raid로, 전술 마스터는 도전자 컨셉으로 흡수한 방향을 유지한다.
