# 타워 배경·BGM 기획

30층 현재 적용: 5·15·25층 관장, 10·20·30층 챔피언. 빌런은 일반 층에 같은 조직의 조직원으로 무작위 등장하며 시설 배경·빌런 곡을 사용한다. [조직 이벤트 구상과 현재 범위](../gameplay/VILLAIN_EVENTS.md). 챔피언은 정상 배경을 우선하고 일반 층은 전체 타워의 진행 비율에 따른 기존 배경을 사용한다.

2026-10-09. 사용자 요청을 정리한 콘텐츠 설계 문서다. 현재 CC0 완성 음원 6곡(전투 5·승리 보상 1), 자체 결과 음악 2곡(완주·패배), CSS 경기장 5종을 적용했다. 관장·챔피언은 현재 관장 곡 Battle Theme A를 공유한다. 음악 전환은 1.1초 크로스페이드다. 현재 적용은 [배틀 연출과 소리](../gameplay/BATTLE_AUDIO.md)를 따른다. 아래는 초안의 근거와 남은 확장 구상이다.

추후 관장·챔피언 전투에 후보곡을 여러 개 추가하고 대결마다 후보 중 하나를 선택해 재생한다. 현재는 후보 추첨을 구현하지 않고 공통 곡 하나를 사용한다. 후보 구성과 선택 확률은 곡을 추가할 때 정한다.

## 테마와 무작위 상대

- 50층 단위 세대 테마는 트레이너 출신과 외형의 기준으로 사용한다. 포켓몬은 세대 제한 없이 구성한다.
- 각 층의 상대는 타입 전문·혼합·전술 중심 후보에서 선택한다. 부족한 네임드 조합은 일반·엘리트 트레이너로 채운다.
- 같은 타입·인물이 과도하게 연속 등장하는 것을 제한하지만, 10층 구간마다 상대 타입을 고정하지 않는다.
- 층에 따른 변화는 배경, 음악, 상대 전술 수준으로 표현한다. 배경이 다음 상대 타입의 정답이 되지 않도록 한다.

## 필요한 음악

| 상황 | 음악 역할 |
|---|---|
| 일반 트레이너 배틀 | 기본 긴장감과 빠른 반복 플레이 |
| 엘리트 배틀 | 일반보다 강한 상대의 분위기; 별도 곡은 후속 후보 |
| 관장 배틀 | 공식 도전과 관문 |
| 빌런·악당조직 배틀 | 위협과 불안감 |
| 챔피언 배틀 | 구간의 절정 |
| 상대 준전설·전설·환상 등장 | 하나의 묵직한 희귀 포켓몬 전투곡 |
| 승리 후 영입·기술·보상 선택 | 승리해서 신난 축하 분위기의 반복 곡 |
| 타워 완주 | 짧은 축하 도입과 명예의 전당 음악 |
| 패배 | 짧고 차분한 마무리 음악 |

상점·출전 준비 음악은 보상 선택 곡을 우선 재사용하는 후보로 두고, 별도 곡은 나중에 판단한다. 층마다 새 곡을 만드는 대신 위 역할에 맞는 곡부터 확보한다. 세대별 곡 변형은 이후 확장이다.

### 전환 규칙 초안

- 배틀 시작은 트레이너 역할에 맞는 곡을 사용한다. 역할은 표시 이름 문자열에서 추측하지 않고 트레이너 콘텐츠 정보로 지정한다.
- 상대 준전설·환상·전설이 실제 등장해 공개될 때 특별 곡을 적용한다. 서버의 미공개 파티를 미리 읽어 음악으로 상대를 알려주지 않는다. 플레이어가 같은 종을 사용한다는 이유로 상대 음악을 바꾸지는 않는다.
- 일반·엘리트 배틀은 특별 곡으로 전환 후 해당 경기 끝까지 유지하는 안을 우선 검토한다. 교체마다 일반 곡과 특별 곡이 반복 전환되는 것을 피한다.
- 관장·빌런·챔피언 곡과 특별 곡의 우선순위는 미확정이다. 초안은 네임드 고유 곡을 유지하고 특별 등장에 짧은 음악 도입을 추가하는 방식이다. 특별 곡으로 완전히 전환하는 방식과 실제로 들어보고 결정한다.
- 한 경기에서 서로 다른 희귀 분류가 공개될 때의 우선순위는 미확정이다. 여러 곡을 빠르게 오가는 대신 한 곡을 유지하거나 한 번 강화하는 방식으로 정한다.
- 준전설·환상·전설은 별도 콘텐츠 분류표로 관리한다. 종과 폼을 포함하며 능력치 합계만으로 분류하지 않는다.
- 승패가 서버에서 확정되어도 배틀 연출 종료 시점에 결과 음악으로 전환한다. 승리 후 선택 화면, 최종 완주, 패배를 각각 구분한다. 마지막 층에서는 완주 곡으로 바로 이어지는 안을 사용한다.
- Shift 건너뛰기·새로고침·이어하기에도 현재 공개 상태와 화면에 맞는 음악으로 복구한다. 같은 곡은 렌더링이나 행동마다 처음부터 다시 시작하지 않는다.
- 곡 변경은 짧게 음량을 낮추고 다음 곡으로 이어 붙이는 방식으로 갑작스러운 전환을 줄인다. 기존 음소거·음량·탭 숨김·사용자 입력 후 재생 규칙을 유지한다.

## 배경 후보

최종 배경 자산은 아직 선정하지 않았다. 초기에는 기존 경기장 구조를 유지하면서 색·하늘·조명·실루엣을 바꾸는 방식으로 분위기를 비교할 수 있다.

| 후보 | 표현 방향 |
|---|---|
| 입구·야외 경기장 | 밝은 하늘, 낮은 관중석, 여행 시작 |
| 중층 실내 경기장 | 벽과 조명, 타워 안쪽으로 들어온 느낌 |
| 야간·도시 경기장 | 창밖 도시 실루엣, 다른 시간대의 분위기 |
| 상층 경기장 | 높은 창, 구름과 먼 풍경 |
| 정상·챔피언 경기장 | 중앙 조명과 장식, 최종 도전 |
| 악당조직 전용 경기장 | 어두운 시설, 단체별 장식; 특별 상대에만 사용 |

이 표는 층 배치 확정안이 아니다. 20·30층 플레이 구간에 맞춰 적은 수의 배경부터 배치한다. 포켓몬·HP·기술 선택의 가독성과 기존 바닥 위치를 유지하며 PC·모바일에 같은 구도를 적용한다.

배경 확보 방식은 직접 제작한 2D 배경 또는 이용 범위가 확인된 배경 자산 중 선택한다. 사용자에게 여러 스타일을 보여주고 최종 방향을 정한다. 기존 포켓몬 도트와 어울리는 밀도와 색감을 우선한다.

## 현재 구현과 다음 적용 순서

CC0 전투 BGM 6곡과 자체 결과 음악 3곡을 적용했고 설정에 곡별 미리듣기를 추가했다. 기존 관장·챔피언·새 엘리트와 공개된 상대 희귀 종, 보상·완주·패배 전환을 연결했다. 빌런은 곡·분기와 트레이너 샘플을 준비했으며 실제 층 배치는 후속이다. 경기장 5종을 CSS로 제작해 타워 진행 비율·상대 역할에 따라 선택한다. 외부 음악의 출처·라이선스를 THIRD_PARTY에 기록했다. 배경은 자체 CSS다.

실험용 우선순위는 공개된 희귀 포켓몬 통합 곡 > 트레이너 역할 곡이다. 희귀 곡은 같은 경기에서 유지한다. 네임드의 음악을 유지하는 위 초안 대신 특별 포켓몬의 등장감을 우선 적용했다. 플레이 피드백에 따라 바꿀 수 있다.

1. 트레이너 샘플에 세대·역할·타입/전술·파티 정보를 연결한다.
2. 희귀 종 분류와 공개 등장 기준, 음악 전환 우선순위를 정한다.
3. 역할별 곡을 선정 또는 제작하고 재생 분기를 구현한다. 외부 음원은 출처와 사용 범위를 THIRD_PARTY에 기록한다.
4. 배경 후보를 비교하고 적은 수부터 20·30층 구간에 적용한다.
5. Shift, 교체, 보상 선택, 완주, 패배, 새로고침에서 음악과 화면이 일치하는지 확인한다.
