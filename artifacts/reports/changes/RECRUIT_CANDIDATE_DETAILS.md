# 영입 후보 기본 정보

갱신: 2026-10-14.

승리 후 영입 후보를 선택해 정보 버튼을 누르면 도감 기본 정보와 같은 `PokemonSummary` 배치로 표시한다.

- 포켓몬 이미지·전국번호·지역/세대·타입·테라스탈 타입·변신 가능 배지
- 종족값 육각형 그래프와 수치·합계
- 실제 상대 특성 및 설명 툴팁·성격
- 4개 기술의 이름·타입·물리/특수/변화 아이콘·위력·명중률·PP

사용자가 제시한 마지막 화면 기준으로 기술 효과 설명 본문은 표시하지 않는다. 도감의 기존 기술 목록은 변경하지 않는다. 후보 정보는 개인 도감의 육성 세팅이 아닌 저장된 상대 팀을 사용한다. 타입·테라타입·이로치도 승리 후에만 반환하며 배틀 중에는 후보 정보를 공개하지 않는다.

딱구리·히스이 윈디·피카츄·두랄루돈을 실제 CSS로 별도 렌더링해 Chrome1280px/390px의 가로 넘침 없음,4개 기술 표시와 배지를 확인했다. 이 검증은 실사용 DB의 상호작용 테스트와 구분한다. 캡처는 `artifacts/qa/screenshots/recruit-summary-20261014/`다. 관련37개 회귀와 타입 검사 통과, 전체 테스트·프로덕션 빌드는 이번에 미실행.
