# 1차 완성 이후

기준: 2026-10-20. Normal Mode 100층의 1차 완성은 82c870ed에서 마쳤다. 완료된 개발 단계와 과거 수치는 Git과 [보고서](../../artifacts/README.md)에 남기고 이 문서에는 후속 방향만 둔다.

## 현재 작업

- 불필요한 구버전·중복 파일과 임시 출력을 정리한다.
- 현재 기능을 설명하는 문서와 날짜별 작업 보고서를 분리하고, 코드의 실제 설정·저장 버전·파일 경로에 맞춘다.
- 정리 후 관련 자동 검사와 빌드로 참조 누락을 확인한다.

## 유지보수

- 실제 플레이에서 발견한 진행 불가·저장/재접속·입력·표시 문제부터 수정한다.
- 난이도·경제·이벤트 빈도는 Run 결과를 보고 조정한다. 전체 발생률, 종류 weight, 내부 결과 확률은 구분한다.
- 추가 콘텐츠·연출·음향은 필요성을 확인한 범위에서 개선한다. 이미 완료한 UI·알뽑기·이벤트를 다시 미구현 목록에 넣지 않는다.
- 사람의 100층 플레이와 실제 모바일/컨트롤러 확인은 자동 테스트·AI 승률과 구별해 기록한다.

## 향후 검토

- **Hard Mode:** Normal Mode와 구분한 난이도·자원·상대/보상 설계.
- **ML AI:** 충분한 플레이 기록을 쌓은 뒤 연구한다. 현재 규칙 기반 AI를 즉시 교체하지 않는다.

150/200층, 온라인 대전, PWA, 공개 서비스 운영은 현재 계획이 없다. 개인 실행기·Docker·임시 터널을 통한 접속을 유지한다.
