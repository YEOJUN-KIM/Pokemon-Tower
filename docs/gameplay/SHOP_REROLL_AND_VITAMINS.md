# 상점 리롤·소모품·영양제 · 2026-10-10

2026-10-12 후속 기획: 영양제를 히든 상점/추후 이벤트로 옮기고 판매4→2종, 기본 가격 인상·같은 포켓몬 반복 투여 할증·한 도전 한 마리 총 약3개 제한을 검토한다. 등장 확률·가격·최종 제한 수는 미정이다. 현재 코드는 매 정비 상점4종·+5포인트·투여 횟수 제한 없음으로 유지한다. [제안과 미정 수치](../current/BATTLE_REBALANCE_PLAN.md).

후속 변경(2026-10-10): 현재100층 도전은10층 상점, 종류별 리롤1회, 일반 상점에 배틀 소모품과 지닌 도구를 함께 표시한다. 영양제는 육성 탭이다. 보유 도구·맞지 않는 메가스톤을 제외해도 희귀 등급 확률은 유지하고 품절 자리는 빈칸으로 둔다. 아래 측정은 변경 전의 이력이다. [현재 규칙·측정](../archive/history/PLAYTEST_USABILITY.md).

도구와 기술머신은 각각 전체 리롤한다. 구매한 자리도 다시 추첨하며, 이미 산 도구/기술/도감 해금은 유지한다. 같은 상품이 다시 추첨될 수 있다. 리롤 비용은 각 상점별 200 → 400 → 700 → 1,100… 코인. 다음 상점에서 초기화한다. 기존 희귀도 확률은 동일하다. 리롤 횟수와 상품은 서버에 저장하며, 상점 세대 번호로 중복 리롤/이전 상품 구매를 거절한다. 상품이 없는 기술머신 상점은 리롤 버튼을 비활성화한다.

소모품: 플러스파워(공격·특수공격 +20%), 스피드업(스피드 +20%), 이펙트가드(상대에 의한 능력치 하락 방지). 각 200코인, 팀 전체에 다음 5층 동안 적용. PokéAPI 도트 PNG 아이콘을 사용한다. 기존 attack/speed 저장 키와 효과는 유지한다.

소모품 아래 영양제는 맥스업(HP), 타우린(공격), 사포닌(방어), 리보플라빈(특수공격), 키토산(특수방어), 알칼로이드(스피드) 6종 중 중복 없이 4종을 고정 추첨한다. 리롤 없음. 해당 상점에서 각 상품 1회 구매, 다음 상점에서는 새 4종을 추첨한다. 6층 가격 1,400코인부터, 5층 진행마다 400코인 증가한다(1,000 + 80 × 클리어층). 46층은 4,600코인이다.

선택한 보유 포켓몬 1마리에게 해당 능력 포인트 +5를 구매 즉시 추가한다. 기존 투자 한도 각 32/총 66과 별도로 이번 도전 끝까지 누적 적용한다. 실제 능력치에는 성격 보정이 반영되며, 껍질몬 HP는 1을 유지한다. 도감 영구 프로필은 변경하지 않는다. 도전 종료/새 도전에는 이어지지 않는다. 다음 배틀 팀의 독립 메타데이터에 추가 포인트를 기록해 재시작·리플레이·변신 뒤에도 계산을 유지한다. 구 EV 프로필은 기존 계산을 유지하면서 별도 추가값만 적용한다.

DB v18: 리롤 횟수/세대별 구매 표시/고정 영양제 상점/누적 능력 포인트 저장. 기존 상점 seed 및 배틀 팀을 유지하며 run_upgrades의 소모품 허용 제약을 확장한다. 부모 상점 행을 지우지 않고 상품 JSON만 교체해 기존 구매 기록을 보존한다.

검증: 실제 배틀 능력치·리플레이, 영구 도감 격리, 위협 하락 방지, 리롤 비용 분리·이전 요청 거절·자금 부족 롤백·구매한 상품 보존. 전체 단위 테스트 116개 통과 시점에 별도 재구매 검사 추가. Chrome 상점/기술머신/도구 E2E 11개 통과(소모품 모바일 배치 조정 후 관련 3개 재검증). PC/모바일 사진은 test-results/consumable-vitamins-1280.png, consumable-vitamins-390.png, item-reroll-1280.png, item-reroll-390.png.


## 소모품 랜덤 진열

매 상점마다 8종 중 중복 없이 3종을 추첨해 consumable_shops에 저장한다. 새로고침·재시작·다른 상점 리롤·구매로 바뀌지 않는다. 판매하지 않는 종류는 서버에서도 구매를 거절한다. 다음 상점은 새로 추첨하며 소모품 리롤은 없다. 모든 소모품은 각 200코인, 출전 팀 전체에 5층 동안 적용한다. 영양제는 기존대로 6종 중 4종, 리롤 없음.

| 소모품 | 효과 | 아이콘 파일 |
|---|---|---|
| 플러스파워 | 공격·특수공격 +20% (기존 효과 유지) | x-attack |
| 스피드업 | 스피드 +20% | x-speed |
| 이펙트가드 | 상대가 유발하는 능력치 하락 방지 | guard-spec |
| 디펜드업 | 방어 +20% | x-defense |
| 스페셜업 | 특수공격 +20% | x-sp-atk |
| 스페셜가드 | 특수방어 +20% | x-sp-def |
| 잘맞히기 | 수치 명중률 ×1.2 (최대100), 필중 기술 유지 | x-accuracy |
| 크리티컬커터 | 급소율 +1단계 | dire-hit |

스페셜업은 기존 플러스파워와 함께 적용 가능하다. 배틀 단위 이벤트만 사용하며 저장된 배틀·리플레이에 소모품 종류를 기록한다. DB v17 업그레이드와 구매 기록을 유지한다.
