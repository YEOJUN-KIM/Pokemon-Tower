# 화면과 설정

현재 키 조작·도감 탭·상점 분류는 [플레이 피드백 반영](PLAYTEST_USABILITY.md)을 따른다.

새 도전은 임시 **2세대 성도 테마**다. 관장은 8명에서 중복 없이 추첨하고 10·20·30층은 성도 사천왕 후보, 40층은 사천왕급 목호, 50층은 챔피언 레드를 배치한다. 기존 도전은 종전 배치를 유지한다. 포켓몬 세대는 제한하지 않는다. 상세는 [성도 테마](JOHTO_THEME.md)를 따른다.

최종 갱신: 2026-10-09. 현재 구현은 605종 도감·50층 타워다.

## 진입과 저장

- `/`: 타이틀. 진행 중 도전에는 이어하기와 새로하기를 표시한다. 새로하기는 정산 안내를 확인한 뒤 현재 도전을 종료한다. 영구 도감·성장 포인트·소리 설정은 유지한다.
- `/battle?prepare=1`: 새 도전 준비. 과거 종료 경기의 결과창을 숨기며 처음 출발 파티는 미선택 상태다. 3마리를 고른 뒤 서버에서 새 도전을 생성한다.
- `/battle`: 배틀·결과·영입·다음 층·상점. 타이틀이나 도감으로 이동하는 것만으로 도전을 포기하지 않는다.
- `/pokedex`: 도감 조회·검색·필터·즐겨찾기·파티 선택·영구 세팅 조정. 여기서도 새 도전을 시작할 수 있다.
- `/settings`: 소리 설정과 게스트 저장 안내. 로그인·다른 기기 저장 연동은 미구현이다.

도전·영구 도감·성장은 SQLite에 저장하며 같은 브라우저 쿠키로 조회한다. 도감 조회는 `/api/battle?view=collection`을 사용해 배틀 엔진을 재개하지 않는다. 저장 구조는 [DATABASE.md](DATABASE.md)를 따른다.

## 도감과 파티 준비

최종 진화형과 별도로 선정한 진화의휘석 활용 후보 605종을 표시한다. 넓은 화면에서는 한 줄에 8~10마리를 배치하고 화면 크기에 맞춰 페이지 표시 수를 조정한다. 목록 더보기나 긴 바깥 스크롤을 사용하지 않는다. 보유 여부는 영구 해금 기준이며 미보유 이미지는 흑백으로 표시한다.

검색은 이름만 대상으로 한글 일부·초성·영문 이름·영문 자판으로 입력한 한글을 지원한다. 표시(전체/보유/미보유), 타입, 세대, 메가진화 가능, 거다이맥스 가능, 즐겨찾기 필터가 있다. 변신 가능 필터는 데이터 표시이며 실제 변신 기능은 미구현이다.

검색과 필터는 버튼으로 열고 입력창 또는 선택 팝업에서 적용·취소한다. 웹 Tab 초점과 별도의 게임 선택 커서로 목록·필터·파티를 이동한다.

| 키 | 도감 동작 |
|---|---|
| 방향키 | 목록·필터·파티·팝업 이동 |
| Z | 목록에서 파티 추가, 파티에서 제외/설정/취소 메뉴, 팝업 결정 |
| X | 선택 포켓몬을 파티에서 제외하거나 열린 화면 취소/뒤로 |
| C | 선택 포켓몬 설정 |
| Q / E | 이전 / 다음 페이지 |

선택한 포켓몬만 움직이는 이미지를 재생한다. 다른 칸은 같은 GIF의 정지 프레임을 사용하며 애니메이션 미지원·이미지 실패 시 PNG 또는 대체 표시를 사용한다. 정지/움직임 전환에서 같은 크기와 위치를 유지한다.

오른쪽 출발 파티는 현재 정확히 3마리가 있어야 출발하며 첫 번째가 선봉이다. 코스트는 미정이다. 도감 설정에는 6가지 개체값·실수치·능력 포인트 슬라이더와 증감 버튼·성격 표·특성·합법 기술배치가 있다. 최초 개체값은 6Z, 포인트는 0, 성격은 보정 없는 성실이다. 포인트는 합계 66·능력치별 32를 넘길 수 없다. 영구 세팅 저장은 다음 도전에 적용한다.

## 트레이너 등장과 배틀

밝은 풀밭 경기장에 지우와 상대가 함께 등장하며 아래 로그에 ‘이름이/가 나타났다!’를 표시한다. **Enter 또는 ‘포켓몬 내보내기’ 버튼을 누를 때까지 기다린다.** 확인하면 0.55초 볼 던지기와 포켓몬 등장 뒤 행동을 선택한다. 도감에서 바로 시작해도 같은 흐름이다.

일반 상대는 18타입 일반·엘리트와 혼합 파티 샘플을 사용한다. 이름·그림·역할과 실제 파티를 배틀 생성 시 함께 저장하며 엘리트는 전용 음악을 사용한다. 이전 경기는 기존 배틀 ID 기반 4종 외형으로 복구한다. 새 도전은 성도 관장 8명·사천왕 4명 중 추첨하고 40층 목호·50층 레드를 배치한다. 네임드는 각 6마리 후보에서 조합을 고려해 3마리가 출전한다. 빌런 9명은 후속 배치용이다. 별도 엘리트 보상·강화 개체값은 아직 없다. 지우 뒷모습은 정면 이미지를 참고한 생성 4프레임이고 공식 뒷모습 리소스는 아니다.

| 키 | 배틀 동작 |
|---|---|
| 방향키 / Z | 기술·교체·팝업 이동 / 결정 |
| X | 배틀 메뉴 또는 열린 화면 취소 |
| A | 교체 선택 |
| S | 배틀 기록 팝업 |
| C 누르기 | 날씨·벽·트릭룸·설치기·남은 턴·양쪽 공개 랭크 변화; 놓으면 닫힘 |
| Shift | 진행 중 등장·기술 연출 건너뛰기 |

매 턴 행동 커서는 ‘싸운다’에서 시작하며 기술 화면에서는 첫 기술 또는 마지막 사용 기술을 선택한다. 기술 설명은 기술 선택 화면에 함께 표시한다. C 필드 패널은 창 비활성화 때도 닫힌다. V와 D는 사용하지 않는다. 마우스·터치에서는 톱니 메뉴의 필드 확인으로 같은 내용을 확인한다.

메뉴에는 도감·설정·포기·타이틀·계속하기가 있으며 포기는 정산 안내를 확인한다. 층·코인·파티는 경기장 안에 표시한다. HP창의 타입 표시는 없고 상태이상은 색상·문구로 보여 준다. 상대 몬스터볼은 생존 수를 나타내며 기절하면 회색이 된다. 미공개 상대 종·기술·특성·도구는 공개하지 않는다.

## 결과·영입·다음 층

승패는 결과 팝업으로 확인한다. 승리 후 동료 후보도 팝업에서 고르며 선택 뒤에는 ‘영입하고 계속’ 등 다음 결정 버튼으로 커서를 옮긴다. 기존 도감 개체값이 실제로 오를 후보에만 상승 표시를 제공하고 새 기술에는 NEW를 표시한다.

선택한 상대 1마리는 영입 여부와 관계없이 영구 도감에 보유 등록하고, 개체값은 능력치별 높은 값으로 누적하며 새 기술도 저장한다. 영입은 이번 도전의 파티에 데려오는 선택이다. 최대 보유 6마리를 넘으면 기존 멤버와 교체한다. 기술은 도감에만 두거나 이번 도전 기술 한 칸에 바로 장착할 수 있다. ‘기술만 저장하고 계속’은 포켓몬·기술·개체값을 영구 도감에 저장하고 이번 파티와 기술배치는 유지한다. 상대를 선택하지 않고 건너뛰면 도감에 추가하지 않는다.

층 사이에는 HP·PP·상태이상을 전부 회복한다. 출전 순서는 직전 배틀 시작 팀을 기준으로 유지하고 영입 교체 자리에는 새 멤버를 넣는다. 다음 층 준비도 팝업에서 진행한다. 새100층 도전에서는10층마다 클리어 뒤 상점을 열며 각 상점에서 구매한 소모품은 다음 5개 층에 적용한다. 타워 코인은 현재 도전용, 성장 포인트는 영구 성장용이다.

상점 상단에 보유 코인을 크게 표시하고 구매 후 즉시 갱신한다. 소모품·기술머신·지닌 도구를 전환해 표시하고, ‘출전 팀 선택’으로 넘어가거나 출전 준비에서 상점으로 돌아올 수 있다. 모바일에서도 상품 목록과 출전 선택을 한 화면에 쌓지 않는다.

기술머신 선택 시 파티 전체의 학습 가능 여부를 카드로 표시한다. 대상을 선택하고 ‘바로 장착’을 고르면 능력치·현재 기술 목록·새 기술과 포커스한 기술의 상세 설명을 함께 표시한다. 방향키로 현재 기술을 선택하고 Z로 교체 확인, 다시 Z로 결제·교체한다. X는 확인 → 기술 목록 → 사용 방식 → 대상 선택 → 상점 순서로 돌아간다. 취소는 결제하거나 기술을 변경하지 않는다.

상점에는 파티가 배울 수 있는 미수집 기술머신을 최대 4개 제시한다. 등급별 100~1,000코인이며 상품 목록은 새로고침·재시작 후에도 유지된다. 기술 확인 → 대상 포켓몬 → 도감에만 저장 또는 바로 장착 → 장착 시 기술 칸·비교 확인 → 구매 순서다. 기술은 선택한 종의 도감에 영구 저장하고, 장착은 이번 도전에만 적용한다. 기본 도감 기술배치는 유지한다. 구매 완료 상품은 비활성화하며, 취소는 코인을 소모하지 않는다. 방향키·Z·X와 마우스·터치를 지원한다. 판매 후보가 없으면 빈 목록을 안내한다. 기술머신 47종의 개별 등급·층별 확률을 적용하며 상품 이름과 구매 창 제목에 등급 색만 표시한다. 확률과 목록은 MACHINE_SHOP.md를 따른다. 100층 확장은 계획이다.

결과 확인은 보상을 재지급하지 않는다. 새로고침·서버 재시작은 서버에 확정된 상태로 돌아가며 등장·공격 연출을 반복하지 않는다. 도감 출발의 한 번짜리 화면 전환 표시는 sessionStorage에 배틀 ID를 넣어 전달하고 읽을 때 제거한다. 이 표시는 게임 저장이나 보상 기준이 아니다.

## 테마와 소리

타이틀·도감·배틀·설정·팝업은 보라색 패널·붉은 테두리·로컬 Neo둥근모 픽셀 글꼴을 공유한다. 포케로그/게임기 같은 레트로 느낌을 기준으로 하며 특정 원작 버전의 복제는 아니다.

처음에는 음소거이고 설정은 localStorage의 `tower-audio-v1`에 저장한다. BGM은 CC0 외부 음원과 자체 결과 음악, 효과음은 직접 합성한 임시 소리를 사용한다. 울음소리 연결은 준비했지만 파일은 제공하지 않는다. 제공 범위는 [BATTLE_AUDIO.md](BATTLE_AUDIO.md), 리소스 출처는 [THIRD_PARTY.md](THIRD_PARTY.md)를 따른다.

## 2026-10-09 배틀 명령·필드 UI 갱신

- 매 턴 하단은 ‘싸운다 / 교체’ 두 선택으로 시작한다. 하단 바는 PC 260px, 모바일은 상황 메시지 76px + 명령 220px를 사용한다. 싸운다 화면에서는 메시지 공간까지 기술 메뉴로 사용한다.
- 싸운다: 2×2 기술 목록과 선택 기술의 타입·물리(공격)/특수(특공)/변화·실제 현재 PP/최대 PP·위력·명중률·설명을 함께 표시한다. 방향키·Z로 선택/실행하고 X로 첫 메뉴에 돌아간다. 기술 설명은 선택 기술 정보에서 바로 확인한다. 빈 칸·PP 부족·사용 불가 기술은 실행할 수 없다.
- 교체: 현재 출전 포켓몬과 두 후보의 그림·HP·상태를 함께 보여주는 큰 파티 화면이다. 후보를 Z/클릭하면 교체한다. 기절한 후보와 현재 포켓몬은 선택할 수 없다. 강제 교체는 취소할 수 없으며 가능한 후보를 골라야 한다.
- C를 누르는 동안 경기장 왼쪽에서 필드 패널이 들어오고 놓으면 빠져나간다. 화면 버튼으로도 열고 닫는다. 양쪽 공개 포켓몬과 공격·방어·특공·특방·스피드·명중·회피 랭크를 동시에 표시하며 상승/하락 막대와 수치에 전환 효과를 적용한다. 날씨, 양쪽 벽/순풍 등의 편별 효과, 트릭룸/필드 등의 공통 효과와 남은 턴을 구분한다. 공개되지 않은 연장 도구가 영향을 줄 수 있는 효과는 기존처럼 턴 범위를 표시한다. 배틀 연출 중에도 C 확인을 지원한다. 모션 감소 설정에서는 전환을 생략한다.
- S는 기록, X는 첫 메뉴에서 배틀 메뉴를 연다. A는 교체 화면을 바로 여는 보조 키다. 기절/상태/공개 정보의 엔진 처리는 유지한다. 기술머신 이름은 상품 등급 색을 사용한다. 배틀 기술의 타입 색과 도구 상품의 등급 색은 구분한다.
- 기술 목록과 상세의 타입은 18종 타입별 색과 로컬 SVG 아이콘으로 표시한다. 타입 색은 기술 등급과 별개다. 요청 처리·기술/교체 연출 중에는 하단 명령 버튼을 없애고 로그가 바 전체를 차지한다. 연출이 끝난 뒤 다음 행동 메뉴 또는 강제 교체창이 나타난다.
- 상단은 흰색 층수·노란색 코인·톱니 메뉴만 표시한다. 필드 확인과 소리 토글·설정은 톱니 메뉴에서 접근한다. 필드 단축키는 C 누르기로 변경했고 별도 기술 상세 단축키는 제거했다. 하단의 대화와 조작 안내 글자를 확대한다.
- 같은 종류의 지닌 도구는 도전 보유 멤버 전체에서 한 마리만 장착한다. 여분이 가방에 있어도 중복 장착할 수 없으며, 기존 장착을 해제한 뒤 다른 멤버에게 옮긴다. 상점과 관리 화면은 장착 중인 멤버를 표시하고 서버도 중복 구매·장착을 거절한다.
- 지닌 도구는 83종 중 층별 등급 확률로 무작위 4종만 판매한다. 상품은 도전/상점 층별로 저장해 새로고침과 재접속에서도 유지한다. 초반부터 모든 등급에 작은 확률이 있고, 높은 층일수록 높은 등급 비중이 증가한다. 등급은 이름 색만 사용하며 별도 배지를 붙이지 않는다. 도구 관리의 목록에는 실제 가방 수량이 있거나 현재 장착 중인 도구만 표시한다. 미보유 도구와 수량 0만 남은 항목은 표시하지 않고, 보유 도구가 없으면 빈 가방 안내를 표시한다.
