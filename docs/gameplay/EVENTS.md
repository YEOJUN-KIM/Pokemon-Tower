# 이벤트와 보상 기획

기준: 2026-10-14. 이벤트 보상 종류를 정리합니다. 아래는 대화에서 채택한 기획 후보이며, 구현 완료를 의미하지는 않습니다. 지급량·확률·사용 조건은 아직 정하지 않았습니다. 구체적인 이벤트 후보는 [이벤트 후보 선별](EVENT_CANDIDATES.md), 알 종류 확장은 [알 종류 구상](EGGS.md)에서 관리합니다.

## 보상 후보

| 보상 | 용도·방향 | 이후 정할 내용 |
|---|---|---|
| 돈 | 상점 구매 등에 사용하는 금전 보상 | 지급량과 기존 경제 밸런스 |
| 희귀한 포켓몬 | 희귀 포켓몬 획득·영입 기회 | 대상 포켓몬과 도감 해금 여부 |
| 영양제 | 포켓몬 능력치 강화 | 종류·수량·강화 한도와 희소성 |
| 영구재화 | 다음 도전에도 이어지는 성장·해금용 재화 | 명칭·사용처·지급량 |
| 이로치 교환권 | 이로치 획득 또는 교환에 사용하는 보상 | 대상 선택 방식과 교환 조건 |
| 알 뽑기권 | 알 뽑기에 사용하는 보상 | 일반·희귀·이로치 알은 공통 티켓을 사용하며 [알 종류와 부화](EGGS.md)를 따름. 이벤트 지급량·확률은 별도 검토 |
| 도구 교환권 | 희귀한 지닌 도구 등을 선택해 획득 | 교환 가능한 도구와 등급 |
| 기술머신·기술 교환권 | 포켓몬에게 필요한 기술을 배우게 하는 보상 | 기술 목록·습득 조건·기존 기술머신 상점과의 관계 |
| 성격 변경권 | 포켓몬의 성격 조정 | 도전 중 또는 시작 전 사용 여부 |
| 특성 변경권 | 포켓몬의 특성 조정 | 일반 특성·숨겨진 특성 구분과 희소성·사용 시점 |
| 개체치 강화권 | 특정 능력치의 개체치 강화 | 강화 수치·최대치·사용 시점 |
| 기믹 관련 보상 | 메가스톤·Z크리스탈·테라타입 변경권 등 | 보상 종류·룰별 사용 조건·기존 해금 방식과의 관계 |
| 포켓몬 선택 영입권 | 정해진 후보 중 원하는 포켓몬을 선택해 영입 | 후보 목록·등급·희귀 포켓몬 보상과의 차이 |
| 상점 갱신권 | 상점 상품을 다시 갱신 | 대상 상점·사용 횟수·기존 갱신 기능과의 관계 |
| 상점 할인권 | 상점 상품을 할인된 가격에 구매 | 할인율·적용 범위·유효 기간 |

## 제외한 보상

- **회복권·부활권:** 매 배틀 전에 회복해주는 현재 흐름에서는 필요하지 않아 후보에서 제외합니다.

## 보류한 보상

- **폼 변경·진화 재료:** 도감에서 포켓몬을 해금하면 폼체인지를 자유롭게 할 수 있으므로 보류합니다. 도입 여부와 기존 해금 방식과의 관계는 추후 검토합니다.

## 외형 보상: 후속 구상

- 현재 하나인 플레이어 스프라이트의 선택지를 늘리는 방향을 검토합니다.
- 추가 트레이너 외형을 이벤트 보상으로 해금하는 방식은 구상 단계입니다.
- 외형 종류, 리소스 확보 방식, 선택 화면, 해금 조건은 아직 정하지 않았습니다.
- 칭호·프로필 테두리·배틀 배경 등 다른 외형 보상의 범위도 추후 검토합니다.

## 추후 결정할 규칙

- 이벤트의 구체적인 내용·등장 조건·등장 빈도.
- 보상별 수량·등급·획득 확률과 선택형·무작위 지급 여부.
- 현재 도전에서만 사용하는 보상과 다음 도전에도 남는 보상의 구분.
- 도전 중 사용 가능한 보상과 도전 시작 전에만 사용하는 보상의 구분.
- 교환권의 보관·중복·소모 규칙과 기존 도감·상점·영구 성장 기능과의 관계.
- 돈과 영구재화를 기본 통화로 두고 나머지를 보상 아이템으로 관리하는 방식은 제안 단계이며, 아직 확정하지 않았습니다.
