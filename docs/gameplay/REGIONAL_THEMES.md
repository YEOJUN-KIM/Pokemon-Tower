# 1~9세대 랜덤 지역 테마

2026-10-12 현재 기준: 새 도전은 앞/뒤50층에 서로 다른 지역을 사용하고, 빌런 조직은 지역과 독립적으로 선정해100층 동안 유지한다. 관동·성도 구간은 챔피언 뒤 레드 추가전이다. 아래 지역별 빌런 후보와 단일 지역100층 배치는 당시 이력이며 현재 선정 방식이 아니다. [현재 상태](../STATUS.md), [배틀 개선 기준](../current/BATTLE_REBALANCE_PLAN.md).

2026-10-10 구현. 새 도전 시작 시 9개 지역 중 하나를 같은 확률로 추첨하고 저장한다. 도전 중에는 다시 추첨하지 않는다. 관장·사천왕급·챔피언·최종 상대·빌런 조직이 같은 테마를 따른다. 기존 성도 도전과 테마 없는 저장에는 새 테마를 소급 적용하지 않는다.

## 현재 배치

5·15·25·35·45층은 관장/캡틴 후보 중 서로 다른 5명, 10·20·30층은 사천왕/컵 후보 중 서로 다른 3명을 배치한다. 40층과50층은 아래 인물을 사용한다. 성도의 목호40층·레드50층 배치와 추첨 순서는 유지했다. 이 표는 첫 50층 구간의 타워용 각색이며 원작의 도전 순서를 그대로 재현하지 않는다. 새 도전은 같은 지역 테마로 100층까지 이어진다. 55·65·75·85·95층 관장, 60·70·80층 사천왕급은 별도 시드로 다시 추첨하며 90층은 40층 챔피언, 100층은 50층 최종 상대의 강화 재대결이다. 알로라는 캡틴을 관장 구간에 사용하고, 울트라썬/울트라문 계열 사천왕 후보를 사용한다. 가라르는 챔피언컵 참가자가 사천왕급 구간을 맡고 50층은 단델 재대결이다. 가라르 히든 최종전은 추가하지 않았다. 나머지 지역의 라이벌/최종 도전자 배치도 타워용 샘플이며 실제 난이도와 최종전 구도는 후속 검토한다.

호연은 버전별 관장을 함께 포함하며 하나는 BW/BW2 관장 후보를 함께 포함한다. 트레이너 테마는 지역을 제한하지만 포켓몬 세대는 제한하지 않는다. 따라서 원작에서 영감을 받은 후보와 타워용 보완 파트너가 섞여 있다. 공용 일반/엘리트 직업39종은 계속 사용하고 저장된 인물의 세대 표기를 현재 지역에 맞춘다. 세대별 전용 경기장/BGM 팩은 이번 범위에 포함하지 않았으며 기존 역할별 음악과 경기장을 사용한다.

## 샘플과 파티

네임드 배치 샘플105개를 추가해144개, 공용39종을 합쳐 총183종이다. 같은 인물의 지역·직급별 샘플은 별도 ID를 사용한다. 각 네임드는 대표1마리 + 파트너2마리를 가중 추첨하며, 5~6종 후보에서 기술·특성·도구를 실제 배틀용으로 구성한다. 파티 안 도구 중복을 피한다. 대표가 선봉으로 고정되는 것은 아니다.

성도14명의 HGSS 원작 자료는 기존대로 유지했다. 나머지 파티는 원작 참고 샘플이며 원작의 기술/특성/도구를 완전히 대조한 팀으로 설명하지 않는다. 지역 형태는 이번에도 별도 도감 항목으로 확장하지 않았다. 원작 후보 중 필요했던 Onix/Haunter/Sealeo/Weepinbell/Ursaring을 지원해 도감·배틀 풀은607→612종이다. 새 챔피언 후보27종에는 합법4기술 세팅을 추가했다.

## 빌런·저장

새 도전의 빌런은 지역 후보에서 조직 하나를 저장한다. 호연의 마그마/아쿠아, 알로라의 스컬/에테르 후보는 같은 확률로 추첨하고 한 도전에는 한 조직만 나온다. 1·2세대는 로켓단, 나머지는 해당 지역 조직이다. 기존 도전은 예전 조직을 유지한다.

조직원/간부/보스의 임시8% 등장 추첨·층별 직급 비율·보너스·보스 격파 후 이벤트 종료는 기존 규칙을 유지한다. [빌런 상세](VILLAIN_EVENTS.md). 새4개 조직에도 간부와 보스 파티를 준비했다. 스타단 피냐/모란 및 에테르재단의 적대 관계는 타워 각색이다. 매크로코스모스 조직원은 임시 회사원 초상화를 사용한다.

지역 테마 추가 당시에는 DB v20을 유지했다. 이후 100층 확장에서 v21과 run_progression을 추가했으며 기존 테마·캠페인 데이터는 보존한다. 이미 생성된 상대 팀·인물·AI 버전·조직은 다시 추첨하지 않는다. 새 배틀은 상대 AI v7을 사용하고 기존 v6 이하 저장은 당시 정책으로 복구한다. Z기술·6개 기믹 룰 분리·영구 성장 상품은 이번에 구현하지 않았다.

## 검증

전체 단위·통합147개, 관련 Chrome PC/모바일25개, 타입 검사·프로덕션 빌드 통과. 9개 테마의 중복 없는 관장/사천왕급 추첨,9,000개 시드 분포, 무작위 시작과 조직 일치, 실제 주요 층 배틀, 프리뷰/파티 저장·재시작·기존 성도 복구,10개 조직의3직급을 확인했다. 144개 네임드의 후보 출현·다양한 조합·합법 기술·도구도 검사했다.

브라우저에서는9개 테마 × PC/모바일18개, 기존 성도1개·일반/엘리트2개·빌런4개를 확인했다. 화면은 artifacts/screenshots/regional-themes-ready/에 저장했다. 전체 브라우저 묶음은 재실행하지 않았다. 이후 새 등반 난이도/경제는 9세대별 16코스로 [재측정](../experiments/balance/REGIONAL_SIMULATION.md)했다.
