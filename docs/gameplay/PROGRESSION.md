# 타워 진행

일반 모드의 새 도전은 100층입니다. 팀·룰 선택 → 배틀 → 승리 보상·영입 → 출전 준비 → 다음 층 순서로 진행합니다. 50층은 중간 관문이고 이후 잠시 완화한 뒤 최종 관문까지 난이도가 다시 올라갑니다.

앞·뒤 50층에 서로 다른 지역 테마가 적용됩니다. 관장·사천왕·챔피언과 지역별 추가 상대가 등장하며, 빌런 조직은 지역과 독립적으로 도전 동안 이어집니다. 빌런 보스는 75층 이후의 가능한 이벤트 자리에 배치하며 5층 단위 관문은 교체하지 않습니다.

상점이 없는 층에서도 출전 멤버·선봉과 도구를 준비할 수 있습니다. 패배 후에는 확장한 다시하기 횟수 안에서 같은 상대에 맞춰 준비를 바꿀 수 있습니다. 이미 사용한 자원과 정산 기록을 되돌리거나 보상을 중복 지급하지 않습니다.

새로하기는 현재 도전의 종료와 성장 포인트 정산을 확인한 뒤 진행합니다. 계정의 영구 수집·육성은 유지됩니다. 기존 도전과 배틀은 생성 당시 팀·버전을 유지할 수 있습니다.
