# 설치와 실행

Pokémon Tower는 Windows에서 간단한 CMD 파일로 설치하고 실행할 수 있습니다.

**로컬 플레이에는 Docker가 필요하지 않습니다.**

## 준비물

- Windows
- [Node.js 24 이상](https://nodejs.org/)
- 첫 설치 시 인터넷 연결

## 처음 설치

1. Node.js 24 이상을 설치합니다. npm이 포함된 공식 설치 프로그램을 사용하고 Node.js를 PATH에 추가합니다.
2. GitHub 저장소를 다운로드하거나 clone합니다.
3. 압축을 풀었다면 프로젝트 폴더를 엽니다.
4. **`포켓몬타워 설치.cmd`를 더블클릭**합니다.

설치 CMD가 다음 작업을 자동으로 처리합니다.

- Node.js와 설치 도구 확인
- 필요한 프로젝트 파일 설치
- 설치 완료 후 Pokémon Tower 실행

## 다음부터 실행

설치가 끝난 뒤에는 **`포켓몬타워 로컬 실행.cmd`를 더블클릭**하면 됩니다.

서버가 준비되면 브라우저에서 [http://127.0.0.1:3000](http://127.0.0.1:3000)을 자동으로 엽니다.

## 종료

실행 중인 CMD 창에서 **Ctrl+C**를 누릅니다.

## 문제 해결

### Node.js가 없거나 버전이 낮다고 나오는 경우

[Node.js 24 이상](https://nodejs.org/)을 설치한 뒤 `포켓몬타워 설치.cmd`를 다시 실행합니다.

### npm 또는 npx를 찾을 수 없다는 경우

Node.js 공식 설치 프로그램으로 npm과 npx를 포함해 다시 설치한 뒤 `포켓몬타워 설치.cmd`를 다시 실행합니다.

### 의존성 설치 실패

인터넷 연결을 확인하고 `포켓몬타워 설치.cmd`를 다시 실행합니다. 계속 실패하면 설치 창에 표시된 실패 단계와 오류 코드를 확인합니다. 창을 닫기 전에 오류 메시지를 복사하거나 캡처해 주세요.

### 3000번 포트를 사용 중이라는 경우

기존 Pokémon Tower 실행 창이나 다른 3000번 포트 서버를 종료한 뒤 다시 실행합니다.

### 브라우저가 자동으로 열리지 않는 경우

브라우저에서 직접 [http://127.0.0.1:3000](http://127.0.0.1:3000)으로 접속합니다.

개발 관련 상세 내용은 [개발 문서](../engineering/README.md)를 참고하세요.
