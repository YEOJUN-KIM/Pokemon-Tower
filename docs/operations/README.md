# 실행과 운영

일반 Windows 사용자는 [SETUP](SETUP.md)부터 읽습니다. 개발 clone·개인 서버 이전 절차와 섞지 않습니다.

| 문서 | 담당 범위 |
|---|---|
| [SETUP](SETUP.md) | GitHub Release ZIP 다운로드, 게임 실행·재열기·종료, 사용자 문제 해결 |
| [WINDOWS_PLAYER](WINDOWS_PLAYER.md) | EXE/Node/runtime, 설치 marker·health·트레이·프로세스 소유권과 패키징 구조 |
| [ACCOUNTS](ACCOUNTS.md) | 로그인·가입·비밀번호/저장 복구, 계정 운영 정책 |
| [BACKUPS](BACKUPS.md) | Windows/개발/Docker 저장 구분, 백업·검사·복원 |
| [DEPLOYMENT](DEPLOYMENT.md) | 서버/웹 패키지, Docker·HTTPS·임시 터널 운영 |
| [COMPUTER_MOVE](COMPUTER_MOVE.md) | 개발환경·개인 서버를 다른 PC로 이전 |

공개 asset과 당시 검증은 [beta.5 완료 기록](../releases/WINDOWS_BETA_5.md), 재생성 명령은 [개발자 명령어](../development/DEVELOPER_COMMANDS.md)를 따릅니다. 정기 자동 백업은 미설정이며 DB 변경 전 필요한 백업은 별도로 수행합니다.
