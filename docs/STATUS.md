# 현재 게임 상태

기준: 2026-10-21. 현재 공개 버전은 **v1.0.0-beta.1**이다. **Normal Mode 100층의 1차 완성**을 마쳤으며, 음향과 기술 이펙트 보강이 남아 베타 버전으로 표시한다. 100층 1차 완성 기준 커밋은 82c870ed이며, 이후 유지보수와 개선 방향은 [ROADMAP](current/ROADMAP.md)에서 관리한다.

| 영역 | 현재 구현 |
|---|---|
| 타워 | 100층, 전·후반 두 지역 테마, 50/100층 관문, 지역별 네임드·챕터 히든보스 |
| 배틀 | 3대3 턴제 싱글, 기술·교체·특성·상태이상·도구, Showdown 기반 효과 계산 |
| 기믹 | 기본·메가·다이맥스·테라·혼합·Z 룰. 원시회귀·거다이맥스와 폼별 처리 포함 |
| NPC | 공통 Sample 20개와 Normal/Elite/Master. 검토 입력 180행·911마리 후보, 그중 156행은 allFloors 단일 후보 빌드 |
| 일반 이벤트 | 상자·브리더·여행 상인·도전자·히든상점·Raid·순간이동. 적격 일반층의 발생률 15%, 통과 순서 쿨다운 2 |
| 특수 전투 | 보스 20종의 다단계 Raid, 조직별 독립 빌런 캠페인, Mirror 도전자, 확정 히든보스 |
| 수집·육성 | 도감·영입·알, 개체값·기술·이로치 수집, 공통 포켓몬 설정, 기술 자동 저장·폼별 설정 |
| 보상·경제 | 일반/히든상점·TM·도구·영양제·트레이너 장비·공통 보상/선택 영수증. 1차 재화 밸런스 반영 |
| 영구 상점 | 리롤·재도전·출발 지원금 3종. 알뽑기는 별도 페이지, 기본 1회 200P·1/10회·티켓 우선 결제 |
| 알 | 일반/레어/슈퍼레어 85/12/3%, 별도 이로치 0.24%, 대표 알 배출·개별/전체 부화·전용 보상 티켓 |
| 화면·입력 | 공통 게임 메뉴·대화창·설정, PC/모바일, 키보드·마우스·터치·게임패드 입력, 배속/기록/스킵 |
| 저장 | SQLite schema 47, 튜토리얼의 첫 선택 포켓몬 유지, 기본 새 일반 전투 정책 v13, 과거 전투 정책·이벤트/NPC snapshot·영수증 복구 |
| 개인 실행 | Windows 통합 실행기, Docker·임시 터널·주소 복사·게임 열기, 별도 개발 저장 |

알의 지역/타입 조정과 알 탐색 연구는 현재 화면에서 제거했다. 서버/API·저장 호환 경로는 남아 있으며 신규 UI 작업으로 간주하지 않는다. 이로치 상시 교환권 판매도 종료했다.

1차 완성은 모든 난이도·기기에서 검증을 끝냈다는 뜻은 아니다. 자동 테스트, 시뮬레이션, 실제 사람의 플레이 결과를 구별한다. 기존 팀·시드·보상·정책은 저장 당시 snapshot을 유지하며 새 설정으로 다시 추첨하지 않는다.
