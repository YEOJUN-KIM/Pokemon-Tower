# 배틀 룰 선택

2026-10-12 현재 구현: Z기술을 포함한 여섯 룰을 선택할 수 있으며 양쪽 동일 룰 제한을 유지한다. 이후 플레이어·엘리트의 선택 기믹과 네임드·빌런 간부/보스의 대표 기믹을 분리하는 방향이다. NPC별 고정 기믹과 예외는 후속 설계이며 현재 기능과 혼동하지 않는다. [배틀 개선 기준](../current/BATTLE_REBALANCE_PLAN.md), [Z기술 규칙](Z_MOVES.md).

2026-10-11 표시명 반영: 혼합룰. 내부 ID chaos와 기존 저장은 유지한다. 아래 검증 수치는 구현 당시 기록이다.

새 도전은 출발 파티에서 룰을 선택한다. 기본 선택은 기본룰이며 도전 도중 변경할 수 없다. 세대 테마는 기존처럼 랜덤이다.

- 기본룰: 메가진화·다이맥스·테라스탈·Z기술 모두 금지.
- 메진룰: 메가스톤으로 메가진화만 허용.
- 다맥룰: 다이버섯(내부 아이템 Dynamax Band)으로 다이맥스만 허용.
- 테라룰: 팀 공용 테라권으로 테라스탈만 허용.
- 혼합룰: 네 기믹을 허용. 팀의 메가진화/다이맥스 사용권은 배틀당 한 번을 공유하고, 테라와 Z기술은 각각 별도로 배틀당 한 번이다. 같은 포켓몬의 변신 중첩 금지는 유지하며 Z크리스탈을 든 포켓몬은 테라스탈할 수 없다.
- Z기술 룰: 대응하는 Z크리스탈을 장착해 Z기술만 허용. 크리스탈은 소모되지 않으며 팀당 배틀 1회다.

양쪽 엔진 요청에 동일한 제한을 적용한다. 금지된 기믹 도구는 상대 팀에서 제외하고 상점에서 판매하지 않으며 장착 요청도 거절한다. 테라 허용 룰에서만 초기 테라권 1장과 테라권 상점이 생긴다. 일반 도구와 배틀 소모품은 모든 룰에서 유지한다.

DB v23에서 run_rules에 도전 룰, battles.rule에 배틀 당시 룰을 저장했다. 당시 이전 도전/배틀은 chaos로 복원하여 이전 동작과 기록 재생을 보존했다. 현재 스키마 v27은 기존 룰과 기록을 유지하며 z 룰을 추가한다. 배틀 로그에도 룰을 저장하고 완료 시 저장된 룰과 일치하는지 검증한다. API는 룰 생략 시 basic; 기존 내부 TowerStore.start(owner,selected) 호출은 이전 chaos 동작을 유지한다. 새 UI는 항상 선택한 룰을 명시한다.

이전 다섯 룰 구현 당시 검증: 단위/통합 170개 통과, 빌드 통과. 각 룰의 양쪽 합법 행동 목록, 금지 명령, 배틀 로그 재생, 룰별 상점/상대 및 기존 도전 호환을 확인했다. PC/모바일 브라우저에서 선택·Q/E 이동·기본룰 시작·새로고침 복원·버튼 숨김을 확인했다. 룰 선택/API 3개 및 기존 사용성 2개 브라우저 테스트가 통과했다. Z기술 추가 검증은 [Z기술 문서](Z_MOVES.md)를 따른다.

이번 변경에는 룰별 난이도 수치나 가격 조정을 넣지 않았다. 기존 혼합룰 시뮬레이션 수치를 기본룰의 결과로 해석하지 않는다.
