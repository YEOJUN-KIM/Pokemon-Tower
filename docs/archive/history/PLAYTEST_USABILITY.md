# 플레이 피드백 반영 · 2026-10-10

이 문서는 직전 규칙의 기록이다. 최신 소모품·정비·가격·무료 리롤은 [배틀 도구와 정비](../../gameplay/BATTLE_ITEMS_MAINTENANCE.md)를 따른다.

도감 능력치 조정은 능력치 / 성격 / 특성·테라 탭으로 나눈다. 수정 중인 설정은 탭을 바꿔도 유지하고 저장 버튼에서 한 번에 저장한다. PC와 390×844 모바일에서 기본 능력치 탭에 세로 스크롤이 생기지 않는 것을 확인했다. 규칙 설명을 펼치거나 작은 화면에서는 내용에 따라 스크롤할 수 있다.

조작은 방향키 위·아래/좌·우 이동, Q/E 이전·다음 탭, Enter 결정, Z/X 취소다. 도감 목록에서는 Q/E가 페이지 이동이며 팝업 탭이 열려 있으면 탭 이동을 우선한다. 숫자 입력·특성 선택 중에도 Q/E로 탭을 바꿀 수 있다. 검색어 입력에는 문자 키를 그대로 사용한다. 텍스트·숫자·선택 입력 자체는 브라우저 편집을 유지한다. 성격 표의 방향키는 같은 행·열의 인접 칸으로 이동한다.

메가진화·다이맥스 버튼은 해당 포켓몬의 합법적 변신 행동이 있을 때만 표시한다. 도구가 없거나 진영 공용 기믹을 이미 사용했다면 두 버튼을 숨긴다. 예약 버튼을 누른 뒤 기술을 확정하기 전에는 다시 예약을 취소할 수 있고, 실제 발동 후에는 버튼이 사라진다. 테라 버튼의 타입색·비활성 표시는 그대로다.

100층 도전 상점은 10·20·30·40·50·60·70·80·90층 클리어 후 열린다. 기존 100층 미만 저장은 이전 5층 간격을 유지한다. 일반 상점은 배틀 소모품 3종·지닌 도구 최대4종·테라권을 함께 표시한다. 기술머신과 육성(영양제)은 별도 탭이다. 배틀 소모품의 효과는 기존 5층 지속이며 영양제는 도전 내내 유지한다. 판매 수·가격과 보상은 바꾸지 않았다.

리롤은 상점별 지닌 도구 1회, 기술머신 1회로 각각 제한하며 첫 리롤 가격200코인을 유지한다. 소모품·영양제는 리롤하지 않는다. 영구재화로 종류별 최대3회까지 늘리는 기능은 후속 구상이며 가격·재화 종류·해금 단계는 미정이다.

도구 구매는 바로 장착할 포켓몬을 고르거나 가방에 넣기를 선택한다. 가방·장착 중인 동일 도구는 다시 구매할 수 없다. 다음 상점 및 리롤에서는 보유 도구를 제외한다. 메가스톤은 이번 도전의 보유 파티에 맞는 후보만 표시·추첨한다. 이전에 저장된 맞지 않는 상품도 UI에서 숨기고 서버 구매를 거절한다.

희귀 등급을 먼저 원래 확률로 추첨한다. 해당 등급에 판매할 도구가 없으면 자리를 비워두며 다른 등급으로 다시 뽑지 않는다. 따라서 일반 도구를 모두 샀다고 메가스톤이 확정 등장하지 않는다. 호환되는 메가스톤 사이의 조건부 확률은 후보 수가 줄어 높아질 수 있으나, 메가스톤/다이맥스가 속한 전설 등급의 슬롯 확률은 유지한다(30층 이후2%).

검증: 전체156개 단위·통합 실행에서155개 통과 후 변경된 중복 구매 오류 문구를 기대하던1개를 수정했다. 관련25개를 재실행해 모두 통과했다. 최종 타입 검사·프로덕션 빌드, PC/모바일 Chrome14개 통과. 마지막 입력 중 Q/E와 모바일 라벨 수정 후 PC·모바일2개를 추가 검사해 통과했다. 전체 브라우저 묶음 재실행은 아니다.
