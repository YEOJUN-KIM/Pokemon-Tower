# 50층 어려움 난이도 — 2026-10-09

기본 목표는 **첫 완주까지 여러 번 실패하면서 도감·개체값·기술·도구 세팅을 준비하는 로그라이크**다. 시작부터 모든 상대 정보를 제공하거나 적의 종족값을 몰래 높이지 않는다. 준비한 팀으로도 매번 완주가 보장되지는 않게 한다.

## 이번 조정

성도 관장 8명·사천왕 4명·목호·레드, 총 14명의 후보와 기본 세팅을 HGSS 재대결/은빛산 기준으로 교체했다. 대표 한 마리 + 해당 원작 엔트리의 두 마리를 추첨한다. 레드 후보는 피카츄·라프라스·잠만보·이상해꽃·리자몽·거북왕이다. 원작 특성과 도구를 우선 보존하고, 일격기·명확히 불리한 반동 대기 기술·동작 준비를 AI가 지원하지 않는 기술 일부만 교체했다. 개별 교체 목록은 [네임드 구성](../../gameplay/NAMED_TRAINER_BUILDS.md)에 있다.

관장·사천왕의 원래 빈 도구 칸을 전부 채우던 강화를 없앴다. 원작에 있던 화염구슬/맹독구슬/열매 등은 유지한다. 챔피언급의 빈 칸은 기술에 맞는 도구로 보완한다. 팀 내 같은 도구는 금지한다. 1층부터 올라가는 기존 개체값 상한과 후반 능력 포인트는 유지한다. 보상·상점 가격·등급 확률은 변경하지 않았다. 목호 40층, 레드 50층 배치도 유지한다.

## 측정 결과

실제 생성 경로에서 얻은 **32개의 50층 코스**를 저장하고 변경 전후를 비교했다. 일반 전투와 시드는 동일하며, 네임드만 새로운 원작 구성으로 생성한다. 네임드의 저장된 자리별 개체값도 유지한다.

| 시작 준비 상태 | 변경 전 평균 클리어 층 | 변경 후 평균 클리어 층 | 변경 전 완주 | 변경 후 완주 |
|---|---:|---:|---:|---:|
| 기본 시작 3마리, 개체값 0·능력 포인트 0 | 3.0 | 4.3 | 0/32 | 0/32 |
| 기본 시작 3마리, 개체값 15·능력 포인트 33 | 9.4 | 10.6 | 0/32 | 0/32 |
| 기본 시작 3마리, 개체값 31·능력 포인트 66·공격 성격 | 18.3 | 20.7 | 0/32 | 1/32 |
| 수집한 한카리아스·갸라도스·팬텀, 최대 육성·합법 기술 준비 | 30.8 | 32.7 | 3/32 | 5/32 |

고정된 충분히 육성한 기본 시작 팀의 독립 전투 검사에서 5층 승리는 29→30/32, 목호 40층은 12→18/32, 레드 50층은 25→20/32였다. 레드 피카츄의 전기구슬과 원작 볼트태클을 유지해 최종전의 위협은 남겼다. 독립 전투는 모든 검사 층에 같은 시작 팀을 새로 투입하므로 연속 등반 성공률과 구분한다.

이 결과에서는 쉬운 첫 완주로 바뀌지 않으면서 수집·육성 준비의 효과가 나타난다. 현재 어려움 기준의 첫 조정으로 채택하고, 실제 플레이의 탈락 층·답답한 조합을 보고 추가 조정한다.

## 시뮬레이션 조건과 한계

- 양쪽 모두 기존 TowerPolicy를 사용하며 자신의 팀과 공개된 상대 정보만 읽는다. 사람의 승률로 해석하지 않는다.
- 승리 후 공개된 후보 중 종족값이 높은 포켓몬을 영입하고 기술을 수집한다. 최대 6마리에서 자신의 능력치와 타입 폭을 보고 3마리를 고른다. 다음 상대를 보고 맞춤 카운터 팀을 고르지 않는다.
- 5층 간격 상점에서 실제 가격·등급 가중치로 4개 도구와 최대 4개 기술머신을 추첨한다. 돈 범위 내에서 공격/스피드 강화와 적합한 도구·기술을 구매한다. 지닌 도구 중복과 소모 도구 소실을 반영한다.
- 상점은 시뮬레이션의 저장 배틀 시드에서 재현되며 실제 계정의 상점 스냅샷을 그대로 복제한 것은 아니다. 기술 수집 완료에 따른 후보 제외, 회수한 도구의 가방 재장착 등은 단순화했다.
- 도구 적합성·기술 선택은 단순 휴리스틱이다. 능동적인 교체, 정교한 벽·날씨·교란 전략, 특수 기믹은 사용하지 않는다. 따라서 32코스 수치를 목표 사람 승률로 고정하지 않는다.
- 일반 상대는 변경 전 저장 팀을 그대로 사용한다. 이번에 원작 후보 지원을 위해 추가한 키링키·신뇽이 일반 층에 새로 추첨되는 효과는 이 비교에 포함하지 않는다.
- 플레이어와 상대는 현행 규칙대로 레벨 50이다. 원작 레벨 수치는 자료에 보존하지만 그대로 대입하지 않는다.

## 쉬움 모드 — 후속 구상

어려움이 지나치다고 느껴질 때 선택할 수 있도록 **다음 상대의 이름과 출전 포켓몬 예고**를 제공한다. 먼저 정보를 주어 파티·기술·도구 선택을 돕는 방향이며, 아직 별도 모드나 모든 일반 층 예고 기능을 구현하지 않았다.
