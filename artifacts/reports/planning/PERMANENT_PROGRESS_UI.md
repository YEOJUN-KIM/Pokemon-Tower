# 도감과 영구 성장 메뉴 개편

2026-10-11 사용자 논의 정리. **도감 UI·영구 재화 기능 → 배포 준비 → AI 개선** 순서다. 아래 기능 전체가 구현 완료라는 의미는 아니다.

## 사용자 요구

- 도감의 웹 관리 화면 느낌을 줄이고 게임 메뉴처럼 보이게 한다. 영구 재화 사용처를 추가하면서 함께 개편한다.
- 영구 사용처는 리롤 확장권·이로치 교환권·포켓몬 뽑기다. 기존 성장 포인트와 육성 소비를 함께 고려한다.
- 포켓몬 뽑기는 랜덤 종과 랜덤 개체값을 얻는다. 새 종은 도감에 추가하고, 보유 종은 기존보다 높은 개체값을 수집한다. 모든 뽑기가 이득일 필요는 없다.
- 결과에는 해당되는 경우 **새 포켓몬! / 개체값 상승! / 새 기술!**를 표시한다. 여러 획득이 있으면 함께 표시한다. '변화 없음' 문구는 표시하지 않는다. 획득 표시가 없을 때도 뽑힌 포켓몬과 개체값은 보여준다.
- 배틀 메뉴의 필드 상태·소리 켜기/끄기·도감 항목은 제거한다. 도감은 타이틀에서, 소리는 설정에서 접근한다. 배틀 메뉴는 설정·도전 포기·타이틀·계속하기로 줄인다.

## 화면 구성 — 도감과 영구 업그레이드 구현

타이틀에서 **도전 준비 / 도감 / 영구 상점 / 설정**으로 목적을 구분한다. 도감과 영구 상점은 같은 시각 스타일과 키 조작을 공유하되, 실제 도전 중 코인 상점과 영구 재화 상점을 혼동하지 않게 한다.

도감은 선택한 포켓몬과 정보를 중심으로 구성한다. 수집 목록·파티·선택 포켓몬의 큰 이미지와 정보를 보여주고 검색/필터는 필요할 때 여는 보조 메뉴로 둔다. 영어 관리 도구 문구나 긴 안내 문장은 줄인다. 능력치·기술은 하위 메뉴에서 조정한다. 방향키 이동, Enter/Z 확정, X 뒤로, Q/E 탭이라는 기존 조작 흐름을 유지한다.

영구 상점은 리롤 확장·이로치 교환·포켓몬 뽑기를 큰 선택 항목으로 보여준다. 항목 선택 시 가격·얻는 내용·현재 단계·잔액을 확인하고 구매한다. 뽑기는 결과 포켓몬이 주인공인 연출과 실제 얻은 것의 표시를 사용한다. 웹 상품 목록처럼 많은 버튼과 설명을 한 화면에 쌓지 않는다.

## 최초 논의 기준 (현재 구현은 아래 최신 구현 항목 참고)

| 항목 | 논의 기준 | 아직 정하지 않은 것 |
|---|---|---|
| 리롤 확장 | 무료1→2→3회 영구 확장 구상 | 단계 가격, 도구/TM 공유 업그레이드 여부, 기존 도전 적용 시점 |
| 이로치 교환 | 교환권을 영구 재화로 얻는 사용처 | 대상 선택 방식, 일반/이로치 전환과 저장, 도전 중 적용 |
| 포켓몬 뽑기 | 랜덤 포켓몬·IV, 새 종 해금과 중복 IV 수집 | 대상 풀·전설 포함·등급 확률·IV 분포·가격·기술 배정 |
| 재화 | 기존 성장 포인트가 있음 | 같은 재화를 쓸지, 육성/상점 비용과 획득량의 균형 |

중복은 기존 IV를 낮추지 않고 능력치별 높은 값만 갱신하는 기존 수집 구조를 우선 기준으로 한다. 중복 재화 환급은 도입하지 않은 제안이다. '새 기술!' 표시는 새 기술을 실제로 획득한 경우에만 적용하며, 기술 배정 규칙이 정해지기 전에 표시만 만들어 두지 않는다.

구매와 획득 저장은 서버에서 검증하고 재접속/재시도에 중복 차감·추가 뽑기가 발생하지 않도록 한다. 리롤 업그레이드·외형 해금·뽑기 기록과 결과의 저장 범위를 함께 설계한다.

## 배포 준비와 이후

기능 연결 후 PC/모바일·키보드·기존 저장·구매 복구를 확인한다. 현재 SQLite·Node.js 서버에 맞는 호스팅과 영속 저장/백업·환경 변수·자산 출처·운영 검증을 준비한다. 호스팅 대상과 공개 시점은 아직 결정하지 않았다. 배포 준비가 끝난 뒤 AI 조건 검사와 난이도 재검증으로 돌아간다.

## 도감 첫 시안과 참고 출처

사용자 요청으로 포켓몬 센터 PC와 닌텐도 DS 시절 메뉴를 참고한다. [Nintendo 공식 하트골드 설명서](https://csassets.nintendo.com/noaext/image/private/t_KA_PDF/DS_Pokemon_HeartGold)의 메뉴 화면과 포켓몬 센터/PC 설명을 확인했다. 원작 스크린샷을 게임 자산으로 복사하지 않고 목록·정보 화면 분리, 작은 명령 버튼, 선택 테두리와 밝은 정보 패널을 현재 화면 크기에 맞게 재구성했다.

현재 적용한 첫 시안은 보라색 단말기 프레임과 연녹색 보관 목록, 선택 포켓몬의 큰 이미지·타입·종족값·테라 타입, 별도 출발 파티다. 모바일은 선택 포켓몬을 가로 정보창으로 축소하며 상세 종족값은 기본 정보 메뉴에서도 확인한다. 검색/필터 기능과 Q/E·Enter/Z, 기존 파티 선택/육성 메뉴를 유지한다. 검색은 상단 입력칸에 직접 입력하며 팝업을 열지 않는다. 입력 중에는 Q/E/Z/X를 문자로 처리하며 Enter·↓·Escape로 목록에 돌아간다. 검색어만 지우는 초기화 버튼을 검색칸 옆에 둔다.

도감과 배틀의 키보드 포커스는 두꺼운 노란 이중 테두리 대신 얇은 민트색 테두리와 은은한 배경 강조를 사용한다. 도감에서 선택한 포켓몬은 연한 금색으로 구분하며, 배틀의 기술·교체·도구와 대화상자 버튼도 같은 포커스 방향을 적용한다. 기믹 버튼은 둥근 테두리로 형태를 유지한다.

아래 첫 시안 기록 당시 영구 상점은 미구현이었으며, 현재는 아래 최신 구현 항목을 따른다. 원작 DS UI를 그대로 재현하거나 타이틀 전체를 개편한 상태도 아니다. 첫 도감 시안을 확인한 뒤 공통 메뉴로 확장한다.

출발 파티에 있는 포켓몬의 선택 메뉴 1번은 ‘포켓몬 제외하기’로 전환한다. 세 번째 포켓몬을 추가하면 ‘새 도전 시작’ 버튼으로 게임 커서를 옮긴다. 파티 슬롯의 투명 선택 버튼은 포커스를 받아도 이미지·이름을 덮지 않으며, 모바일 슬롯은 이미지 비율을 유지한다. 배틀 룰은 화면 상단 오른쪽의 ‘출발 설정’ 버튼으로 여는 별도 창에서 고른다. 출발 파티 영역에는 룰 버튼을 두지 않는다. PC·모바일의 제외/추가, 자동 포커스, 파티 표시와 룰 유지까지 포함한 검증 9개 및 빌드 통과.

승리 후 다음 층의 출전 준비는 3마리가 이미 준비되어 있으면 진행 버튼부터 선택한다. 출전 멤버를 다시 고른 뒤 3마리가 채워져도 진행 버튼으로 커서를 옮긴다. 포켓몬 목록의 마지막 선택 가능한 줄에서 아래 방향키를 누르면 진행 버튼으로 바로 이동하며, 진행 버튼에서 위 방향키로 목록에 돌아갈 수 있다. 관련 배틀·도감 검증 16개 통과 후 파티 이미지 위치 보완을 포함한 도감/다음 층 검증 6개 재확인.

타입 검사·빌드, PC1280×720/모바일390×844의 메뉴·상세·검색/필터·키 조작과 화면 범위 검증7개 통과. 캡처는 [PC 도감](../../qa/screenshots/pokedex-center/collection-1280.png), [모바일 도감](../../qa/screenshots/pokedex-center/collection-390.png).

도감 목록의 좌우 끝에서는 같은 행을 기준으로 다음/이전 페이지 포켓몬으로 이동한다. 첫/마지막 페이지 밖으로는 넘어가지 않는다. 목록의 마지막 행에서 아래 방향키로 출발 파티에 접근하며, 필터에서 위 방향키로 상단 출발 설정에 접근한다. Q/E는 계속 상단 검색/필터 항목을 가리킨다. PC·모바일 도감 회귀 검증 11개와 빌드 통과.

직접 입력 검색·검색어 초기화와 나머지 필터 유지, 좌우 페이지 전환·파티 포커스, 다음 층 이동·배틀 조작을 PC/모바일로 검증한 20개 테스트와 빌드 통과. 초기화 버튼은 검색어가 있을 때 활성화되며 Tab으로 이동한 뒤 Enter/Z로 실행할 수 있다.

검색칸과 필터/초기화 버튼의 높이는 PC 34px·모바일 30px로 맞췄다. 검색칸의 좌우 방향키는 상단 항목 이동으로 바꾸고, 초기화는 붉은색 계열로 구분한다. 선택 팝업은 포켓볼 표시·밝은 포켓몬 정보 영역·타입 배지·번호가 있는 메뉴 버튼으로 구성하며 기존 숫자키와 선택/제외·설정 동작을 유지한다. 관련 PC/모바일 테스트 16개와 빌드 통과.

도감 중앙 정보창에 선택 포켓몬의 종족값 육각형 차트를 추가했다. 높이가 충분하면 숫자 표를 함께 표시하며 낮은 PC 화면에서는 차트의 수치로 확인한다. 모바일은 가로 요약창을 유지하고 기본 정보에서 차트를 확인한다. 선택 팝업은 PC 기준 최대 360px로 줄이고 옆 장식 아이콘을 제거했다.

능력치·성격·특성/테라·기술배치 설정창은 밝은 PC 패널, 초록 탭과 민트색 커서로 통일했다. 능력 포인트 입력 및 슬라이더의 대비를 보완하고 저장 버튼을 하단에 고정했다. 도감 회귀 테스트 9개 통과 후 저장 버튼 보완에 대해 PC/모바일 2개를 재검증했으며 빌드도 통과했다. 성장 포인트 차감과 능력 포인트·테라 타입·기술배치 저장/재접속 유지까지 확인했다. 캡처: [능력치 조정](../../qa/screenshots/pokedex-center/adjustment-1280.png), [기술배치](../../qa/screenshots/pokedex-center/moves-1280.png), [종족값 차트](../../qa/screenshots/pokedex-center/radar-1920.png).

도감은 웹 문서처럼 중앙 최대 1480px에 묶지 않고 전체 화면 너비를 사용한다. 좌우 외곽 여백은 24px이며 넓은 화면에서는 목록이 최대 10열로 늘고 정보창·출발 파티도 화면에 비례해 넓어진다. 1920×902와 2560×1440에서 가로 넘침과 정보창 잘림이 없고 좌우 페이지 이동이 유지됨을 확인했다. 도감 테스트 11개와 빌드 통과 후 카드 포커스 대비 보완 및 넓은 화면 2개 재검증. [전체 너비 도감](../../qa/screenshots/pokedex-center/full-width-1920.png).

상단의 큰 제목/안내 패널을 제거하고 작은 도감 제목과 보유 수·성장 포인트를 메뉴 줄에 합쳤다. 타이틀/게임 이어하기/새 도전 준비 링크는 버튼 형태로 구분한다. 중앙 정보창의 숫자 종족값 표는 없애고 차트를 크게 표시하며 저장된 특성·성격을 대신 보여 준다. 하단 조작 안내는 키 배지와 PC 11px·모바일 10px 글자로 줄바꿈해 표시한다. PC·모바일 도감 테스트 11개 통과 후 상단 메뉴 합치기 변경에 대해 화면/차트 검증 5개를 재확인했고 빌드 통과.

사용자가 제공한 빨간 포켓몬 도감 본체와 DS 등록 화면을 참고해 외곽 프레임·검색/필터 바·출발 파티·선택 메뉴·설정창 제목을 붉은색으로 통일했다. 파란 표시등과 밝은 목록/정보 패널, 민트 포커스는 유지한다. 현재 도감 테마는 초기 보라색 PC 시안을 대체하는 빨간 도감 테마다. PC·모바일 화면 및 설정 저장 검증 6개와 빌드 통과.

붉은색의 면적이 부담스럽다는 피드백을 반영해 색 배치를 다시 조정했다. 빨강은 차분한 상단 도감 바와 대화상자 제목에 한정하며, 바깥 배경·검색/필터·출발 파티·조작 안내는 청회색, 목록/정보 화면은 밝은 회백색, 선택 표시는 청록색으로 구분한다. PC·모바일 화면 검증 4개와 빌드 통과.

출발 룰 설정은 도감 상단에서 제거했다. 3마리 선택 후 ‘새 도전 시작’에서 룰을 선택하고 ‘이 룰로 도전 시작’으로 출발한다. 취소해도 선택 파티와 임시 룰은 유지한다. 화면 표기는 기본 룰·메가진화 룰·다이맥스 룰·테라스탈 룰·혼합 룰로 풀어 쓴다. 도감/룰/스프라이트 브라우저 검증 18개, 룰 단위 검증 7개와 빌드 통과.

도감 큰 스프라이트는 원본 픽셀 기준 최대 2배로 제한하고 픽셀 렌더링과 그림자 제거로 흐림을 줄인다. 작은 원본을 억지로 같은 크기까지 확대하지 않으며 애니메이션과 기존 폴백 이미지를 유지한다. 도감 중앙/기본 정보/선택 메뉴에 적용하며 배틀 크기는 유지한다. 전체 도감 전수 검사 결과는 `artifacts/reports/pokedex-sprites/`에 세대별로 저장한다.

전체 도감 612종(1~9세대)을 실제 브라우저에서 검색/선택해 검사 완료했다. 이미지 로딩/그림 영역/확대 배율/잘림/렌더링 검사 오류 0건, 세대별 전수 테스트 9개 통과. [전수 검사 보고서](../../qa/assets/reports/pokedex-sprites/README.md)에 범위와 작은 원본 목록을 기록했다. 별도 메가진화/배틀 폼 자산은 이 도감 검사 범위에 포함하지 않는다.

## 최신 구현 — 2026-10-11 영구 업그레이드

타이틀과 도감에 영구 업그레이드 진입을 추가했다. 리롤 확장은 종류별 무료1→2회500P,2→3회1,000P로 즉시 적용한다. 이로치 교환권은 사용자 요청 가격10,000P, 대상 보유 포켓몬 외형 영구 해금·다음 도전 적용. 알 뽑기1회200P,1/10회 뽑기에서 티켓 우선·나머지 포인트 차감을 지원한다. 기계 회전→알 배출→결과 카드, 신규 종/IV 상승/기술/이로치만 조건에 맞게 강조한다. 배틀 지원612종 중 일반95%·준전설3.5%·전설1%·환상0.5%를 먼저 추첨, 각 등급 내 동일 확률, 개체값 각각0~31 균등, 합법 기술1종 추첨. 알 이로치1/1,024, 새 상대 포켓몬 이로치1/8,192이며 별빛 등장 연출을 제공한다. 기존 배틀 스냅샷은 보존한다.

새 스키마24에 영구 확장/권 보유량과 요청 영수증을 저장한다. 서버 트랜잭션으로 차감·획득을 함께 저장하고 동일 요청번호 재시도는 같은 결과를 반환한다. 네트워크 오류 시 UI는 동일 요청을 재확인하고, 결과를 받기 전 새 거래를 막는다. 일반 알이 중복돼도 기존 이로치/IV를 낮추지 않는다. 뽑기1/10회 모두 현재 도전 파티 스냅샷과 독립된 영구 도감에 반영된다.

알 뽑기는 티켓 구매 단계 없이 1회/10회 버튼으로 바로 진행한다. 보유 티켓 우선 차감, 부족한 횟수만 성장 포인트200P씩 차감하며, 혼합 결제도 하나의 거래로 저장한다. 티켓3장으로10회는3장+1,400P. 포인트 부족 시 티켓도 소비하지 않는다.
