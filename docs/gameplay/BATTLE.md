# 배틀과 룰

3마리 팀의 턴제 싱글 배틀입니다. 출전 포켓몬의 기술을 고르거나 멤버를 교체하며, 서버가 사용 가능한 행동을 검증합니다. 피해량·상태·턴·승패는 Pokémon Showdown 엔진이 계산합니다.

새 도전에서 기본·메진·다맥·테라·혼합·Z기술 중 하나를 선택합니다. 플레이어의 룰은 도전 중 바꿀 수 없고, NPC의 대표 기믹 배정과는 별개입니다.

| 기믹 | 주요 조건 |
|---|---|
| 메가진화·원시회귀 | 해당 포켓몬과 도구, 사용 가능한 룰 필요 |
| 다이맥스·거다이맥스 | 트레이너의 다이맥스밴드와 룰 조건 필요. 지원 종·폼에 따라 모습 결정 |
| 테라스탈 | 선택한 타입, 룰 조건, 트레이너의 테라스탈오브 필요 |
| Z기술 | 맞는 크리스탈과 강화 가능한 기술, 룰 조건 필요 |

트레이너 장비를 보유한 플레이어는 Z크리스탈·메가스톤을 지녔어도 변신 전에는 가능한 기믹 중 하나를 선택합니다. 거다이맥스 미지원 종은 일반 다이맥스를 사용하며, 팬텀은 팬텀나이트를 지닌 상태에서 메가진화·거다이맥스 중 선택할 수 있습니다. 테라스탈도 지닌 도구만을 이유로 차단하지 않습니다.

트레이너 장비 방식의 플레이어는 메가진화·원시회귀가 팀당 1회를 공유하고, 다이맥스는 별도로 팀당 1회 사용할 수 있습니다. 혼합룰에서는 Z기술까지 포함해 한 포켓몬이 배틀 중 사용할 수 있는 기믹은 하나입니다. 사용 후 교체하거나 다이맥스가 끝나도 다른 기믹을 사용할 수 없습니다. 다른 동료의 남은 기믹 사용권은 유지되며, 다음 배틀에서는 다시 선택할 수 있습니다. 기존 저장·NPC의 공용 사용권은 유지합니다. 테라와 Z기술은 별도 기회가 있으며 같은 포켓몬의 변신 중첩은 제한됩니다. 실제 사용 가능 여부는 현재 화면의 버튼과 안내를 따릅니다.

NPC는 기존 샘플의 지닌 도구·테라권 방식이 유지됩니다. NPC 장비와 일반 도구의 분리는 후속 작업입니다.

기술 정보는 타입·분류·위력·명중률·PP와 공개 정보 기준의 상성을 보여줍니다. 배틀 로그·포켓몬 상세·필드 상태를 확인할 수 있고, 모바일에서는 길게 눌러 상세를 확인합니다. 소리와 재생 속도는 설정에서 조정합니다.

## 현재 대화문과 지난 기록

배틀 상황은 기존 배틀 화면과 어울리는 테두리 없이 어두운 청록색 배경으로 이어지는 포켓몬식 대화창에서 최신 문장 하나를 순서대로 표시합니다. 기술 사용·효과가 굉장함/별로임·상태이상·기절 등은 현재 창에 남기며, HP 감소 문장과 남은 HP 퍼센트는 지난 기록에서만 확인합니다. 회복은 짧은 문장으로 표시하되 남은 HP 퍼센트를 생략합니다. 트레이너가 볼을 던지는 단계의 별도 안내 문구는 표시하지 않고 연출은 유지합니다.

글자 표시 연출은 배틀 재생·HP 갱신·버튼 활성 시점을 기다리게 하지 않습니다. 다음 문장이 오면 이전 글자 표시를 취소하고, 동작 감소 설정에서는 문장을 바로 표시합니다. 지난 기록은 배틀 시작과 턴별로 묶으며 HP 수치와 원래 문장을 보존합니다. S 또는 배틀 메뉴의 기록 기능으로 확인합니다.

현재 대화문은 기술 사용 → 급소(발생 시, 금빛 노란색) → 상성(2배 이상/반감 발생 시) 순으로 표시합니다. 1배 공격에는 별도 상성 문구를 추가하지 않습니다. 표시 순서만 정리하며 서버에 저장된 원본 기록과 실제 피해량은 바꾸지 않습니다. 특성으로 공격을 막거나 흡수하면 먼저 소유 포켓몬의 특성 이름을 보여주고 효과가 없다는 안내를 이어서 표시합니다.

| 상태 | 걸렸을 때 | 이후 상황 |
|---|---|---|
| 독·맹독 | 몸에 독/맹독이 퍼지기 시작했다 | 잔여 피해 때 독/맹독이 퍼지고 있다는 문장 |
| 화상 | 화상을 입었다 | 잔여 피해 때 화상 때문에 괴로워한다는 문장 |
| 마비 | 몸이 저려 마비되었다 | 행동 실패 시 몸이 저려 움직일 수 없다는 문장 |
| 잠듦 | 잠에 빠졌다 | 수면으로 행동하지 못하면 깊이 잠들어 있다는 문장 |
| 얼음 | 몸이 얼어붙었다 | 행동 실패 시 얼어붙어 움직일 수 없다는 문장 |
| 혼란 | 혼란에 빠졌다 | 혼란 지속·자해·해제를 상황에 맞게 표시 |

회복 시에도 독 해제·화상 치유·마비 해제·기상·해빙을 구별합니다. 상태이상 잔여 피해를 설명할 때도 현재 창에는 HP 퍼센트를 붙이지 않으며 수치는 지난 기록에 남습니다.
