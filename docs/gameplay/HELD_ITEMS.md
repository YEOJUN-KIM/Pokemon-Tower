# 지닌 도구

최신 후속(2026-10-13): 매 층 출전 준비에 도구 관리와 장착 표시를 제공한다. 선택 폼과 기본 멤버의 도구 저장을 통일하고 기존 중복 기록을 복구한다. 오거폰 가면 등 고정 도구는 해제·이동·교환할 수 없다. [적용과 검증](FORM_EQUIPMENT_FIXES.md).

2026-10-13 변경: 포켓몬 조정 메뉴에서도 도구를 관리한다. 다른 멤버의 도구를 선택하면 확인 후 이동 또는 상호 교환한다. 기합의띠는 배틀 안에서1회 발동하지만 자연 소모 후 다음 배틀에 다시 사용할 수 있다. 상대 기술에 의한 제거는 유지한다. [적용·검증](PLAYTEST_2026_10_13.md).

5층 클리어마다 열리는 상점에서 83종 중 등급 확률로 뽑은 4종을 판매한다. 포켓몬을 선택하면 구매와 장착을 함께 처리한다. 일반 도구는 모든 파티 포켓몬이 사용할 수 있고 메가스톤은 해당 종만 장착하며 한 마리당 하나만 장착한다. 상점마다 판매 종류별 한 개를 구매할 수 있다. 전체 등급·가격은 [등급 목록](SHOP_RARITIES.md), 추첨 확률은 [도구 상점](ITEM_SHOP.md)을 따른다. 아래 표는 최초 5종의 효과를 설명한다.

| 도구 | 가격 | 효과 |
|---|---:|---|
| 자뭉열매 | 150코인 | 배틀마다 1회, HP가 절반 이하일 때 최대 HP의 1/4 회복. 다음 층 재사용 |
| 먹다남은음식 | 400코인 | 매 턴 종료 시 최대 HP의 1/16 회복 |
| 목탄 | 200코인 | 불꽃 공격 기술 위력 20% 증가 |
| 신비의물방울 | 200코인 | 물 공격 기술 위력 20% 증가 |
| 기적의씨 | 200코인 | 풀 공격 기술 위력 20% 증가 |

효과와 특성·기술의 상호작용은 설치된 Showdown 엔진의 도구 처리를 그대로 사용한다. 배틀 중 자신의 포켓몬 상세 정보에 현재 도구를 표시하며, 열매·회복 발동은 기존 도구 연출을 사용한다. 상대의 비공개 도구 정보는 노출하지 않는다.

상점·포켓몬 조정·매 층 출전 준비에서 ‘지닌 도구 관리’를 열어 해제·재장착한다. 해제하거나 다른 도구로 교체하면 기존 도구는 도전 가방으로 돌아간다. 다른 멤버의 도구를 선택하면 확인 후 직접 이동하거나 기존 도구와 상호 교환한다. 동일 도구를 이미 지닌 포켓몬에게 중복 구매할 수 없다. 영입으로 내보내는 멤버의 도구도 가방으로 회수한다. 방향키·Z 선택과 X 취소를 지원한다.

구매·코인 차감·장착은 하나의 트랜잭션이다. 배틀 생성 당시 도구를 직렬화 팀에 저장하여 새로고침과 재생에 반영하고, 완료 시 실제 엔진의 도구 변경 이벤트를 한 번 정산한다. 자뭉열매는 발동해도 장착을 유지하고 다음 층에서 다시 쓸 수 있다. 배틀 중 엔진에서는 사용 상태로 처리하며, 리사이클 등으로 되찾아도 같은 포켓몬은 해당 배틀에서 두 번 발동하지 않는다. 탁쳐서떨구기 등 별도 제거 효과는 기존 엔진 규칙을 따른다. 도구와 가방은 이번 도전에만 유지되며 다음 도전에 이어지지 않는다.

같은 종류의 도구를 여러 파티 포켓몬에게 동시에 장착할 수 없다. 가방에는 실제 보유 수량이 있거나 장착 중인 도구만 표시한다. 기합의띠와 자뭉열매는 배틀 안에서1회 발동하며 자연 발동 후 다음 배틀에 장착을 유지한다. 상대 기술에 의한 제거는 별도로 정산한다.

메가스톤 47종과 다이맥스밴드는 레전더리 상품이며 [배틀 기믹](BATTLE_GIMMICKS.md)을 따른다. 원작 상대 도구는 구현했고 드롭·보상 선택, 진화 도구와 Z크리스탈은 후속 범위다. 현재 가격은 리롤·소모품·영양제를 포함한 50층 시뮬레이션으로 조정했다. 결과는 [상점 경제 검증](../experiments/balance/SHOP_ECONOMY_50.md)에 기록한다.

상점·구매 팝업·가방·장착 상태·배틀 상세의 도구 이름 옆에 로컬 도트 아이콘을 표시한다. 출처는 THIRD_PARTY.md에 기록한다.
