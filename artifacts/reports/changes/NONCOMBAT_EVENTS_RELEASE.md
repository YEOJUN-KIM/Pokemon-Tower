# 비전투 이벤트와 배포 검증

기준: 2026-10-16. 현재 규칙은 [이벤트 안내](../../../docs/gameplay/EVENTS.md), 실행 절차는 [배포 안내](../../../docs/operations/DEPLOYMENT.md)를 따른다.

## 적용 내용

- 상자 외에 브리더의 알 뽑기권 1장 선물과 여행 상인의 300코인→알 뽑기권 1장 구매를 추가했다. 전체 등장률 10%를 유지하며 만남 종류는 상자 50% / 브리더 30% / 상인 20%다.
- 층·승리 횟수를 소모하지 않고, 관문·최종 클리어 제외와 다음 두 층 재등장 방지를 공유한다.
- 필드에는 그림과 이펙트, 메시지 바로 위 왼쪽에는 짧은 요약을 표시한다. 아래 전체 폭에서 설명→선택→보상으로 진행하고, 선택 후 요약과 이벤트 중 발판을 숨긴다.
- 브리더와 상인은 기존 아로마 아가씨·등산가 그림을 임시 사용한다.
- DB v33에서 종류를 저장하며 기존 기록은 상자로 보존한다. 상인 차감·티켓 지급·처리 상태를 같은 트랜잭션에 기록한다.
- 기존 로컬 파일로 표시 가능한 일부 NPC 포켓몬의 비어 있던 정면·뒷면 경로를 보완했다. 사용하지 않는 미진화체 자산을 새로 내려받지는 않았다.

## 준비된 산출물

- 최종 Windows 패키지: `dist/tower-2026-10-15T16-23-17-347Z/`.
- 개인 `.data`·실제 `.env`는 패키지에서 제외했다. Node.js 24와 빌드에 맞는 OS·CPU가 필요하다.
- 개인 플레이용 더블클릭 실행기를 추가했다. 이 PC의 Docker Linux 엔진에서 이미지 빌드·DB 백업·서버/터널 시작·종료·재시작과 새 HTTPS 주소의 health 200을 확인했다. 다른 Linux 호스팅 환경에 복사하는 경우는 별도 환경 검증이 필요하다.
- 재현: `pnpm deploy:package`, `node scripts/verify-deploy.mjs 패키지경로`.

## 개인용 더블클릭 실행

루트의 `포켓몬타워 실행.cmd` 하나가 `scripts/launcher-window.ps1`의 WinForms 통합 창을 연다. 켜기·끄기·상태 확인은 `scripts/launch-preview.mjs`를 사용하고, 게임 열기와 주소 복사는 같은 창의 버튼으로 처리한다. 기존 종료·상태용 CMD는 통합했다. 다른 폴더에서 CMD를 호출하고 PATH에 Node·Docker가 없어도 설치 위치를 찾아 동작하는 것을 확인했다. 서버와 SQLite는 기존 `tower-preview` 볼륨을 사용하며 로컬 개발 DB를 덮어쓰지 않는다.

`preview.mjs`는 이미지 빌드 후 서버를 바꾸기 전에 기존 DB를 SQLite backup API로 백업한다. 종료 시 볼륨은 유지한다. 다시 켤 때에는 현재 터널 컨테이너의 시작 시각 이후 로그에서만 주소를 찾아, 지난 실행의 주소를 잘못 표시하지 않는다. 실행 완료 시 브라우저를 열고 `.data/preview-url.txt`에 주소를 저장한다. PC 부팅 시 예약 실행이나 외부 호스팅 등록은 하지 않는다.

통합 창의 실제 서버 상태 읽기·현재 URL 표시·버튼 활성화와 창 렌더링을 `launcher-window.ps1 -SelfTest`로 확인했다. 갱신 중 주소 공유 버튼은 비활성화되며, 창을 닫는 동작으로 게임 서버를 종료하지 않는다. QR코드 및 외부 주소 변환 서비스를 사용하지 않는다.

## 작업 인계와 GitHub 업로드

개인 이전용 ZIP은 `.data/transfers/pokemon-private-save-20261016-*.zip`에 만든다. 이번 묶음에는 실제 `.env.local` 경로의 개발 저장(v32), Docker 저장(v33), 환경 설정·이전 안내·파일 해시를 담았으며 두 DB의 무결성과 ZIP 항목 해시 일치를 확인했다. 원본 DB·Docker 볼륨을 덮어쓰지 않았다. 개인 ZIP·환경 설정은 Git에서 제외하며 자세한 복원 절차는 [컴퓨터 이전](../../../docs/operations/COMPUTER_MOVE.md)을 따른다.

업로드 설명 예시:

```text
feat: 비전투 이벤트와 개인용 통합 실행기 추가

- 상자·브리더·여행 상인 이벤트와 보상·결제·저장 복구 구현
- 배틀 대화창·배속·등장 및 클리어 전환 개선
- 기술배치 자동 저장과 관련 UI 정리
- 서버·DB·터널 실행/종료, 게임 열기·주소 복사를 한 실행기로 통합
- 문서·저장 이전 안내·회귀 테스트 최신화
```

새 파일(실행 CMD·PowerShell·Node 실행기, 이벤트 코드·테스트·보고서·문서에 연결된 GIF)을 기존 수정 파일과 함께 커밋한다. 자동 생성된 패키지·캐시·개인 DB는 GitHub에 올리지 않는다. 이번 작업은 사용자 직접 업로드를 위한 준비이며 커밋·푸시는 수행하지 않았다.
