# 유형별 보고서와 결과물

현재 게임 기능은 [게임 안내](../docs/README.md)에서 확인합니다. 여기는 실험 결과나 변경 이유가 필요할 때만 읽습니다.

| 찾는 자료 | 위치 |
|---|---|
| 공개 정보·기술 선택·무효 학습 등 AI 비교 | [AI 보고서](experiments/ai/README.md) |
| 난이도·보스·룰 차이·상점 경제 | [밸런스 보고서](experiments/balance/README.md) |
| 팀 조합·트릭룸·벽·샘플 검증 | [팀 샘플 보고서](experiments/samples/README.md) |
| 버그 원인·기능 변경·검증 기록 | [변경 근거](reports/changes/README.md) |
| NPC 파티와 육성 표·CSV | [NPC 검토](reports/npc/README.md) |
| 아직 유효한 후속 구상 | [기획 참고](reports/planning/README.md) |
| 화면·자산 검사 | `qa/` |

각 실험 유형 안에서 같은 접두사·실험 ID의 보고서, 요약, 입력, 상세 로그, manifest를 함께 찾습니다. 같은 실험의 중복 안내는 기준 보고서로 합쳤습니다. 자동 정책의 승률은 사람 승률이 아니고 과거 수치는 새 팀·새 IV 이후의 측정 결과가 아닙니다.

해결한 문제의 일시적인 결과물은 `temporary/`에 두고 작업 종료 후 삭제합니다. 모든 캡처나 로그를 영구 보관하지 않습니다. [전체 기계 색인](index.md)은 개발용이며 일반 사용자가 읽을 필요는 없습니다.
