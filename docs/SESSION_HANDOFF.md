# 작업 인계

갱신: 2026-10-11. **다른 컴퓨터에서 이어갈 때 [컴퓨터 이전 안내](current/COMPUTER_MOVE.md)를 먼저 읽는다.**

## 현재 사용자 결정

- 무료 PC + Docker + Cloudflare Quick Tunnel로 테스트를 유지한다. 유료 서버·도메인·PWA는 지금 진행하지 않는다.
- 실제 휴대폰에서 길게 누르기, 손 떼기, 더블 터치 스킵, 로그인 유지, 화면 잘림이 잘 동작함을 사용자가 확인했다.
- 다음 작업은 새 컴퓨터에서 최신 코드와 저장을 복원하고 로컬 개발을 이어가는 것이다. AI·가격·난이도를 임의로 변경하지 않는다.

## 마지막 완료 작업

- 로그인·회원가입·복구 키, 30일 로그인 유지, 27종 스타팅 기본 해금. 로컬 자동 로그인은 개발 loopback 전용이며 인터넷 서버에서는 차단한다.
- 타이틀 새로하기 확인 팝업, 도감 기본 정보 변신 미리보기·성격 이름·특성 툴팁, 기술배치와 능력치 조정 키보드 흐름, 정비 상점/6마리 선택 팝업을 정리했다.
- 모바일 키보드 안내·커서·내보내기/스킵 버튼 숨김. 화면 터치로 내보내기, 누르는 동안만 기술·날씨·랭크 툴팁, 연출 중 빠른 두 번 터치로 스킵.
- PC·모바일 영입 확인에서 기술 목록/즉시 장착 선택 제거. 개체값 비교 접기, 취소30%/확인70% 한 줄 버튼. 도감 등록 또는 동료 합류를 선택하며 새 기술은 완료 화면에서만 표시한다.
- 최근 프로덕션 빌드, 영입/도감 등록 PC·모바일4개, 모바일 터치/PC 키보드2개 통과. 전체 과거 테스트가 최신 인증/UI와 일치한다고 가정하지 않는다.

## 저장과 무료 공개

인터넷 DB는 `tower-preview_tower-data` 볼륨의 `/data/tower.sqlite`. 로컬 개발 DB와 자동 동기화되지 않는다. 최신 백업 이름, 새 PC 복원 명령, 실행 순서는 [컴퓨터 이전 안내](current/COMPUTER_MOVE.md)에 있다. Docker 볼륨은 코드 폴더 복사에 따라가지 않는다. 최신 파일은 Git untracked가 많으므로 clone만으로 옮길 수 없다.

임시 주소는 재시작 후 바뀔 수 있으며 `.data/preview.env`와 실제 터널 로그를 확인한다. 게임 자동 재시작은 설정돼 있지만 터널 자동 시작·정기 백업·고정 주소는 아직 미설정이다. `down -v`와 volume prune을 쓰지 않는다.
