기믹·상점·지역별 구현 기록도 같은 폴더에 있습니다. 날짜별 과거 수치는 현재값이 아니며, 새 작은 수정마다 별도 파일을 만들지 않고 해당 주제 기록을 갱신합니다.

위 두 날짜별 보고서는 `docs/` 루트에서 이 폴더로 옮겼다. 본문·당시 수치·검증 결과는 보존하고 상대 이미지 링크만 새 위치에 맞췄다. 현재 규칙은 STATUS·gameplay, 향후 계획은 ROADMAP, 자동 테스트 로그·스크린샷은 `artifacts/qa`에서 확인한다. 과거 보고서의 수치는 현재값으로 덮어쓰지 않는다.
