# 빌런 이벤트와 확장 이력

최신 상태(2026-10-10): 새 도전에 조직원·간부·보스 추첨, 보스 격파 후 해당 도전의 조직 이벤트 종료와 특별 보상을 구현했다. 기존 진행 중 도전은 조직원 방식과 저장된 배틀을 유지한다. 새 도전의 조직은 선택된 지역 테마의 후보에서 한 번 추첨한다. 현재 타워 배치는 [세대 테마](REGIONAL_THEMES.md), 후속 순서는 [로드맵](../current/ROADMAP.md)을 따른다.

## 현재 50층 구현

한 도전에서 추첨한 같은 조직만 등장한다. 일반 층의 이벤트 추첨은 기존 임시 8%를 유지한다. 직전 배틀이 빌런이면 연속 등장을 막고, 5층 단위 네임드전을 대체하지 않는다. 후보 종이 현재 층의 제한을 통과한 3마리 이상일 때만 실제 이벤트를 만든다. 조직은 첫 등장 전 공개하지 않는다.

| 층 | 조직원 | 간부 | 보스 |
|---|---|---|---|
| 1~15 | 100% | 0% | 0% |
| 16~30 | 65% | 35% | 0% |
| 31~50 | 35% | 40% | 25% |

표의 비율은 이벤트 등장 추첨을 통과했을 때의 조건부 확률이다. 등장 층·비율은 이번 구현의 시험용 설정이며 이전 대화의 확정 수치가 아니다. 간부나 보스가 모든 도전에 반드시 등장하거나 조직원→간부→보스 순서로 나오는 구조는 아니다.

| 조직 | 간부 | 보스 |
|---|---|---|
| 로켓단 | 아폴로 | 비주기 |
| 마그마단 | 호걸 | 마적 |
| 갤럭시단 | 마스 | 태홍 |
| 플라스마단 | 칠현인 비오 | 게치스 |
| 플레어단 | 크세로시키 | 플라드리 |
| 스컬단 | 플루메리 | 구즈마 |
| 아쿠아단 | 해조 | 아강 |
| 에테르재단 | 자우보 | 루자미네 |
| 매크로코스모스 | 올리브 | 로즈 |
| 스타단 | 피냐 | 모란 |

스타단의 간부/보스와 에테르재단의 적대 이벤트는 원작 조직 관계를 참고한 타워 각색이다. 매크로코스모스 조직원은 임시로 회사원 초상화를 사용한다.

간부·보스는 대표 포켓몬을 고정하고 테마 후보에서 파트너 둘을 추첨한다. 합법 기술·중복 없는 도구를 구성하되 공식 고정 팀의 재현으로 취급하지 않는다. 추가 변신 기믹이나 임의 레벨 상승은 넣지 않았다. 기존 층별 능력 포인트와 상대 테라 규칙을 적용한다.

추가 승리 보상은 조직원 0, 간부 250, 보스 1,000코인이다. 기본 층 보상과 합산한 금액을 배틀 생성 시 저장한다. 승리 화면·영입 화면에서 추가 보상이 합계에 포함되어 있음을 표시한다. 가격·경제·난이도 재측정 전의 임시 보상이다.

보스에게 승리하면 같은 트랜잭션에서 배틀 완료·보상 지급·캠페인 종료를 저장한다. 기절·패배·무승부나 단순 등장만으로 종료하지 않는다. 이후 일반 층에 해당 조직이 다시 나오지 않으며 타워는 계속 진행한다. 새 도전은 새 조직 추첨과 종료되지 않은 캠페인으로 시작한다.

DB v20: `run_villain_campaigns.defeated_battle_id`와 `battles.villain_event`를 추가했다. 기존 도전에 캠페인을 소급 부여하지 않고 기존 팀·보상·종료 층을 유지한다. 클라이언트가 보상이나 승패를 지정하는 API는 없다.

검증: 전체 단위·통합 135개, 관련 Chrome PC/모바일 8개, 타입 검사·프로덕션 빌드 통과. 6개 조직의 간부·보스 12팀에 대표 포켓몬·도구 중복·기술 합법성·사진을 확인했다. 실제 엔진 승리/패배, 중복 완료, 보상 실패 시 전체 롤백, 보스 격파 후 등장 중단, 새 도전 초기화, v19 복구를 검사했다. 영양제 기존 검사는 기절 후 HP 문자열로 초기 능력치를 덮어쓰던 문제를 수정해 첫 출전 능력치를 검사한다. 브라우저 전체 묶음을 재실행한 것은 아니다.

캡처: `artifacts/screenshots/villain-campaign/`. 트레이너 이미지는 [Pokémon Showdown 제공원](https://play.pokemonshowdown.com/sprites/trainers/)에서 수정 없이 저장했다. 작가 표기와 URL은 `trainer-sprite-sources.json`, 재현 명령은 `node --import tsx scripts/import-trainer-samples.mjs`에 있다.

## 아래는 30층 구현 당시 이력

2026-10-09 사용자와 정한 구조:

- 일반 층에서 빌런 등장 여부를 먼저 추첨한다. 등장하면 층에 따른 등급 비율로 조직원·간부·보스를 추첨한다. 제시된 10%, 30·50·100층 비율은 설명용 예시이며 확정 수치가 아니다.
- 한 도전에서는 같은 조직만 나온다. 보스에게 승리하면 해당 도전의 빌런 이벤트를 종료한다. 새 도전에서 조직과 이벤트를 다시 시작한다.

현재 30층 버전:

- 로켓단·마그마단·갤럭시단·플라스마단·플레어단·스컬단 중 하나를 새 도전 시작 때 추첨해 서버에 저장한다. 등장하기 전 조직 정보는 플레이어에게 전달하지 않는다.
- 일반 층에서 임시 8% 이벤트 추첨을 적용한다. 바로 이전 경기가 빌런이면 이번에는 제외하며 5층 단위 관장·챔피언 경기는 대체하지 않는다. 후보 엔트리 중 현재 층의 종 제한을 통과한 3마리 이상이 있을 때만 등장한다. 따라서 실제 등장률은 후보 부족과 연속 제한에 따라 낮아질 수 있다.
- 30층까지는 조직원만 등장한다. 팀은 조직별 샘플 엔트리에서 조합을 고려해 3마리를 선택하며 공식 고정 팀 재현은 아니다. 층별 제한과 능력치 증가를 그대로 적용한다. 빌런 음악과 시설 배경을 연결하고 일반전과 동일한 보상을 준다.
- 간부·보스의 등장 층·비율, 보스 격파 종료와 특별 보상은 높은 층의 콘텐츠를 추가할 때 구현한다. 현재 30층에 보스를 억지로 앞당겨 배치하지 않는다.

30층 진행 규칙:

- 5·15·25층 관장/캡틴, 10·20·30층 챔피언/최종 상대. 각 역할의 기존 후보 9명에서 도전 ID와 층으로 추첨한다. 상대 타입·포켓몬 세대 제한은 없다.
- 5·10·15·20·25층 승리 후 다음 층 준비(6·11·16·21·26층)에 상점이 열린다. 상품과 구매는 상점마다 저장되고 강화는 5개 층 지속한다. 만료된 강화는 다음 상점에서 다시 살 수 있다.
- 11층 이후 상대에게 층당 총 1 능력 포인트를 추가하여 30층에서 총 20포인트를 준다. 주 공격 능력치 60%, HP 40%로 나누며 별도의 임의 레벨 인상은 없다. 일반 종 후보 제한과 기존 기술 생성은 유지한다. 보상·강화·등장률은 임시 값이며 승률 균형 검사는 후속이다.
- DB v12는 기존 도전의 종료 층·배틀·파티·입력·구매·육성을 유지한다. 새 도전부터 30층이다. 최종 층 승리 후 마지막 영입 처리를 마치면 명예의 전당과 종료 정산으로 이동한다.
