# 일반 모드 확정 기준

2026-10-13 사용자 결정. 먼저 일반100층을 완성하고, 하드모드 설계는 이후에 진행한다. 같은 NPC에 룰별 파티를 만들지 않으며 플레이어 룰과 독립적인 대표 기믹을 유지한다.

## 네 구간과 두 단계 샘플

| 구간 | 상대 | 사용할 샘플 | 기믹 |
|---|---|---|---|
| 5~45층 | 관장·사천왕 | 전반 샘플 | 사용 안 함 |
| 50층 | 첫 챔피언·관문 보스 | 첫 관문 샘플 | 대표 기믹 첫 사용 |
| 55~95층 | 관장·사천왕 | 후반 샘플 | 대표 기믹 사용 |
| 100층 | 챔피언·최종 보스 | 최종 샘플 | 대표 기믹 사용 |

관장·사천왕은 전반/후반 두 개, 챔피언·보스는 첫 관문/최종 두 개만 만든다. 모든 층별로 별도 팀을 만들지 않는다. 51~54층은 기존 후반부 진입 완화 구간을 유지하며 첫 후반 관장은55층이다.

일반 트레이너·조직원은 기믹 없이 싸운다. 간부는 관장 쪽의55층 기준을 따른다. 빌런 보스는75층 이상에서만 등장하며 후반·최종 샘플을 사용한다. 5층 단위 관문은 빌런 이벤트로 교체하지 않아 실제 첫 이벤트 가능 층은76층이다. 전설75층·환상90층 해금은 유지한다. 마적은 주홍구슬을 지닌 그란돈을 에이스로 사용한다.

전반 샘플은 기본 공격·단순 지원과 낮은 육성, 후반은 기술·도구·특성·육성이 역할에 맞는 팀을 목표로 한다. 후반 샘플의 기믹 에이스를 동료의 상태이상·날씨·벽·교체가 돕도록 다듬는다. 50층은 첫 기믹을 배우는 관문,100층은 그 전술에 대응하는 최종 시험이다.

## 현재 반영과 남은 작업

- **반영 완료:** 새 일반 모드 네임드 배틀에 고정3마리·기술·도구·특성·성격·역할별 육성을 연결했다. 챔피언50층, 관장·사천왕/간부55층부터 기믹을 사용하며 빌런 보스는75층 이상에서만 등장한다. 저장된 배틀의 packed team과 legacy 팀 생성은 유지한다.
- **사용자 검토:** [일반 모드 두 단계 샘플](../npc/NORMAL_MODE_SAMPLES.md). 164종×두 단계=328팀,984마리. NPC당 한 줄로 두 단계를 비교하고 아래 상세 표에서 세팅을 확인한다. 최고 단계 검토 문서도 유지한다.
- **코드용 데이터:** CSV는 영문 내부 이름·고정 키·숫자 필드로 생성한다. 일반/참고 모드를 구분하고 샘플 ID로 단계 혼동을 막는다. [CSV 규약](../../../docs/engineering/NPC_DATA.md)에 생성·검증 방법을 기록했다. 사용자는 CSV를 볼 필요가 없다.
- **육성 수치:** 표의 대표45/50/95/100층은 참고 IV10/12/28/31, 포인트7/8/58/66이다.2026-10-14부터 실제 관장급 IV만 [총합 예산·역할 랜덤 배분](../changes/NAMED_OPPONENT_IVS.md)으로 대체한다. 일반·엘리트 IV는 유지한다. 능력 포인트는 해당 층의 기존 곡선과 템플릿 육성 중 낮은 값을 상한으로 역할별 비율을 유지한다. 난이도 측정으로 새 수치를 정한 것은 아니다.
- **다음:** 같은 플레이어 팀·코스로 네 구간과 각 룰 난이도를 비교하고 실제 플레이 체감을 확인한다. 고정 샘플 연결은 완료했으며 10층별 추가 보정과 하드모드는 보류한다.

## 10층 단위 육성·도구 조정은 후속 작업

### 2026-10-13 시뮬레이션 1차 확인

[승률 검사](../../experiments/balance/NORMAL_MODE_BALANCE_CHECK.md): 네 고정 플레이어 팀·여섯 룰·동일 층 육성으로19,584전, 별도 재실행54전 일치, 오류0건. 일반 구간 약81~82%,50층54.2%,100층59.0%였다. 다이맥스87.8%가 기본76.8%보다 유리했다. 극단 상대의 출전 순서 추가 검사에서는 마적31.9%,단델18.6%,비주기95.8%,구즈마96.3%로 격차가 남았다. 빌런76/96층·단델50/100층 합산이며 층별 표는 별도 문서에 기록했다.

단판 AI 승률이고 장비 직접 지급·테라권 제공 조건이다. 쇼핑 경제·포획·영양제 추가분·소모품·연속 완주와 사람 승률을 측정한 것이 아니다. 전체를 일괄 강화하기보다 보스별 격차와 다이맥스 유리함을 추가 검토할 근거이며 현재 샘플·게임 수치는 변경하지 않았다.

2026-10-13 사용자 결정: 현재 네 구간과 두 단계 샘플은 이 상태로 유지한다. 지금 10층마다 별도 샘플을 늘리거나 육성·도구를 추가 조정하지 않는다.

추후 배틀 시뮬레이션이나 머신러닝 등으로 각 10층 구간의 샘플 데이터를 검토한다. 조정 후보는 개체치 상승, 능력 포인트(노력치에 해당하는 게임 내 육성) 상승, 더 좋은 지닌 도구 배정이다. 현재 샘플을 기준 데이터로 사용하고, 기믹 시작 시점50/55층과 전설 해금 같은 제약은 유지하면서 승률·플레이 체감에 따라 보정한다. 방법·목표 승률·최종 수치는 아직 정하지 않았다.

## 하드모드 구상으로 보관

일반 모드가 완성된 후 검토한다. 최고 단계부터 시작하고 출발 시 지닌 도구를 선택하는 별도 하드모드, 또는101~200층 확장은 미구현 구상이다.

NPC는 고정된6마리 후보를 미리 공개하고 그 안에서3마리를 출전시키는 방향이다. 공개 화면은 **현재 배틀 UI 좌측 위의 플레이어 출전 포켓몬 UI를 상대 쪽에도 대응하여 사용**한다. 상대 후보6마리와 출전/남은 포켓몬 상태를 어떻게 구분할지는 추후 설계한다. 공개·선택 시점과 NPC 선택 규칙도 미정이며 플레이어의 비공개 기술·IV를 몰래 읽어 맞춤 파티를 생성하지 않는다.

이번 작업에서는 하드모드·200층·상대6마리 UI를 구현하지 않는다.
