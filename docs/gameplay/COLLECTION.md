# 수집과 육성

도감에서 보유 포켓몬 3마리를 출발 파티로 선택합니다. 첫 번째가 선봉입니다. 기본 스타터는 1~9세대 일반 최종 진화형 27종이며 현재 서버 도감은 615개 항목입니다.

승리 후 상대를 영입하거나 도감에 등록하고, 중복 수집으로 더 높은 개체값과 기술을 모읍니다. 도전이 끝나도 계정의 도감·육성·성장 포인트는 남습니다. 수집 가능한 미진화 예외는 폴리곤2·스라크·피카츄·두랄루돈입니다.

능력치 조정에서 개체값·능력 포인트·성격·특성·테라 타입을 관리하고 기술배치에서 기술 4개를 선택합니다. 게임의 능력 포인트는 원작의 EV 252 수치와 구분합니다. 선택 폼은 기본종의 수집·육성을 공유하며 출발 전에 모습 설정에서 고릅니다. 배틀 중에만 바뀌는 변신폼은 기본 정보에서 확인할 수 있지만 출발 폼으로 저장하지 않습니다.

매 층 출전 준비에서 지닌 도구를 관리할 수 있습니다. 이미 시작한 도전이나 생성된 배틀에는 저장된 스냅샷이 있으므로 영구 도감 변경이 모든 과거 기록에 소급 적용되지는 않습니다.
