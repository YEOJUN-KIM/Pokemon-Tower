## 기술 교환과 저장

다른 슬롯의 기술을 선택하면 현재 기술과 해당 슬롯의 기술을 교환한다. 마우스와 Enter/Z가 같은 onClick 및 withSettingMove 함수를 사용한다. 이미 현재 슬롯에 있는 기술은 그대로 유지한다. 다음 빈 슬롯으로 기존 기술을 옮길 때는 빈 중간 칸 없이 배열을 압축한다.

변경한 moves 배열은 기존 draft와 onSave → train → saveTrainingForm / pokemon_training 경로로 저장한다. 엔드포인트, DB 스키마, 서버의 중복 기술 검증은 변경하지 않았다. 브라우저 테스트에서 API와 DB의 순서 및 도감 재진입을 확인한다.

## 폼 선택

직접 선택할 수 있는 폼이 두 개 이상일 때만 오른쪽 기술 1~4 / 특성 / 테라스탈 아래에 폼체인지 행을 표시한다. 카드에는 스프라이트·폼 이름·타입·현재 선택 체크만 남겼다. 공유 능력치, 특성, 기술배치, 폼별 저장 규칙, 다음 도전 적용, 저장 버튼 안내 문단과 큰 모습 적용 버튼을 제거했다.

방향키로 카드를 이동하고 Enter/Z 또는 클릭으로 draft에 반영한 뒤 메인 설정으로 돌아온다. X/Esc 취소는 draft를 변경하지 않는다. 공통 footer와 커서 복귀를 유지한다. profileForForm과 기존 formOptions.settings를 재사용하여 폼별 기술·특성·테라 설정을 복원하고, 메인 설정의 스프라이트·이름·타입·기술 후보도 선택 폼을 따른다.

## 아이템 조건 폼의 현재 게임 규칙

도감 UI의 포켓몬 이름 하드코딩을 제거하고 공통 formItemFor / formItems 장비 메타데이터를 재사용했다. 배낭 장착으로만 변하는 장비 폼은 영구 도감 설정 선택 목록에서 제외한다. 전용 도구를 자동 적용하는 기존 오리진 폼은 그대로 선택 가능하다.

현재 가면 구매/소유/장착은 도전별 run_item_bag / run_held_items에 저장되며 영구 폼 해금이 아니다. 따라서 오거폰은 가면 구매 이후에도 도감에서 선택하지 않고 기존 배낭에서 장착한다. 가면 장착 후 해당 폼 적용, 해제 후 기본 폼 복귀, 재시작 보존, 새 도전 시 가면 미지급 테스트를 통과했다. 요청의 “조건 충족 후 도감 목록 노출”은 현재 게임 규칙과 다르므로 적용하지 않았다. 이를 도감의 영구 선택으로 허용하려면 별도 게임 규칙 결정이 필요하다.

## 성별

도감 선택 포켓몬, 선택 메뉴, 기본 정보, 통합 설정 이름 옆에 재사용 PokemonGenderIcon을 적용했다. 수컷은 차분한 파랑, 암컷은 분홍이며 무성/미확인은 생략한다. 통합 설정은 draft.gender에 연결하여 저장 전에 즉시 갱신한다. 설정 저장 후 도감 및 재진입에서도 저장된 성별을 사용한다.

## 수동 확인 범위

실제 사용자 계정과 운영 DB에서는 실행하지 않았다. 물리 게임패드, Chrome 이외 브라우저, 모든 포켓몬의 긴 폼 이름은 수동 확인이 남아 있다. 아이템 취득 후 도감 폼 노출은 위의 기존 규칙에 따른 의도적 미적용 사항이다.

## 후속 메뉴 정리

통합 설정에 기술 편집이 포함되어 도감 선택 메뉴의 별도 기술배치 항목과 onMoves 진입 경로/상태를 제거했다. 메뉴 번호와 단축키는 1 선택/제외, 2 포켓몬 설정, 3 기본 정보, 4 취소로 정리했다. 기존 설정 E2E에서 메뉴 제거·번호 속성·2번 키 설정 진입을 확인한다.
