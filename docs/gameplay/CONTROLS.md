# 화면과 조작

현재 화면의 조작 방법입니다. 변경 과정과 검증 기록은 [유형별 보고서](../../artifacts/README.md)에 있습니다.

기술 선택 화면에서 테라스탈은 메가진화·Z기술·다이맥스와 같은 왼쪽 기믹 아이콘 줄에 표시합니다. 현재 포켓몬의 테라 타입에 맞는 보석 아이콘을 사용합니다. 메가진화·Z기술 버튼은 현재 지닌 메가스톤·Z크리스탈 아이콘을 표시하며 선택하면 주변 빛이 일렁이고 아이콘이 빛납니다. A키를 누를 때마다 사용 가능한 아이콘을 화면 왼쪽부터 오른쪽으로 선택하고, 마지막 다음에는 모두 해제합니다. 비활성 아이콘은 건너뜁니다. 선택은 사용을 예약하는 단계이며 기술을 결정하면 발동합니다. 아이콘 줄 위의 별도 변신 선택 안내 문구는 표시하지 않습니다.

다이맥스밴드·테라스탈오브는 보유한 것만 좌측 상단 포켓몬 명단 옆에 아이콘으로 표시합니다. 장비가 있어야 해당 변신 버튼이 나타나며, 배틀에서 사용한 기믹은 교체 후에도 반투명 비활성 상태로 남습니다.

최신 출전 준비: 매 층 팀 선택에서 각 멤버의 선택 모습·지닌 도구를 표시하고 ‘지닌 도구 관리’를 연다. 보유 멤버를 고른 뒤 장착·해제하거나 다른 멤버의 도구를 확인 후 이동·교환한다.24층처럼 상점이 없는 층에서도 사용할 수 있다. 오거폰 가면 등 고정 도구는 변경할 수 없다. [적용과 검증](../../artifacts/reports/changes/FORM_EQUIPMENT_FIXES.md).

## 타이틀과 도감

로그인 후 타이틀에서 새로하기·이어하기·도감으로 이동한다. 진행 중인 도전이 있을 때 새로하기는 종료 여부와 받을 성장 포인트를 팝업으로 확인한다. 출발 포켓몬 3마리를 고르고 룰을 확인해 시작하며 첫 번째가 선봉이다.

| 키 | 도감 동작 |
|---|---|
| 방향키 | 목록·메뉴 이동 |
| Enter/Z | 선택·설정 메뉴 열기, 확정; 선택 해제도 이 메뉴에서 처리 |
| X | 메뉴에서 뒤로, 도감 메인에서는 타이틀 복귀 확인 |
| F | 현재 포켓몬 즐겨찾기 전환 |
| V | 즐겨찾기만 보기 전환 |
| R | 필터 초기화 |
| PageUp/PageDown | 페이지 이동 |

검색칸에서는 문자 입력을 우선한다. 기본 정보는 타입·종족값·특성·성격 이름·기술을 표시한다. 메가/거다이맥스가 있는 포켓몬은 모습과 변경된 정보를 미리 볼 수 있다. 특성에 마우스를 올리거나 포커스를 주면 설명이 뜬다.

## 기술배치와 능력치 조정

내 기술 칸에서 좌우로 칸을 고르고 **Z 또는 아래 키**로 기술 목록에 들어간다. 기술을 고르면 무료로 즉시 저장하며 별도 저장 버튼은 없다. 저장 실패 시 이전 배치로 되돌리고 오류를 표시한다. 기술 목록 맨 위에서 위를 눌러도 목록 안에 머문다. 기술 선택 Z 또는 취소 X는 내 기술 칸으로 돌아간다. 저장 완료 문구는 잠시 표시한 뒤 사라진다.

이미 다른 칸에 배치된 기술을 선택하면 두 칸의 기술 위치를 맞바꾼다. 기술배치 편집기와 육성 화면의 기술 선택 모두 같은 방식이며 중복 기술을 만들지 않는다.

능력치 / 성격·특성·테라스탈 두 탭은 방향키 이동 즉시 내용을 바꾸고 Z로 세부 설정에 들어간다. 능력치는 위아래로 항목을 선택하고 좌우로 노력치를 조정한다. 성격·특성·테라스탈은 별도 선택 팝업을 연다. 개체값 31과 최대 노력치는 금색, 개체값 0은 회색으로 구분한다.

## 배틀

PC에서는 싸운다에서 기술을 선택한다. 기술 선택 화면에서 A는 룰에 따라 메가진화·다이맥스·테라스탈·Z기술을 예약하거나 해제한다. 혼합룰은 사용 가능한 버튼을 화면 왼쪽부터 순환한 뒤 모두 해제하며, 기본룰에는 A 안내가 없다. 교체는 배틀 메뉴의 교체 버튼으로 선택한다. S는 기록, C를 누르는 동안 날씨·랭크 확인, Shift는 연출 스킵이다. 키 안내는 키캡과 동작 라벨로 표시한다. 조건을 만족한 기믹을 예약하고 기술을 결정하면 기믹 발동 후 공격한다. 배틀 아이템 사용은 턴을 소모하지 않는다.

Z기술 선택 중 강화 가능한 기술은 금빛 버튼과 굵은 기울임꼴 기술명으로 강조한다. 별도 `Z POWER` 표식은 없으며 강화할 수 없는 기술은 비활성화한다. 키보드 선택도 금빛 테두리를 유지한다. [크리스탈·사용권·효과](../../artifacts/reports/changes/Z_MOVES.md).

상단 팀은 보유 포켓몬 6칸을 표시한다. 이번 배틀 출전 멤버만 색을 유지하고 미출전·기절 멤버는 회색과 상태 라벨로 구분한다. 보유 포켓몬이 6마리보다 적으면 빈 슬롯으로 표시한다. 기믹 버튼을 마우스로 클릭할 때 포커스 원은 표시하지 않고 키보드 선택은 사각 테두리로 표시한다.

모바일에서는 키보드 안내·포커스 표시·내보내기/스킵 버튼을 숨긴다. 등장 안내는 화면 터치로 진행한다. 기술을 450ms 이상 누르는 동안만 설명을 표시하고 손을 떼면 닫으며, 이 동작으로 공격하지 않는다. 경기 화면을 누르는 동안 날씨·랭크를 표시한다. 공격 연출 중 빠른 두 번 터치로 스킵한다.

설정의 배틀 재생에서 1배·2배·4배를 선택한다. 기술·변신 연출과 HP 갱신은 배속하되 새 메시지에는 읽을 시간을 확보하며, Shift 전체 스킵도 유지한다. 배속은 이 브라우저에 저장한다.

## 영입과 정비

영입 후보에 새 포켓몬·도감 미등록 또는 도감 등록됨을 표시하고, 새 기술 수집 개수는 별도 라벨로 표시한다. 확인과 완료 화면도 포켓몬 등록과 기술 수집을 나눠 보여준다.

승리 후 도감에 등록하거나 동료로 데려갈 수 있다. 도감 등록은 이번 팀을 유지하고 다음 도전부터 선택할 수 있게 한다. 확인 팝업의 개체값 비교는 접혀 있으며 기술 목록·즉시 장착 선택은 없다. 기술 수집은 자동 처리하고 새 기술은 완료 화면에서만 표시한다. 취소와 확인 버튼은 한 줄에 3:7 비율로 배치한다.

층 사이 HP·PP·상태를 회복한다. 10층 클리어 정비는 상점 / 포켓몬 조정을 상위 메뉴에서 선택한다. 포켓몬 선택은 HP 없이 6마리의 스프라이트 카드로 표시한다. 상점은 지닌 도구 / 배틀 아이템 / 기술머신 / 육성으로 나눈다. 탭의 Z는 상품 목록, 아래 키는 관리·리롤 등 버튼으로 이동한다. 정비 팝업은 크기를 통일한다.

동작 버튼에는 확인·취소·돌아가기 등 동작 이름만 표시하며 Z·X·Enter·Shift 꼬리표는 생략한다. 실제 키보드 입력과 조작 안내는 유지한다.

## 영구 업그레이드와 소리

성장 포인트 화면은 영구 업그레이드 / 알 뽑기 두 탭으로 나눈다. 업그레이드 탭에는 다시하기 확장·리롤 확장권·이로치 교환권을 표시한다. PC에서는 세 항목을 한 줄에, 좁은 화면에서는 세로로 배치한다. 알 뽑기는 별도 탭에서 진행하며 성장 포인트와 구매 상태를 공유한다. Q/E로 탭을 전환할 수 있다.

알 뽑기는 알 뽑기 탭의 기계에서 1회/10회 버튼으로 진행한다. 알 확률 팝업에서 일반 85%·레어 12%·슈퍼레어 3%의 분류 추첨과 별도 이로치 판정 0.24%를 확인한다. 티켓을 먼저 사용하고 부족한 횟수는 성장 포인트를 차감한다. 받은 알을 터치해 개별 부화하거나 한 번에 열기로 남은 알을 공개한다. 무지개 알은 준전설·패러독스·울트라비스트, 슈퍼레어 알은 초전설·환상, 황금 알은 모든 등급 포켓몬의 이로치 확정이며 결과는 연출 전에 저장된다. [알 종류와 확률](EGGS.md)을 참고한다. 이로치 교환은 미해금 포켓몬을 도감 번호순으로 표시하며 이름·타입·세대를 확인하고 검색할 수 있다. 포켓몬을 선택하면 일반/이로치 모습을 나란히 미리 보여준다. 선택만으로 교환권을 소비하지 않으며 교환권 1장 사용을 눌러 적용한다.

기본은 음소거이며 설정에서 켠다. [소리와 연출](../../artifacts/reports/changes/BATTLE_AUDIO.md), [자산 출처](../references/THIRD_PARTY.md)를 참고한다.


## 지역과 히든 보스

2026-10-12 이후 새 도전은 1~50층과 51~100층에 서로 다른 지역 테마를 저장한다. 각 구간의 10·20·30·40층은 사천왕급, 50·100층은 해당 지역 챔피언이다. 관동·성도에서는 챔피언 승리 후 같은 층의 히든 보스 레드 추가전을 치른다. 영입 선택, HP·PP·상태 회복, 팀 재선택 뒤 추가전을 시작하고 레드 승리 후에만 다음 구간 또는 클리어로 진행한다. 기존 진행 저장은 종전의 테마와 관문 배치를 유지한다. 지닌 도구 상점은 판매 가능한 다른 등급으로 보충해 서로 다른 4종을 채운다. 기존에 3종으로 저장된 상점도 원래 상품을 유지하며 보충한다. 배틀 소모품 상점은 3종이다.

## 조작·이미지 보완 (2026-10-12)

배틀 키 안내는 라벨 사이 간격을 둔다. 방향키는 선택 불가능한 칸을 건너뛰며 같은 행·열에 후보가 없으면 같은 그리드의 대각선 후보로 이동한다. 정지한 마우스 아래 항목이 키보드 선택을 덮어쓰지 않도록 실제 포인터 이동만 커서에 반영한다. 일반 상대는 직업명, 네임드는 이름과 타입 관장 정보를 표시한다. 설정에서 도감으로 바로 이동할 수 있다. 뽑기의 새 기술은 배지로 표시하며 기존 이로치 이름 옆 별표를 유지한다.

2·4배속에서도 특성·도구 팝업은 최소 1.2초 표시하고 팝업 등장 애니메이션은 배속하지 않는다. 일반 기술 연출은 설정 배속을 유지하며, 새 메시지는 기본 재생 시간을 넘기지 않는 범위에서 약 0.75~1.6초를 확보한다. 전체 이미지/폼 1,095개(일반·이로치 2,190쌍)의 로컬 이미지 경로를 점검했고, 앞모습 반전으로 채워진 뒷모습 123개를 실제 뒷모습으로 대체했다. 당시 뒷모습 감사 보고서 경로는 `artifacts/qa/assets/back-sprite-audit/report.json`이며 현재 작업 폴더에는 해당 원자료가 없다. 위 수치는 당시 작업 기록이다.

## 배틀 화면 배치 (2026-10-12)

팀과 상대 트레이너 정보는 별도 상단 칸 없이 경기장 내부 상단에 표시한다. 건너뛰기 버튼은 로그 헤더에 배치해 트레이너 정보를 가리지 않으며 모바일에서도 터치로 사용할 수 있다. 이름·HP 카드는 청록·남색 계열의 얇은 프레임으로 통일하고, HP 30% 이하에서는 빨간 바와 옅은 카드 강조만 사용한다. 위험 상태 라벨은 표시하지 않는다. 움직임 줄이기 설정에서는 낮은 체력 강조를 정적으로 표시한다.

## HP 패널과 성별 (2026-10-12)

HP 패널은 플래티넘을 참고한 회색·올리브색의 각진 프레임과 긴 HP 바로 구성한다. 경기장 내부 팀 아이콘에는 나의 팀 문구를 붙이지 않고, 상대 트레이너는 VS와 직업명/네임드 이름만 표시한다. 혼합룰 A 안내는 변신 선택이다. HP 30% 이하의 붉은 강조는 유지한다.

새 도전의 보유 포켓몬은 종별 성비로 성별을 정하고 도감 성격·특성·테라스탈 탭의 성별 선택에서 무료로 바꿀 수 있다. 성별 고정 종과 무성은 변경할 수 없다. 새 상대도 종별 성비로 정하며 생성된 팀에 저장한다. HP 이름 옆의 ♂/♀는 실제 엔진의 공개 성별이며 무성은 표시하지 않는다. 기존 저장 배틀과 진행 중인 도전의 스냅샷은 보존한다. 헤롱헤롱은 엔진에서 이성에게만 적용된다.

HP 이름 옆 타입은 현재 공개된 타입을 표시한다. 변환자재·리베로 등 타입 변경은 특성 안내와 타입 변경 메시지 뒤에 반영하고 교체 시 원래 타입으로 돌아간다. 상대의 미공개 특성은 표시하지 않는다. [특성 발동과 화면 재생](../../artifacts/reports/changes/ABILITY_EFFECT_TIMING.md).


상자·브리더·여행 상인 이벤트는 필드에 그림을 보여주고 메시지창 바로 위 왼쪽 작은 안내창에 요약을 표시한다. 선택을 마치면 요약창이 사라지며 이벤트 중 포켓몬 발판은 숨긴다. 하단 전체 폭에서 메시지를 읽고 `선택지 보기`로 전환한 뒤 이벤트에 따라 열기·선물 받기·구매 또는 지나가기를 고르고, 보상을 받은 뒤 `계속하기`로 정비·출전 준비에 돌아간다. 배틀 배속에 따라 자동으로 넘어가지 않으며, 새로고침해도 선택·보상이 보존된다.
