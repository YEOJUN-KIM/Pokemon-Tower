# 특성 발동과 화면 재생

2026-10-12 점검. 실제 효과와 발동 조건은 설치된 Showdown 엔진이 결정하며, 화면은 공개 이벤트만 재생한다.

- 변환자재·리베로: 특성 안내 → 타입 변경 안내·이름 옆 타입 갱신 → 기술 연출. 엔진이 기술 선언 뒤 타입 변경을 기록하므로 화면에서 인접한 두 이벤트의 재생 순서만 바꾼다. 저장 로그와 전투 판정은 그대로 유지한다.
- HP·랭크·상태·타입·날씨·필드 변화: 특성 안내 프레임에서는 변경 전 상태를 유지하고, 다음 프레임에서 효과와 메시지를 적용한다. 위협처럼 별도 특성 이벤트가 먼저 있는 경우 중복 안내하지 않는다.
- 저수·축전: 무효/흡수 안내 후 회복. 까칠한피부 등 접촉 반응은 공격 후 특성 안내와 반응 효과를 순서대로 재생한다.
- 재생력: 엔진에서 교체 시 최대 HP의 1/3을 회복한다. 소유자의 비공개 요청에서 벤치 HP를 갱신한다. 공개 발동 이벤트가 없으므로 숨은 상대 특성을 임의로 표시하지 않는다. 위력·속도 보정처럼 공개 발동 이벤트가 없는 상시 특성도 임의의 팝업을 추가하지 않는다.
- 특성 재생 수정 당시 개발 서비스 버전을 33으로 갱신했으며 현재 Z기술 구현 버전은 34다. 버전 변경 시 수정 전 배틀 객체를 재사용하지 않는다. 저장된 행동으로 복원해 타입 변경을 재구성하며, 교체 전까지 다음 턴·새로고침에도 유지한다.

검증은 `tests/ability-timing.test.ts`, `tests/effects.test.ts`, `tests/presentation.test.ts`, 타입·상성 회귀 테스트와 `e2e/ability-timing.spec.ts`에 있다. 실제 엔진으로 변환자재·리베로·위협·잔비·가뭄·가속·까칠한피부·저수·변색·재생력을 확인했고, 공개 이벤트 재생으로 깨어진갑옷·정전기·포이즌힐·그래스메이커의 선후 관계도 확인했다. 모든 특성 조합을 전수 플레이한 결과는 아니다.
