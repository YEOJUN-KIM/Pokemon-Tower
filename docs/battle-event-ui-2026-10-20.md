# 배틀 · 이벤트 · 출전 준비 UI 정리 (2026-10-20)

## 적용 방식

- 일반 이벤트는 기존 배틀의 near/far ground 좌표와 플레이어 뒷모습 스프라이트를 재사용한다. 플레이어는 좌측 하단, 상자·NPC·도전자는 우측 상단에 배치하고 설명은 좌측 상단에 둔다. 이벤트 중 보유 포켓몬 HUD는 숨겨 설명과 겹치지 않게 했다.
- 상자와 NPC는 기존 이벤트 렌더러를 유지한다. 도전자의 초상화만 설명 패널에서 분리해 적 위치 레이어에 배치했다. 선택한 도전자를 바꾸면 해당 초상화가 함께 바뀌며 미러 초상화도 유지한다.
- 레이드와 숨겨진 상점은 기존 전용 장면을 유지한다. 이벤트 확률·선택지·보상·배틀 AI·밸런스·저장 계약은 변경하지 않았다.
- 출전 준비의 역할 문구를 제거하고 01/02/03 번호 배지를 확대했다. 선택 상태는 금색 번호 배지로, 현재 게임 커서는 민트색 카드 테두리와 배경으로 표시한다. 카드를 제외하면 남은 번호를 기존 선택 순서에 맞춰 다시 부여한다.
- 이름 아래 타입은 공통 TypeBadge를 사용한다. 카탈로그의 한국어 타입을 기존 타입 키에 맞춰 전달하며 현재 폼의 타입을 표시한다.
- 배낭 진입 버튼은 최소 120×48px로 확대했다. 배틀 명령의 도구 버튼은 다른 명령과 동일한 칸을 사용한다. 배낭 목록 하단의 닫기와 내부 조작 footer를 제거하고 공통 화면 footer에 현재 단계의 키를 표시한다. 상단 X 및 Esc/X의 기존 뒤로가기·닫기를 유지한다.
- Pocket 변경과 대상 선택 취소 직후 커서를 즉시 목록으로 복원해 빠른 결정키가 이전 탭을 다시 누르지 않게 했다.
- 배틀 시작의 별도 포켓몬 내보내기 버튼을 제거했다. Z/Enter 또는 실제 메시지 영역 클릭이 기존 introContinue 확인 경로를 실행한다. 확인 참조는 한 번 실행할 때 비워 중복 진행을 방지한다. 텍스트가 선택된 클릭은 진행시키지 않으며 제목·기록 영역은 확인 영역에 포함하지 않는다. 모달이 열려 있으면 시작 키를 가로채지 않는다.
- 네 번째 배틀 명령은 도망친다!를 표시한다. native disabled와 tabindex=-1을 사용하고 회색으로 표시한다. 기존 공통 커서의 disabled 필터를 그대로 이용하며 실행 핸들러나 도망 로직을 추가하지 않았다.
- 이벤트·출전 준비·배낭은 기존 GameMenuProvider/공통 footer를 유지한다. 도전자 선택에는 실제로 가능한 X 돌아가기 안내를 추가했다.

## 후속 수정: 출전 준비 6칸과 영입 메시지

사용자 후속 요청에 따라 출전 준비를 6칸 한 줄로 고정했다. 3~5마리를 보유하면 빈 슬롯을 남기며, 보유 수가 달라져도 팝업의 폭·높이를 유지한다. 작은 화면은 카드 영역만 가로 스크롤한다. 팝업의 상단과 최대 높이는 현재 배틀 장면의 실제 영역에 맞추므로 아래 배틀 상황 메시지창을 가리지 않는다. 출전 준비의 backdrop은 투명하게 해 기존 메시지를 어둡게 덮지 않는다. 배낭은 배틀 시작 왼쪽을 유지한다.

영입 결과는 공통 키 안내 footer에서 제거하고 기존 BattleMessages에 표시한다. 이벤트로 이어지면 기존 이벤트 메시지에 함께 표시하며 최종 클리어에서는 클리어 화면의 대화 요소를 사용한다. GameMenuBar의 메시지 전용 높이와 렌더링은 제거했다.

수정 파일: battle-stage.tsx, tower-controls.tsx, battle-messages.tsx, battle-game.tsx, run-event.tsx, tower-clear.tsx, game-menu-context.tsx 및 post-battle/party-preparation/game-menu-context 스타일. recruitment.spec.ts에 3·4·5·6마리 크기 유지, 한 줄 배치, 메시지창 겹침·backdrop·버튼 영역 검증을 추가했다. battle-ui-polish.spec.ts는 공통 hover의 색 전환 완료를 기다리도록 보완했다.

프로덕션 빌드·타입 검사·CSS 구조 검사·공백 검사를 통과했다. 출전/배틀 명령·영입 16개 시나리오와 최종 배치·일반 이벤트·정비 배낭 회귀 검사를 수행했다.


## 후속 수정: 안내 위치·팝업 확대·순차 메시지

출전 준비 팝업의 최대 크기를 1440×420px로 확대하고, 중복되던 층별 출전 안내를 팝업에서 제거했다. 카드 영역은 남은 높이를 사용하며 이미지도 88px로 키웠다. 선택 수는 버튼 행 왼쪽에 표시한다. 실제 높이는 배틀 장면 안으로 제한하며 6칸 한 줄과 보유 수에 따른 크기 고정은 유지한다.

층별 출전 안내는 기존 배틀 상황창에 표시한다. 출전 준비 중에는 다음 층 준비 버튼을 렌더링하지 않고 메시지창이 하단 행 전체 너비를 사용한다. 실제 배틀의 명령 4칸은 유지한다.

영입/도감 등록 결과와 다음 안내가 동시에 나오지 않도록 결과 메시지를 먼저 단독 표시한다. Z/Enter 또는 메시지 영역 클릭으로 확인하면 결과를 지우고 출전 준비·이벤트·레이드 보상·최종 클리어를 표시한다. 결과를 확인하기 전에는 다음 이벤트 컴포넌트를 마운트하지 않으므로 자동 이벤트도 먼저 시작되지 않는다. 확인은 화면 표시만 진행하며 저장·영입 요청을 다시 보내지 않는다. 기존 서버 저장 시점·보상·확률은 유지한다.

데스크톱/모바일의 출전·배틀 시작·영입·상인 이벤트 순서 테스트 18개를 통과했다. 상인 이벤트가 서버에 이미 저장된 상황에서도 결과 확인 전에는 상인/이벤트 안내가 나타나지 않고, 확인 후에는 등록 메시지가 남지 않는 것을 검증했다. 프로덕션 빌드·타입·CSS 구조·공백 검사도 통과했다.
