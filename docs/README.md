# 무엇을 읽으면 될까요?

다른 컴퓨터에서 이어갈 때는 **[컴퓨터 이전 안내](current/COMPUTER_MOVE.md)**와 [작업 인계](SESSION_HANDOFF.md)를 먼저 읽으세요. 최신 저장 백업·Docker 복원·로컬 실행·다음 GPT에게 보낼 요청이 있습니다.

| 알고 싶은 것 | 읽을 문서 | 내용 |
|---|---|---|
| 지금 게임이 어디까지 만들어졌어? | [현재 게임 상태](STATUS.md) | 100층·룰·상점·상대 AI 등 실제 구현 |
| 다음에 무엇을 만들면 돼? | [다음 작업](current/ROADMAP.md) | 현재 우선순위와 보류한 기능 |

작업을 이어받는 개발자는 [작업 인계](SESSION_HANDOFF.md)까지 읽으면 됩니다.

2026-10-13 최신 기능 안내: [플레이 피드백 반영](gameplay/PLAYTEST_2026_10_13.md), [선택 폼·거다이맥스·매 층 도구 관리](gameplay/FORM_EQUIPMENT_FIXES.md), [패배 후 다시하기](gameplay/BATTLE_RETRY.md). 새 일반 모드 상대 AI v10·저장 스키마 v28을 기준으로 읽으세요. 기존 배틀은 당시 AI와 팀 기록을 유지합니다.
