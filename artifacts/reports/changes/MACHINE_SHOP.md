# 기술머신 등급과 상점

기준일: 2026-10-10. 47종의 개별 등급과 층별 확률을 적용했다. 가격은 언커먼 100·레어 200·유니크 400·에픽 650·레전더리 1,000코인이며 등급·확률·가격은 난이도 측정 후 조정할 임시 값이다.

파티가 합법적으로 배울 수 있는 미수집 기술 중 중복 없이 최대 4개를 판매한다. 등급을 먼저 추첨하고 해당 등급의 기술을 뽑는다. 후보가 없는 등급은 제외하고 남은 가중치를 다시 나눈다. 모든 후보가 비면 빈 상점으로 안내한다.

5층부터 모든 등급을 추첨할 수 있지만 현재 파티에 학습 가능한 후보가 있어야 한다. 레전더리 기술머신은 나비춤·껍질깨기처럼 큰 강화 효과를 가진 기술이다. 특수 기믹 상품의 레전더리 등급과 별개다. 메가·다이맥스는 구현했고 테라는 기획이다.

화면에는 기술 이름과 구매 창 제목에 등급 색만 적용하고 등급 배지는 붙이지 않는다. 타입 표시는 기존 타입 색과 아이콘을 사용한다.

## 저장과 기존 도전

상품·등급·학습 대상·가격을 최초 조회 때 저장하며 재접속과 재시작으로 다시 추첨되지 않는다. 이미 저장된 구버전 상품 목록은 다시 뽑지 않고 기존 가격·대상을 유지한다. 구버전 상품에 등급 정보가 없으면 현재 기술별 등급으로 이름 색만 표시한다. 구매는 서버에서 상품·학습 대상·보유 코인을 검증하며 영구 수집과 이번 도전 장착을 지원한다.
