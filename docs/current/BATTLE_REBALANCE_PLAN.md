# 100층 플레이 피드백과 배틀 개선 기준

갱신: 2026-10-12. 사용자와 논의한 구현 상태·설계 방향·구상을 구분한다. Z기술 기반과 선택 화면 강조는 완료했고, 다음은 이 문서를 기준으로 NPC 데이터를 정비한다. 초기 설계 정리 이후 Z기술을 구현했으며 NPC별 고정 대표 기믹·팀 프리셋은 후속 작업이다.

## 구현 완료: 초반 다양성과 빌런 캠페인

### 포켓몬 후보군 확대

사용자는 미진화 제한을 풀기보다 전체 종족값 상한을 높이는 방향을 선택했다. 현재 `hundred-floor-v1` 도전의 이후 생성 배틀에 적용한다. 이미 저장된 팀을 다시 생성하지 않으며 legacy 도전의 기존 곡선은 유지한다.

후보 수는 각 층의 공용 후보군이다. 타입 전문 트레이너는 이 중 자기 타입만 사용하므로 실제 팀 후보 수와 다르다. 51~60층 완화 구간은 유지한다. IV·능력 포인트·성격·전설/환상 해금 층·미진화 예외는 이번 변경에 포함하지 않았다.

### 빌런 등장과 승리 누적

- 등장 가능한 일반 층에서 기본 이벤트 추첨 **15%**. 논의 중 제안된 20%는 사용자 요청으로 15%로 변경했다.
- 5의 배수 네임드 층과 직전 배틀이 빌런인 경우는 제외한다. 실제 전체 층 대비 등장 비율은 15%보다 낮다.
- 새 도전 시작에 지원하는 10개 조직 중 하나를 지역 테마와 독립적으로 선정한다. 1~100층 같은 조직을 유지하고 50→51층에서 교체·캠페인 초기화를 하지 않는다.
- 조직원 승리는 조직원 비중을 간부·보스 쪽으로, 간부 승리는 간부 비중을 보스 쪽으로 옮긴다. 다른 일반 트레이너를 이긴 횟수는 이 계산에 포함하지 않는다.
- 승리 기록은 실제 보상 영수증과 저장된 빌런 이벤트를 연결해 계산한다. 패배·단순 등장·중복 완료는 추가 승리로 세지 않으며 재시작 후에도 유지된다.
- 출전 가능한 3마리와 에이스가 있는 직급만 추첨 후보로 삼고, 그 직급들의 비중을 정규화한다. 선택 불가능한 간부·보스 때문에 이벤트 전체를 버리지 않는다. 모든 직급이 불가능하면 이벤트는 생기지 않는다.
- 보스에게 승리하면 캠페인이 종료된다. 빌런 보스의 등장 층 고정이나 100층 이내 강제 등장은 없다. 관장·사천왕·챔피언의 정해진 배치와는 별개다.

직급 비율은 이벤트가 발생했을 때의 조건부 비율이다. 아래는 출전 가능 여부로 정규화하기 전 수치다.

| 구간 | 기본 조직원/간부/보스 | 승리 반영 |
|---|---|---|
| 1~15층 | 100 / 0 / 0% | 간부·보스는 아직 해금되지 않음 |
| 16~30층 | 65 / 35 / 0% | 조직원 승리당 조직원 −10%p, 간부로 이전; 조직원 최소 5% |
| 31~100층 | 35 / 40 / 25% | 조직원 승리당 최대 −8%p를 간부·보스에 나누어 이전; 간부 승리당 최대 −12%p를 보스로 이전 |

31층 이후 조직원·간부의 최저 비중은 각각 5%다. 승리 누적은 해금 이후 구간에도 이어진다. 이전 저장의 조직은 다시 추첨하지 않고, 캠페인 없는 과거 도전에 새 캠페인을 소급 부여하지 않는다.

검증: 관련 단위·통합 32개, 타입 검사 통과. 100층 진행, 지역 전환·히든 보스, 빌런 종료/보상/복구/중복 완료, 파티 합법성을 검사했다. 실제 플레이 난이도나 인간 승률을 측정한 결과는 아니다.

## 합의한 설계 방향: NPC의 개성과 후반 난이도

아래는 아직 구현되지 않았다. 현재 게임은 양쪽에 같은 도전 룰을 적용한다.

| 상대 구분 | 목표 방향 |
|---|---|
| 일반 트레이너 | 기믹·전설·환상 없이 강한 일반 포켓몬과 개선된 세팅으로 성장 |
| 엘리트 | 플레이어가 선택한 기믹에 맞는 팀; 후반 비율과 완성도 조정 |
| 네임드 | NPC별 대표 기믹과 핵심 전술 고정, 층수별로 준비된 팀 사용 |
| 빌런 간부·보스 | 컨셉에 맞는 대표 기믹과 준비된 팀; 랜덤으로 등장한 층수에 맞는 구성 사용 |
| 오리지널 NPC | 엘리트보다 상위인 고유 컨셉의 강적. 구상 단계이며 실제 인물·팀·등장 조건 미정 |

플레이어가 메가진화를 선택해도 다이맥스가 특기인 NPC를 만날 수 있게 하는 방향이다. 적용 시 선택 화면은 시합 전체의 제한보다 **플레이어가 사용할 기믹**임을 명확히 설명하고, 상대 기믹을 배틀 전에 알려준다. 기본 모드의 예외 범위와 혼합 모드의 기믹 사용권은 구현 전에 정리해야 한다.

난천의 메가한카리아스는 대표 기믹 설명용 예시다. 모든 NPC의 최종 배정표를 확정한 것은 아니다. 고정 기믹을 위한 후보 추가가 필요하면 원작 사용 포켓몬과 타입·컨셉을 우선한다. 기믹을 쓸 수 없는 인물의 대체 전술도 별도로 설계한다.

### 준비된 팀과 상황 판단

- 대표 기믹 담당·핵심 동료·전술을 정하고, 층수 구간별 기술·도구·특성·육성 프리셋을 만든다. 전부 무작위로 구성하지 않는다.
- 팀이 고정되어도 선봉·교체·기믹 사용 시점은 상황을 보고 결정한다. 매번 동일한 행동 순서로 싸우게 만들지는 않는다.
- 후반에는 높은 개체값이 나올 확률뿐 아니라 최소 품질을 보장하는 방향을 검토한다. 보스와 일반을 같은 층수 육성만으로 처리하는 현 구조를 개선한다.
- 성격과 능력 포인트는 실제 기술·역할에 맞춘다. 종족값의 공격/특수공격 대소만으로 결정하지 않는다.
- 동 구간의 평균 위협 수준은 일반 < 엘리트 < 관장·사천왕 < 챔피언을 목표로 한다. 상성에 따른 개별 역전은 허용한다.
- 일반의 전설·환상 금지는 아직 미적용이다. 현재 공용 풀은 75층 전설·90층 환상을 허용한다. 엘리트·간부에 허용할 전설 등급과 수량은 미정이다.

현재 확인한 문제: 레드에게 지정된 피카츄 다이맥스 도구가 메진 룰에서 제거되어 대체 기믹 없이 싸운다. 대부분 네임드에도 룰에 맞는 기믹 담당이 보장되지 않는다. 망나뇽은 특수 기술 구성에서도 물리 투자와 고집 성격을 받을 수 있다. 실제 엔진의 메가·다이맥스 변신 순서는 기술 실행 전이다.

### 구상으로 보관할 오리지널 NPC

라이벌 관계·고정 재대결 일정부터 정하지 않고, 고유 파트너·기믹·전술을 가진 NPC 한 명부터 검토한다. 초반에는 미완성 팀, 후반에는 같은 컨셉이 완성된 팀을 사용할 수 있다. 플레이어와 다른 기믹을 쓰는 것도 허용하는 방향이다.

메가레쿠쟈 라이벌은 대화 중 예시이며 채택하지 않았다. 인물 이름·외형·파트너·최종 에이스·등장 빈도·보상은 미정이다. Z기술과 기존 NPC 정비보다 먼저 구현하지 않는다.

## 영양제 개선 방향과 미정 수치

현재는 모든 정비 상점에서 4종을 판매하고 하나당 +5 능력 포인트를 별도로 누적한다. 포켓몬당 투여 횟수 제한이나 반복 투여 가격 할증은 없다.

사용자 제안: 히든 상점 또는 추후 이벤트에서 등장, 4종→2종, 기본 가격 인상, 이미 투여한 포켓몬의 추가 구매 비용 인상, 포켓몬당 최대 약 3개 제한.

정리한 제안은 **한 도전에서 한 포켓몬에 모든 종류 합쳐 최대 3개**이며 능력치별 3개가 아니다. 정확한 제한 수는 최종 조정 전이다. 히든 상점 확률·기본 가격·할증 배율은 미정이다. 대화에서 제시한 기본가 약 1.5배, 두 번째 1.5배/세 번째 2배는 검토 예시로만 보관한다.

구매 화면에는 대상 포켓몬의 투여 횟수·최종 가격·남은 횟수를 선택 전에 보여줘야 한다. 한 마리 몰아주기를 줄이되 코인 수급과 파티 성장 보상까지 함께 검증한다. 이벤트 시스템은 아직 구현 범위가 아니다.

## Z기술 기반 구현 완료

2026-10-12 기반 구현 완료. [Z기술 사용·범위·검증](../gameplay/Z_MOVES.md). 아래 체크 범위는 구현 기준으로 보존하며 다음 작업은 NPC별 고정 기믹/팀 프리셋이다.

우선순위는 **기획 기준 정리 → Z기술 → NPC별 기믹/층수 프리셋 → 육성·AI·상대 등급 조정 → 영양제 경제 검증**이다. 오리지널 NPC와 150/200층 확장은 후속 구상으로 둔다.

Z기술 구현에서 필요한 범위:

1. 엔진이 제공하는 Z기술과 Z크리스탈 지원 확인. 타입별·전용 Z기술, 공격·변화 기술의 지원 범위를 명시한다.
2. 룰/권한·팀당 사용 횟수·다른 기믹과의 관계 정리. NPC별 별도 기믹 권한 도입은 후속 데이터 정비와 구분한다.
3. 크리스탈 도구·장착 조건·상점, 기술별 합법 행동과 표시 위력/분류, 기술 확정 시 발동하는 UI·키보드·터치 연결.
4. 실제 발동·효과·사용권 소모·사용 불가 조건·공개 메시지와 연출, 상대 AI 연결.
5. 저장된 룰·도구·행동 로그 재생 및 기존 메가/다이맥스/테라/기본 저장 호환 검증.
6. 기반 검증 후 알로라 NPC들의 대표 Z기술·에이스·지원 동료·층수별 세팅을 설계한다. 썬·문 NPC 데이터가 준비된 것으로 간주하지 않는다.

검증은 각 플레이어 기믹별, 층수별, 다양한 팀 상성별로 수행한다. 고정된 NPC 세팅의 변경 전후 비교와 새 코스 검증을 함께 사용한다. 자동 승률과 인간 플레이 체감은 구분하며 비공개 플레이어 정보를 읽는 맞춤 카운터 팀 생성은 하지 않는다.
