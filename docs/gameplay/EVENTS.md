# 이벤트와 보상 기획

기준: 2026-10-16. 현재 구현된 임시 이벤트와 확정된 콘텐츠 방향을 구분합니다. **기획의 방향 확정은 구현 완료가 아닙니다.** 세부 설계·삭제·흡수·보류 상태는 [이벤트 콘텐츠 설계](EVENT_CANDIDATES.md), 알의 현재 규칙과 확장 방향은 [알 종류와 부화](EGGS.md)에서 관리합니다.

## 현재 구현: 임시 비전투 이벤트 3종

전체 이벤트 등장률은 대상 층마다 **10%**이며, 등장한 경우 상자 50% / 브리더 30% / 여행 상인 20%로 종류를 정합니다. 종류별로 따로 10%를 추첨하지 않습니다. 아래는 현재 구현값이며, 향후 콘텐츠의 확정 확률·가격·보상량이 아닙니다. 이번 기획 문서 정리로 변경하지 않습니다.

| 이벤트 | 선택과 보상 |
|---|---|
| 길에서 발견한 상자 | 열기 / 지나가기. 열면 80%로 150코인, 20%로 알 뽑기권 1장 |
| 브리더의 응원 | 선물 받기 / 지나가기. 받으면 알 뽑기권 1장 |
| 여행 상인의 제안 | 300코인으로 구매 / 지나가기. 구매하면 알 뽑기권 1장. 코인이 부족하면 지급·차감 없이 다시 선택 가능 |

중앙 배틀 필드에는 상자 또는 기존 트레이너 스프라이트를 표시합니다. 브리더는 아로마 아가씨, 상인은 등산가 스프라이트를 임시 사용합니다. 결제·보상·처리 상태는 같은 트랜잭션에 저장하고, 구매 요청을 재전송해도 다시 차감하거나 지급하지 않습니다. 저장 구조와 확장 방법은 [이벤트 개발 문서](../engineering/EVENT_SYSTEM.md)를 따릅니다.

### 현재 공통 진행

- 새 도전에서 일반층 승리·영입 선택을 마친 뒤 공통 등장률로 만남을 추첨합니다. 5의 배수 관문과 마지막 클리어·히든 보스 대기에는 추가하지 않습니다.
- 한 번 이벤트를 만난 뒤 다음 두 층에서는 모든 종류의 이벤트가 다시 등장하지 않습니다. 열지 않고 지나가도 같은 제한이 적용됩니다.
- 상단 배틀 필드에는 상자 그림과 열림 이펙트를 표시하고, 왼쪽 아래 메시지창 바로 위에는 그림 없이 제목과 짧은 요약만 담은 작은 이벤트 안내창을 띄웁니다. 선택을 마치면 요약창을 없애고, 이벤트 중에는 포켓몬 발판을 숨깁니다. 자세한 설명은 하단 메시지창에서 보여줍니다. 보상 단계에는 상자 아래 획득한 수량을 표시합니다. 하단은 좌우로 나누지 않고 전체 폭을 사용합니다. 메시지 → `선택지 보기` → 전체 폭의 `상자를 연다 / 지나간다` 목록 → 보상 확인 → 기존 정비·출전 준비 순서입니다. 선택지를 고르는 동안에는 요약창이 유지됩니다. 층·배틀 승리 횟수·보스 배치를 소모하거나 변경하지 않습니다.
- 선택지는 메시지와 동시에 표시하지 않는 테두리 없는 세로 목록이며, 긴 문장은 줄바꿈합니다. 위·아래 키로 이동하며 선택 항목은 왼쪽 `>` 표시와 살짝 앞으로 나오는 글자로 강조합니다.
- [배틀 대화창](BATTLE.md)의 `GameDialogue`를 사용하되 사용자가 선택·확인을 눌러야 진행합니다. 배틀 배속으로 이벤트 문장을 자동으로 넘기지 않습니다.
- 선택과 보상을 서버에 저장합니다. 새로고침하면 같은 상자·결과로 돌아오며, 열기 요청이 중복되거나 응답을 잃어 재시도해도 한 번만 지급합니다. 확인 전 다음 배틀 진입은 서버에서도 막습니다.
- 코인은 현재 도전의 지갑과 클리어 누적 보상에 포함합니다. 알 뽑기권은 영구 보관하며 도전 종료 후에도 유지되고, 기존 알 뽑기에서 먼저 사용됩니다.
- 기존 진행 중인 도전에는 이벤트를 소급 추가하지 않습니다. 새 게임 API가 시작하는 도전에 이벤트 규칙 v1을 저장합니다.

[실제 이벤트 화면 GIF](../../artifacts/qa/previews/events/chest-event.gif) — 상자 발견 → 열기 → 하단 보상 메시지. 별도 테스트 계정의 실제 화면을 녹화했습니다. `e2e/run-event-preview.spec.ts`와 `scripts/render-run-event-preview.py`로 다시 만들 수 있습니다.

## 확정된 큰 방향: 후속 구현

| 이벤트 | 방향 |
|---|---|
| 도전자 선택전 | 컨셉 풀에서 약 3명 무작위 후보, 위험도·성향·예상 보상 안내, 마지막은 돌아간다. 승리 후 영입 없이 공통 Reward UI 사용 |
| 특수개체 레이드 | 플레이어 3마리 대 특수개체 1마리. 이벤트 보스 자체는 소유 불가, 지급한다면 정상 개체·도감·알·티켓·해금 등 별도 보상 |
| 빌런 캠페인 이벤트 | 등반당 한 조직, 사건 개입·기습·정보·거점·보스의 별도 연계 서브 스토리. 활성 목적지는 최대 1개 |
| 히든 상인 | 룰 기믹 조기 획득·희귀 상품 판매. 정상 획득 경로 유지. 런 강화 상품은 타워 코인, 알·영구 수집 상품은 영구재화 |
| 영양제 상인 | 고정 영양제 상점을 제거·축소하고 랜덤 이벤트 판매로 이동. 장기간 미등장 보정은 검토 |
| 미러 매치 계열 | 같은 종·폼에 다른 세팅을 쓰는 일반 미러, 보유 6마리 중 무작위 3마리의 왜곡 미러, 희귀·고난도 챔피언 미러 |
| 미스터리 상자 | 현재 상자를 꽝·손해·좋은 보상·매우 좋은 보상이 가능한 위험·보상 이벤트로 발전 |

- 도전자 선택전은 상·중·하 후보를 한 명씩 보장하지 않습니다. 후보 전원이 강하거나 약할 수도 있고, 정확한 후보 수·보상은 추후 결정합니다.
- 공통 Reward UI는 도구·영양제 선택, 재화·특별 보상 획득을 처리하고 레이드·빌런·기타 이벤트에서 재사용하는 방향입니다. 현재 보상 확인 화면과 다른 미구현 기획입니다.
- 기존 빌런 층 교체 방식은 줄이거나 제거하는 방향입니다. 현재 구현은 [타워 진행](PROGRESSION.md)을 따르며, 새 캠페인의 기습전은 일반전 뒤 추가 전투입니다.
- 레이드 특수개체의 소유 금지, 도전자 선택전의 영입 없음은 확정 방향입니다. 다른 이벤트의 포켓몬 보상까지 일괄 금지하는 뜻은 아닙니다.
- 챔피언 미러의 기믹 예외는 해당 이벤트에만 적용하는 방향이며, 일반 배틀 규칙을 바꾼 것은 아닙니다.
- 현재 브리더의 응원·여행 상인은 임시 구현으로 남습니다. 독립 후보인 브리더의 알 선택을 히든 상인에 흡수한 결정과 혼동하지 않습니다.
- 히든 상인의 알 상품은 영구재화 사용 방향입니다. 현재 여행 상인의 300코인 거래를 이번 작업에서 변경하지 않았고, 전환 여부는 추후 결정합니다.

상세 설계와 예시는 [이벤트 콘텐츠 설계](EVENT_CANDIDATES.md)에만 모읍니다. 확률·가격·보상량·등장 층의 구체적인 값은 별도 확정 전까지 TODO이며, 미스터리 상자의 50/30/20 같은 구상 수치는 구현값이 아닙니다.

## 보상 후보와 적용 범위

| 보상 | 용도·방향 | 이후 정할 내용 |
|---|---|---|
| 돈 | 상점 구매 등에 사용하는 금전 보상 | 지급량과 기존 경제 밸런스 |
| 희귀한 포켓몬 | 레이드 등의 정상 개체·도감 해금 보상 후보 | 이벤트 특수개체 자체는 소유 불가. 도전자 선택전은 영입 없음. 대상·지급 방식은 추후 결정 |
| 영양제 | 포켓몬 능력치 강화 | 종류·수량·강화 한도와 희소성 |
| 영구재화 | 다음 도전에도 이어지는 성장·해금용 재화 | 명칭·사용처·지급량 |
| 이로치 교환권 | 이로치 획득 또는 교환에 사용하는 보상 | 대상 선택 방식과 교환 조건 |
| 알 뽑기권 | 현재 공통 티켓, 추후 희귀·초희귀 등급별 뽑기·티켓 확장 | 확률·풀·티켓 조건은 [알 문서](EGGS.md)에서 관리. 히든 상인의 알 상품은 영구재화 사용 |
| 도구 교환권 | 희귀한 지닌 도구 등을 선택해 획득 | 교환 가능한 도구와 등급 |
| 기술머신·기술 교환권 | 포켓몬에게 필요한 기술을 배우게 하는 보상 | 기술 목록·습득 조건·기존 기술머신 상점과의 관계 |
| 성격 변경권 | 포켓몬의 성격 조정 | 도전 중 또는 시작 전 사용 여부 |
| 특성 변경권 | 포켓몬의 특성 조정 | 일반 특성·숨겨진 특성 구분과 희소성·사용 시점 |
| 개체치 강화권 | 특정 능력치의 개체치 강화 | 강화 수치·최대치·사용 시점 |
| 기믹 관련 보상 | 메가스톤·Z크리스탈·테라타입 변경권 등 후보, 히든 상인의 룰 기믹 조기 획득 | 정상 획득 경로 유지. 룰별 대상·시점·가격은 추후 결정 |
| 포켓몬 선택 영입권 | 포켓몬 획득이 허용되는 이벤트의 보상 후보 | 도전자 선택전에는 적용하지 않음. 후보 목록·등급·사용 조건은 추후 결정 |
| 상점 갱신권 | 상점 상품을 다시 갱신 | 대상 상점·사용 횟수·기존 갱신 기능과의 관계 |
| 상점 할인권 | 상점 상품을 할인된 가격에 구매 | 할인율·적용 범위·유효 기간 |

## 제외한 보상

- **회복권·부활권:** 매 배틀 전에 회복해주는 현재 흐름에서는 필요하지 않아 후보에서 제외합니다.

## 보류한 보상

- **폼 변경·진화 재료:** 도감에서 포켓몬을 해금하면 폼체인지를 자유롭게 할 수 있으므로 보류합니다. 도입 여부와 기존 해금 방식과의 관계는 추후 검토합니다.

## 외형 보상: 후속 구상

- 현재 하나인 플레이어 스프라이트의 선택지를 늘리는 방향을 검토합니다.
- 추가 트레이너 외형을 이벤트 보상으로 해금하는 방식은 구상 단계입니다.
- 외형 종류, 리소스 확보 방식, 선택 화면, 해금 조건은 아직 정하지 않았습니다.
- 칭호·프로필 테두리·배틀 배경 등 다른 외형 보상의 범위도 추후 검토합니다.

## 추후 결정할 규칙

- 새 이벤트별 등장 확률·간격·층·배치 순서와 임시 이벤트의 전환 범위.
- 보상별 수량·등급·확률·선택 개수와 공통 Reward UI의 정산·저장·복구.
- 전투 이벤트의 패배·포기·다시하기, 빌런 기습의 출전 멤버 고정·HP/PP 회복 여부.
- 히든 상인의 가격·상품·룰별 조기 획득 시점과 영양제 상인의 고정 판매 축소 범위·미등장 보정.
- 등급별 알 뽑기의 확률·풀·가격·티켓 조건은 알 문서에서 관리.
- 보상별 현재 도전·영구 보관 범위, 사용 시점, 중복·소모 규칙과 기존 기능의 관계.
- 영구재화의 구체적인 종류·가격·지급량. 현재 성장 포인트의 사용 여부와 새 통화 필요성은 추후 결정.
