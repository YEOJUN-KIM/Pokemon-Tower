# NPC 라인업 갱신

2026-10-13. 확장된 포켓몬 목록을 반영해 빌런 보스의 조직 테마 전설, 지역 폼, 챔피언 대표 포켓몬을 수정했다. 새 일반 모드 배틀에 적용하며 기존 저장 배틀은 그대로 복원한다. 원작의 실제 출전 팀을 재현한 표가 아니라 타워용 구성이다.

## 빌런 보스

아래는 75층 이상에서 사용하는 최종 팀이다. ★는 기믹 담당이며 전설과 기믹 담당이 다를 수 있다. 전설을 추가해도 팀은 3마리, 대표 기믹은 1개다.

| 보스 | 최종 라인업 | 대표 기믹 |
|---|---|---|
| 비주기 | 뮤츠 · 거대코뿌리 · ★캥카 | 메가캥카 |
| 마적 | ★그란돈 · 폭타 · 크로뱃 | 원시그란돈 · 주홍구슬 |
| 아강 | ★가이오가 · 샤크니아 · 크로뱃 | 원시가이오가 · 쪽빛구슬 |
| 태홍 | 디아루가 · ★포푸니라 · 크로뱃 | 악 Z기술 |
| 게치스 | 큐레무 · ★삼삼드래 · 데스니칸 | 드래곤 Z기술 |
| 플라드리 | 이벨타르 · ★갸라도스 · 화염레오 | 메가갸라도스 |
| 루자미네 | 텅비드 · ★픽시 · 밀로틱 | 페어리 Z기술 |
| 로즈 | 무한다이노 · ★대왕끼리동 · 자포코일 | 거다이맥스 |

구즈마와 모란은 갑주무사·님피아 중심 테마를 유지한다. 전설 추가 팀은 일반 네임드 ID와 조직 보스 ID에 함께 적용한다. 첫 관문 비교 샘플에서는 전설 대신 기존 일반 포켓몬을 사용하며, 실제 조직 보스 이벤트는 기존처럼 75층 이상에서만 허용한다.

## 관장·챔피언의 지역 폼과 에이스

| NPC | 적용한 대표 구성 |
|---|---|
| 키아웨 | 알로라 텅구리 · 폭거북스 · 염뉴트 |
| 쿠쿠이 | 어흥염 · 알로라 나인테일 · 워글 |
| 하우 | 누리레느 · 알로라 라이츄 · 모단단게 |
| 포플러 | 마휘핑 · 가라르 또도가스 · 토게키스 |
| 멜론 | 라프라스 · 가라르 불비달마 · 모스노우 |
| 비트 | 브리무음 · 가라르 날쌩마 · 가디안 |
| 아이리스 | 액스라이즈 · 삼삼드래 · 라프라스; 액스라이즈의 드래곤 Z기술 |

전체 NPC 164명·일반 모드 328개 템플릿과 최고 단계 참고 자료, CSV를 다시 생성했다. [전체 두 단계 비교](../npc/NORMAL_MODE_SAMPLES.md)에서 확인할 수 있다. 지역 폼에는 알로라·가라르 표기를 붙였다.

재생성은 `build-npc-review.ts` → `build-normal-npc-samples.ts` → `export-normal-npc-runtime.mjs` 순서다. 최고 단계 생성기는 기존 실게임 템플릿을 우회하고 원본 후보·프리셋에서 생성하므로, 수정 전 팀을 다시 복사하는 문제가 없다. 원시회귀의 검사·폼 정보·육성 계산은 두 구슬 모두 지원한다.

검증: 전체 생성 팀의 엔진 유효성·육성 포인트 검사, NPC 관련 회귀 검사 18개, TypeScript 검사와 프로덕션 빌드 통과. 기존 밸런스 시뮬레이션은 변경 전 라인업의 결과다. 새 전설 팀의 승률·완주율은 아직 측정하지 않았다.
