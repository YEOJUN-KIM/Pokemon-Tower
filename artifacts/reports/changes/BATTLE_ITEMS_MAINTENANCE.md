# 배틀 도구와 10층 정비 · 2026-10-10

최신 가격: 일반 상품 인하, 첫 영양제2,400·소모품300·테라권1,350, 메가스톤/다이맥스밴드5,000 유지. [가격·재측정](../../experiments/balance/SHOP_PRICE_DISCOUNT.md). 아래 이전 가격은 당시 기록이다.

100층 도전은 10층 클리어마다 상점/포켓몬 조정 메뉴를 제공한다. 영양제는 별도 육성 탭을 유지한다. 기존 짧은 저장은 이전 상점 간격을 유지한다.

배틀 소모품은 구매 후 가방에 쌓이고 배틀의 도구 메뉴에서 현재 출전 포켓몬에게 사용한다. 턴·PP를 소모하지 않으며 사용 후 기술을 선택한다. 플러스파워는 공격만 +1랭크, 나머지 능력치 도구도 해당 능력치 +1랭크다. 정상 랭크 상한과 심술꾸러기/단순 같은 엔진 규칙을 따른다. 교체 시 랭크가 초기화되고 전투가 끝나면 효과가 사라진다. 이펙트가드는 상대 능력치 하락을 막고 크리티컬커터는 급소율 +1단계이며 둘 다 교체 시 해제한다. 소모품은 반복 구매 가능하고 지닌 도구의 중복 보유 제한과 별개다.

정비의 기술배치/능력치 조정은 현재 보유 파티와 영구 도감에 함께 저장한다. 기술은 해금한 기술만 무료로 배치하며 능력치·성격·특성 비용은 기존 성장 포인트를 사용한다. 영양제 보너스는 유지한다. 개체값은 직접 수정할 수 없다. 저장 시 파티 스냅샷과 도감 revision을 확인해 오래된 요청, 다른 층/진행 중 배틀, 부족한 포인트의 변경을 거절한다.

상점 코인 가격을 기존의 2배로 조정했다. 소모품 400, 테라권 1,800, 메가스톤/다이맥스밴드 5,000코인. 기술머신 등급별 200/400/800/1,300/2,000코인, 영양제는 2,000+160×(입장 층-1)코인이다. 이전에 확정 저장된 기술머신/영양제 상품의 가격은 유지한다. 일반 상점과 기술머신은 각각 무료 1회 리롤하며 소모품/영양제는 리롤하지 않는다. 영구재화로 최대3회 확장은 후속 구상이다.

DB v22는 run_battle_items와 battles.battle_items를 추가한다. 초기 재고를 배틀에 저장하고 사용 입력과 재고 차감을 한 트랜잭션으로 기록한다. 새로고침/세션 복구는 기록된 행동을 재현해 추가 차감 없이 랭크를 복원한다. 기존 구매된 5층 지속 강화와 구형 배틀 로그는 그대로 복구한다.

검증: 전체 단위·통합 159개 통과, 추가 상한/교체/심술꾸러기/가드·급소 해제 검사 및 지닌 도구 회귀 12개 통과. 프로덕션 빌드와 타입 검사 통과. Chrome PC1280/모바일390에서 무료 리롤, 능력치 저장, 턴 소모 없는 도구 사용과 새로고침 재고 확인, Q/E 탭 이동 총6개 통과. 기존 배틀 명령·육성6개 회귀 통과.
