# 수집 목록과 미진화체 정리

2026-10-13 사용자 결정: 수집 가능한 미진화체는 **폴리곤2·스라크 두 종만** 남긴다.

- 도감·알뽑기·영입·새 도전의 출발 선택에 같은 기준을 적용한다.
- 삐삐·우츠동·골뱃·피카츄 등35종을 수집 목록에서 제외해617종에서 **582종**으로 줄였다.
- 최종 진화체, 선택 폼24개, 배틀 변신폼13개의 기본 정보는 유지한다.
- 예전 보유·육성·배틀 기록은 삭제하지 않으며, 제외된 미진화체는 수집 화면과 새 도전에서 사용하지 않는다. 내부 배틀 데이터는 기존 NPC·저장된 배틀 호환을 위해 유지한다.

## 스프라이트

파이리와 이로치 파이리 등 사용하지 않는 미진화체 이미지 **3,417개(42,756,209바이트, 약40.8MiB)**를 삭제했다. 일반·이로치·정면·후면·애니메이션 파일을 함께 정리했다. 폴리곤2·스라크와 최종 진화체·변신폼의 이미지는 남겼다.

기존 NPC에 필요한 럭키·미라몽·글라이거·피카츄·두랄루돈 이미지는 배틀 표시용으로 보존했다. 이들은 플레이어 수집 목록에 다시 표시하지 않는다. 레드의 피카츄나 가라르의 거다이맥스 두랄루돈 등 기존 NPC 기믹·샘플은 이번에 바꾸지 않았다.

정리 스크립트는 `scripts/prune-unevolved-sprites.ts`이며, 먼저 삭제 대상 보고서를 생성한 뒤 `--apply`로 지정된 이미지 폴더 안의 파일만 삭제한다. 결과 목록은 `artifacts/reports/unevolved-sprite-pruning.json`, 재수입 방지 목록은 `src/data/removed-pokemon-sprite-ids.json`이다. 로컬 스프라이트 가져오기에서도 제외 목록을 적용한다.

## 검증

미진화체 예외2종, 기존 보유 기록 보존, 새 출발 선택 차단, 도감과 모든 일반·이로치·폼 이미지 파일 존재 등11개 검사와 실제 도감 화면 검사를 통과했다. 선택 폼·배틀 폼 검사도 통과했으며 타입 검사와 프로덕션 빌드가 성공했다. 서비스 버전40, DB 스키마27이다.
