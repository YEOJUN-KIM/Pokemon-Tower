# 팀 선발·기술 정비 진단 · 2026-10-10

무효 처리만 적용한 실험 플레이어를 유지하고, 실제 영입·TM 교체·영양제 구매 전후의 전체 보유 프로필과 선택 파티를 기록했다. 같은 18팀·9코스·3룰, 486등반·10,638배틀이다. 팀·행동·전체 공개 프로토콜·경제·등반 요약이 이전 immunity-only 결과와 모두 정확히 일치했다. 마지막 패배 483개는 이미 전체 재생을 검증한 이전 기록과 동일하다. 완주도 기본 2, 테라 0, 개판 1로 같다. 게임 상대·가격·난이도를 바꾸지 않았다.

## 발견한 점

- **양쪽 벽 유지가 기술 평가에 반영되지 않는다.** 양쪽 벽을 가지고 출발한 81등반 중 41등반은 마지막 패배 시 하나만 남았다. 역할 손실 사건은 47회(TＭ 교체 41, 영입 6); 다시 얻고 잃는 사건이 있어 등반 수와 다르다. 예를 들어 오롱털은 10층 정비에서 잠자기를 구매하면서 빛의장막을 지웠다. 기술별 회복 점수는 있지만 파티 점수는 벽을 하나라도 가지면 같은 역할로 계산하므로 이런 교체를 개선으로 판단한다. 역할 손실 자체가 패배 원인이라는 인과 검증은 아직 없다.
- **트릭룸 역할은 유지됐다.** 트릭룸 보유 및 별도 느린 동료(현재 스피드 ≤105)는 해당 81등반에서 손실 사건이 없었다. 이를 억지로 고칠 근거는 발견하지 못했다.
- **껍질몬 공격 수단은 출전 시점에 모두 있었다.** 영입·기술 정비로 원래 타입의 껍질몬을 직접 공격할 기술이 사라지거나, 보유 후보에만 남기고 출전시키지 않은 사례는 0이었다. 따라서 이번 표본의 반복 무효를 선발 시 공격 범위 상실로 설명할 수 없다.
- **전투 도중의 상태는 달랐다.** 반복 무효가 발생한 마지막 패배 66개 중 65개에서 살아 있는 아군에게 정적 공격 수단이 없는 시점이 관측됐다. 다른 시점에 후보 아군에게만 공격 수단이 남아 있던 패배는 53개, 현재 아군에게 다른 공격 수단이 있던 패배는 4개였다. 시간에 따른 중복 그룹이다. 상대의 공개 타입/테라/특성과 기절을 반영한 기술 목록 검사이며, PP·봉인·도구·진입 생존·자기 테라 기술 변화까지 포함한 실제 행동 가능성 검사는 아니다. 공격 담당 기절과 상대 테라 변화 등은 별도 원인 분리가 필요하다.
- **자동 샘플이 위력만 높고 사용 부담이 큰 기술을 과대평가한다.** 반복 코스와 룰을 제외한 시작 파티 54슬롯 중 42슬롯에 파괴광선·기가임팩트·블러스트번 같은 반동 대기 기술이 있었다. 마지막 패배 483개 중 310개에서 실제 반동 대기가 총 477턴 발생했다. 생성기와 기술/파티 점수는 차지 턴에 감점하지만 `flags.recharge`에는 감점하지 않는다. 오롱털의 힘껏펀치, 잠들게 할 기술 없는 로토무의 꿈먹기, 폭발·트랩셸 등도 샘플에서 보인다. 이런 기술은 높은 위력과 별개로 사용 조건·자해·턴 손해를 평가해야 한다. 관측 빈도만으로 패배 원인이나 수정 후 승률을 확정하지 않는다.

## 다음 비교

우선 **실험용 샘플의 기술 점수**에 반동 대기·발동 조건·자해 비용을 반영하고, **벽 두 종류의 유지 가치**를 별도 후보로 비교한다. 변경 효과를 분리하려면 샘플만 수정 / 벽 유지 평가만 수정 / 둘 다 / 기존을 같은 코스로 비교해야 한다. 실제 게임 난이도 조정이나 NPC 벽 사용 확대보다 먼저 확인할 문제다. 이번 결과는 같은 코스를 재사용한 관찰 진단이며 사람 승률이나 독립 검증, 학습 모델 훈련이 아니다.

## 재실행과 자료

새 숫자 시드의 기존 auto-suite 및 coverage-factors 결과가 있어야 한다. 원본 및 기존 결과의 해시를 확인하고 파일을 덮어쓰지 않는다.

```powershell
node scripts/run-composition-diagnostics-v2.mjs <seed>
node node_modules/tsx/dist/cli.mjs scripts/audit-composition-survivors.ts <seed>
```

기록된 20261010 결과만 재감사:

```powershell
node node_modules/tsx/dist/cli.mjs scripts/audit-composition-diagnostics-v2.ts 20261010
node node_modules/tsx/dist/cli.mjs scripts/audit-composition-survivors.ts 20261010
```

- `artifacts/composition-diagnostics-20261010-manifest.json`: 원본 시뮬·정책·입력 해시.
- `artifacts/composition-diagnostics-20261010-audit-v2-manifest.json`: 수정한 감사 도구 해시. 첫 감사 스크립트의 괄호 누락으로 감사 실행이 실패해 원본을 보존하고 v2에서 수정했다. 배틀 재실행이나 기록 변경은 없었다. 이후 실행은 v2 도구를 사용한다.
- `artifacts/composition-diagnostics-20261010-{basic|tera|chaos}-trace.jsonl`: 선택·영입·기술·영양제 전후의 실제 보유 프로필. 상대의 숨겨진 정보를 정책에 제공하지 않는다.
- `artifacts/composition-diagnostics-20261010-audit.json`, `report.md`: 역할·공격 범위 검사와 구체적 전후 기술 목록.
- `artifacts/composition-diagnostics-20261010-survivors.json`: 실제 공개 무효 사건의 생존 아군별 검사, 시작 샘플 반동 대기 기술 목록 및 자료 해시.

관련 단위 테스트 40개 및 `tsc --noEmit` 통과. 새 검사 3개는 벽 한 종류 손실, 공격 수단을 후보에 남기는 선발, 영양제를 반영한 트릭룸 동료 판정을 검증한다. 화면 및 실제 게임 코드 변경은 없다.
