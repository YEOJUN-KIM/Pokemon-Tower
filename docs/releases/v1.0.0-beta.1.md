# Pokémon Tower v1.0.0-beta.1 — Normal Mode First Complete Beta

Normal Mode 100층의 1차 완성을 마친 베타 버전입니다. 음향과 기술 이펙트 보강이 남아 있어 v1.0.0-beta.1로 공개합니다.

좋아하는 세 마리의 포켓몬으로 시작해 100층의 Battle Tower를 오르며, 새로운 동료와 기술을 수집하고 파티를 성장시키는 싱글 플레이 포켓몬 팬 게임입니다.

## 주요 콘텐츠

- 전·후반 두 지역 테마로 이어지는 100층 Normal Mode
- Pokémon Showdown 기반 3대3 턴제 싱글 배틀
- 관장·사천왕·챔피언·네임드 트레이너
- 기본·Mega·Dynamax·Tera·Mixed·Z의 여섯 배틀 룰
- 일반 이벤트·20종 Raid 보스·빌런 캠페인·히든보스
- 포켓몬 영입·도감·육성·알뽑기
- 일반 상점·히든 상점·영구 성장
- PC·모바일 화면과 키보드·마우스·터치·게임패드 조작
- SQLite 기반 저장과 배틀·이벤트·NPC snapshot 기반 이어하기
- Windows용 범용 설치·로컬 실행 CMD

## 향후 업데이트

v1.0.0-beta.1 이후에는 음향·기술 이펙트를 보강하고 게임의 완성도와 콘텐츠를 확장하는 데 집중합니다.

- UI/UX와 비주얼 디자인 개선
- 새로운 이벤트·Raid·빌런 캠페인·특수 전투
- 기술 이펙트·효과음·BGM 개선
- 플레이 피드백 기반 난이도와 보상 밸런스 조정
- Normal Mode와 별도로 설계할 Hard Mode 검토

ML AI는 충분한 플레이 데이터를 확보한 뒤 장기 연구 대상으로 검토합니다. 세부 방향은 [ROADMAP](../current/ROADMAP.md)을 참고하세요.

## 실행과 안내

> 과거 실행 안내: beta.1은 소스 기준 이정표이며 당시 CMD 실행 경로는 현재 제거되었습니다. 최신 일반 사용자 실행은 [Release ZIP → PokemonTower.exe](../operations/SETUP.md), 소스 개발은 [개발자 명령어](../development/DEVELOPER_COMMANDS.md)를 따릅니다.

이 Release는 소스와 프로젝트 상태의 v1.0.0-beta.1 milestone입니다. 개인 실행 EXE·개인 실행기용 CMD·개인 환경변수·저장 DB는 배포하지 않습니다.

이 프로젝트는 개인적으로 즐기기 위한 비공식 팬 프로젝트이며 수익화·공개 서비스 운영을 목적으로 하지 않습니다. 공식 Pokémon 서비스와 관련이 없으며 Pokémon 관련 권리는 해당 권리자에게 있습니다. 배틀 계산은 Pokémon Showdown을 바탕으로 합니다. 이미지·음원·글꼴 등 외부 자료의 출처와 라이선스는 [출처 안내](../references/THIRD_PARTY.md)를 참고하세요.
