# 상대 트레이너

관장·사천왕·챔피언·네임드·빌런은 대표 기믹과 대부분의 단계별 팀을 유지합니다. 검토한 6종은 단일 5~6마리 후보에서 실제 3마리를 선택합니다. 새 일반층 랜덤 NPC는 공통 Sample 20개와 Normal/Elite/Master Rank를 사용합니다. Normal은 기믹 없이, Elite/Master는 현재 룰에서 허용한 기믹을 Rank별 비중으로 사용합니다. 아래 표는 기존 네임드 시스템의 규칙입니다.

| 구간 | 팀 단계·기믹 |
|---|---|
| 5~45층 관장·사천왕 | 전반 팀, 기믹 없음 |
| 50층 챔피언·관문 | 첫 관문 팀, 대표 기믹 사용 시작 |
| 55~95층 관장·사천왕·간부 | 후반 팀과 대표 기믹 |
| 100층 챔피언·최종 보스 | 최종 팀과 대표 기믹 |

빌런은 일반층의 독립 8% 추첨 대신 공통 이벤트 추첨의 캠페인으로 등장합니다. 저장된 단서·간부·보스 진행과 팀/보상을 재사용하며, 완료한 로켓단 단계는 다시 추첨하지 않습니다. [캠페인](../rocket-campaign-implementation.md)을 따릅니다.

51~54층은 완화 구간입니다. 기존 단계별 빌런 보스는 75층 이상에서 후반·최종 팀을 사용하며, 현재 단일 후보 빌드와 이벤트 캠페인은 각자의 적격 조건을 따릅니다. 능력 포인트는 해당 층의 육성 곡선을 상한으로 역할 비율을 유지합니다. 새 관장 이상급의 IV는 총합 예산과 역할 가중치로 시드 기반 랜덤 배분하고, 구 런 일반·엘리트의 기존 IV는 유지하고 새 런의 랜덤 NPC는 Rank 프로필로 육성합니다.

현재 검토 입력은 단계별/단일 빌드 합계 320행·977마리 후보입니다. 표의 균등 IV는 템플릿 참고값이며 실제 배틀에 저장되는 역할별 IV와 다릅니다. 상대 AI는 공개된 정보를 이용하고 플레이어의 비공개 팀 정보를 미리 읽어 맞춤 파티를 만들지 않습니다.

새 일반층과 도전자 선택전은 현재 층의 일반 종족 풀에 같은 [NPC Sample·Rank·Training 프로필](../engineering/NPC_TRAINING.md)을 적용합니다. IV·EV·도구·기술·기믹 성향을 층과 분리하며, Sample은 전투 컨셉만 정의합니다. 도전자는 Sample/표시 클래스 중복 없이 3명을 추첨하고 실제 팀까지 저장합니다. [전체 Sample 및 5/20/40층 생성 예시](../../artifacts/reports/npc/NPC_RANK_SAMPLES.md)를 확인할 수 있습니다.

클래스별 Rank 성향과 teamConcept을 적용합니다. 반바지 소년은 Bug 3마리, 낚시꾼은 Water 3마리, 등산가는 Rock/Ground 3마리를 유지하고 에이스·베테랑은 competitive 팀을 사용합니다. Normal 도구는 초반 0개, 중반 0~1개, 후반 1~2개입니다. 저장된 v1 팀은 재해석하지 않으며 새 생성부터 v2를 저장합니다.
