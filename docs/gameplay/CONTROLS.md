# 화면과 조작

기준: 2026-10-18. 현재 화면의 조작 방법입니다. 변경 과정과 검증 기록은 [유형별 보고서](../../artifacts/README.md)에 있습니다.

기술 선택 화면에서 테라스탈은 메가진화·Z기술·다이맥스와 같은 왼쪽 기믹 아이콘 줄에 표시합니다. 현재 포켓몬의 테라 타입에 맞는 보석 아이콘을 사용합니다. 메가진화·Z기술 버튼은 현재 지닌 메가스톤·Z크리스탈 아이콘을 표시하며 선택하면 주변 빛이 일렁이고 아이콘이 빛납니다. A키를 누를 때마다 사용 가능한 아이콘을 화면 왼쪽부터 오른쪽으로 선택하고, 마지막 다음에는 모두 해제합니다. 비활성 아이콘은 건너뜁니다. 선택은 사용을 예약하는 단계이며 기술을 결정하면 발동합니다. 아이콘 줄 위의 별도 변신 선택 안내 문구는 표시하지 않습니다.

다이맥스밴드·테라스탈오브는 보유한 것만 좌측 상단 포켓몬 명단 옆에 아이콘으로 표시합니다. 장비가 있어야 해당 변신 버튼이 나타나며, 배틀에서 사용한 기믹은 교체 후에도 반투명 비활성 상태로 남습니다.

매 층 출전 준비에서는 멤버의 선택 모습·지닌 도구를 확인하고 공통 **배낭**을 엽니다. 도구/TM 목록은 hover·포커스로 상세를 확인하고 클릭·Z/Enter로 대상을 고릅니다. 다른 멤버의 도구를 옮기면 원 소지자는 해제되며 대상의 기존 도구는 배낭으로 반환됩니다. 자동 교환은 하지 않습니다. 오거폰 가면 등 고정 도구는 변경할 수 없습니다. [배낭 규칙](../engineering/BAG.md).

## 타이틀과 도감

로그인 후 타이틀에서 새로하기·이어하기·도감으로 이동한다. 진행 중인 도전이 있을 때 새로하기는 종료 여부와 받을 성장 포인트를 팝업으로 확인한다. 출발 포켓몬 3마리를 고르고 룰을 확인해 시작하며 첫 번째가 선봉이다.

| 키 | 도감 동작 |
|---|---|
| 방향키 | 목록·메뉴 이동 |
| Enter/Z | 선택·설정 메뉴 열기, 확정; 선택 해제도 이 메뉴에서 처리 |
| X | 메뉴에서 뒤로, 도감 메인에서는 타이틀 복귀 확인 |
| F | 현재 포켓몬 즐겨찾기 전환 |
| V | 즐겨찾기만 보기 전환 |
| R | 필터 초기화 |
| PageUp/PageDown | 페이지 이동 |

검색칸에서는 문자 입력을 우선한다. 기본 정보는 타입·종족값·특성·성격 이름·기술을 표시한다. 메가/거다이맥스가 있는 포켓몬은 모습과 변경된 정보를 미리 볼 수 있다. 특성에 마우스를 올리거나 포커스를 주면 설명이 뜬다.

## 기술배치와 능력치 조정

내 기술 칸에서 좌우로 칸을 고르고 **Z 또는 아래 키**로 기술 목록에 들어간다. 기술을 고르면 무료로 즉시 저장하며 별도 저장 버튼은 없다. 저장 실패 시 이전 배치로 되돌리고 오류를 표시한다. 기술 목록 맨 위에서 위를 눌러도 목록 안에 머문다. 기술 선택 Z 또는 취소 X는 내 기술 칸으로 돌아간다. 저장 완료 문구는 잠시 표시한 뒤 사라진다.

이미 다른 칸에 배치된 기술을 선택하면 두 칸의 기술 위치를 맞바꾼다. 기술배치 편집기와 육성 화면의 기술 선택 모두 같은 방식이며 중복 기술을 만들지 않는다.

능력치 / 성격·특성·테라스탈 두 탭은 방향키 이동 즉시 내용을 바꾸고 Z로 세부 설정에 들어간다. 능력치는 위아래로 항목을 선택하고 좌우로 노력치를 조정한다. 성격·특성·테라스탈은 별도 선택 팝업을 연다. 개체값 31과 최대 노력치는 금색, 개체값 0은 회색으로 구분한다.

## 배틀

PC에서는 싸운다에서 기술을 선택한다. 기술 선택 화면에서 A는 룰에 따라 메가진화·다이맥스·테라스탈·Z기술을 예약하거나 해제한다. 혼합룰은 사용 가능한 버튼을 화면 왼쪽부터 순환한 뒤 모두 해제하며, 기본룰에는 A 안내가 없다. 교체는 배틀 메뉴의 교체 버튼으로 선택한다. S는 기록, C를 누르는 동안 날씨·랭크 확인, Shift는 연출 스킵이다. 키 안내는 키캡과 동작 라벨로 표시한다. 조건을 만족한 기믹을 예약하고 기술을 결정하면 기믹 발동 후 공격한다. 배틀 아이템 사용은 턴을 소모하지 않는다.

Z기술 선택 중 강화 가능한 기술은 금빛 버튼과 굵은 기울임꼴 기술명으로 강조한다. 별도 `Z POWER` 표식은 없으며 강화할 수 없는 기술은 비활성화한다. 키보드 선택도 금빛 테두리를 유지한다. [크리스탈·사용권·효과](../../artifacts/reports/changes/Z_MOVES.md).

상단 팀은 보유 포켓몬 6칸을 표시한다. 이번 배틀 출전 멤버만 색을 유지하고 미출전·기절 멤버는 회색과 상태 라벨로 구분한다. 보유 포켓몬이 6마리보다 적으면 빈 슬롯으로 표시한다. 기믹 버튼을 마우스로 클릭할 때 포커스 원은 표시하지 않고 키보드 선택은 사각 테두리로 표시한다.

모바일에서는 키보드 안내·포커스 표시·내보내기/스킵 버튼을 숨긴다. 등장 안내는 화면 터치로 진행한다. 기술을 450ms 이상 누르는 동안만 설명을 표시하고 손을 떼면 닫으며, 이 동작으로 공격하지 않는다. 경기 화면을 누르는 동안 날씨·랭크를 표시한다. 공격 연출 중 빠른 두 번 터치로 스킵한다.

설정의 배틀 재생에서 1배·2배·4배를 선택한다. 기술·변신 연출과 HP 갱신은 배속하되 새 메시지에는 읽을 시간을 확보하며, Shift 전체 스킵도 유지한다. 배속은 이 브라우저에 저장한다.

## 영입과 정비

영입 후보에 새 포켓몬·도감 미등록 또는 도감 등록됨을 표시하고, 새 기술 수집 개수는 별도 라벨로 표시한다. 확인과 완료 화면도 포켓몬 등록과 기술 수집을 나눠 보여준다.

승리 후 도감에 등록하거나 동료로 데려갈 수 있다. 도감 등록은 이번 팀을 유지하고 다음 도전부터 선택할 수 있게 한다. 확인 팝업의 개체값 비교는 접혀 있으며 기술 목록·즉시 장착 선택은 없다. 기술 수집은 자동 처리하고 새 기술은 완료 화면에서만 표시한다. 취소와 확인 버튼은 한 줄에 3:7 비율로 배치한다.

층 사이 HP·PP·상태를 회복한다. 10층 클리어 정비는 상점 / 포켓몬 조정을 상위 메뉴에서 선택한다. 포켓몬 선택은 HP 없이 6마리의 스프라이트 카드로 표시한다. 상점은 지닌 도구 / 배틀 아이템 / 기술머신으로 나눈다. 모든 탭에서 Z/Enter로 상품 목록에 들어가고, 방향키는 해당 목록의 상품 사이에서만 이동한다. 가장자리에서 계속 눌러도 탭·리롤·배낭으로 벗어나지 않는다. X로 선택한 탭에 돌아가며, 탭의 아래 키는 리롤 등 보조 버튼으로 이동한다. 정비 팝업은 크기를 통일한다.

동작 버튼에는 확인·취소·돌아가기 등 동작 이름만 표시하며 Z·X·Enter·Shift 꼬리표는 생략한다. 실제 키보드 입력과 조작 안내는 유지한다.

## 영구 업그레이드와 소리

타이틀의 업그레이드와 알뽑기는 별도 페이지다. 업그레이드는 출발 지원금·다시하기 확장·리롤 확장 3종을 표시한다. 알뽑기는 기본 기계의 1회·10회와 보유 보상 티켓을 사용하며, Y 또는 A 보조키로 확률을 확인하고 X로 타이틀에 돌아간다. 지역/타입 선택과 알 탐색 연구 UI, 이로치 상시 교환은 제공하지 않는다. 기존 저장 값과 이로치 기록은 보존한다.

알 뽑기는 알 뽑기 탭의 기계에서 1회/10회 버튼으로 진행한다. 알 확률 팝업에서 일반 85%·레어 12%·슈퍼레어 3%의 분류 추첨과 별도 이로치 판정 0.24%를 확인한다. 티켓을 먼저 사용하고 부족한 횟수는 성장 포인트를 차감한다. 받은 알을 터치해 개별 부화하거나 한 번에 열기로 남은 알을 공개한다. 무지개 알은 준전설·패러독스·울트라비스트, 슈퍼레어 알은 초전설·환상, 황금 알은 모든 등급 포켓몬의 이로치 확정이며 결과는 연출 전에 저장된다. [알 종류와 확률](EGGS.md)을 참고한다.

기본은 음소거이며 설정에서 켠다. [소리와 연출](../../artifacts/reports/changes/BATTLE_AUDIO.md), [자산 출처](../references/THIRD_PARTY.md)를 참고한다.


## 지역과 히든 보스

새 도전은 앞·뒤 50층에 서로 다른 지역 테마를 저장합니다. 관동·성도 등 히든보스가 있는 테마는 챕터 챔피언 격파 후 같은 층의 확정 이벤트·회복 안내·등장 연출을 거쳐 자동으로 추가 전투에 들어갑니다. 중간 영입/정비/팀 재선택은 하지 않으며 해당 보스까지 격파해야 다음 구간이나 클리어로 이어집니다. [현재 진행](PROGRESSION.md)·[히든보스](../engineering/HIDDEN_BOSS.md)를 따릅니다.

## 표시·메시지·이벤트

상대 표시는 직업명 또는 네임드 이름/역할을 사용하고 일반·엘리트·마스터 Rank 접미사는 붙이지 않습니다. HP 카드에는 현재 공개된 타입·성별·HP를 표시하며 미공개 상대 정보를 노출하지 않습니다. 이미지와 연출의 실제 색/간격은 현행 CSS를 따르고 과거 화면 수정 로그를 현재 명세로 섞지 않습니다.

현재 대화창은 기술명·급소·상성·상태이상 등 핵심 결과를 표시합니다. HP 감소/남은 퍼센트와 상세 원인은 지난 기록에 남깁니다. 급소·무효·상태이상 등의 읽기 시간과 배속·스킵은 기존 재생기를 따릅니다. 예전 작업 당시의 밀리초 값을 현재 모든 화면의 공통 규칙으로 사용하지 않습니다.

일반 이벤트는 필드 그림/효과, 메시지창 위 왼쪽 요약과 하단 전체 폭 대화/선택지로 진행합니다. 선택 후 요약은 사라지고 이벤트 중 포켓몬 발판은 숨깁니다. 특수 배틀/상점/보상은 각 화면 흐름을 사용합니다. 도전자 숫자키 1~3은 후보 확인, Z/Enter 또는 도전 동작으로 확정합니다. 히든상점 1~5는 상품 확인, 구매 동작·Z/Enter로 구매하며 B로 배낭을 엽니다.

키보드 기본 포커스·팝업 복귀·hover/선택/비활성·터치·모바일·긴 목록 스크롤의 전 화면 일관성은 [ROADMAP](../current/ROADMAP.md)의 실사용 검증 대상입니다. 이 문서가 해당 검증을 모두 마쳤다는 뜻은 아닙니다.
