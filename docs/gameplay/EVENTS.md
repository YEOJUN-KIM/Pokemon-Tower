# 이벤트와 보상

기준: 2026-10-23. 일반 이벤트는 층을 추가 소모하지 않고 지나온 일반층 사이에서 발생한다. 신규 빌런 트랙과 확정 히든보스는 별도 흐름이다.

## 발생과 화면

일반 이벤트의 기본 발생 판정은 **20%**, 통과 순서 쿨다운은 **2**다. 5의 배수 통과 층은 일반 추첨을 하지 않는다. 이는 모든 층의 단순 20%나 특정 이벤트 자체의 20%라는 뜻이 아니다. 순간이동 뒤에도 통과 횟수로 간격을 판단한다.

발생하면 배틀 장면 중앙에 그림·연출, 하단 전체에 대화와 선택지를 표시한다. 작은 요약은 메시지창 바로 위 왼쪽에 두고 선택 후 닫는다. 이벤트 중 포켓몬 발판은 숨긴다. 줄어든 동작 설정도 지원한다. 일반 선택 이벤트와 Raid는 진행하거나 지나갈 수 있으며 지나가면 해당 이벤트 보상을 받지 않는다. PC 선택지는 위아래로 표시한다. 빌런 이벤트에는 지나가기 선택지가 없다.

## 현재 콘텐츠

| 이벤트 | 진행과 결과 |
|---|---|
| 미스터리 상자 | 열거나 지나간다. v2에는 꽝·코인 손실·코인/티켓 보상이 있다. |
| 브리더 | 공통 알뽑기권 1장 선물 |
| 여행 상인 | 900코인으로 공통 알뽑기권 1장 구매 |
| 도전자 선택전 | 후보 3명의 상대·보상을 확인하고 한 명과 배틀. 영입은 없으며 Rank별 보상 지급/선택 |
| Mirror | 적격 조건에서 도전자 후보 한 슬롯을 3%로 교체. 원본 팀·보상 snapshot을 저장 |
| 히든상점 | 상품·가격·재화·구매 한도를 저장하고 코인 또는 성장 포인트로 거래 |
| Raid | 20종 보스의 다단계 전투·영입·보상. 기존 일반층으로 복귀 |
| 순간이동 | 구간 안의 목적지를 한 번 고르고 저장. 재방문도 별도 통과 순서로 진행 |

종류 선택은 적격 종류의 weight를 정규화한다. 상자 50·브리더 15·여행 상인 20, 도전자 20·히든상점 12·Raid 20·순간이동 10과 각 최소 조건이 데이터에 정의되어 있다. 일반 발생률과 종류 weight, 선택 후 내부 결과 확률은 별개다. 기준 위치와 버전 차이는 [이벤트 개발](../engineering/EVENT_SYSTEM.md)을 따른다.

## 상자의 내부 결과

새 런 v2는 꽝 25%, 보유 코인 15% 손실 25%, 300코인 15%, 공통 티켓 1장 15%, 1,000코인+티켓 1장 10%, 티켓 2장 10%다. 이 수치는 상자를 열었을 때의 조건부 확률이다. 과거 v1 상자는 저장 규칙에 따라 150코인 80% / 티켓 1장 20% 경로를 유지한다.

## 빌런·히든보스

신규 런은 첫 지역에 맞는 조직을 정해 조무래기→간부→보스 트랙을 이어간다. 독립 판정은 기본 5%·실패당 +3%p·최대 35%, 일반 단계 간격 3회·보스 전 5회이며 최소 층과 적격 조건을 함께 검사한다. 일반 이벤트가 끝난 뒤 후속 판정을 하므로 같은 클리어 뒤 둘 다 발생할 수 있다. 과거 로켓단 v1 진행은 그대로 복구한다. [빌런 트랙](../engineering/VILLAIN_CAMPAIGNS.md).

히든보스는 조건을 만족한 챕터 완료에서 확정 생성한다. 회복·조우·등장 메시지를 확인한 뒤 배틀하며, 별도의 영입/팀 재선택을 거치지 않는다. [히든보스](../engineering/HIDDEN_BOSS.md).

## 보상과 복구

실제 보상이 있는 이벤트 결과는 승리/발견 안내 → 발견 오브젝트 → 열어보기·확인 → 개봉 연출 → 보상 공개 → 기존 받기/진행 순서로 표시한다. 탐색·Raid·NPC·희귀 만남의 안내는 공통 Reward Reveal 설정으로 구분한다. 이 표시 단계는 기존 서버의 지급·선택 영수증 처리를 대체하지 않는다.

상대 팀·시드·분기·보상·선택 후보는 발생 때 snapshot한다. 재접속·실패·재도전으로 다시 뽑지 않는다. 선택과 결제/지급은 소유권·잔액·영수증을 확인하는 트랜잭션에서 처리하며, 같은 완료 요청은 중복 지급하지 않는다.

도전자 보상은 src/data/challenger-rewards.ts가 기준이다. Normal은 코인/티켓, Elite는 코인·티켓 1~2장·영양제·성장 120P·도구/TM 후보, Master는 알/성장 500P/장비 중 선택을 제공한다. 단일 도구/TM의 중복 소유와 장비 품절은 snapshot의 대체 보상으로 처리한다. 과거 저장 보상은 현재 수치로 소급 변경하지 않는다.
