# 트레이너 장비·기믹·화면 재검사

2026-10-14. 다른 PC의 저장을 이전한 뒤, 실제 플레이 DB와 분리된 `.data/e2e.sqlite` 및 메모리 DB에서 검사했다. 게임 가격·확률·AI·NPC 팀과 실제 플레이 진행은 변경하지 않았다.

## 확인한 동작

- 1280px PC와 390px 모바일: 밴드·오브 동시 구매, 포켓몬 도구 칸 비점유, 보유 장비 아이콘과 로컬 이미지 로딩, 화면 가로 넘침 없음.
- 지닌 도구와 장비 동시 사용, 기믹 선택 A키 순환, 사용 후 교체·새로고침에서도 사용 완료 버튼 유지와 비활성화.
- 메가스톤·Z크리스탈 개별 아이콘, 선택 강조, 동작 감소 설정, 테라 타입 저장과 상대 테라 표시.
- 기술 길게 누르기와 손 떼기, 필드 확인, 연출 스킵, 공격·HP·기절 표시 순서, 화염방사 양방향 연출과 종료 정리.
- 혼합룰 기믹별 사용권 분리, 포켓몬당 하나의 기믹, Z 사용·교체·다이맥스 종료 후 중복 기믹 차단, 장비와 배틀 재생 보존.
- 현재 관장급 IV 배분과 100층 상대 생성의 합법성.

대표 화면: [PC 다이맥스 장비](../../qa/screenshots/trainer-equipment-20261014/trainer-equipment-dynamax-1280.png), [모바일 테라 사용 후](../../qa/screenshots/trainer-equipment-20261014/trainer-equipment-terastallize-390.png). 실제 브라우저 테스트 계정에서 촬영했고 두 화면의 배치를 확인했다.

## 검사와 수정

선택한 브라우저 33개 사례를 확인했다. `battle-controls`, `faint-timing`, `mobile-battle-touch`, `move-visuals`의 19개가 통과했고, 테스트 입력 갱신 뒤 `tera`와 `trainer-equipment`의 14개가 통과했다. 관련 핵심 검사 30개, 타입 검사, 프로덕션 빌드와 CSS 구조 검사도 통과했다.

`e2e/battle-controls.spec.ts`에는 메가스톤·트레이너 장비가 없는 과거 입력이 있었다. 현재 계약에 맞는 보유 장비와 지닌 도구를 추가했다. `e2e/tera.spec.ts`는 Z크리스탈 보유 시 테라 선택을 막던 이전 기대값과 이전 탭 이름을 사용했다. 현재 혼합룰에서는 발동 전 선택이 가능하고 발동 후 같은 포켓몬의 다른 기믹이 금지되므로, 선택 순환과 발동 후 비활성 검사를 유지하며 갱신했다. 런타임 UI나 배틀 규칙은 수정하지 않았다.

제한된 실행 환경에서 브라우저 전용 서버가 응답하지 않아 일반 실행 환경에서 다시 검사했다. 문서·폴더 검사에는 이전 QA 자료의 누락 링크 두 개가 남아 있다: 화염방사 GIF와 Showdown FX contact-sheet. 처음 누락됐던 move-effects 캡처 폴더는 이번 검사에서 다시 생성됐다. 게임용 자산 검사 실패와는 구분한다.

## 난이도와 후속 확인

[현재 규칙 13,248전 비교](../../experiments/balance/NORMAL_MODE_BALANCE_CURRENT_EQUIPMENT.md)와 [극단 상대 4,224전 추가 검사](../../experiments/balance/NORMAL_MODE_BALANCE_CURRENT_OUTLIERS.md)를 작성했다. 두 검사에 배틀 오류가 없었고, 합계 24개 재실행의 이벤트 해시가 일치했다.

준비된 고정 팀 AI 단판 기준으로 다이맥스·혼합이 유리했다. 추가 검사에서 플레이어 승률은 단델 13.3%, 맥실러 21.9%, 아강 25.8%, 플라드리 28.3%, 마적 32.6%, 구즈마 96.6%였다. 서로 다른 층·상성의 표집 결과이므로 최종 보스 강함 순위가 아니다.

실제 100층 플레이에서는 장비 획득 시점과 비용, 영입·육성 상태, 기믹 선택 전략에 따른 체감을 추가 확인해야 한다. 이번 단판 측정으로 완주율이나 사람 승률을 확정하지 않는다. NPC 트레이너 장비 분리는 후속 구현 여부를 결정할 항목으로 남아 있다.
